## I. Product Overview

The TDP-0 is a small desktop manual tablet press designed specifically to press various granular raw materials into round tablets. As the most basic and compact model in the series, this equipment is entirely driven by a hand crank, requiring no power connection, allowing you to work anytime, anywhere.

The machine only installs one set of punch dies at a time, but it allows the operator to flexibly adjust the material filling depth and tablet forming thickness according to actual needs. It is highly suitable for laboratory pilot trials, new formula sampling, and very small-scale custom production.
