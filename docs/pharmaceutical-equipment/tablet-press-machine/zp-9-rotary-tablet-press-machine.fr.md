## IV. Foire aux questions (FAQ)

**Q : Le nombre de moules installés sur le plateau rotatif de la machine est-il fixe ?**
**R :** Non, il n'est pas fixe. Le nombre réel de moules installés sur une presse rotative dépend principalement de la taille de vos comprimés personnalisés (c'est-à-dire les poinçons et les matrices). En termes simples : **plus la taille du moule personnalisé est grande, moins le nombre de moules pouvant être accueillis sur le plateau rotatif est élevé ; à l'inverse, plus la taille du moule est petite, plus le nombre de moules pouvant être installés est important**. Les « 9 jeux » dans le tableau des paramètres techniques correspondent à une référence de configuration standard pour ce modèle aux tailles moyennes régulières.

**Q : Cette machine est classée comme équipement pharmaceutique. Ai-je besoin de qualifications spéciales pour le dédouanement à l'importation ? Et si je ne les possède pas ?**

Dans des circonstances normales, les douanes du pays de destination exigeront que le destinataire dispose des qualifications d'importation correspondantes pour les équipements médicaux ou pharmaceutiques. Si votre entreprise ou vous-même en tant que particulier **ne possédez actuellement pas les qualifications d'importation requises, veuillez contacter directement nos représentants commerciaux**.
