## I. Tinjauan Produk

TDP-0 adalah mesin tablet manual desktop kecil yang dirancang khusus untuk menekan berbagai bahan baku granular menjadi tablet bulat. Sebagai model yang paling dasar dan ringkas dalam seri ini, peralatan ini sepenuhnya digerakkan oleh engkol tangan, tidak memerlukan sambungan listrik, memungkinkan Anda bekerja kapan saja, di mana saja.

Mesin ini hanya memasang satu set cetakan punch pada satu waktu, tetapi memungkinkan operator untuk secara fleksibel menyesuaikan kedalaman pengisian material dan ketebalan pembentukan tablet sesuai dengan kebutuhan aktual. Mesin ini sangat cocok untuk uji coba skala laboratorium, pengambilan sampel formula baru, dan produksi khusus skala sangat kecil.
