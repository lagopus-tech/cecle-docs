## 第一步：确定您的生产层级

选择最符合您实际情况的层级：

### 第一层级 — 手动填充板
**如果您需要以下功能，则非常适合：**
- 在实验室中测试和开发新的胶囊配方
- 在诊所、药房或家庭工作室手工填充胶囊
- 以最低的前期投入进行小批量生产（每次数百至数千粒）
- 对每粒胶囊保持完全的手动控制

**产量范围：** 完全取决于操作人员速度 — 通常每次数百至数千粒。

### 第二层级 — CGN-208D 半自动机器
**如果您需要以下功能，则非常适合：**
- 稳定地每小时生产 10,000 至 30,000 粒胶囊
- 频繁切换多种产品品种（模具更换仅需 5–8 分钟）
- 运营中小型保健品或制药车间
- 从手动生产过渡到自动化生产，无需巨额资本投入

**产量范围：** 10,000 – 30,000 粒/小时

### 第三层级 — NJP系列全自动机器
**如果您需要以下功能，则非常适合：**
- 以最少的人工干预，每小时生产 12,000 至 150,000 粒胶囊
- 运行标准化、连续的生产线，输出质量稳定一致
- 实现 ±3.5% 的填充精度和 99% 以上的胶囊上机合格率
- 在同一产品系列内将产能从中试规模扩展到全面工业规模

**产量范围：** 12,000 – 150,000 粒/小时（视型号而定）

## 第二步：选择您的具体型号

| 孔数 | 材质 | 适用场景 |
| :--------: | :------------ | :----------------------------------------------------------- |

| **100** | 透明塑料 | 需要目视监控粉末填充深度时 — 非常适合教学和研发。 |

| **400** | 透明塑料 | 可视化操作与中等批量产出相结合。 |
| **400** | 亚克力 | 半工业级强度。专为长时间、持续手动操作而设计。 |
| **600** | 亚克力 | 高频药房或零售柜台操作。 |
| **800** | 亚克力 | 半工业手动生产的高单批产量。 |

> **材质说明：** 600、800 和 1000 孔型号仅采用亚克力制造，以确保较大尺寸下的结构完整性。所有彩色塑料选项仅提供蓝色。

**关键决策因素：**
- **预算有限 / 刚起步** → 100孔蓝色塑料
- **需要清晰观察填充过程** → 透明塑料（100或400孔）
- **高频日常使用 / 较大批量胶囊** → 亚克力（400孔及以上）

## 第四步：材质与合规性说明

| 标准 | 升级 | 何时需要升级 |
| :--------------------------- | :---------------------------- | :----------------------------------------------------------- |
| 304 / SUS304 不锈钢 | 316 / SUS316L 不锈钢 | 填充物料涉及强酸、强碱或特殊药物制剂；或生产设施必须通过 GMP / FDA 认证时 |
| 蓝色塑料（手动填充板） | 透明塑料或亚克力 | 需要目视监控（透明）或在重负荷使用下延长使用寿命（亚克力） |
