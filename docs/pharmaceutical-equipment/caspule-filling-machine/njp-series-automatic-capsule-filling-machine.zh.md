## 1. 什么是全自动胶囊充填机？

NJP系列全自动胶囊充填机是一款专为**粉末及颗粒状物料**定制的高效制药及保健品充填设备。该设备采用先进的间歇往复运动原理，全自动完成胶囊送料、胶囊分离、精密充填、废囊剔除、锁合及成品输出等全部工序，将粉末物料精确、高效地充填至硬质空胶囊中。

### 核心工艺与工业技术优势
1. **改良型旋转模具盘设计**：内部转盘结构经过全面优化。核心传动部件直接采用**原装进口日本直线轴承**，确保设备在长时间高速运转下仍能保持极高精度与超长使用寿命。
2. **全底置凸轮与全封闭润滑**：工位凸轮在维护极佳的全封闭润滑轨道内运行。内部润滑油路充分，彻底解决了传统机型凸轮上置、轴承易暴露于干燥或粉末污染环境中的痛点。
3. **真空胶囊定位与极高成品率**：采用高精度真空吸囊定位机构，稳定保持上机合格率在**99%以上**。
4. **精湛的充填精度**：充填精度可达**±3.5%**（远超±5%的国家标准），确保每一粒胶囊的物料剂量一致性。
5. **智能安全保护**：配备先进的微电脑/PLC触摸屏操作及无级变频调速系统，并实时数字显示。同时，内置全面的安全保护装置，确保在缺料、缺囊或开门等情况下，设备自动触发暂停保护。

## 3. 常见问题解答（FAQ）

**问：如何确保设备产量与整体生产线速度匹配？哪些因素会影响实际生产能力？**
**答：** 全自动充填机的实际生产能力直接受粉末物料的堆积密度和流动性，以及胶囊尺寸（支持00#–5#及A-E安全胶囊）的影响。我们将根据您预期的每班日产量严格计算设备运行速度，并建议在工艺条件允许范围内预留15%–20%的产能余量，以适应未来业务增长。

**问：设备材质是否符合制药卫生合规标准？有哪些高端定制选项？**
**答：** 我们的标准机型采用优质SUS304不锈钢制造，其耐腐蚀、防锈、耐热性能完全满足绝大多数常规保健品及食品级粉末的充填需求。如果充填物料涉及高腐蚀性强酸/强碱、特殊西药制剂，或车间必须通过严格的GMP/FDA认证，我们可以将全部物料接触面定制升级为SUS316L顶级不锈钢，确保符合最高级别的卫生标准。

**问：设备核心部件采用什么品牌？机械使用寿命如何保证？**
**答：** 为消除传动故障和定位偏差，NJP系列核心直线轴承直接从日本进口。同时，设备上下段密封结构独家采用进口双唇密封圈，提供无与伦比的密封屏障，有效防止粉尘被回吸至机器内部磨损部件，将设备使用寿命延长至普通机型的数倍。

**问：设备如何进行跨境运输包装？生产交期大约多久？**
**答：** 所有机器出厂前均经过防锈液处理和重型缠绕膜包裹，最后完全封闭于坚固的免熏蒸胶合板不锈钢框架木箱（Plywood Case）中，以抵御海盐喷雾和颠簸。标准机型在图纸确认并收到付款后，最快可在15天内完成总装、测试和发货，并支持全球货运代理协调。
