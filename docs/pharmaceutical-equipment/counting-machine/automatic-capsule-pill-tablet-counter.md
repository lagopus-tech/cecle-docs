## IV. Frequently Asked Questions (FAQ)

**Q: Can this counting machine count capsules and tablets of different sizes at the same time?**
**A:** Yes. The machine is highly adaptable to granular materials. Whether it is a 00# capsule or a small-sized plain tablet or sugar-coated tablet, you only need to adjust the corresponding counting parameters in the touch screen system and make a simple micro-adjustment to the spacing of the discharging tracks to achieve compatible production.

**Q: Why is the capacity range of the machine so large (20 to 300 bottles/min)?**
**A:** Because the YMGP series is highly customizable equipment. If you choose the single-head basic model, the speed is 20~50 bottles/min; if you are a large-scale pharmaceutical factory, we can customize a high-speed discharging channel with multiple heads (such as 8, 16, or even 24 heads) for you, and the capacity can instantly soar to 100~300 bottles/min.

**Q: If we change the shape or size of the packaging bottles in the future, can the machine still be used?**
**A:** It can continue to be used. The conveyor belt baffles and the height of the discharging nozzles of the machine can be adjusted. As long as the dimensions of the new bottle are within the machine's adjustable physical range, operators simply need to adjust the position of the photoelectric sensors and the width of the guardrails to adapt to the new packaging, without needing to return the entire machine to the factory.
