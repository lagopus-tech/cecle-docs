# คู่มือการเลือกเครื่องจักรบรรจุภัณฑ์แนวตั้งแบบรูป-เติม-ปิด (VFFS) และภาพรวมผลิตภัณฑ์

### 1. ตารางภาพรวมผลิตภัณฑ์ (เปรียบเทียบอย่างรวดเร็ว)

| รุ่นซีรีส์ | ประเภทผลิตภัณฑ์ | ระบบจ่ายหลัก | รุ่นที่มีให้เลือกและช่วงปริมาตรการบรรจุ | ความเข้ากันได้กับฟิล์มและถุง | ผลิตภัณฑ์ที่ใช้งานได้โดยตรง |

### 2. รายละเอียดรุ่นซีรีส์และสถานการณ์การใช้งาน

1. **ซีรีส์เครื่อง VFFS สำหรับของเหลว (ซีรีส์ SJ / SJZF)**
   * **คุณสมบัติ**: ออกแบบมาสำหรับของเหลวที่มีความหนืดต่ำ โดยซีรีส์ SJ มีประสิทธิภาพมาตรฐานในราคาประหยัด (ใช้ฟิล์มชั้นเดียวเท่านั้น) ส่วนซีรีส์ SJZF มีเซ็นเซอร์ไฟฟ้าแสงและมอเตอร์สเต็ปเพื่อการจับตำแหน่งภาพอย่างแม่นยำและรองรับฟิล์มผสม
   * **เหมาะกับ**: โรงงานบรรจุขวดน้ำ, โรงงานผลิตนม, และผู้ผลิตถุงใส่เครื่องปรุงรสของเหลว

2. **ซีรีส์เครื่อง VFFS สำหรับครีม/ซอส (ซีรีส์ PA)**
   * **คุณสมบัติ**: ออกแบบมาสำหรับของที่มีความหนืดสูงและกึ่งของไหล โดยมีปั๊มครีมป้องกันหยด รองรับการขึ้นรูปตามคำสั่งเฉพาะสำหรับสไตล์การปิดด้าน 3 ด้าน, 4 ด้าน หรือด้านหลัง
   * **เหมาะกับ**: ผู้ผลิตซอสปรุงรส, ผู้ผลิตถุงซองเครื่องสำอาง, และสายการผลิตบรรจุน้ำผึ้ง/ซอสมะเขือเทศ

3. **ซีรีส์เครื่อง VFFS สำหรับผง (ซีรีส์ P)**
   * **คุณสมบัติ**: ติดตั้งระบบวัดปริมาณแบบเกลียวข้อเหวี่ยงความแม่นยำสูงสำหรับควบคุมผงละเอียด โดยมีตัวเลือกเพิ่มเติมในการติดตั้งเครื่องจ่ายเกลียวเพื่อการจ่ายอัตโนมัติไร้ฝุ่น
   * **เหมาะกับ**: การบรรจุผงนม, กาแฟ, ผงเครื่องเทศ, และผงยา/เคมีภัณฑ์

4. **ซีรีส์เครื่อง VFFS สำหรับเม็ดเล็ก (ซีรีส์ G)**
   * **คุณสมบัติ**: ใช้ระบบถ้วยหมุนประสิทธิภาพสูง หรือสามารถอัปเกรดเป็นเครื่องชั่งแบบหลายหัว คู่กับเครื่องยกแบบ Z เพื่อจัดการวัตถุดิบอัตโนมัติ
   * **เหมาะกับ**: ผู้ประมวลผลถั่ว, โรงงานผลิตของว่าง, การบรรจุเมล็ดพันธุ์, และการกระจายชา

### 3. ความแตกต่างสำคัญและการแนะนำการเลือก

เมื่อแนะนำรุ่นให้ลูกค้า ให้ช่วยพวกเขาพิจารณาจาก 3 ปัจจัยหลัก:

1. **การเลือกตามสถานะวัสดุ:**
   * **ของเหลว (น้ำ, นม, น้ำผลไม้)**: เลือก **เครื่อง VFFS สำหรับของเหลว** (ซีรีส์ SJ/SJZF) หากต้องการการจับตำแหน่งภาพหรือใช้ฟิล์มผสม ให้เลือก **SJZF**
   * **ครีมและซอส (ซอสมะเขือเทศ, แชมพู, น้ำผึ้ง)**: เลือก **เครื่อง VFFS สำหรับครีม/ซอส** (ซีรีส์ PA)
   * **ผง (ผงนม, แป้ง, กาแฟ)**: เลือก **เครื่อง VFFS สำหรับผง** (ซีรีส์ P) พร้อมตัวเลือกเครื่องจ่ายเกลียว
   * **เม็ดเล็ก (ถั่ว, ลูกอม, เมล็ด)**: เลือก **เครื่อง VFFS สำหรับเม็ดเล็ก** (ซีรีส์ G) และอัปเกรดเป็นเครื่องชั่งแบบหลายหัวเพื่อความแม่นยำในการชั่งน้ำหนัก

2. **การเลือกตามช่วงปริมาตรการบรรจุและกำลังการผลิต:**
   * **ถุงขนาดเล็ก / แพ็กตัวอย่าง (5ml-100ml หรือ 5g-100g)**: เลือกรุ่นขนาดเล็กเริ่มต้น เช่น ซีรีส์ Liquid SJ-1000/SJZF-1000, Paste PA100, Powder P100 หรือ Granule G100
   * **ถุงขนาดใหญ่ / การบรรจุจำนวนมาก (200ml-2000ml หรือ 250g-5000g)**: เลือกรุ่นอุตสาหกรรมหนัก เช่น ซีรีส์ Liquid 2000, Paste PA500, Powder P500 หรือ Granule G500
