## 六、工作流程

1. **膜材放卷**：将包装卷膜安装至机器支架上，并通过导辊平稳引出。
2. **紫外线消毒（可选）**：开启可选的UV杀菌灯，对膜表面进行实时照射灭菌。
3. **膜材牵引与定位**：牵引机构（SJZF系列采用步进电机+光电眼）精准拉取并定位膜材进入制袋器。
4. **纵向封合**：膜材经成型器形成管状后，纵向封口装置加热密封重叠边缘。
5. **液体灌装**：物料通过灌装管注入底部已封口的膜管中。
6. **横向封合与编码**：横封模具加热封合袋口，同时钢印或色带编码器印制批次号。
7. **切割与输出**：切刀完成封口袋的切断分离，成品小袋自动滑落，便于收集。
