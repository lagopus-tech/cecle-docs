### 2. Подробности по сериям моделей и сценариям применения

1. **Серия вертикальных машин VFFS для жидкостей (серии SJ / SJZF)**
   * **Особенности**: Разработаны для жидкостей низкой вязкости. Серия SJ предлагает экономичную стандартную производительность (только односторонняя пленка), а серия SJZF оснащена фотоэлементами и шаговыми двигателями для точной регистрации изображений и совместимости с композитными пленками.
   * **Рекомендовано для**: Заводов по бутылке воды, молочных фабрик и предприятий по упаковке жидких приправ.

2. **Серия вертикальных машин VFFS для паст (серия PA)**
   * **Особенности**: Созданы для высоковязких и полужидких продуктов с антикапельными насосами для паст. Поддерживают индивидуальное формование для вариантов 3-стороннего, 4-стороннего или заднего уплотнения.
   * **Рекомендовано для**: Производителей приправ, производителей косметических пакетиков и линий упаковки меда/кетчупа.

3. **Серия вертикальных машин VFFS для порошков (серия P)**
   * **Особенности**: Оборудованы высокоточной системой дозирования с винтовым screw для точного контроля мелких порошков, с возможностью интеграции винтовых питателей для беспылевой автоматической подачи.
   * **Рекомендовано для**: Упаковки молочного порошка, кофе, смесей специй, а также фармацевтических/химических порошков.

4. **Серия вертикальных машин VFFS для гранул (серия G)**
   * **Особенности**: Используют высокоэффективные системы дозирования с вращающимися стаканами или улучшаемые многосекционные комбинированные весовые системы, идеально сочетающиеся с подъемниками типа Z для автоматизации подачи материала.
   * **Рекомендовано для**: Производителей орехов, фабрик снеков, упаковки семян и распределения чая.

### 3. Ключевые различия и рекомендации по выбору

При рекомендации моделей клиентам руководите ими по трем основным критериям:

1. **Выбор по состоянию материала:**
   * **Жидкости (вода, молоко, сок)**: Выберите **вертикальную машину VFFS для жидкостей** (серии SJ/SJZF). Выберите **SJZF**, если требуется регистрация графики или использование композитной пленки.
   * **Пасты и соусы (кетчуп, шампунь, мед)**: Выберите **вертикальную машину VFFS для паст** (серия PA).
   * **Порошки (молочный порошок, мука, кофе)**: Выберите **вертикальную машину VFFS для порошков** (серия P) вместе с опциональным винтовым питателем.
   * **Гранулы (орехи, конфеты, семена)**: Выберите **вертикальную машину VFFS для гранул** (серия G), улучшив ее до комбинированной весовой системы для строгой точности взвешивания.

2. **Выбор по диапазону заполнения и производительности:**
   * **Маленькие пакеты / образцы (5 мл–100 мл или 5 г–100 г)**: Выберите компактные базовые модели, такие как жидкости SJ-1000/SJZF-1000, пасты PA100, порошки P100 или гранулы G100.
   * **Большие пакеты / массовая упаковка (200 мл–2000 мл или 250 г–5000 г)**: Выберите мощные промышленные модели, такие как серии жидкостей 2000, пасты PA500, порошки P500 или гранулы G500.
