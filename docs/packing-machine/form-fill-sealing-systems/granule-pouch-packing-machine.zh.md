* **如何选择合适的型号？**
  * 对于 5g 至 100g 的小型坚果零食袋或试用装，推荐紧凑型且高速的 **G100**。

* **如何选择填充系统？**
  * 若客户追求高性价比且物料密度均匀，标准旋转杯系统是理想之选；若对包装重量精度要求极高（如高端干果、混合坚果），强烈建议升级为组合秤系统。

  * 若日产量较高且人工供料不便，建议向客户推荐配套的 Z 型提升机，实现全自动供料。

## 六、工作流程

1. **自动供料**：配套的 Z 型提升机自动将颗粒物料从地面储料斗提升并送入包装机的称重/旋转杯料斗。
2. **膜卷展开**：将卷膜安装至机器主轴上，通过张力导辊平稳引导包装材料进入制袋区域。
3. **UV 灭菌（可选）**：开启可选的 UV 杀菌灯，对卷膜表面进行持续照射灭菌，确保成型前洁净。
4. **膜卷成型与纵向封口**：成型器将平幅膜折叠成管状，纵向封口机构加热并密封膜材重叠边缘。
5. **定量充填**：旋转杯系统或组合秤系统精确计量目标重量的颗粒物料，平稳落入已成型的膜管中。
6. **横向封口与编码**：横向封口钳加热封合袋口顶部与下一袋底部，同时钢印或 ribbon 编码器印制批次号。
7. **切割与收集**：集成式切刀按选定的平面或锯齿状切割方式切断封口袋，成品颗粒小袋自动落入收集区。
