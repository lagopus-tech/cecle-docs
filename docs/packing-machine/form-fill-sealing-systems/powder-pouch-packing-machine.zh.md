## 一、产品概述

* **产品类别**：粉末用立式成型灌装封口机 / 自动螺杆粉末包装机  
* **应用场合**：广泛用于各类细粉及颗粒状粉末的自动小袋和枕式包装，如奶粉、咖啡粉、面粉、淀粉、蛋白粉、香料粉、医药粉剂及化工添加剂等。  
* **核心功能**：
  * **自动卷膜成型**：自动将平幅薄膜拉伸并包裹成管状，完成纵向封合、容积式螺杆计量与横向封合一体化作业。

  * **自动进料集成**：可无缝对接可选螺杆送料机（螺旋上料机），实现粉末物料全自动输送与供料。

## 六、工作流程

1. **自动进料（可选）**：可选螺杆送料机自动将地面料仓中的粉末物料提升并送入设备料斗。
2. **膜卷展开**：将卷膜安装于轴上，通过张力辊平稳引导包装材料进入成型区。
3. **紫外线消毒（可选）**：开启可选紫外线杀菌灯，对包装膜表面进行连续灭菌处理，确保卫生安全。
4. **膜材成型与纵封**：平面膜经成型器形成管状结构，纵向封合机构对搭接边缘进行热压密封。
5. **螺杆计量与填充**：高精度螺杆旋转实现精准计量，并将目标重量的粉末准确落入已成型的袋体中。
6. **横封与打码**：横封刀加热封合袋口，同时钢印或条码打印机在袋体上打印批次号/生产日期。
7. **切断与收集**：内置切刀完成封口切割（平切或锯齿切），成品粉末小袋自动落入收集区域。
