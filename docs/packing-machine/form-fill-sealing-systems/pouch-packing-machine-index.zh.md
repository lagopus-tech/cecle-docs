### 2. 系列型号与应用场景详解

1. **液体立式成型充填封口机系列（SJ / SJZF系列）**
   * **特点**：专为低粘度液体设计。SJ系列提供经济型标准性能（仅支持单层膜），而SJZF系列配备光电传感器和步进电机，实现精准图像定位，并兼容复合膜。
   * **适用场景**：瓶装水厂、乳品企业、液体调味品包装线。

2. **膏体立式成型充填封口机系列（PA系列）**
   * **特点**：专为高粘度及半流体物料设计，采用防滴漏膏体泵，支持定制化三边封、四边封或背封结构。
   * **适用场景**：调味品制造商、化妆品小袋生产商、蜂蜜/番茄酱包装线。

3. **粉末立式成型充填封口机系列（P系列）**
   * **特点**：配备高精度螺杆计量机构，实现细粉精准控制，可选配螺杆送料器，实现无尘自动化供料。
   * **适用场景**：奶粉、咖啡、香料混合物、医药及化工粉剂包装。

4. **颗粒立式成型充填封口机系列（G系列）**
   * **特点**：采用高效旋转杯计量系统，支持升级多头组合秤，可搭配Z型提升机实现全自动物料输送。
   * **适用场景**：坚果加工厂、休闲食品厂、种子包装、茶叶分装。

### 3. 关键差异与选型建议

向客户推荐机型时，请引导其从以下三个核心维度进行选择：

1. **按物料状态选型：**
   * **液体（水、牛奶、果汁）**：选择 **液体VFFS机**（SJ/SJZF系列）。若需图案对齐或使用复合膜，推荐 **SJZF** 型号。
   * **膏体与酱料（番茄酱、洗发水、蜂蜜）**：选择 **膏体VFFS机**（PA系列）。
   * **粉末（奶粉、面粉、咖啡）**：选择 **粉末VFFS机**（P系列），并可选配螺杆送料器以提升自动化水平。
   * **颗粒（坚果、糖果、种子）**：选择 **颗粒VFFS机**（G系列），如需严格称重精度，建议升级为组合秤系统。

2. **按填充范围与产能选型：**
   * **小袋/试用装（5ml–100ml 或 5g–100g）**：推荐紧凑型入门机型，如液体SJ-1000/SJZF-1000、膏体PA100、粉末P100或颗粒G100。
   * **大袋/批量包装（200ml–2000ml 或 250g–5000g）**：推荐重型工业机型，如液体2000系列、膏体PA500、粉末P500或颗粒G500。
