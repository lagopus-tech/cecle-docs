## I. ภาพรวมผลิตภัณฑ์

* **หมวดหมู่ผลิตภัณฑ์**: เครื่องบรรจุภัณฑ์แนวตั้งแบบรูปทรงท่อน (VFFS) สำหรับเม็ด / เครื่องบรรจุเม็ดแบบหมุนเวียน + ชุดชั่งน้ำหนักแบบผสม
* **สถานการณ์การใช้งาน**: ใช้กันอย่างแพร่หลายในการบรรจุถุงอัตโนมัติของวัสดุในรูปแบบก้อน แผ่น แถบ และเม็ด เช่น ถั่ว ถั่วลิสง ลูกอม อาหารพอง หวี ถั่ว ชา อนุภาคพลาสติก และชิ้นส่วนโลหะขนาดเล็ก
* **ฟังก์ชันหลัก**:
  * **การสร้างรูปแบบฟิล์มม้วนอัตโนมัติ**: ดึงและห่อฟิล์มแบนให้กลายเป็นรูปท่อนโดยอัตโนมัติ รวมถึงการปิดผนึกแนวดิ่ง การเติมเม็ดแบบหมุนเวียนตามปริมาตร และการปิดผนึกแนวนอน
  * **ระบบเติมเม็ดแบบหมุนเวียนและชุดชั่งน้ำหนักผสม**: มาพร้อมระบบเติมเม็ดแบบหมุนเวียนที่มีเสถียรภาพและประสิทธิภาพสูง สามารถอัปเกรดได้อย่างยืดหยุ่นเป็นระบบชั่งน้ำหนักแบบหลายหัวตามความต้องการด้านความแม่นยำ
  * **ตัวเลือกการปิดผนึกและตัดที่ยืดหยุ่น**: รองรับการปิดผนึก 3 ด้าน 4 ด้าน หรือปิดด้านหลัง พร้อมตัวเลือกการตัดแบบเรียบหรือแบบขั้นบันได เพื่อตอบโจทย์การออกแบบแบรนด์
  * **การติดฉลากแบบเบชและควบคุมความสะอาด**: ติดฉลากวันผลิตและหมายเลขเบชโดยใช้เครื่องพิมพ์เหล็กมาตรฐาน (ตัวเลือกเพิ่มเติม: รหัสสายพิมพ์), พร้อมตัวเลือกการฆ่าเชื้อด้วยแสงยูวีเพื่อการทำความสะอาดฟิล์มแบบเรียลไทม์
  * **การเชื่อมต่อระบบลำเลียงอัตโนมัติ**: สามารถเชื่อมต่อกับเครื่องยกวัสดุแบบ Z-type เพื่อให้เกิดการขนส่งและยกวัสดุอัตโนมัติ ลดภาระงานด้วยมือได้อย่างมาก

2. **ช่วงรุ่นที่ครอบคลุม รองรับการบรรจุทุกขนาด**

3. **สไตล์ถุงและวิธีการตัดที่ปรับแต่งได้**

   * เชื่อมต่อกับเครื่องยกวัสดุแบบ Z-type ได้อย่างราบรื่น เพื่อสร้างสายการผลิตบรรจุภัณฑ์อัตโนมัติเต็มรูปแบบ ทำงานต่อเนื่องโดยไม่ต้องมีคน
5. **ทนทาน คงที่ และบำรุงรักษาง่าย**
   * สร้างจากโครงสร้างอุตสาหกรรมคุณภาพสูง ควบคุมด้วยไมโครคอมพิวเตอร์ขั้นสูง และโครงสร้างกลไกที่แม่นยำ ทำให้มีอัตราความผิดพลาดต่ำมาก และทนทานต่อการทำงานความเร็วสูงในระยะยาว

## VI. ขั้นตอนการทำงาน

1. **การเติมวัสดุอัตโนมัติ**: เครื่องยกแบบ Z-type ที่จับคู่กันยกวัสดุเม็ดจากถังเก็บใต้พื้นขึ้นไปยังถังชั่ง/ถังหมุนเวียนของเครื่องบรรจุ
2. **การปลดฟิล์มม้วน**: ใส่ฟิล์มม้วนลงบนแกนเครื่อง แล้วนำวัสดุบรรจุผ่านรางควบคุมแรงตึงเข้าสู่พื้นที่สร้างถุง
3. **การฆ่าเชื้อด้วยแสงยูวี (ตัวเลือก)**: เปิดใช้งานหลอดไฟฆ่าเชื้อแบบยูวีเพื่อฉายแสงต่อเนื่องฆ่าเชื้อผิวฟิล์มม้วนก่อนการสร้างรูป
4. **การสร้างรูปแบบฟิล์มและการปิดผนึกแนวดิ่ง**: ฟิล์มแบนจะถูกพับเป็นรูปท่อนโดยแม่พิมพ์ แล้วระบบปิดผนึกแนวดิ่งจะใช้ความร้อนปิดผนึกขอบฟิล์มที่ทับซ้อนกัน
5. **การเติมเม็ดแบบปริมาณแน่นอน**: ระบบหมุนเวียนหรือระบบชั่งน้ำหนักผสมจะเติมวัสดุเม็ดตามน้ำหนักที่ต้องการอย่างแม่นยำ แล้วปล่อยลงในท่อนฟิล์มที่สร้างไว้
6. **การปิดผนึกแนวนอนและการติดฉลาก**: คีมปิดผนึกแนวนอนจะใช้ความร้อนปิดผนึกด้านบนของถุงและด้านล่างของถุงถัดไป ในขณะเดียวกันเครื่องพิมพ์เหล็กหรือเครื่องพิมพ์สายจะติดฉลากหมายเลขเบช
7. **การตัดและรวบรวม**: เครื่องตัดรวมจะตัดถุงที่ปิดผนึกตามรูปแบบการตัดแบบเรียบหรือแบบขั้นบันได แล้วปล่อยถุงบรรจุภัณฑ์สำเร็จรูปลงไปยังพื้นที่รวบรวมโดยอัตโนมัติ
