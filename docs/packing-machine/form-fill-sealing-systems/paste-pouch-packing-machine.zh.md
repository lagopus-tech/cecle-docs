## 六、工作流程

1. **膜卷展开**：将卷膜安装至机器主轴上，通过导辊平稳输送薄膜材料。
2. **紫外线消毒（可选）**：开启可选的紫外线杀菌灯，对薄膜表面进行持续消毒，确保成袋前洁净。
3. **膜管成型与纵向封合**：平面膜经成型器平滑卷成管状，纵向封合机构对重叠边缘进行热封。
4. **定量糊状物灌装**：糊状物泵精确计量并注入目标量的酱料、蜂蜜或膏霜至成型膜管内。
5. **横向封合与编码**：横向封口夹具加热密封当前袋顶部与下一袋底部，同时钢印或色带编码器印制批次编号。
6. **切断与收集**：集成式切刀完成封口袋的切断（平切或锯齿切），成品糊状小袋落入收集区。
