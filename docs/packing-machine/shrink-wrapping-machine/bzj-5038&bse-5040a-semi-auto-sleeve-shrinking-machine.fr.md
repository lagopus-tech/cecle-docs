### VI. Flux de Travail
1. **Préparation** : Les produits (bouteilles, canettes ou cartons) sont groupés manuellement sur la table d'alimentation.
2. **Alimentation** : L'opérateur pousse le produit groupé dans le film PE, où l'emballage à manchon s'effectue.
3. **Scellage/Coupe** : La thermoscelleuse pneumatique se referme pour couper et sceller solidement les extrémités du film PE.
4. **Rétraction** : L'emballage scellé entre automatiquement dans le tunnel de rétraction à haute température BSE-5040A.
5. **Refroidissement/Sortie** : Le film PE se rétracte étroitement autour du produit dans le tunnel, et le fardeau fini, prêt pour la palettisation, sort du tunnel pour refroidissement.
