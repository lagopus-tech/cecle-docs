### 四、尺寸计算指南
为确保产品完美适配机器，请按以下公式计算所需**对折POF膜宽度**：

* **膜宽计算公式**：`膜宽 = 产品宽度（W） + 产品高度（H） + 150mm（余量）`
* **注意事项**：
    * **FQA-450硬性规格**：产品长度须在 **100–450mm** 之间，最大产品宽度为 **300mm**，最大高度为 **150mm**。
    * **FQA-550硬性规格**：产品长度须在 **100–550mm** 之间，最大产品宽度为 **400mm**，最大高度为 **150mm**。
    * 若产品长度小于100mm，务必咨询加装“密带一体化”功能，否则产品可能卡入输送带间隙。
    * 若产品材质特殊或尺寸处于临界值，请提供样品产品尺寸，以便我们评估是否需要非标定制。

### 五、销售策略与常见问题
#### **销售策略**
* **PE与POF膜的选择**：POF膜是零售包装的主流选择，透明度高且环保。若您的产品为重型工业品或整箱饮料等需使用PE膜，请在订购时说明，以便我们重新配置切刀和收缩隧道。
* **尺寸评估**：本机为高精度自动化设备，对尺寸有严格要求。建议客户在订购前提供产品三维尺寸（宽、高、长），以便我们预先审核是否在机器包装范围内。
* **产线延伸价值**：向追求人机工程学流程升级的客户推荐可选的前端进料和后端出料输送带，最大限度减少人工搬运瓶颈。

#### **常见问题（FAQ）**
* **问：是否可以增加额外的输送带来进行进料和收料？**
    * 答：可以！我们提供可选的前端进料输送带（带推料机构，可逐一送料），以及后端出料输送带或无动力滚筒输送台，方便工人轻松收集成品（需额外收费）。
* **问：产品长度小于100mm怎么办？**
    * 答：标准皮带间距对过小产品存在卡料风险。我们可以定制加装“密带一体化”组件，专门解决微小产品的输送问题（需额外收费）。
* **问：机器能否包装PE膜？**
    * 答：可以，但需要定制。PE膜比POF膜更厚更坚韧，需要专用的替换切刀和PE专用收缩隧道。请购买前告知我们。
* **问：如何计算需要购买的膜宽？**
    * 答：简单计算：`产品宽度（W） + 产品高度（H） + 150mm`。该公式提供了足够的封口余量，确保最佳包装效果。

### 七、工作流程
1. **送料**：产品放置于可选的前端进料输送带（或人工送料）上，由推料装置自动推入封切区域，光电传感器精准定位。
2. **封切**：L型封切刀自动下压并切断薄膜，实现精准封口。
3. **自动输送**：封切完成的产品自动推入后方的热收缩隧道。
4. **恒温收缩**：产品在恒温热风环境中平稳通过，薄膜均匀收缩并紧密包裹产品。
5. **成品输出**：包装精美且冷却完成的产品从出料端输出至可选的后端输送带或滚筒台，即可进行后续装箱或码垛作业。
