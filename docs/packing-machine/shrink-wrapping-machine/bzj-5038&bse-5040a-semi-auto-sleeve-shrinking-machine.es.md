### VI. Flujo de Trabajo
1. **Preparación**: Los productos (botellas, latas o cajas) se agrupan manualmente sobre la mesa de entrada.
2. **Alimentación**: El operador empuja el producto agrupado hacia la película de PE, donde se realiza la envoltura tipo manga.
3. **Sellado/Corte**: La selladora neumática se cierra para cortar y sellar los extremos de la película de PE de forma segura.
4. **Termorretractado**: El paquete sellado entra automáticamente al túnel de termorretractado de alta temperatura BSE-5040A.
5. **Enfriamiento/Salida**: La película de PE se encoge firmemente alrededor del producto dentro del túnel, y el paquete terminado, listo para paletizar, sale del túnel para enfriarse.
