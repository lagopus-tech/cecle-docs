### 六、工作流程
1. **送料**：将产品放入折叠好的热缩膜中，推入封口区域。
2. **封口切膜**：按下透明盖/封口框架。设备自动完成封口和切膜动作，形成初步包裹。
3. **热收缩**：封口完成后，产品进入内部收缩室。在设定的恒温热风作用下，薄膜迅速收缩并紧贴产品。
4. **取件**：收缩完成后，透明盖自动复位或手动打开，取出包装完美的成品，进入下一个包装循环。
