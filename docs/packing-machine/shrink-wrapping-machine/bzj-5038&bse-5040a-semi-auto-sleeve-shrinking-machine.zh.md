### 六、工作流程
1. **准备**：将产品（瓶装、罐装或盒装）人工分组放置在进料台上。
2. **送料**：操作员将分组好的产品推入PE热缩膜中，完成袖口式包裹。
3. **封口/切割**：气动封口机下压，牢固地切割并密封PE膜两端。
4. **热缩**：包装好的产品自动进入BSE-5040A高温热缩隧道。
5. **冷却/出料**：PE膜在隧道内紧贴产品收缩，完成后的托盘级包装从隧道出口送出进行冷却。
