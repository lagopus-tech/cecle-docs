### VI. Технологический процесс
1. **Подготовка**: Изделия (бутылки, банки или коробки) вручную группируются на подающем столе.
2. **Подача**: Оператор вручную продвигает сгруппированные изделия в PE-пленку, где происходит рукавная обертка.
3. **Запайка/Резка**: Пневматический запайщик опускается для резки и надежной запайки концов PE-пленки.
4. **Усадка**: Запаянная упаковка автоматически поступает в высокотемпературную термоусадочную камеру BSE-5040A.
5. **Охлаждение/Выход**: PE-пленка плотно обтягивает изделие внутри камеры, и готовая упаковка, готовая к паллетированию, выходит из камеры для охлаждения.
