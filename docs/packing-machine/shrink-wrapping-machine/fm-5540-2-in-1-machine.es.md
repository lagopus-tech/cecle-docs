### VI. Flujo de Trabajo
1. **Alimentación**: Coloque el producto dentro de la película retráctil doblada y empújelo hacia el área de sellado.
2. **Sellado y Corte**: Presione la cubierta transparente/marco de sellado. El equipo realiza automáticamente las acciones de sellado y corte, creando un envoltorio preliminar.
3. **Retractilado**: Después de completar el sellado, el producto entra en la cámara de retractilado interna. Bajo la acción del aire caliente a temperatura constante configurada, la película se encoge rápidamente para envolver el producto.
4. **Extracción**: Una vez finalizado el retractilado, la cubierta transparente se restablece automáticamente o se abre manualmente, permitiéndole retirar el producto terminado perfectamente envasado y proceder al siguiente ciclo de envasado.
