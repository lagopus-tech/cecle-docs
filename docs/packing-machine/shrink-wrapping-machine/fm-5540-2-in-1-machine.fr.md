### VI. Processus de travail
1. **Alimentation** : Placez le produit à l'intérieur du film rétractable plié et poussez-le dans la zone de scellage.
2. **Scellage et découpe** : Abaissez le couvercle transparent/cadre de scellage. L'équipement effectue automatiquement les actions de scellage et de découpe, créant un emballage préliminaire.
3. **Rétraction** : Une fois le scellage terminé, le produit entre dans la chambre de rétraction interne. Sous l'action de l'air chaud à température constante réglée, le film se rétracte rapidement pour envelopper le produit.
4. **Extraction** : Une fois la rétraction terminée, le couvercle transparent se réinitialise automatiquement ou s'ouvre manuellement, vous permettant de retirer le produit fini parfaitement emballé et de passer au cycle d'emballage suivant.
