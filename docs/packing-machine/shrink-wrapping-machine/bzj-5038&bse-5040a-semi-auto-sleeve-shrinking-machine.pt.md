### VI. Fluxo de Trabalho
1. **Preparação**: Os produtos (garrafas, latas ou caixas) são agrupados manualmente na mesa de alimentação.
2. **Alimentação**: O operador empurra o produto agrupado para dentro do filme PE, onde ocorre o envolvimento tipo manga.
3. **Selagem/Corte**: A seladora pneumática pressiona para cortar e selar as extremidades do filme PE com segurança.
4. **Termoencolhimento**: A embalagem selada entra automaticamente no túnel de termoencolhimento de alta temperatura BSE-5040A.
5. **Resfriamento/Saída**: O filme PE encolhe firmemente ao redor do produto dentro do túnel, e o pacote finalizado, pronto para paletização, sai do túnel para resfriamento.
