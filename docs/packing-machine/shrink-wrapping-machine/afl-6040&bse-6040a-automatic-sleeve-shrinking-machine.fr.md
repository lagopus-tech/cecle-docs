### IV. Stratégie de vente et FAQ
#### **Stratégie de vente**
* **L'argument « Sans main-d'œuvre »** : Mettre en avant que cette machine s'amortit en remplaçant 1 à 2 opérateurs par équipe qui seraient autrement nécessaires pour regrouper manuellement les bouteilles.
* **La stabilité comme priorité** : Souligner la précision de regroupement de l'AFL-6040 ; les regroupements instables sont la cause n°1 des temps d'arrêt sur les lignes d'emballage. Notre système garantit une perfection avant l'emballage.

#### **Questions fréquemment posées (FAQ)**
* **Q : L'opérateur doit-il arranger les bouteilles manuellement ?**
    * R : Non. La machine comprend un système d'alimentation et de regroupement automatique. Les opérateurs doivent uniquement placer les bouteilles en vrac sur le convoyeur, et la machine s'occupe du reste.
* **Q : Cette machine peut-elle gérer différentes tailles de produits ?**
    * R : Oui, le système est réglable pour s'adapter à différents diamètres de bouteilles et configurations de regroupement (par exemple, 2x3, 3x4).
* **Q : Pourquoi le film PE est-il utilisé pour cette machine ?**
    * R : Le film PE est la norme industrielle pour le regroupement de boissons et les charges lourdes en raison de sa résistance élevée à la traction et à la déchirure, ce qui maintient les caisses lourdes sécurisées pendant le transport.

### VI. Processus de fonctionnement
1. **Alimentation automatisée** : Les produits (bouteilles/canettes) sont placés sur le convoyeur. Le convoyeur les achemine vers la zone de regroupement.
2. **Regroupement automatique** : Un poussoir intelligent interne et un système de capteurs comptent et organisent automatiquement les produits dans le format de lot souhaité.
3. **Emballage à manchon pneumatique** : Le lot rassemblé est poussé dans le film PE. La soudeuse pneumatique coupe et soude les extrémités du film avec une haute précision.
4. **Rétraction thermique** : Le lot emballé est automatiquement poussé dans le four de rétraction à haute température BSE-6040A.
5. **Refroidissement et évacuation** : Le film se resserre fermement autour du produit. Le lot terminé sort du four, refroidit et est prêt pour la palettisation.
