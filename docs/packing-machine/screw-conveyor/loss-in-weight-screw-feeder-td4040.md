## 1. Product Overview

* **Category**: Industrial Automation Metering & Dosing System / Powder Gravimetric Feeder.
* **Applications**: Widely used in industries requiring high-precision continuous or batch dosing, such as chemicals, pharmaceuticals, food processing, plastic compounding (e.g., masterbatch addition), and battery material production. Specifically designed for fine powders or granules with poor flowability or bridging tendencies.
* **Core Function**: Utilizing dynamic weighing technology, the system monitors the weight reduction rate of the material in the hopper (loss-in-weight logic). A PLC system precisely controls the screw auger speed to achieve stable, accurate material feeding.

## 2. Core Advantages

1.  **High-Precision Dosing Control**: Equipped with industrial-grade high-sensitivity load cells for real-time weight feedback. Metering accuracy reaches ±1% - 2%, ensuring strict consistency in formulations.
2.  **S304 Stainless Steel Construction**: Parts in contact with materials are made of food/pharmaceutical-grade S304 stainless steel. It is corrosion-resistant, easy to clean, and complies with international hygiene standards, ensuring no material contamination.
3.  **Active Agitation & Anti-Bridging Technology**: Features an internal agitation mechanism to forcibly eliminate material "bridging" or "rat-holing" within the hopper. This ensures smooth flow even for sticky or ultra-fine powders.
4.  **Intelligent PLC Closed-Loop System**: The system automatically adjusts the variable frequency motor speed based on the target feeding rate, eliminating the need for manual intervention. Supports linkage with other production line equipment.
5.  **Modular Customization**: The discharge outlet height and interface style can be customized to fit your existing reactor, packaging machine, or mixer height.

## 3. Operation Process

1.  **Material Loading**: Load the material into the 40L storage hopper.
2.  **Parameter Setting**: Set the target feeding rate (e.g., kg/h) or total batch weight on the control panel or PLC touch screen.
3.  **Start Operation**: Once activated, the PLC reads the initial weight from the load cell.
4.  **Loss-in-Weight Monitoring**: As the screw rotates, the weight in the hopper decreases. The PLC calculates the weight difference per unit of time.
5.  **Dynamic Adjustment**: If the actual flow rate is below the set value, the PLC automatically increases the screw speed; if it exceeds, it decreases, maintaining a constant output.
6.  **Automatic Stop/Refill**: The system stops automatically or triggers a low-level alarm once the target weight is reached or material is low.
