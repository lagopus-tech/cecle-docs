## 1. Visión General del Producto

* **Categoría**: Sistema de dosificación y medición de automatización industrial / Dosificador gravimétrico para polvos.
* **Aplicaciones**: Ampliamente utilizado en industrias que requieren dosificación continua o por lotes de alta precisión, como productos químicos, farmacéuticos, procesamiento de alimentos, compuestos plásticos (por ejemplo, aditivos masterbatch) y producción de materiales para baterías. Especialmente diseñado para polvos finos o granulos con mala fluidez o tendencia a formar puentes.
* **Función Principal**: Utiliza tecnología de pesaje dinámico para monitorear la tasa de reducción de peso del material en el tolva (lógica de pérdida de peso). Un sistema PLC controla con precisión la velocidad del tornillo sinfín para lograr una alimentación estable y precisa.

## 2. Ventajas Principales

1.  **Control de Dosis de Alta Precisión**: Equipado con células de carga industriales de alta sensibilidad para retroalimentación en tiempo real del peso. La exactitud de dosificación alcanza ±1% - 2%, garantizando consistencia estricta en las formulaciones.
2.  **Construcción en Acero Inoxidable S304**: Las partes en contacto con el material están fabricadas en acero inoxidable S304 de grado alimenticio/farmacéutico. Resistente a la corrosión, fácil de limpiar y cumple con estándares internacionales de higiene, asegurando que no haya contaminación del material.
3.  **Tecnología de Agitación Activa y Anti-Puentes**: Incorpora un mecanismo interno de agitación para eliminar forzadamente fenómenos de "puentes" o "rat-holing" dentro del tolva. Esto garantiza un flujo suave incluso con polvos pegajosos o extremadamente finos.
4.  **Sistema PLC Inteligente de Bucle Cerrado**: El sistema ajusta automáticamente la velocidad del motor de frecuencia variable según la tasa de alimentación objetivo, eliminando la necesidad de intervención manual. Compatible con equipos de línea de producción adicionales.
5.  **Personalización Modular**: La altura de salida y el tipo de conexión pueden personalizarse para adaptarse a tu reactor existente, máquina de empaque o mezcladora.

## 3. Proceso de Operación

1.  **Carga de Material**: Cargue el material en el tolva de almacenamiento de 40L.
2.  **Configuración de Parámetros**: Establezca la tasa de alimentación objetivo (por ejemplo, kg/h) o el peso total del lote mediante el panel de control o pantalla táctil PLC.
3.  **Inicio de Operación**: Una vez activado, el PLC lee el peso inicial desde la célula de carga.
4.  **Monitoreo de Pérdida de Peso**: Mientras el tornillo gira, el peso en el tolva disminuye. El PLC calcula la diferencia de peso por unidad de tiempo.
5.  **Ajuste Dinámico**: Si la tasa de flujo real es inferior al valor establecido, el PLC aumenta automáticamente la velocidad del tornillo; si excede, la reduce, manteniendo un flujo constante.
6.  **Parada Automática / Recarga**: El sistema se detiene automáticamente o activa una alarma de nivel bajo una vez alcanzado el peso objetivo o cuando el material está bajo.
