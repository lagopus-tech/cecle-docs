## 1. Przegląd Produktu

* **Kategoria**: System do automatyzacji przemysłowej – dosowanie i dawkowanie / Dosowacz grawimetryczny proszków.
* **Zastosowania**: Szeroko stosowany w przemyśle wymagającym wysokiej precyzji dosowania ciągłego lub partii, takim jak chemia, farmacja, przetwory żywnościowe, komponowanie tworzyw sztucznych (np. dodatek masterbatch), oraz produkcja materiałów akumulatorowych. Specjalnie zaprojektowany dla drobnych proszków lub granulatów o słabej płynności lub skłonności do zaciekania.
* **Podstawowa funkcja**: Wykorzystując technologię dynamicznego ważenia, system monitoruje tempo spadku masy materiału w zbiorniku (logika straty wagi). System PLC precyzyjnie kontroluje prędkość wkrętu, umożliwiając stabilne i dokładne podawanie materiału.

## 2. Kluczowe Zalety

1.  **Wysoka Precyzja Kontrolowania Dawkowania**: Zintegrowane przemysłowe czujniki ciężaru o wysokiej czułości zapewniają real-time feedback masy. Dokładność dosowania osiąga ±1% - 2%, gwarantując ścisłą spójność składów.
2.  **Wykonanie ze stali nierdzewnej S304**: Elementy kontaktujące się z materiałem wykonane są ze stali nierdzewnej S304 klasy spożywczej/farmaceutycznej. Odporność na korozję, łatwość czyszczenia oraz zgodność z międzynarodowymi standardami higienicznymi zapewniają brak zanieczyszczeń materiału.
3.  **Aktywne mieszanie i technologia zapobiegająca zaciekaniu**: Posiada wewnętrzną mechanizm mieszający, który eliminuje siły „zaciekania” lub „przebijania” w zbiorniku. Gwarantuje płynne przepływy nawet dla lepkich lub ekstremalnie drobnych proszków.
4.  **Inteligentny system zamknięty PLC**: System automatycznie dostosowuje prędkość silnika zmiennoprądowego na podstawie ustawionej szybkości podawania, eliminując potrzebę interwencji ręcznej. Obsługuje integrację z innymi urządzeniami linii produkcyjnej.
5.  **Modularna personalizacja**: Wysokość wyjścia i styl połączenia mogą być dopasowane do istniejącego reaktora, maszyny pakującej lub mieszarki.

## 3. Proces Eksploatacji

1.  **Napełnianie materiału**: Włóż materiał do zbiornika magazynowego o pojemności 40L.
2.  **Ustawienie parametrów**: Ustaw docelową szybkość podawania (np. kg/h) lub całkowitą wagę partii na panelu sterowania lub ekranie dotykowym PLC.
3.  **Uruchomienie działania**: Po aktywacji, PLC odczytuje początkową wagę z czujnika ciężaru.
4.  **Monitorowanie straty wagi**: Podczas obrotu wkrętu masa w zbiorniku maleje. PLC oblicza różnicę masy w jednostce czasu.
5.  **Dostosowanie dynamiczne**: Jeśli rzeczywista szybkość przepływu jest niższa niż ustawiona, PLC automatycznie zwiększa prędkość wkrętu; jeśli wyższa – zmniejsza ją, utrzymując stałą wydajność.
6.  **Automatyczne zatrzymanie / uzupełnienie**: System zatrzymuje się automatycznie lub wywołuje ostrzeżenie niskiego poziomu, gdy osiągnięto docelową wagę lub poziom materiału jest niski.
