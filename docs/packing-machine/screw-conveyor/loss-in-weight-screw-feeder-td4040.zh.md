## 1. 产品概述

* **类别**：工业自动化计量与定量系统 / 粉体失重式喂料机  
* **应用领域**：广泛应用于对高精度连续或间歇定量要求较高的行业，如化工、制药、食品加工、塑料配混（如母粒添加）及电池材料生产。特别适用于流动性差、易结块或架桥的细粉或颗粒物料。
* **核心功能**：采用动态称重技术，实时监测料斗内物料重量的减少量（失重逻辑）。通过PLC系统精确控制螺杆螺旋轴转速，实现稳定、精准的物料输送。

## 2. 核心优势

1.  **高精度计量控制**：配备工业级高灵敏度称重传感器，实现实时重量反馈。计量精度可达 ±1% - 2%，确保配方严格一致。
2.  **S304不锈钢结构**：与物料接触部分均采用食品/制药级S304不锈钢材质，耐腐蚀、易清洁，符合国际卫生标准，杜绝物料污染。
3.  **主动搅拌与防架桥技术**：内置搅拌装置，可强制消除料斗内物料“架桥”或“缩颈”现象，确保粘性或超细粉末也能顺畅流动。
4.  **智能PLC闭环控制系统**：系统根据设定喂料速率自动调节变频电机转速，无需人工干预。支持与其他生产线设备联动。
5.  **模块化定制设计**：出料口高度及接口形式可根据客户现有反应釜、包装机或混合机的高度进行定制。

## 3. 工作流程

1.  **加料**：将物料装入40L储料斗中。
2.  **参数设置**：在控制面板或PLC触摸屏上设定目标喂料速率（如 kg/h）或总批次重量。
3.  **启动运行**：启动后，PLC读取称重传感器的初始重量值。
4.  **失重监控**：螺杆旋转过程中，料斗内重量持续下降，PLC计算单位时间内的重量变化。
5.  **动态调节**：若实际流量低于设定值，PLC自动提高螺杆转速；若高于设定值，则降低转速，保持恒定输出。
6.  **自动停机/补料**：达到目标重量或物料低位时，系统自动停止，或触发低料位报警。
