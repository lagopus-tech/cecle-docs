# TDZD-400 / TDZD-500 / TDZD-600 Machine à emballage automatique à joint central et à trois côtés pour sachets stratifiés

> **Résumé principal :**  
> Les séries TDZD-400 / TDZD-500 / TDZD-600 sont des machines automatiques haute performance pour la fabrication de sachets stratifiés avec joint central et à trois côtés, conçues pour traiter les matériaux PET/PE, PA/PE, feuilles d’aluminium et films papier-plastique stratifiés. Adaptées aux usines de transformation alimentaire, aux convertisseurs d’emballages flexibles et aux fabricants de sachets sous vide, ces machines utilisent des entraînements multi-servo, un guidage de bande EPC, un suivi photoélectrique double et un contrôle automatique de tension. Elles atteignent une vitesse maximale de 170 pièces/min avec une fonction de défilement 6x pour les sachets surdimensionnés, offrant ainsi une solution CE conforme, fiable et polyvalente pour produire des sachets sous vide, des sachets à gousset et des emballages stratifiés.

## IV. Processus de fonctionnement
> Le processus opératoire est identique pour les modèles TDZD-400 / 500 / 600.
1. Vérifier les circuits électriques et pneumatiques avant le démarrage, s’assurer d’un approvisionnement normal en compresseur d’air ; nettoyer les traces sur les rouleaux guide et les lames de soudure ; installer les couteaux de soudure, les lames de découpe et les moules à gousset correspondants à la spécification du sachet cible.
2. Monter le rouleau stratifié sur l’unité de déroulement, passer le matériau successivement par les rouleaux guide, les mécanismes de tension, le guidage EPC, les capteurs photoélectriques et les stations de soudure.
3. Configurer la longueur du sachet, le multiplicateur de défilement, la température de soudure, la vitesse de production et les paramètres de comptage sur l’écran tactile HMI ; calibrer les marques d’impression photoélectriques et sélectionner la langue d’opération souhaitée.
4. Une fois que les stations de soudure ont atteint la température opérationnelle, démarrer l’équipement à faible vitesse pour produire des échantillons, vérifier la résistance du joint, les dimensions, la formation du gousset et la performance de découpage.
5. Après validation de l’échantillon, accélérer progressivement jusqu’à la vitesse de production complète pour une fabrication automatisée par lots, effectuant des contrôles qualité réguliers.
6. Après la production, éteindre l’appareil et laisser refroidir les chauffants, éteindre le compresseur d’air, retirer les matériaux résiduels et les déchets, et effectuer une lubrification et un entretien réguliers.

## V. Conseils commerciaux & FAQ
### Conseils commerciaux
1. **TDZD-400** : Idéal pour les sachets sous vide, sachets à joint central et sachets à trois côtés de petite à moyenne taille ; choix privilégié pour les petites et moyennes usines d’emballages flexibles.
2. **TDZD-500** : Meilleure polyvalence, couvre les formats de sachets courants du marché ; recommandé comme choix principal pour la plupart des clients.
3. **TDZD-600** : Spécialement conçu pour les sachets larges, produisant de grands sachets sous vide, de grands sachets à gousset et des laminés papier-plastique surdimensionnés.
4. Convient à la production à grande échelle de sachets stratifiés ; préféré par les entreprises d’emballage alimentaire, carnés, de collations et de thé (non adapté aux échantillonnages micro-batch).
5. Les matières premières doivent privilégier le PET/PE, le PA/PE, l’aluminium et les laminés papier-plastique ; le papier non stratifié ne peut pas être traité directement.
6. Pour les sachets stand-up, poignées ou coins arrondis, recommander de choisir les modules optionnels correspondants ; le compresseur d’air est fourni par le client.

### FAQ
**Q1 : Quel type d’alimentation électrique est requis ?**  
R1 : Alimentation standard triphasée 380 V, compatible 50 Hz / 60 Hz, possibilité de personnalisation selon demande.

**Q2 : Les moules peuvent-ils être interchangeés entre les trois modèles ?**  
R2 : Les moules plus petits pouvant tenir dans la largeur maximale d’un modèle donné peuvent être partagés ; dépasser cette largeur nécessite des outillages spécifiques au modèle.

**Q3 : Cette machine peut-elle produire des sachets sous vide ?**  
R3 : Oui. Elle est entièrement compatible avec les films PA/PE et autres films stratifiés pour produire des sachets d’emballage alimentaire sous vide.

**Q4 : Les pièces d’usure sont-elles couvertes par la garantie ?**  
R4 : La machine bénéficie d’une garantie de 1 an ; les lames de soudure et les couteaux de découpe ne sont pas incluses.

**Q5 : L’opération est-elle difficile, et la formation est-elle nécessaire ?**  
R5 : Dotée d’une interface tactile multilingue, il s’agit d’une machine de conditionnement avancée et à haute vitesse ; une formation technique sur site par le fabricant est obligatoire avant utilisation.

**Q6 : Le compresseur d’air est-il inclus ?**  
R6 : Le compresseur d’air est fourni par le client ; un compresseur de 5 HP est recommandé pour les TDZD-400/500, et de 6,5 HP pour le TDZD-600.

**Q7 : Peut-elle produire des sachets très longs ?**  
R7 : Oui, elle supporte jusqu’à un défilement 6x avec des longueurs maximales de sachet atteignant 2100 mm via les réglages de multiplicateur sur l’écran tactile.
