# Автоматическая машина для производства пакетов с центральным и трёхсторонним термосвариванием TDZD-400 / TDZD-500 / TDZD-600
![](https://cdn.shopify.com/s/files/1/0010/4982/1242/files/CWZD-400A___1000x1000_7af89d02-a07a-43ec-99a8-71f8d3978871.png?v=1788921115)

> **Основная информация:**  
> Серия TDZD-400 / TDZD-500 / TDZD-600 — это высокопроизводительные автоматические машины для изготовления пакетов с центральным и трёхсторонним термосвариванием, предназначенные для обработки материалов из PET/PE, PA/PE, алюминиевой фольги и бумага-пластиковые композиты. Идеально подходят для пищевых производств, предприятий по производству гибкой упаковки и изготовителей вакуумных пакетов. Оборудование оснащено многосервоприводами, системой EPC управления полотном, двойной фотоэлектрической навигацией и автоматическим регулированием натяжения. Скорость до 170 шт./мин с возможностью 6-кратного пропуска для больших пакетов обеспечивает соответствие стандартам CE, надежность и универсальность при производстве вакуумных пакетов, мешков с карманом (гуссет), а также ламинированных упаковок.

## II. Ключевые преимущества
1. Оснащена импортными сервомоторами и системами управления PLC с многосервоприводами, обеспечивающими высокую точность длины пакета, положения шва и согласованности резки.
2. Комплектуется системой EPC управления полотном + двойной фотоэлектрической навигацией для размотки, а также автоматической системой контроля натяжения для плавной подачи и точной регистрации печатных меток.
3. Поддерживает производство расширенных пакетов с 6-кратным пропуском для крупногабаритных упаковок; включает автоматическую систему перекатки отходов для удобного повторного использования отходов.
4. Централизованная система смазки снижает износ оборудования, увеличивает срок службы и позволяет длительную непрерывную массовую выработку.
5. Прямые поставки с завода, стабильное качество всей машины, гарантия на весь агрегат — 1 год, поддержка ключевых компонентов.
6. Модульная конструкция позволяет быструю замену форм; поддерживает различные опциональные модули для расширения производственных возможностей.
7. Совместимость с различными ламинированными композитными материалами (PET/PE, PA/PE, алюминиевая фольга, бумага-пластик); идеально подходит для вакуумных, гуссетных, трёхсторонних и центральных пакетов.
8. Поддержка интерфейсов на нескольких языках для международных клиентов, соответствие стандартам безопасности CE.

## IV. Процесс эксплуатации
> Процесс работы одинаков для моделей TDZD-400 / 500 / 600.
1. Перед запуском проверьте электрические и пневматические цепи, убедитесь в нормальной работе компрессора; очистите загрязнения на направляющих роликах и термических ножах; установите соответствующие термические ножи, режущие лезвия и формы для кармана, соответствующие требуемому формату пакета.
2. Закрепите рулон ламинированного материала на устройстве размотки, проденьте материал последовательно через направляющие ролики, механизмы натяжения, систему EPC управления полотном, фотоэлектрические датчики и станции термосварки.
3. На сенсорном экране HMI задайте параметры длины пакета, множитель пропуска, температуру термосварки, скорость производства и количество; отрегулируйте печатные метки с помощью фотоэлектрических датчиков и выберите нужный язык интерфейса.
4. После достижения рабочей температуры станций термосварки запустите оборудование на низкой скорости для изготовления образцов, проверьте прочность шва, размеры, форму кармана и качество резки.
5. После одобрения образцов увеличьте скорость до полной производительности для автоматического массового производства, проводя регулярные проверки качества.
6. После окончания производства выключите оборудование, дайте нагревательным элементам остыть, отключите компрессор, удалите остаточные материалы и отходы, выполните обычную смазку и техобслуживание.

## V. Рекомендации по продаже и ЧАВО
### Рекомендации по продаже
1. TDZD-400: Идеален для малых и средних вакуумных пакетов, пакетов с центральным швом и трёхсторонним швом; лучший выбор для малых и средних предприятий по производству гибкой упаковки.
2. TDZD-500: Наиболее универсальная модель, охватывает основные рыночные форматы пакетов; рекомендуется как основной выбор для большинства клиентов.
3. TDZD-600: Создана специально для широких пакетов, производит большие вакуумные пакеты, крупные пакеты с карманом и крупные бумага-пластиковые ламинаты.
4. Подходит для массового производства ламинированных пакетов; предпочитается предприятиями по упаковке пищи, мяса, закусок и чая (не подходит для микробатч-образцов).
5. При выборе сырья предпочтение следует отдавать материалам PET/PE, PA/PE, алюминию и бумага-пластиковые ламинаты; необработанная бумага напрямую не может использоваться.
6. Для производства стоячих пакетов, пробойника ручки или скруглённых углов рекомендуется выбрать соответствующие опциональные модули; компрессор поставляется заказчиком.

### ЧАВО
**В1: Какое питание требуется для оборудования?**  
О1: Стандартное 3-фазное 380 В, поддержка 50/60 Гц, настраиваемое напряжение доступно по запросу.

**В2: Можно ли использовать формы взаимозаменяемо между тремя моделями?**  
О2: Формы меньшего размера, входящие в максимальную ширину пакета конкретной модели, могут быть общими; при превышении максимальной ширины необходимы специальные инструменты для каждой модели.

**В3: Может ли эта машина производить вакуумные пакеты?**  
О3: Да. Полностью совместима с материалами PA/PE и другими ламинированными пленками для производства пищевых вакуумных упаковок.

**В4: Покрывается ли износные детали гарантией?**  
О4: На всю машину предоставляется гарантия 1 год; термические ножи и режущие лезвия не входят в гарантийное покрытие.

**В5: Сложно ли в эксплуатации, требуется ли обучение?**  
О5: Обладает многоязычным сенсорным интерфейсом, представляет собой передовую высокоскоростную упаковочную машину; обязательное на-site обучение техническим специалистам производителя перед началом эксплуатации.

**В6: Входит ли компрессор в комплект?**  
О6: Компрессор поставляется заказчиком; рекомендуется компрессор 5 л.с. для TDZD-400/500, 6,5 л.с. для TDZD-600.

**В7: Может ли она производить очень длинные пакеты?**  
О7: Да, поддерживает до 6-кратного пропуска, максимальная длина пакета достигает 2100 мм с настройкой множителя через сенсорный экран.
