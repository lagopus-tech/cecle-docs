### 二、核心优势
1.  **全材质兼容性**：精密设计的旋盖头可适应**刚性铝盖**和**柔性塑料盖**。施加均匀扭矩，不损伤瓶盖，不留划痕。

    *   标准配置为6个旋盖头，支持双旋盖头同时作业，效率高且易于调节。
    *   可根据客户需求定制旋盖头数量（单头、双头等）及输送带规格。

### 六、工作流程
1.  **自动进瓶**：瓶子通过2米不锈钢输送带平稳进入工作工位。
2.  **物料检测**：德国西克（SICK）传感器精准识别瓶体位置，防止误操作。
3.  **精准套盖**：引导铝盖或塑料盖，确保瓶盖垂直放置在瓶口上。
4.  **同步旋盖**：双旋盖头同时垂直下压，按照预设扭矩旋紧瓶盖。
5.  **成品出料**：旋盖完成后，定位机构释放，成品沿输送带进入下一道包装工序。
