### 一、产品概述
*   **产品类别**：半自动封罐/封口机
*   **应用场景**：广泛应用于食品、饮料、制药、日化及工矿行业。特别适用于马口铁罐、铝罐、塑料罐、纸罐和玻璃瓶的金属盖或易开盖密封。
*   **核心功能**：通过电机驱动罐体旋转，利用滚轮滚压封口原理，将罐体与罐盖紧密结合，实现高真空密封或防漏密封效果。

### 六、操作流程
1.  **高度调节**：根据容器高度手动调节托盘升降机构，确保罐盖与压头紧密贴合。
2.  **放置容器**：操作员将预装好内容物并盖上盖子的容器稳妥放置于底部托盘上。
3.  **启动操作**：通过脚踏板或手动开关启动，托盘自动上升夹紧容器。
4.  **自动封口**：压头带动容器旋转，滚轮自动靠近完成卷边压紧过程。
5.  **循环完成**：封口完成后，托盘下降，操作员取出成品，准备下一循环。
