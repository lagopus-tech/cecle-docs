### 一、产品概述
*   **产品类别**：半自动电动气动旋盖机
*   **应用范围**：广泛应用于日化、化妆品、食品、制药等行业。特别适用于拧紧塑料螺纹盖、喷嘴、泵头、鸭嘴盖和扳机喷雾盖等复杂瓶盖。
*   **核心功能**：双电机驱动旋盖头旋转，配合气动夹紧装置，实现对各种形状瓶身和瓶盖的精准拧紧与密封，解决异形瓶盖旋盖难题。

### 二、核心优势
1.  **优质材料**：主控箱和支撑架采用 **304 不锈钢** 制造。底板和主体采用阳极氧化铝合金，确保耐腐蚀性和结构稳定性。
2.  **性能强劲**：采用进口品牌双电机驱动，扭矩充足，性能稳定，控制逻辑简单直观。
3.  **兼容性高**：除标准圆形瓶盖外，特别优化适用于 **鸭嘴盖、尖嘴盖、异形塑料盖、泵头** 等，应用范围极广。
4.  **参数精准可调**：采用数字继电器控制；可根据瓶盖材质自由调节旋盖时间、扭矩大小和转速，既防止损坏，又保持拧紧度一致。
5.  **调节便捷**：切换不同瓶型时，只需手动调节旋盖头高度即可，无需繁琐拆卸。

### 六、操作流程
1.  **高度调节**：根据待处理瓶身的高度，调节旋盖头支架的垂直位置。
2.  **参数设置**：根据瓶盖材质，在控制面板上设置旋盖时间、速度和扭矩等级。
3.  **放置瓶与盖**：手动将瓶盖预旋至瓶口，并将瓶子放入工作台上的定位区域。
4.  **按压拧紧**：触发传感器或脚踏开关。气缸将旋盖头下压，双电机同时启动，完成拧紧动作。
5.  **复位取瓶**：达到预设扭矩后，旋盖头自动上升复位。取出成品瓶，进入下一循环。
