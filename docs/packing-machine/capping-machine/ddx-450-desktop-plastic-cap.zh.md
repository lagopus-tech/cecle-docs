### 六、操作流程
1.  **设备调整**：根据待加工瓶子的高度和瓶盖尺寸，手动调节行程高度和定位底座。
2.  **放置瓶子**：操作员手动将瓶子（瓶盖预置其上）放置在工作台的定位块处。
3.  **旋盖操作**：机器以恒定速度上下运动；旋盖头下降与瓶盖啮合，通过摩擦力将其拧紧。
4.  **手动更换**：在连续运行过程中，操作员按照机器的运行节奏，手动取出已封口成品并放入新瓶子。
