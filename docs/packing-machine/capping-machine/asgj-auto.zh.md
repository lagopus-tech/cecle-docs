# 产品规格：ASGJ旋盖机（自动旋盖机）

![ASGJ旋盖机](https://cdn.shopify.com/s/files/1/0010/4982/1242/files/17861781873056.png?v=1786178222)

> **核心摘要**：ASGJ自动直线式旋盖机是一款高效包装解决方案，专为日化、制药、食品及饮料生产线设计。配备耐用的201不锈钢机架、智能PLC触摸屏控制以及高精度德国SICK光电传感器，可处理瓶身高度80–400mm，旋盖速度30–45瓶/分钟。特别针对泵头、鸭嘴盖、喷头等复杂瓶盖进行了优化，确保旋盖过程不损伤瓶盖。

## 一、产品概述
*   **类别**：自动直线式旋盖机
*   **应用场景**：适用于日化、食品、制药及饮料行业的自动化生产线。特别适用于以下瓶型和瓶盖类型：
    *   **个人护理产品**：洗发水、沐浴露等泵瓶。
    *   **制药及饮料**：口服液瓶、各类螺旋盖饮料瓶、喷雾瓶。
    *   **瓶子兼容性**：可处理多种瓶型，瓶身高度范围80–400mm。
*   **核心功能**：通过输送带自动送瓶，利用光电传感器确保“无瓶不送盖/不旋盖”，并通过PLC控制精确执行螺旋盖封口。

## 二、核心优势
1.  **智能控制系统**：采用台湾品牌PLC触摸屏，数字设定，操作直观简便，运行极其稳定。
2.  **高灵敏度传感**：配备德国SICK光电传感器，精确检测瓶子，确保无瓶时不进行旋盖操作。
3.  **坚固耐用结构**：主机架和机身采用201不锈钢制造，符合卫生标准，易于清洁。
4.  **高适应性**：旋盖速度、输送带速度及旋盖头高度均可调节，可无缝集成至现有生产线。
5.  **模块化定制**：标配2米输送带；旋盖头可根据客户需求定制为单头、双头或多头配置。

## 六、工作流程

1.  **进瓶**：瓶子通过前端输送带平稳进入旋盖工位。
2.  **光电检测**：德国SICK传感器检测进入旋盖区域的瓶子。
3.  **送盖/理盖**：瓶盖通过自动理盖器（可选）自动放置，或在进入旋盖头之前手动预放置。
4.  **旋盖封口**：气动夹瓶机构固定瓶子，旋盖头根据预设扭矩下压并旋转，完成封口。
5.  **出瓶**：封口完成的瓶子沿输送带继续输送至下一道工序（如贴标或喷码）。
