*   **Категория**: Полуавтоматическая вакуумная укупорочная машина

    *   **Консервы**: Консервированные персики, фруктовые смеси, соленья, джемы и т.д.

## 6. Рабочий процесс

1.  **Ручная установка бутылки**: Оператор помещает стеклянную банку/бутылку (наполненную и с крышкой) в форму.
2.  **Пуск / Закрытие вакуумной камеры**: Нажатие кнопки пуска; под действием пневмоцилиндра вакуумная камера автоматически опускается, образуя герметичное пространство.
3.  **Вакуумирование**: Запускается вакуумный насос, быстро откачивая воздух из камеры и банки до достижения заданного уровня вакуума.
4.  **Укупорка**: Укупорочная головка опускается с помощью пневматических компонентов и затягивает крышку с заданным крутящим моментом.
5.  **Сброс / Извлечение бутылки**: Вакуумная камера автоматически поднимается, завершая один рабочий цикл, и оператор извлекает готовое изделие.
