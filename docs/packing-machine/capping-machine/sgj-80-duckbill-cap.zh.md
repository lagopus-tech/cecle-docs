# 产品规格：旋盖机（SGJ-80）

![SGJ-80 旋盖机](https://cdn.shopify.com/s/files/1/0010/4982/1242/files/17866100131655.png?v=1786610041)

本规格书详细说明了SGJ-80半自动电动气动旋盖机。该设备专为化妆品、日化品、制药及食品行业设计，能够高效完成喷雾、泵头、触发式等复杂不规则瓶盖的封口作业。整机采用304不锈钢材质，配备双电机驱动，最高转速可达45盖/分钟，通过恒定气压下压与数字扭矩控制相结合，实现高效、无损封盖。

## 1. 产品概述
*   **产品类别**：半自动电动与气动旋盖机  
*   **应用场景**：广泛应用于化妆品、日用化学品、医药及食品行业，特别适用于生产线中对复杂瓶盖（如喷头、泵头、鸭嘴盖、触发喷雾盖等）的密封作业。  
*   **核心功能**：结合电动旋转驱动与气动下压压力控制，可在多种瓶盖材质与形状下实现高速、高精度封盖。  
*   **操作要求**：**本机为气动型号，必须连接空气压缩机（空压机）方可运行。**

## 2. 主要优势
1.  **工业级材料**：主电控箱与支架均采用**304不锈钢**制造，底板与机架经阳极氧化铝合金处理，具备优异的耐用性与抗腐蚀性能。  
2.  **进口双电机驱动**：搭载高功率进口品牌电机，动力储备充足，运行平稳，显著延长设备使用寿命。  
3.  **高效率表现**：相比传统机型大幅提升效率，SGJ-80最高可实现**45盖/分钟**的封盖速度。  
4.  **数字化精准控制**：采用数字继电器控制系统，可独立调节**封盖时间、锁紧时间、扭矩大小、旋转速度**，有效避免瓶盖损伤。  
5.  **不规则瓶盖专家**：气动下压配合可调扭矩，轻松应对**鸭嘴盖、尖嘴瓶盖、非标塑料盖**等复杂封盖任务。

## 4. 销售建议与常见问题解答（FAQ）

### 销售建议
*   **核心卖点**：突出“高兼容性”与“高效率”。强调其在处理**泵头/喷头类不规则瓶盖**时的稳定性，这是纯电动旋盖机难以实现的优势。  
*   **客户提醒**：成交前务必确认客户现场是否配备空气压缩机。推荐使用静音、无油的小型空压机，工作压力约0.5 MPa。  
*   **售后优势**：提供1年全保修服务，终身技术支持。所有易损件均为标准件（如AirTAC气缸），维护成本极低。

### 常见问题解答（FAQ）
*   **Q：为何这款机器优于纯电动型号？**  
    *   A：气动下压力可提供持续且均匀的压力，防止因人工施压不均导致的螺纹滑丝或密封松动。同时，气动运行更有利于保护电机，延长整机寿命。  

*   **Q：不同瓶高调整起来复杂吗？**  
    *   A：非常简单。只需松开侧边固定螺丝，转动顶部手轮即可调节旋盖头高度——无需任何工具。  

*   **Q：瓶盖拧紧程度可以调节吗？**  
    *   A：可以。通过数字面板调节扭矩设置，并调节进气压力，即可精确控制瓶盖紧固度。

## 6. 操作流程
1.  **气源与电源连接**：接入电源，将空压机气管插入快速接头接口，调节气压至标准工作范围。  
2.  **高度调节**：放置目标瓶子，调节旋盖头高度，使其距瓶盖约5–10 mm。  
3.  **参数设定**：根据瓶盖材质，在数字显示屏上设置封盖时间与间隔时间（或切换至脚踏模式）。  
4.  **瓶子放置**：操作员将已预装瓶盖的瓶子放入定位槽，触发脚踏开关或传感器。  
5.  **自动封盖**：**气缸驱动**旋盖头快速下压并旋转，达到设定扭矩或时间后自动停止并复位。  
6.  **产品取出**：取出已封盖的瓶子，进入下一循环。
