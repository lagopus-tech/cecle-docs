## 6. 工作流程

1.  **手动放置瓶子**：操作员将玻璃罐/瓶（已灌装并盖上盖子）放入模具中。
2.  **启动 / 真空室关闭**：按下启动按钮；在气缸驱动下，真空室自动下降，形成密封空间。
3.  **抽真空**：真空泵启动，快速抽取腔体和罐内空气，达到预设真空度。
4.  **旋盖**：旋盖头在气动元件驱动下下降，按照预设扭矩拧紧瓶盖。
5.  **复位 / 取出瓶子**：真空室自动上升，完成一个工作循环，操作员取出成品。
