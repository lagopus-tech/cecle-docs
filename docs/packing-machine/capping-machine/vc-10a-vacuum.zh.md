# 产品规格：VC-10A 真空旋盖机

> **核心摘要**：VC-10A 是一款台式半自动真空旋盖机，专为玻璃瓶配马口铁盖设计。采用双工位设计，生产效率更高（0–600瓶/小时），配备1:1定制模具，集气动与电气操作于一体，为果酱、酱料、蜂蜜、腌菜等食品加工和调味品行业提供可靠的真空密封。

## 1. 产品概述
*   **类别**：台式半自动真空旋盖机
*   **应用**：专为需要高真空密封的玻璃瓶和马口铁盖设计。广泛应用于：
    *   **食品加工**：果酱、辣椒酱、糖水黄桃、蜂蜜、腌菜等。
    *   **高真空需求场景**：去除瓶内空气，有效防止氧化，延长保质期。
*   **核心功能**：结合机械、电气和气动一体化技术，在真空室内完成“抽真空+旋盖”动作，确保瓶内达到预设的高真空度，实现紧密密封。

## 2. 核心优势
1.  **双工位高效设计（2个工位）**：配备两个操作工位，可交替循环作业，生产效率高于普通单工位机型。
2.  **精密定制模具**：根据客户提供的瓶样和盖样进行1:1模具定制，确保100%贴合，防止打滑或损坏瓶盖。
3.  **机身紧凑轻巧**：台式结构设计，外形尺寸仅为950*650*400 mm，节省空间，安装和运输极为便捷。
4.  **性能稳定可靠**：关键气动和电气元件选用国际知名品牌，故障率低，可长期稳定运行。
5.  **操作维护简单**：经过多年研发优化，操作逻辑直观易懂，操作人员经过简单培训即可轻松上手，维护成本低。

## 6. 工作流程

1.  **准备**：将已灌装并轻放瓶盖的瓶子放入双工位模具中。
2.  **合盖抽真空**：按下启动开关，真空室在气缸驱动下自动下降密封。真空泵同时启动，抽取真空室内空气。
3.  **旋盖密封**：达到预设真空度后，旋盖装置下降并快速旋转，将马口铁盖旋紧。
4.  **泄压抬升**：旋盖完成后，系统自动泄压，真空室上升复位。
5.  **成品输出**：操作人员取出已密封的瓶子，准备下一轮操作。
