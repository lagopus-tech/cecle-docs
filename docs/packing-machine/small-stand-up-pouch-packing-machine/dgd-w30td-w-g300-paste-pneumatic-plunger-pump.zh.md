> **核心摘要**
> DGD-W30TD-W-G300 膏体气动柱塞泵自立袋包装机是一款专为食品、调味品及日化行业的膏体和液体产品设计的精英级自动化包装解决方案。该设备配备先进的气动柱塞泵和30升不锈钢料斗，可实现±0.2g的超高包装精度，速度达每分钟20-30袋。采用分体式灵活设计，5分钟即可完成规格切换，坚固耐用的不锈钢系统确保番茄酱等物料实现防漏、切口干净的包装作业。

## 一、产品概述

### 1. 产品类别
* **设备名称**：膏体气动柱塞泵自立袋包装机
* **产品型号**：DGD-W30TD-W-G300
* **设备定位**：专为膏体和液体物料设计的自立袋包装机。配备气动柱塞泵，实现膏体/液体的自动化灌装（也可兼容纯液体的自动化灌装）。

### 2. 应用范围
* **行业应用**：广泛应用于食品、调味品、日化等行业。
* **适用物料**：适用于膏体和液体物料，如番茄酱、枸杞原浆、蓝莓原浆等。
* **包装袋型**：适用于预制袋，如平口袋、自立袋、拉链袋等。

### 3. 核心功能
* **气动柱塞泵供料**：标配高性能气动柱塞泵，推力强劲，不仅能灌装纯液体，还能轻松应对高粘度膏体。
* **PLC控制**：触摸屏操作，用户只需在屏幕上输入目标毫升数即可调整灌装量，免去繁琐的机械调节，性能稳定精准。
* **自动断丝吹气控制系统**：标配自动防滴漏吹气控制系统，有效防止灌装过程中的拉丝现象，彻底解决高粘度膏体物料的自动化灌装难题。

## 二、核心优势

* **±0.2g包装精度**：得益于精密柱塞缸和气动控制，灌装精度高达±0.2g。
* **一键切换**：从50ml切换至300ml包装时，全程无需任何机械调节——只需在触摸屏上修改参数并调整袋仓，5分钟内即可完成生产线转换。
* **30L大料斗**：标配30升不锈钢大料斗，减少人工加料频率，确保生产连续性。

## 四、操作与工作流程

### 1. 使用条件
* **耗材**：预制袋、待包装的液体/膏体物料。
* **气源**：用户需自备空气压缩机，提供稳定的0.6-0.8 MPA气压。
* **电源**：110V/220V电压。

### 2. 标准工作流程
1. **加料**：将膏体/液体物料倒入机器顶部的30L不锈钢料斗中。
2. **装袋**：将预制袋整齐放入机器的袋仓中。
3. **设置**：在触摸屏上直接输入目标灌装量（如100ml）。
4. **自动运行**：机器自动取袋 -> 自动开袋 -> 柱塞泵精准定量灌装 -> 自动热封 -> 输出成品。
