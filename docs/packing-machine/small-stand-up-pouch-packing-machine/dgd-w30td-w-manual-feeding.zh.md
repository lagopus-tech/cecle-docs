## 一、产品概述

### 1. 产品类别
* **设备名称**：手动送料自立袋包装机
* **产品型号**：DGD-W30TD-W
* **设备定位**：专为“难包装物料”设计的预制袋包装主机。极其适用于形状不规则、无法自动定量出料，或在落料过程中易散落、易错位的物料（通过人工送料解决自动化盲区）。

### 2. 应用范围
* **行业应用**：广泛应用于食品、日化及五金行业。例如一次性棉柔巾、休闲零食、五金配件等。
* **适用物料**：人工送料不规则物料的首选机型。同时，本机扩展性强，搭配不同的自动送料器，亦可包装常规颗粒、液体、膏体等物料。
* **包装袋型**：适用于预制袋，如平口袋、自立袋、拉链袋等。不适用于过软的袋子，因其无法被机器正常吸取。

### 3. 核心功能
* **PLC智能控制系统**：采用微电脑PLC控制，性能极其稳定，参数调节简单直观。
* **可选通用接口**：如果您未来有升级为全自动化生产线的计划，请在订购前告知我们。我们可以在出厂前为您定制“通用信号接口”（包括备料信号、卸料信号、脚踏开关、光电传感器等），方便您日后与其他外部称重/灌装设备对接。
* **袋子兼容性**：兼容多种袋型尺寸，可轻松调节以适应5×7cm至20×30cm的袋子规格。

## 四、操作与工作流程

### 1. 使用条件
* **耗材**：预制袋。
* **气源**：用户需自备空气压缩机，提供稳定的0.6-0.8 MPA气压。
* **电源**：110V/220V电压。

### 2. 标准工作流程
1. **装袋**：将预制袋整齐放入机器的储袋仓中。
2. **设置**：在触摸屏上设置参数。
3. **送料**：机器自动取袋并开袋，操作人员手动将物料放入袋中。
4. **封口**：机器自动完成热封并输出成品。
