## 一、产品概述

### 1. 产品类别
* **设备名称**：500克颗粒自立袋包装机
* **产品型号**：DGD-W30TD-W-K500
* **设备定位**：专为形状均匀、颗粒大小相对规整的颗粒物料设计的预制袋包装机。配备**三头电子线性秤**，支持单一物料或多物料混合包装，是高附加值农产品和零食的首选设备。

### 2. 应用范围
* **行业应用**：广泛应用于食品、干货、调味品等行业。
* **适用物料**：形状均匀或颗粒大小相对规整的颗粒物料，如大米、花生、瓜子、白砂糖、鸡精、枸杞等。
* **包装袋型**：适用于预制袋，如平口袋、自立袋、拉链袋等。支持袋尺寸范围为5×7CM至20×30CM。

### 3. 核心功能
* **三头电子线性秤**：支持三个称重头交替或同时下料。不仅可以包装单一物料，还可实现**多种不同物料的精准比例混合包装**。
* **分体式结构**：颗粒填充机与主机包装机采用分体式结构，既可独立使用，也可组合使用。操作简便，满足多样化需求，节省成本。
* **网纹封口**：主机标配优质网纹封口模具（无需钢印）及高品质加热管。加热均匀，气动封口压力强，封口平整美观，不夹料。

## 二、核心优势

* **±0.1克包装精度**：采用**三头电子线性秤**，包装精度可达±0.1克。特别适用于白砂糖、高端坚果、名贵中药材等对重量公差要求极为严格的贵重物料。
* **灵活的多物料混合**：通过PLC控制**三头线性秤**的下料逻辑，操作人员可直接在触摸屏上设定每种物料的配比重量，轻松完成"大米+绿豆（多种规整形状物料混合）"等复杂包装任务，一步到位。
* **一键轻松设定**：更换包装重量（0.1-500克）时，操作人员无需进行任何复杂的机械扳手调节。只需在触摸屏上直接修改目标重量值，即可实现全自动称重包装。

## 四、操作与工作流程

### 1. 使用条件
* **包装耗材**：预制袋、待包装的规整形状颗粒物料。
* **气源**：用户需自备空气压缩机，提供稳定的0.6-0.8 MPA气压。
* **电源**：110V/220V电压。

### 2. 标准工作流程
1. **加料**：将物料倒入顶部30KG不锈钢大料仓中。
2. **装袋**：将预制袋整齐放入机器的袋仓中。
3. **设定**：在触摸屏上输入目标重量（如250克）。
4. **自动运行**：机器自动取袋 → 自动开袋 → **三头电子线性秤**精准下料 → 自动封口 → 输出成品。

## 五、销售技巧与常见问题

### 销售技巧
* **重点突出"多物料"解决方案**：向生产混合物料（如大米和绿豆）的客户推销时，重点强调**三头电子线性秤的交替/同时下料模式**。这是一个极佳的卖点，因为标准的单头秤绝对无法处理混合物料。

### 常见问题
* **问：为什么要使用三头电子线性秤？相比单头秤有哪些优势？**
  * **答**：**三头电子线性秤**由微电脑控制，可交替或同时下料。其优势包括：
    1. **速度更快**：三个称重头协同工作，下料更均匀稳定；
    2. **支持混合包装**：例如，可在A称量斗中放入绿豆、B斗中放入瓜子、C斗中放入枸杞，实现**一袋内三种不同物料的精准配比包装**。
