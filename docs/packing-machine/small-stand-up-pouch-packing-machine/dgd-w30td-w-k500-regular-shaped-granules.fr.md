Il suffit de modifier la valeur du poids cible directement sur l'écran tactile pour réaliser un pesage et un emballage entièrement automatiques.

## IV. Fonctionnement & Processus de Travail

### 1. Conditions Requises
* **Consommables d'emballage** : Sachets préformés, matériaux granulaires de formes régulières à emballer.
* **Alimentation en air** : Un compresseur d'air doit être préparé par l'utilisateur, fournissant une pression d'air stable de 0,6-0,8 MPA.
* **Alimentation électrique** : Tension de 110V/220V.

### 2. Processus de Travail Standard
1. **Chargement** : Versez les matériaux dans la grande trémie en acier inoxydable de 30KG située en haut.
2. **Chargement des sachets** : Placez les sachets préformés soigneusement dans le magasin à sachets de la machine.
3. **Configuration** : Saisissez le poids cible (par exemple, 250g) sur l'écran tactile.
4. **Fonctionnement automatique** : La machine prélève automatiquement le sachet -> ouvre automatiquement le sachet -> la **peseuse linéaire électronique à trois têtes** dépose précisément le matériau -> soude automatiquement -> évacue le produit fini.
