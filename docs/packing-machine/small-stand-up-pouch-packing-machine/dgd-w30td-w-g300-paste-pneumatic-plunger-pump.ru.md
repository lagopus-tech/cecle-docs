## IV. Эксплуатация и технологический процесс

### 1. Необходимые условия
* **Расходные материалы**: Готовые пакеты, жидкие/пастообразные материалы для фасовки.
* **Подача воздуха**: Пользователь должен подготовить воздушный компрессор, обеспечивающий стабильное давление воздуха 0,6-0,8 МПа.
* **Электропитание**: Напряжение 110В/220В.

### 2. Стандартный технологический процесс
1. **Загрузка материала**: Залейте пастообразный/жидкий материал в бункер из нержавеющей стали объемом 30 л в верхней части машины.
2. **Загрузка пакетов**: Аккуратно поместите готовые пакеты в магазин пакетов машины.
3. **Настройка**: Введите целевой объем фасовки (например, 100 мл) непосредственно на сенсорном экране.
4. **Автоматический режим**: Машина автоматически захватывает пакет -> автоматически открывает пакет -> плунжерный насос точно и дозированно наполняет его -> автоматически запаивает -> выдает готовую продукцию.
