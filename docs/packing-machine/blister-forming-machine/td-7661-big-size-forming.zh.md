## 4. 操作流程
1. 根据产品规格安装定制铜质成型模具，固定模具板并检查真空与加热管路；
2. 将塑料板材裁剪至所需尺寸，平整放置于上料位并完成定位与夹紧；
3. 在控制面板设置加热温度、预热时间及真空保压时间；
4. 机器自动启动加热；板材软化后自动下移贴合模具，随后真空吸力启动完成成型；
5. 维持真空压力进行冷却定型，完成后加热组件自动上升；
6. 人工取出半成品，使用标准模具板手动裁切去除废边；
7. 清理废料，重新上料，进入循环批量生产。

### 常见问题解答（FAQs）
**Q1：该设备能否加工环保型 APET 和 PETG 材料？**  
**A1：** 可以。其加热与真空系统特别优化，适用于环保塑料，成型过程中不会出现发白或开裂现象。

**Q2：成型高度是否可以定制更高？**  
**A2：** 标准最大成型高度为 200mm。可根据产品深度需求，定制加长行程与加深模具。

**Q3：设备是否包含成型铜模和裁切板？**  
**A3：** 标配手动裁切模具板；成型铜模需根据您的产品另行定制。

**Q4：是否适合 24 小时不间断大批量生产？**  
**A4：** 重型稳定结构支持长时间连续运行，产能可达每小时 200～300 模。

**Q5：对板材厚度是否有限制？**  
**A5：** 标准适用厚度范围为 0.2–1.5mm。超出此范围的板材将导致加热不均，影响成型质量。
