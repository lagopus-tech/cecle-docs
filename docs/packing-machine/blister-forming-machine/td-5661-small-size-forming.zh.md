## 4. 操作流程
1. 根据产品尺寸安装匹配的铜模，固定模座并调试真空管路；  
2. 将塑料板材裁剪至所需尺寸，平铺于上料平台并夹紧定位；  
3. 在控制面板设置加热温度、加热时间及真空保压时间，启动预热加热；  
4. 将加热软化的板材移下，贴合模具后开启真空负压进行成型；  
5. 保持真空状态冷却定型，完成后关闭真空并升起加热组件；  
6. 手动取出成型泡罩托盘，修除毛边，重复进料实现连续生产。

**Q1：该设备能否加工环保型 APET 和 PETG 板材？**  
**A1：** 可以。其加热与真空系统完全兼容 APET 与 PETG，可稳定实现良好成型效果。

**Q2：成型高度是否可增加？**  
**A2：** 标准最大高度为 200mm。可根据需求定制加深模具或加长行程。

**Q3：机器是否附带成型模具？**  
**A3：** 不包含。铜模或铝模需根据您的产品单独定制。

**Q4：是否适合大规模高产量生产？**

**A5：** 标准适用厚度范围为 0.2～1.5mm。超出此范围的板材无法均匀受热，影响成型质量。
