## 4. 操作流程
1. 手动将胶囊、药片等产品放入PVC泡罩中；
2. 将装好产品的PVC泡罩放入机器模具，再覆盖铝箔膜；
3. 打开设备开关，下压手动杠杆完成封合；
4. 使用刀具或剪刀裁去泡罩周围的多余铝箔，获得成品包装。
