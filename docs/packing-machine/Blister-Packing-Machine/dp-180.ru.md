# DP-180 Вертикальная машина для упаковки в блистерные упаковки

> **Основной обзор:**  
> Вертикальная полуавтоматическая пневматическая машина DP-180 предназначена для герметичного соединения алюминиевой фольги с капсулами и таблетками. Идеально подходит для небольших и средних фармацевтических заводов, производителей медицинских изделий и клиник. Машина оснащена интеллектуальной системой управления PLC + сенсорный экран для точной работы. Ключевое преимущество — автоматическая подача алюминиевой фольги с высокоточным фотоэлектрическим датчиком регистрации, обеспечивающим идеальную выравнивание штамповки без смещения рисунка на печатной фольге. Работает с мощностью пневматического пресса 0,4 Т (требуется внешний воздушный компрессор), обеспечивая стабильную производительность от 10 до 15 штук в минуту. С полной возможностью кастомизации форм и опциональной функцией кодирования даты/серии, DP-180 предлагает компактное, высокоэффективное и надежное решение для упаковки в блистеры.

## 1. Обзор продукта
DP-180 — вертикальная пневматическая машина для упаковки в блистеры из алюминиевой фольги, специально разработанная для капсул, таблеток и аналогичных продуктов.  
Машина использует систему управления PLC + сенсорный экран, автоматическую подачу алюминиевой фольги, фотоэлектрическую регистрацию и пневматическое поднятие нагревательного элемента. Формы можно изготовить по образцам клиентов. Устройство работает стабильно, простое в эксплуатации, подходит для производства малых и средних партий.

---

## 2. Ключевые преимущества
1. Пневматическое управление подъемом нагревательного элемента, стабильное и надежное действие  
2. Автоматическая подача алюминиевой фольги с фотоэлектрической регистрацией (машина оснащена фотоэлектрическим датчиком для обнаружения цветовой метки на фольге. Подача фольги осуществляется с двумя скоростями: сначала быстро, затем замедляется при приближении к датчику. Двигатель останавливается после обнаружения метки, что гарантирует точное совпадение рисунка на ПВХ-блистерах и исключает смещение, особенно важно для печатной алюминиевой фольги с аккуратным и красивым результатом)  
3. PLC + сенсорный экран + цифровой реле времени для точного контроля температуры и времени  
4. Быстрая замена форм, простое обслуживание, подходит для различных видов продукции  
5. Индивидуальная настройка форм по размеру и форме блистера клиента  
6. Возможность кастомизации функции интегрированной герметизации + кодирования (серийный номер / дата)  
7. Компактная конструкция, малая площадь, простое управление, подходит для небольших фабрик

## 4. Процесс работы
1. Ручная загрузка капсул, таблеток и других изделий в ПВХ-блистеры  
2. Установка загруженного блистера в форму машины  
3. Нажатие на ножную педаль для запуска термосварки  
4. Машина автоматически подает/перематывает алюминиевую фольгу и выполняет фотоэлектрическую регистрацию (фотоэлектрический датчик обнаруживает цветовую метку с двухскоростным управлением, обеспечивая точное выравнивание рисунка и исключая смещение)  
5. Обрезка краев ножницами или режущим устройством  
6. Получение готового упакованного блистера
