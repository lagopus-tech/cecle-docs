## 1. 产品概述  
DP-180 是一款专为胶囊、片剂等产品设计的立式气动铝塑泡罩包装机，用于铝箔密封。  
采用PLC + 触摸屏控制，具备自动铝箔供料、光电定位和气动热压升降功能。模具可根据客户提供的泡罩样品进行定制。机器运行稳定，操作简便，适合小批量至中批量生产。

---

## 2. 核心优势  
1. 气动控制热压板升降，动作稳定可靠  
2. 自动铝箔供料配合光电定位（设备内置光电传感器，检测铝箔上的色标；铝箔采用双速进给：先快速前进，接近传感器时减速定位色标，一旦识别即停止电机，确保PVC泡罩上图案精准对齐，避免偏移，特别适合印刷铝箔产品，封口整齐美观）  
3. PLC + 触摸屏 + 数字时间继电器，实现温度与时间的精确控制  
4. 模具更换快捷，维护方便，适用多种产品  
5. 可根据客户需求定制模具尺寸与形状  
6. 支持定制化集成封口 + 编码（批号/日期）功能  
7. 结构紧凑，占地面积小，操作简单，适合小型工厂使用

## 4. 操作流程  
1. 手动将胶囊、片剂等产品放入PVC泡罩  
2. 将装有产品的PVC泡罩放入机器模具中  
3. 踩下脚踏开关启动热封程序  
4. 机器自动回卷/供料铝箔，并完成光电定位（光电传感器通过双速控制识别铝箔色标，确保图案精准对齐，避免偏移）  
5. 使用剪刀或切边机裁切边缘  
6. 取出成品密封泡罩包装
