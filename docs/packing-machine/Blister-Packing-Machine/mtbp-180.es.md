## 4. Proceso de Operación
1. Coloque manualmente cápsulas, comprimidos u otros productos dentro de los blisters de PVC;
2. Coloque el blister de PVC cargado en el molde de la máquina, luego agregue la película de hoja de aluminio;
3. Encienda el interruptor del dispositivo y presione hacia abajo la palanca manual para completar el sellado;
4. Corte el exceso de hoja de aluminio alrededor del blister con una tijera o cortador para obtener el paquete terminado.
