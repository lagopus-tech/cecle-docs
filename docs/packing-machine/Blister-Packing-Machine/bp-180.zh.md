## 1. 产品概述
BP-180 是一款半自动平板式铝箔-PVC 泡罩包装机，专为胶囊、片剂等小型固态产品的铝箔-PVC 泡罩密封包装而设计。作为基础款经济机型，采用气动驱动与数字温控技术，结构紧凑、操作简便、维护成本低，适用于中小批量生产，广泛应用于制药、保健、电子元件等行业。

## 2. 核心优势
- **专业设计，强适应性**：专为胶囊铝箔包装设计，最大模具尺寸达 180mm×140mm（7.09"×5.51"），兼容相应尺寸的 PVC 泡罩与铝箔材料。
- **气动驱动，稳定高效**：气动控制加热板升降，压力均匀（0.4T），密封牢固。配备数字时间继电器，可精准控制加热时间（3–5秒），确保优异的封口性能。
- **快速换模，灵活定制**：模具可快速更换以适应不同产品生产；模具按泡罩尺寸/形状定制，支持批号与日期的压印定制。
- **操作简便，入门门槛低**：通过脚踏开关控制，操作员仅需手动放置铝箔，无需专业技能，易于上手。
- **耐用可靠，售后无忧**：标准化工厂生产，核心部件质量可控。提供 1 年保修（易损件除外）。
- **紧凑节能，成本低廉**：机身轻巧，占地小，功率仅 1000W。无需复杂安装，连接外置空气压缩机即可使用。

## 4. 操作流程
1. 手动将胶囊、片剂等产品放入 PVC 泡罩中。  
2. 将装有产品的 PVC 泡罩放入机器模具，再覆盖一片铝箔。  
3. 踩下脚踏开关，机器自动下压完成热封。  
4. 用剪刀或裁切机裁切泡罩并修整边缘。  
5. 取得成品密封包装。

### 5.2 常见问题
**Q：BP-180 与 CP-210 的区别是什么？**  
A：BP-180 为基本款，无自动铝箔供料功能，需人工逐片放置铝箔；CP-210 为升级版，支持自动铝箔供料，效率更高，价格也更高。

**Q：机器能否打印批号和生产日期？**  
A：可以，模具可定制压印功能，实现同步热封与批号/日期打印。

**Q：设备售后维护是否方便？**  
A：提供一站式售后服务，1 年保修（易损件除外），保修期后终身维护。问题可通过邮件反馈，海外可安排工程师现场服务。

**Q：对包装材料有何要求？**  
A：PVC 泡罩最大尺寸不得超过 180mm×140mm（7.09"×5.51"），铝箔需适配热封温度。建议使用配套专用铝箔，以保障封口质量。
