## 1. Обзор продукта
Модель TBP-180 — это настольная пневматическая упаковочная машина, специально разработанная для герметизации блистеров из ПВХ + алюминиевая фольга небольших изделий, таких как капсулы, таблетки, мелкие детали и электронные компоненты. Использует прессование цилиндра + цифровое отображение времени, отличается стабильной работой и простотой эксплуатации. Подходит для малых партий, лабораторий, магазинов, производств и небольших внешнеэкономических заказов.

## 2. Ключевые преимущества
- **Пневматическое прессование:** равномерное давление, надежное уплотнение, экономия труда, высокая эффективность

- **Индивидуальные формы:** изготовление форм по образцам клиентских блистеров (необходимо 6–8 образцов), быстрая замена форм, подходит для нескольких видов продукции
- **Широкая совместимость напряжения:** поддержка 110 В / 220 В, 50 / 60 Гц для глобального использования

## 4. Этапы работы
1. Ручная загрузка капсул, таблеток и других изделий в блистер из ПВХ;
2. Установка блистера с изделиями в форму машины, затем накладывание алюминиевой фольги;
3. Нажатие кнопки запуска — машина автоматически опускается и завершает процесс уплотнения;
4. Обрезка лишней алюминиевой фольги по краю блистера ножницами для получения полностью упакованного изделия.
