## 4. 操作步骤  
1. 安装PVC薄膜卷与铝箔卷，调整薄膜进给位置与张力；  
2. 在触摸屏上设置成型温度、热封温度、运行速度等参数；  
3. 启动机器进行预热与空运行测试，检查成型、封口、冲孔是否正常；  
4. 放入物料，启动自动运行，设备将自动完成泡罩成型、填充、热封、打码与冲孔；  
5. 自动收集成品与废料，实现连续自动化生产；  
6. 生产结束后停机，切断电源与气源，清洁设备及模具。
