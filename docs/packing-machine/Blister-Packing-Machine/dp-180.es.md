## 1. Visión General del Producto
La DP-180 es una máquina vertical neumática para empaquetado por blister de aluminio-plástico especialmente diseñada para el sellado de cápsulas, comprimidos y productos similares.  
Adopta control PLC + pantalla táctil, alimentación automática de película aluminio, registro fotoeléctrico y elevación por prensa térmica neumática. Los moldes pueden personalizarse según muestras de blister del cliente. La máquina funciona de forma estable, es fácil de operar y es adecuada para producciones de pequeño a mediano volumen.

---

## 2. Ventajas Principales
1. Control neumático para elevación de placa caliente, acción estable y confiable  
2. Alimentación automática de película aluminio con registro fotoeléctrico (la máquina incluye un sensor fotoeléctrico que detecta marcas de color en la película aluminio. La película se mueve a dos velocidades: primero rápido, luego ralentiza al acercarse al sensor. El motor se detiene al detectar la marca de color, asegurando una alineación precisa del patrón en los blisters de PVC y evitando desplazamientos, ideal para películas aluminio impresas con sellos limpios y estéticos)  
3. PLC + pantalla táctil + relé digital para control preciso de temperatura y tiempo  
4. Cambio rápido de molde, mantenimiento sencillo, adecuado para diversos productos  
5. Personalización de moldes según tamaño y forma del blister del cliente  
6. Función personalizable de sellado + codificación integrada (número de lote / fecha)  
7. Estructura compacta, bajo espacio ocupado, operación simple, ideal para pequeñas fábricas

## 4. Proceso de Operación
1. Coloque manualmente cápsulas, comprimidos u otros productos en los blisters de PVC  
2. Coloque el blister de PVC cargado en el molde de la máquina  
3. Pise el pedal de pie para iniciar el sellado térmico  
4. La máquina alimenta automáticamente la película aluminio y realiza el registro fotoeléctrico (el sensor detecta las marcas de color con control de dos velocidades para asegurar una alineación precisa del patrón y evitar desplazamientos)  
5. Acorte los bordes con tijeras o máquina cortadora  
6. Obtenga el paquete de blister sellado final
