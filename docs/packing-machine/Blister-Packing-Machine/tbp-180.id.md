## 4. Langkah Operasi
1. Masukkan kapsul, tablet, dan produk lain secara manual ke dalam blister PVC;  
2. Letakkan blister PVC berisi produk ke dalam cetakan mesin, lalu tambahkan film foil aluminium;  
3. Tekan saklar perangkat, mesin akan secara otomatis menekan turun untuk menyelesaikan proses penyegelan;  
4. Potong sisa film foil aluminium di bagian tepi blister menggunakan gunting agar mendapatkan kemasan blister yang utuh.
