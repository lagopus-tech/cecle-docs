## 4. Étapes d’utilisation
1. Insérer manuellement les gélules, comprimés ou autres produits dans la plaquette PVC ;  
2. Placer la plaquette PVC contenant les produits dans le moule de la machine, puis ajouter le film d’aluminium ;  
3. Appuyer sur le bouton de commande : la machine descend automatiquement pour effectuer l’opération de scellement ;  
4. Couper les excédents de film d’aluminium autour de la plaquette à l’aide de ciseaux afin d’obtenir un emballage blister entièrement scellé.
