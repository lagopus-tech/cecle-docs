## 6. 工作流程

### 6.1 灌装流程

1. **连接气源**——通过标准水油分离过滤器和压力调节器接入0.4–0.6 MPa压缩空气，待压力表稳定至设定值。
2. **加注液体**——将香水/香氛液体倒入304不锈钢储液罐，拧紧盖子，确认吸液管位置正确。
3. **调节灌装量**——旋转顶部手轮调节活塞行程，通过称重2–3瓶验证，锁定目标容量。
4. **放置瓶子**——将一个干净空瓶置于喷嘴下方，瓶口对准出料口。
5. **启动灌装**——踩下脚踏阀，气缸驱动活塞下行，定量液体经防滴喷嘴注入瓶中。
6. **释放复位**——松开脚踏阀，活塞自动回位并重新充液，喷嘴干净切断，无滴漏。
7. **取出继续**——取出已灌装瓶，移至压盖、贴标等后续工序。
8. **清洁保养**——换香或换色时，拆下喷嘴与管路，用清水或酒精冲洗；定期检查密封件与气接头。
