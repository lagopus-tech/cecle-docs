## Краткое резюме ИИ

Серия FF6 — это **полуавтоматическая горизонтальная полностью пневматическая машина для дозирования пасты (все пневматика / без электричества)** от Wenzhou T&D — разработана для клиентов, которым необходима **взрывобезопасная работа**, **дозирование легковоспламеняющихся продуктов** или **отсутствие электроснабжения на объекте**. В серии представлено 8 моделей (FF6-50/100/300/500/1000/2500/3000/5000) с диапазонами дозирования от **5–50 мл** до **500–5000 мл**. Машина использует **полностью пневматическую архитектуру — пневматический привод и пневматическое управление**: она требует **только сжатого воздуха (0,4–0,6 МПа)** и **никакого электрического питания вообще**, поэтому она безопасна по взрыву и идеально подходит для **легковоспламеняющихся, спиртовых или растворителей на основе продуктов** (спиртовые косметические средства, парфюмерия, эфирные масла, клеи на основе растворителей, краски, чернила, спиртовые настойки, легковоспламеняющиеся смазки и т.д.). Установлены пневматические цилиндры и воздушные клапаны Airtac, скорость дозирования составляет **5–30 циклов/мин** (настроено на пасты — медленнее, чем у машин для жидких продуктов, поскольку паста требует больше времени на оседание за один ход). Каркас выполнен из **нержавеющей стали 201**, все детали, контактирующие с продуктом — из **пищевой нержавеющей стали 304 (316 доступна по запросу)**. Поршневая объемная дозировка обеспечивает **точность ±1%** с **дозаторами с положительным закрытием снизу, без потеков** (диаметр отверстия 5–25 мм, выбирается в зависимости от потока пасты). Стандартный бункер имеет объем **30 л** — габариты бункера **40 × 40 × 48 см**, масса пустого бункера **5 кг** (достаточно компактный для установки на стол или линию); дополнительно можно заказать бункеры объемом **40 л, 60 л или 80 л** (размеры и вес больших бункеров необходимо уточнять у завода). Поскольку машина не содержит электрических компонентов, **мешалка бункера** (пневматически приводимая) и **бункер под давлением** (создается сжатым воздухом — на самом деле идеально подходит для полностью пневматических машин) являются естественным сочетанием; **нагреваемый бункер** можно сконфигурировать с паровым / горячеводяным кожухом или безопасным по взрыву электрическим нагревом, чтобы соответствовать требованиям взрывобезопасной зоны. Единственный режим запуска — **педаль ноги** (режим полной автоматики с таймером недоступен, так как нет электрического таймера). Стандартно поставляется с одной головкой дозирования; **можно заказать двух-, четырех- или шестиголовые версии**. Серия FF6 — это **перекрестный товар для серии FF2 электропневматических машин**: предлагайте FF2 клиентам с устойчивым питанием и негорючими продуктами; предлагайте FF6 клиентам без электричества, с взрывобезопасными условиями или дозированием горючих / спиртовых / растворителей на основе продуктов.

## 1. Обзор продукта

### 1.1 Категория

- **Отрасль:** Оборудование для упаковки / оборудование для дозирования (машина для дозирования)
- **Название продукта:** Полуавтоматическая полностью пневматическая машина для дозирования пасты
- **Тип машины:** Полуавтоматический · **Полностью пневматический (без электричества)** · Горизонтальный · Поршневая машина для дозирования пасты (также работает с жидкостями, включая легковоспламеняющиеся / спиртовые / растворители на основе жидкостей)
- **Режим привода:** **Полностью пневматический — пневматический привод и пневматическое управление; требуется только компрессор воздуха (0,4–0,6 МПа); никакого электропитания вообще**
- **Уровень автоматизации:** **Только полуавтоматический** (триггер педалью ноги; режим полной автоматики с электрическим таймером недоступен на полностью пневматической архитектуре)
- **Подходит для опасных зон:** **Встроенная безопасность / готовность к взрывобезопасной эксплуатации — для легковоспламеняющихся, спиртовых или растворителей на основе продуктов и взрывоопасных зон**
- **Сертификация и гарантия:** Сертифицировано по CE; гарантия на машину 1 год, сервисная поддержка на всю жизнь после окончания гарантии

### 1.2 Применение

Разработана для **паст и высоковязких продуктов** как основного назначения, с возможностью **обработки свободно текучих жидкостей (включая легковоспламеняющиеся / спиртовые / растворители на основе жидкостей)** как вторичной функции — одна машина, два типа продуктов, **электричество не требуется**. Типовые продукты и отрасли:

**Основное — Пасты / Высоковязкие (включая легковоспламеняющиеся пасты):**

- **Косметика и личная гигиена (спиртовые / легковоспламеняющиеся):** гель для рук на спирту, спиртовой тоник, бальзам для парфюмерии, легковоспламеняющийся крем
- **Продукты питания:** соус, кетчуп, джем, мед, арахисовое масло, шоколадная паста, горчица, майонез
- **Бытовая химия:** паста для стирки, мыло для посуды (густое), полироль для обуви
- **Фармацевтика:** мази, местные кремы, лекарственные пасты, спиртовые настойки (малые объемы, легковоспламеняющиеся)
- **Химикаты:** клеи на основе растворителей, легковоспламеняющиеся смазки, герметики, краски, чернила

**Вторичное — Свободно текучие жидкости (включая легковоспламеняющиеся жидкости):**

- спиртовые жидкости (парфюмерия, эфирные масла, спиртовые настойки, базовая жидкость для дезинфекторов), растворители (разбавитель, очиститель), краски и чернила (низкая вязкость), питьевая вода, сок, молоко, пищевое масло, жидкие приправы

**Типичные клиенты:** производители паст / косметики / продуктов, заполняющие легковоспламеняющиеся или спиртовые продукты; мастерские в **взрывоопасных зонах** (электричество запрещено); предприятия **без электроснабжения на объекте** (отдаленные участки, мобильные мастерские, определенные регионы экспорта с нестабильной сетью); фармацевтические и химические производители, заполняющие легковоспламеняющиеся растворители; клиенты, которые ценят минимальные эксплуатационные расходы (никакой счет за электроэнергию вообще); компании, заполняющие как пасты, так и жидкости (включая легковоспламеняющиеся товары) и желающие иметь одну машину для обоих типов продукции.

### 1.3 Основные функции

- **Поршневая объемная дозировка, оптимизированная для паст:** поршень, приводимый цилиндром, с регулируемым ходом — обрабатывает густые продукты (соус, крем, мазь, клей на основе растворителя) без разбрызгивания или разрыва; объем можно изменять бесступенчато в пределах диапазона модели; изменение параметров без замены деталей
- **Дополнительная возможность работы с жидкостями (включая легковоспламеняющиеся жидкости):** переключение с пасты на жидкость (включая спиртовые / растворители на основе жидкости) возможно сменой насадки и регулировкой хода поршня; одна машина охватывает оба типа продуктов с полной взрывобезопасностью
- **Полностью пневматический привод и управление — без электричества:** пневматическое управление осуществляется через пневматические клапаны; на машине нет электрических компонентов вообще; нет предохранителей, реле, таймеров, ПЛК — встроенная безопасность по конструкции
- **Одиночный режим триггера — педаль ноги:** оператор запускает каждый цикл педалью ноги; **режим полной автоматики с таймером недоступен** на полностью пневматической архитектуре (это компромисс по сравнению с электрическим управлением FF2: теряется автоматический таймер, но выигрывается взрывобезопасность)
- **Без потеков при дозировании:** насадки с положительным закрытием снизу — выпуск прекращается моментально после окончания дозировки; **нет потеков, нет «струн», нет остатков пасты на горлышках бутылок** (критично для косметики, продуктов питания и легковоспламеняющихся продуктов)
- **Настройка количества дозирования:** стандартно одна головка; **возможны двух-, четырех- или шестиголовые конфигурации** для пропорционального увеличения производительности
- **Регулируемый объем дозирования и скорость:** подстраивается под различные форматы контейнеров (маленькие баночки, большие ведра) и темпы линии
- **Гибкие варианты бункера / подачи:** стандартный **бункер объемом 30 л**; дополнительные **бункеры объемом 40 л / 60 л / 80 л** уменьшают количество остановок для пополнения. Поскольку машина полностью пневматическая, **мешалка бункера** (пневматически приводимая) и **бункер под давлением** (подпитка сжатым воздухом — естественный выбор) идеально сочетаются; **нагреваемый бункер** можно установить с паровым / горячеводяным кожухом или безопасным по взрыву электрическим нагревом для взрывобезопасной эксплуатации — выбирайте тип бункера в зависимости от характеристик продукта.

## 2. Ключевые преимущества

> **Полностью пневматическая / без электричества — главный аргумент продаж этой серии — первые пять преимуществ ниже сосредоточены именно на этом. Взрывобезопасность — главное преимущество.**

1. **Никакого электричества вообще — встроенная безопасность, взрывобезопасность по конструкции.** В серии FF6 нет абсолютно никаких электрических компонентов (нет двигателей, нет соленоидов, нет таймеров, нет реле, нет ПЛК). Работает только на сжатом воздухе (0,4–0,6 МПа). Поскольку нет электрических элементов, способных вызвать искру, машина встроенно безопасна и **подходит для взрывоопасных зон и дозирования легковоспламеняющихся, спиртовых или растворителей на основе продуктов** — открывает рынки, которые серия FF2 электропневматических машин просто не может обслуживать.
2. **Мгновенная замена для легковоспламеняющихся, спиртовых или растворителей на основе продуктов.** Для таких продуктов, как спиртовой дезинфектор для рук, парфюмерия, спиртовая настойка, эфирные масла, клей на основе растворителей, краски, чернила, разбавитель, легковоспламеняющаяся смазка — FF6 заполняет их безопасно без риска возгорания. FF2 не может этого сделать; FF6 — это ответ.
3. **Не нужна электросеть — работает в любом месте.** Машине нужен только компрессор воздуха. Она работает в мастерских **без электроснабжения на объекте**, удаленных участках, мобильных линиях, регионах с нестабильной сетью и на полевых объектах. Никакого электрика, никакой подгонки напряжения, никаких проблем с заземлением — просто подключите воздух и начинайте работу.
4. **Нет счета за электроэнергию — минимальные эксплуатационные расходы.** Поскольку машина потребляет нулевую электрическую мощность, единственные затраты — это сжатый воздух. Для предприятий с высокой нагрузкой это существенно снижает постоянные расходы; для редко используемых машин — полностью исключает электроэнергию из бюджета эксплуатации.
5. **Простота в эксплуатации — подключите воздух и начните.** Подключите компрессор воздуха (0,4–0,6 МПа), и производство может начаться. Нет электрического пульта управления, который нужно учить — только пневматический блок управления и педаль ноги. Новые операторы учатся за минуты.
6. **Пневматические цилиндры и воздушные клапаны Airtac.** Цилиндры и пневматические клапаны Taiwan Airtac обеспечивают стабильную работу и долгий срок службы. Запчасти доступны по всему миру, и стоимость технического обслуживания остается низкой. Отсутствие электрики означает отсутствие электрических запчастей, плат реле, отказов датчиков.
7. **±1% точность дозирования + без потеков насадки.** Поршневая дозировка стабильна и надежна для паст (нет недозировки или переполнения); насадки с положительным закрытием снизу устраняют потеки, «струны» и остатки пасты, сохраняя горлышки бутылок и рабочий стол чистыми — критически важно для косметических банок, пищевых контейнеров, особенно для легковоспламеняющихся продуктов, где остаток на горлышке бутылки — источник пожара.
8. **Бункер под давлением — идеальное естественное сочетание.** Поскольку FF6 работает на сжатом воздухе, **бункер под давлением** (подпитка сжатым воздухом) интегрируется без проблем — никакого дополнительного источника энергии не нужно. Для очень вязких паст (клеи, тяжелые смазки, густая шоколадная паста) бункер под давлением превращает «сложно подаваемый» продукт в «стабильный поток».
9. **8 моделей охватывают 5–5000 мл; изменение параметров — бесплатно.** Измените ход поршня, чтобы изменить объем дозирования — без замены деталей; изменение параметров занимает всего 2–3 минуты. Охватывает всё — от образцов косметики до больших ведер.
10. **Каркас из нержавеющей стали 201 + детали, контактирующие с продуктом, из пищевой нержавеющей стали 304; 316 доступна.** Все нержавеющие каркас и пищевые детали, контактирующие с продуктом, соответствуют требованиям безопасности пищевых продуктов по умолчанию (304); **детали, контактирующие с продуктом, можно заказать из нержавеющей стали 316** для повышенной устойчивости к кислотам, щелочам и коррозии — подходит для фармацевтических, химических и коррозионных продуктов. Нержавеющий клапанный узел устойчив к коррозии и легко поддерживается в чистоте.
11. **Гибкий бункер — 30 л стандартно, 40 л / 60 л / 80 л опционально, можно настроить мешалку / под давлением / нагрев.** Стандартный **бункер объемом 30 л**; **40 л, 60 л или 80 л** — большие размеры сокращают количество остановок на высокопроизводительных линиях. Для сложных в работе продуктов установите **мешалку бункера** (пневматически приводимую, без электричества), **бункер под давлением** (подпитка сжатым воздухом — естественное сочетание) или **нагреваемый бункер** (паровой / горячеводяной кожух или безопасный по взрыву электрический нагрев для взрывобезопасной эксплуатации) — подбирайте бункер под характеристики продукта.
12. **Горизонтальный, компактный и легкий.** Горизонтальный корпус имеет малую площадь и весит всего 22–32 кг (нетто), поэтому он помещается на столе, рабочем столе или в существующей линии и легко перемещается.
13. **Силиконовые уплотнения пищевого класса (выдерживают до 200 °C).** Стандартные пищевые силиконовые кольца; при дозировании коррозионных или липких продуктов можно установить уплотнения из коррозионностойкого резины.
14. **Многоголовочный вариант (2 головки / 4 головки / 6 головок).** Начните с одной головки; когда объем растет, перейдите на **двух-, четырех- или шестиголовую** машину (один пневмоцилиндр на головку) — без замены оборудования, без потерь инвестиций.

### 4.2 ЧАВО

**В1: Нужна ли этой машине электрическая энергия?**  
О: **Нет.** Серия FF6 — это **полностью пневматическое устройство (все пневматическое приводное и управляющее оборудование)**: машина не содержит никаких электрических компонентов — ни двигателей, ни соленоидов, ни таймеров, ни реле, ни ПЛК. Она работает исключительно на сжатом воздухе и требует только **компрессора воздуха (0,4–0,6 МПа)**. **Электричество не используется, нет счета за электроэнергию, и нет источника искры — что делает ее встроенно безопасной для взрывобезопасной эксплуатации.**

**В2: Нужен ли мне компрессор воздуха?**  
О: Да. FF6 — полностью пневматическая, поэтому она должна быть подключена к компрессору воздуха, подающему **0,4–0,6 МПа**. Обычный маленький поршневой компрессор (с ресивером/баком) достаточен; его можно добавить к заказу.

**В3: Машина взрывобезопасна? Можно ли заполнять спиртовые или растворители на основе продуктов?**  
О: **Да — это главный аргумент продаж серии FF6.** FF6 не содержит электрических компонентов, поэтому на ней нет источника искры. Она **встроенно безопасна / взрывобезопасна по конструкции** и **подходит для заполнения легковоспламеняющихся, спиртовых или растворителей на основе продуктов** (спиртовой дезинфектор для рук, парфюмерия, эфирные масла, спиртовые настойки, клей на основе растворителей, краски, чернила, разбавитель, легковоспламеняющаяся смазка и т.д.) и для работы в взрывоопасных зонах. Если клиенту нужно заполнять легковоспламеняющиеся продукты, FF6 — единственный вариант в этой линейке.

**В4: Какова точность и скорость дозирования?**  
О: Точность — **в пределах ±1%** (поршневая дозировка — стабильная, без дрейфа); скорость — **5–30 циклов/мин** (настроена на пасты; медленнее, чем у машин для жидких продуктов, поскольку паста требует больше времени на оседание за один ход), и скорость регулируется.

**В5: Может ли она заполнять как пасты, так и жидкости? Может ли она обрабатывать легковоспламеняющиеся продукты?**  
О: **Да — FF6 оптимизирована для паст и высоковязких продуктов, а также заполняет свободно текучие жидкости, включая легковоспламеняющиеся / спиртовые / растворители на основе продуктов в обоих категориях.** Основное применение: соус, кетчуп, джем, мед, арахисовое масло, шоколадная паста, горчица, майонез; легковоспламеняющиеся или спиртовые косметические кремы и гели; мази; легковоспламеняющиеся или растворители на основе клеи, краски, чернила; легковоспламеняющиеся смазки. Вторичное применение: спиртовые жидкости (парфюмерия, эфирные масла, спиртовые настойки, базовая жидкость для дезинфекторов), растворители, а также вода, сок, молоко, пищевое масло. **Одна машина охватывает оба типа продуктов — пасты и жидкости — с полной взрывобезопасностью — поменяйте насадку, отрегулируйте ход поршня, переключитесь на другой тип продукции за несколько минут.**

**В6: Может ли FF6 работать полностью автоматически с электрическим таймером?**  
О: **Нет.** Поскольку FF6 полностью пневматическая и не содержит электрических компонентов, **режим автоматического электрического таймера недоступен** — машина поддерживает **только запуск педалью ноги**, то есть **полуавтоматический режим**. Каждый цикл инициируется оператором, нажимающим на педаль. Если клиенту нужна полностью автоматическая работа без оператора, он должен выбрать **серии FF2 электропневматических машин** (с электрическим таймером) — при условии, что мастерская не находится в взрывоопасной зоне и продукт не легковоспламеняющийся.

**В7: Чем отличается FF6 от FF2?**  
О: Обе — поршневые машины для дозирования пасты, охватывающие 5–5000 мл с теми же вариантами бункеров и тем же диапазоном насадок. Различия:

- **FF2** — **электропневматическая интеграция** — требуется 220 В / 50–60 Гц (~100 Вт) **плюс** воздух (0,4–0,6 МПа). Электрическое управление стабилизирует время циклов и позволяет использовать **режим автоматического таймера**. Лучше для длительных непрерывных циклов и стабильного ритма. **Не подходит** для взрывоопасных зон или легковоспламеняющихся продуктов.
- **FF6** — **полностью пневматическая** — требуется **только** воздух (0,4–0,6 МПа); **никакого электричества вообще**. Встроенно безопасна для **взрывоопасной эксплуатации и легковоспламеняющихся / спиртовых / растворителей на основе продуктов**. Компромисс: теряется режим автоматического таймера (только педаль ноги) и стабильность циклов, обеспечиваемая электрическим управлением FF2.

Выбирайте **FF2**, если: у мастерской стабильное электропитание, продукт негорючий, клиент хочет наиболее стабильные циклы и режим автоматического таймера. Выбирайте **FF6**, если: у мастерской нет электричества, она находится в взрывоопасной зоне, или продукт легковоспламеняющийся / спиртовой / на основе растворителей.

**В8: Являются ли детали, контактирующие с продуктом, пищевыми?**  
О: Каркас — нержавеющая сталь 201, **все детали, контактирующие с продуктом, — пищевая нержавеющая сталь 304**, соответствуют требованиям безопасности пищевых продуктов; **316 нержавеющая сталь может быть настроена** (повышенная устойчивость к кислотам, щелочам и коррозии — подходит для фармацевтических, химических и коррозионных продуктов). Уплотнения — пищевой силикон (выдерживают до 200 °C).

**В9: Будет ли происходить потек, «струна» или остаток пасты?**  
О: Нет. Насадка использует **положительное закрытие снизу** — выпуск закрывается моментально после окончания дозирования, гарантируя работу без потеков. **Для паст это критично:** нет «струн», нет остатков пасты, нет загрязнений на горлышках бутылок. **Для легковоспламеняющихся продуктов это также безопасность от пожара** — нет легковоспламеняющегося остатка на горлышке бутылки. Диаметр отверстия насадки можно выбрать в диапазоне 5–25 мм (подбирается под поток пасты).

**В10: Трудно ли менять объем дозирования или переключаться между пастой и жидкостью на FF6?**  
О: Совсем нет. ## 6. Процесс работы

### 6.1 Процесс дозирования

```
① Настройка
   Подключите компрессор воздуха; установите давление подачи на 0,4–0,6 МПа
   (электрическое подключение не требуется)
        │
② Подача
   Добавьте пасту (или жидкость — включая легковоспламеняющиеся / спиртовые / растворители на основе продуктов)
   в бункер (стандартный 30 л; опционально 40/60/80 л)
   (мешалка / бункер под давлением / нагреваемый бункер для продуктов, которые требуют этого)
        │
③ Установка объема
   Отрегулируйте ход поршня → установите объем дозирования на цикл (бесступенчато в пределах диапазона)
   При необходимости отрегулируйте скорость дозирования (для паст обычно 5–30 циклов/мин)
        │
④ Установка контейнера
   Разместите банку / бутылку / ведро прямо под насадкой дозирования
   (для паст: используйте насадку для пасты 5–25 мм; для жидкостей: переключитесь на насадку для жидкости 5–25 мм)
        │
⑤ Запуск дозирования
   Педаль ноги (полуавтоматический режим — единственный режим на полностью пневматической FF6)
        │
⑥ Заполнено (точность ±1%)
   Насадка с положительным закрытием снизу → нет потеков, нет «струн»,
   нет остатков пасты (и нет легковоспламеняющегося остатка на горлышках бутылок)
        │
⑦ Следующий контейнер — повторите
   Повторите шаги ④–⑥ со скоростью 5–30 циклов/мин (для паст)
        │
⑧ Очистка и остановка
   Остановите машину; отключите воздух;
   разберите и промойте бункер / поршень / насадку дозирования;
   очистите перед переходом на другой продукт
```
