## 6. Workflow

```
Bottle unscrambling (optional bottle distributing machine) → bottle infeed on conveyor → FA4-500 four-head piston filling → automatic cap placing (cap feeding machine) → DC1 automatic capping → (optional PM-168 inkjet coding) → finished product output
```

1. **Bottle infeed**: Empty bottles are unscrambled and aligned automatically by the bottle distributing machine (optional) and enter the conveyor.
2. **Filling**: German SICK photoelectric sensors detect each bottle, then the four FA4-500 filling heads fill simultaneously by piston metering (50–500 ml); bottom close nozzles prevent dripping; no bottle, no filling.
3. **Cap placing**: The cap feeding machine sorts caps automatically and delivers them to the capping station.
4. **Capping**: The DC1 machine tightens with two screw lids working at the same time; SICK sensors ensure no bottle, no operation.
5. **(Optional) Coding**: The PM-168 inkjet printer prints the production date or batch number.
6. **Output**: Finished bottles are discharged on the conveyor to labelling or cartoning.
