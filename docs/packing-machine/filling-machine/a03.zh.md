## 六、工作流程
1.  **组装**：将料斗安装至机器顶部，确保密封圈位置正确。
2.  **设定容量**：调节机器底部的螺杆，锁定所需灌装体积（2.5–50 ml）。
3.  **加料**：将产品倒入料斗。
4.  **排气/试灌**：按压手柄数次，排出泵腔内空气，并确认出料稳定。
5.  **批量生产**：将瓶子置于喷嘴下方，下压手柄完成灌装，松开后手柄自动回弹。
6.  **清洗**：生产结束后，向料斗倒入温水或清洗液，反复按压手柄以冲洗内部泵系统。
