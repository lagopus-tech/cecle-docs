## 1. 产品概述

### 1.1 产品类别

DF4-1000 属于**液体灌装机 / 吸嘴袋灌装机 / 立式袋灌装机 / Doypack灌装机 / 半自动活塞式灌装机**类别，定位为**适用于柔性袋（立式袋、吸嘴袋、Doypack）的半自动多喷嘴容积式灌装机**。

- 按结构：活塞式 + 底部防滴漏正向关闭喷嘴  
- 按控制：气动操作 + 电动控制（气动驱动 + 电动控制），业内称为“电-气一体化”  
- 按自动化：半自动 / 自动可切换（脚踏开关或自动计时器）  
- 按袋型：立式袋、吸嘴袋、Doypack、普通柔性袋

可作为中小型袋装液体生产线的核心灌装主机，也可与我司封盖机、贴标机、喷码机组合，形成小型袋装包装线。

### 1.2 应用场景

- **饮料、果汁、饮用水袋装** —— 20–1000 ml 立式袋/吸嘴袋灌装，最佳效果适用于无颗粒液体  
- **食用油、橄榄油、葡萄酒袋装** —— 流动性良好、中低粘度液体  
- **液体洗涤剂、洗洁精、洗衣液袋装** —— 家用化学品袋装；腐蚀性版本可选橡胶密封圈  
- **酱料、调味汁、液态奶油、番茄酱等薄质酱料** —— 低粘度薄质酱料（高粘度膏体超出本机型范围）  
- **化妆品爽肤水、精华液、香水** —— 低粘度小袋灌装  
- **OEM加工、小品牌试产** —— MOQ 1套，适合多种袋型与规格快速切换  
- **小批量、多SKU电商包装** —— 四喷嘴同时灌装多个袋子，显著提升小线效率  

### 1.3 核心功能

1. **电-气一体化驱动** —— 气源驱动活塞与阀门，电子控制模块处理计时与切换；比纯气动机型更稳定、控制更精细  
2. **活塞式容积灌装** —— 每头一个缸体，灌装量由活塞行程决定，可在20–1000 ml范围内调节  
3. **四喷嘴同步灌装** —— 标准配置4个防滴漏正向关闭喷嘴；可选1头/2头/4头配置；喷嘴直径3–12 mm可选  
4. **脚踏开关 / 自动计时双模式切换** —— 同一台机器可自由切换半自动与自动模式，操作灵活  
5. **食品级304不锈钢接触部件** —— 316不锈钢版本可选；硅胶O型圈耐温达200°C，符合食品卫生要求；腐蚀性液体可选橡胶密封圈  
6. **底部防滴漏正向关闭喷嘴** —— 灌装完成后，喷嘴底部气缸执行正向关闭，彻底消除滴漏与液体残留于袋口  
7. **特殊喷嘴升降装置** —— 喷嘴头可手动推压并自动抬起，适应柔性袋灌装，对袋口友好  
8. **Airtac气动元件** —— 采用台湾Airtac气动元件，性能可靠

- **电子控制模块**负责计时与计数（定时器、脚踏信号）——比纯气动计时更精确、重复性更高  
- 半自动/自动可切换：一台机器相当于两台，小批量试产用半自动，产能提升后切换至自动  
- 行业称其为“电-气一体化”，是DF系列区别于纯气动机型的核心卖点

- 灌装量通过调节活塞行程设定——结构稳定，无漂移  
- 灌装精度≤0.5%，重复性高

- 喷头数量可选1/2/4头，按实际产能需求下单

- 接触部件为**食品级304不锈钢**（316可选）；阀系统采用同材质不锈钢

### 优势5 | 柔性袋适配性强 + 一机多用

### 4.2 常见问题（FAQ）

**Q1：DF4-1000 适用于哪些液体？**  
适用于流动性良好的液体——水、油、果汁（无颗粒）、液体洗涤剂、酱料、酒类、液态奶油等。含颗粒液体、高粘度膏体、强腐蚀性液体不适用（强腐蚀性液体需橡胶密封圈+316不锈钢配置；请订购前咨询Andrea）。

**Q2：机器需要供电吗？控制方式是电动还是气动？**  
机器**需要220V 50/60Hz电源**，且**必须连接空压机**。DF4系列采用**气动操作 + 电动控制**的混合方案：气源驱动活塞与阀门，电子控制模块处理计时、计数与脚踏信号。相比纯气动机型更稳定、调节更精细；相比纯电动机型更耐粗暴使用，寿命更长。

**Q3：标准有几个喷嘴？可以选1个或2个吗？**  
**标准为4个喷嘴**。可选1头、2头、4头配置——头数越少单价越低，多喷嘴机型能显著提升小袋线产能。

**Q4：如何选择喷嘴直径？**  
**可选3–12 mm**。6 mm喷嘴头常用于一般液体（如水、油、果汁、洗涤剂）；8 mm用于薄酱、酒类、化妆品；10–12 mm用于较稠液体。请确认袋口尺寸与液体粘度，Andrea将推荐合适直径。

**Q5：灌装精度如何？能达到什么水平？**  
**灌装精度 ≤ 0.5%**，属活塞式容积机型典型水平。建议量产前称重2–3个袋子进行校准。

**Q6：喷嘴会滴漏或在袋口留下液体吗？**  
不会。标配**底部防滴漏正向关闭喷嘴**——灌装完成后，喷嘴底部气缸执行正向关闭，无残留滴漏或液体附着。袋口保持清洁，可直接进入下一工序。

**Q7：接触部件是什么材质？卫生等级如何？**  
接触部件为**食品级304不锈钢**（316可选），阀系统为不锈钢结构；密封件为**耐200°C食品级硅胶O型圈**。整机符合食品卫生标准，可直接用于食品袋灌装。

完全不麻烦。同一台机器可切换**立式袋、吸嘴袋、Doypack、普通柔性袋**；更换袋型通常只需更换对应夹具/袋夹，灌装量通过活塞行程调节即可。

不麻烦。管路采用快接连接，接触部件易于拆卸；常规液体可用清水或热水冲洗；油类、酱料先用热水冲洗，再用清水冲净。**强腐蚀性液体换料时，需先用相应清洗剂浸泡后再冲洗。**

## 6. 工作流程

### 6.1 袋装灌装流程

1. **连接气源与电源** —— 确认220 V 50/60 Hz电源到位；连接空压机，设定气压至标准范围（**MPa待确认**）；检查压力表、过滤器、电磁阀信号是否正常。
2. **加料 / 上料** —— 将待灌装液体倒入进料罐（或从上游管道供料），确认接触部件密封件选型正确（硅胶O型圈 / 橡胶密封圈）。
3. **装袋 / 放置袋子** —— 将立式袋 / 吸嘴袋 / Doypack固定在对应夹具或袋夹上，袋口对准灌装头；自动升降装置可自适应袋口位置。
4. **选择模式 / 启动** —— 根据当日生产需求选择“脚踏开关（半自动）”或“自动计时（自动）”模式；两种模式可在同一台机器上即时切换。
5. **容积灌装** —— 启动后，气源驱动活塞，4个防滴漏正向关闭喷嘴同步灌装；单喷嘴流量约20 ml/s，自动完成20–1000 ml范围内的灌装。
6. **正向关闭 / 防滴** —— 达到目标容量后，喷嘴底部气缸执行正向关闭，彻底消除滴漏与袋口残留。
7. **卸袋 / 下游流转** —— 取下已灌装袋子，移至下一工序（封口 / 盖帽 / 贴标 / 喷码 / 包装 / 打包）。
8. **CIP清洗 / 换料** —— 更换液体时，拆下喷嘴与接触部件，用清水或热水冲洗；强腐蚀性液体需先用相应清洗剂浸泡再冲洗。**定期检查硅胶O型圈**是否老化、变形或漏气。
