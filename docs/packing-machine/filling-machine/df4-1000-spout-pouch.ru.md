DF4-1000, производимая Wenzhou T&D Packing Machinery Factory, — это **полуавтоматическая электропневматическая машина для наполнения жидкостей в стоячие и сливные пакеты (машина для наполнения пакетов с носиком)**, специально предназначенная для наполнения жидкостей в гибкие упаковки с носиком, такие как стоячие пакеты, пакеты с носиком и Doypack. Машина использует гибридную систему **пневматических компонентов Taiwan Airtac для привода плюс электронное управление** — пневматическая часть отвечает за процесс наполнения (проталкивание поршня и открытие/закрытие клапана), а электрическая часть — за управление (таймер, сигнал педали, переключение между полуавтоматическим и автоматическим режимами). По сравнению с полностью пневматическими моделями, она оснащена электронным блоком управления, обеспечивающим более стабильный поток и точную регулировку объема наполнения. **Стандартная конфигурация из 4 насадок** (по желанию 1/2 головки), производительность одной насадки около 20 мл/с, регулируемый объем наполнения от 20 до 1000 мл, точность наполнения ≤ 0,5%; поршневое объемное наполнение с **антикапельными положительными запирающими насадками снизу** (диаметр 3–12 мм по выбору), исключающими подтекание. Контактные детали выполнены из **пищевой нержавеющей стали 304** (316 по запросу), а уплотнители — из **пищевых силиконовых манжет, рассчитанных на температуру до 200°C** (резиновые уплотнители по запросу для агрессивных жидкостей), что соответствует требованиям безопасности пищевых продуктов. Работа может осуществляться с переключением между педалью и автоматическим таймером, а также свободно переключаться между полуавтоматическим и автоматическим режимами на одной машине. Подходит для текучих жидкостей — воды, масла, сока (без частиц), жидких моющих средств, соусов, вина, жидкой сметаны и др. Собственная масса около 50 кг, размер упаковки 75×55×55 см, доставляется одна машина в усиленной картонной коробке. МОК — 1 комплект, оплата T/T 100%, срок поставки — в течение 10 дней; гарантия на всю машину — 1 год + пожизненное техническое обслуживание.

## 1. Обзор продукта

### 1.1 Категория продукта

DF4-1000 относится к категории **машин для наполнения жидкостей / машин для наполнения пакетов с носиком / машин для наполнения стоячих пакетов / машин для наполнения пакетов Дойпак / полуавтоматических поршневых машин для наполнения**, позиционируется как **полуавтоматическая многонасадочная объемная машина для наполнения гибких пакетов (стоячий пакет, пакет с носиком, Doypack)**.

- По конструкции: поршневой тип + насадка с нижней антикапельной положительной запиранием  
- По системе управления: пневматическое управление + электрическое управление (пневматически управляемая + электрически управляемая), в индустрии также называется «электропневматическая интеграция»  
- По уровню автоматизации: полуавтомат / автомат (переключаемый) (педаль или автоматический таймер)  
- По типу пакета: стоячий пакет, пакет с носиком, Doypack, обычный гибкий пакет

Может использоваться в качестве **основного наполняющего оборудования** для малых и средних линий по производству пакетов с жидкостью, а также может быть объединена с нашими закрывающими устройствами, маркировочными станками и кодировщиками для создания небольшой линии упаковки пакетов.

### 1.2 Применение

- **Напитки, сок, питьевая вода в пакетах** — наполнение стоячих или пакетов с носиком объемом 20–1000 мл, лучшие результаты с жидкостями без частиц  
- **Пищевое масло, оливковое масло, вино в пакетах** — текучие жидкости с низкой и средней вязкостью  
- **Жидкие моющие средства, мыло для посуды, стиральный порошок** — наполнение пакетов бытовой химии; резиновые уплотнители по запросу для агрессивных версий  
- **Соус, приправа, жидкая сметана, кетчуп и другие жидкие соусы** — жидкости с низкой вязкостью (высоковязкие пасты выходят за рамки возможностей этой модели)  
- **Косметический тонер, сыворотка, парфюмерия** — наполнение малых пакетов с низкой вязкостью  
- **OEM-обработка, пробное производство малых брендов** — МОК 1 комплект, идеально подходит для переключения между различными типами и размерами пакетов  
- **Мелкосерийное, многоассортиментное упаковывание для электронной коммерции** — четыре насадки наполняют несколько пакетов одновременно, повышая эффективность небольших линий

### 1.3 Основные функции

1. **Гибридное пневматическое управление + электрическое управление** — воздух приводит поршень и клапаны, электронный блок управляет временем и переключением; более стабильное время и точное управление по сравнению с полностью пневматическими моделями  
2. **Объемное наполнение поршневого типа** — один цилиндр на головку, объем наполнения определяется ходом поршня, регулируется в диапазоне 20–1000 мл  
3. **Четыре одновременных насадки наполнения** — стандартно 4 антикапельные положительные запирающие насадки; по заказу доступны 1, 2 или 4 насадки; диаметр насадки 3–12 мм по выбору  
4. **Переключение между педалью и автоматическим таймером** — полуавтоматический и автоматический режимы могут переключаться на одной машине, гибкая работа  
5. **Контактные части из пищевой нержавеющей стали 304** — по запросу версия из нержавеющей стали 316; манжеты из пищевого силикона, рассчитанные на 200°C, соответствуют требованиям безопасности пищевых продуктов; резиновые уплотнители по запросу для агрессивных жидкостей  
6. **Нижние антикапельные положительные запирающие насадки** — после наполнения цилиндр в нижней части насадки выполняет положительное закрытие, устраняя подтекание и остаточные капли на горловине пакета  
7. **Специальное устройство подъема головки наполнения** — головка насадки может быть нажата и автоматически поднимается, адаптирована для наполнения гибких пакетов и безопасна для горловины пакета  
8. **Пневматические компоненты Airtac** — пневматические компоненты Taiwan Airtac для надежной работы

## 2. Ключевые преимущества

### Преимущество 1 | Пневматическое управление + электрическое управление — более стабильное и точное, чем полностью пневматическое

- Машина **работает от сжатого воздуха** (требуется воздушный компрессор), обеспечивает движение поршня и переключение клапанов — стабильное действие, устойчивость к перегрузкам  
- **Электронный блок управления** отвечает за тайминг и подсчет (таймер, сигнал педали) — более точный и повторяемый, чем чисто пневматическое управление  
- Переключение между полуавтоматическим и автоматическим режимами: одна машина выполняет работу двух — используйте полуавтоматический режим для малых партий и проб, переключитесь на автоматический при увеличении объема производства  
- В индустрии известна как «электропневматическая интеграция», ключевое конкурентное преимущество серии DF перед полностью пневматическими моделями

### Преимущество 2 | Наполнение поршневого типа + регулируемый диапазон 20–1000 мл

- Наполнение поршневого типа, **одна машина покрывает 20–1000 мл** — от малых пакетов до больших, без замены оборудования  
- Объем наполнения задается изменением хода поршня — устойчивая конструкция, отсутствие дрейфа  
- Точность наполнения ≤ 0,5%, высокая повторяемость

### Преимущество 3 | Четыре одновременные насадки + антикапельные положительные запирающие насадки

- **Стандартно 4 насадки**, производительность одной насадки около 20 мл/с; пиковая производительность заметно выше, чем у одноносовых моделей (пиковая производительность в минуту подтверждается дополнительно)  
- **Нижние антикапельные положительные запирающие насадки** — после наполнения цилиндр в нижней части насадки выполняет положительное закрытие, устраняя подтекание и остаточные капли на горловине пакета  
- Диаметр насадки **3–12 мм по выбору**, гибко подстраивается под вязкость жидкости и размер горловины пакета  
- Количество головок можно выбрать: 1 / 2 / 4 насадки в зависимости от потребностей до заказа

### Преимущество 4 | Пищевая нержавеющая сталь 304 + силиконовые манжеты до 200°C

- Контактные части — **пищевая нержавеющая сталь 304** (по запросу 316); система клапанов выполнена из той же нержавеющей стали  
- Уплотнители — **пищевые силиконовые манжеты, рассчитанные на 200°C**, соответствуют требованиям безопасности пищевых продуктов  
- **Резиновые уплотнители доступны для агрессивных жидкостей** — например, алкоголь, сильные кислоты и щелочи  
- Вся машина соответствует требованиям безопасности пищевых продуктов и может использоваться непосредственно для наполнения пищевых пакетов, таких как напитки и соусы

### Преимущество 5 | Гибкая адаптация к пакетам + одна машина для нескольких типов пакетов

- **Специально разработана для гибких упаковочных пакетов** — стоячий пакет, пакет с носиком, Doypack и обычный гибкий пакет — все поддерживаются  
- Головка наполнения имеет устройство подъема, безопасна для горловины пакета — не деформирует пакет, не сжимает его  
- Одна машина заменяет несколько: смена типа пакета требует только замены соответствующего крепления / зажима пакета, не требуется замена основной машины  
- Собственная масса около 50 кг, доставляется одна машина в усиленной картонной коробке — легко отправлять

## 4. Рекомендации по продажам и ЧАВО

### 4.1 Рекомендации по продажам

1. **Цель — клиенты, нуждающиеся в наполнении гибких пакетов** — линии пакетов в напитках, пищевом масле, вине, жидких моющих средствах, соусах и косметике. Ближе к потребностям наполнения пакетов, чем маленькие бутылочные наполнители, такие как PL-88, но дешевле и проще в эксплуатации, чем крупные автоматические машины для упаковки пакетов.
2. **Акцентируйте внимание на «электропневматической интеграции»** — большинство полностью пневматических аналогов не имеют электронного блока управления и не могут переключаться между полуавтоматическим и автоматическим режимами; DF4 предлагает два способа работы в одной машине, решая типичную тревогу «достаточно ли полуавтоматического режима, смогу ли я перейти на автоматический?»
3. **Выделите преимущество «четыре насадки + выбор диаметра насадки»** — наполнение четырьмя насадками одновременно — заметный рост мощности для малых линий пакетов; диаметр 3–12 мм охватывает все размеры горловин пакетов.
4. **Бонусные продажи** — объедините с нашими закрывающими устройствами, маркировочными станками и кодировщиками, чтобы создать небольшую линию упаковки пакетов, преобразуя заказ одной машины в заказ полной линии.

7. **Прогнозируйте выбор уплотнений** — выбор между резиновыми уплотнителями и силиконовыми манжетами должен зависеть от агрессивности жидкости, чтобы избежать покупки неправильного варианта и последующего отказа уплотнения после наполнения.

### 4.2 ЧАВО

**В1: Для каких жидкостей подходит DF4-1000?**  
Текучие жидкости — вода, масло, сок (без частиц), жидкое моющее средство, соус, вино, жидкая сметана и т.д. Жидкости с частицами, высоковязкие пасты и сильно агрессивные жидкости не подходят (для сильно агрессивных жидкостей требуется резиновое уплотнение + конфигурация из нержавеющей стали 316; уточните у Андреа перед заказом).

**В2: Нужна ли машине электросеть? Какой режим управления — электрический или пневматический?**  
Машине **необходимо подключение к сети 220 В 50/60 Гц** и **обязательно подключение к воздушному компрессору**. Серия DF использует гибридную систему **пневматического управления + электрического управления**: источник сжатого воздуха приводит поршень и клапаны, а электронный блок управления отвечает за тайминг, подсчет и сигнал педали. Это обеспечивает более стабильное время и точную регулировку по сравнению с полностью пневматическими моделями, а также более устойчиво к жесткому использованию и долговечно, чем полностью электрические модели.

**В3: Сколько насадок в стандартной комплектации? Можно ли выбрать 1 или 2?**  
**4 насадки в стандартной комплектации.** **1 головка / 2 головки / 4 головки** доступны по заказу — меньшее количество головок означает более низкую цену за единицу, а многонасадочные модели дают значительный прирост мощности для малых пакетов.

**В4: Как выбрать диаметр насадки?**  
**По выбору в диапазоне 3–12 мм.** 6 мм — распространенный вариант для обычных жидкостей (например, вода, масло, сок, моющие средства); 8 мм — для жидких соусов, вина и косметики; 10–12 мм — для более густых жидкостей. Уточните размер горловины пакета и вязкость жидкости перед заказом, Андреа поможет подобрать диаметр.

**В5: Какова точность наполнения? Что можно достигнуть?**  
**Точность наполнения ≤ 0,5%**, типично для поршневых объемных моделей. Рекомендуем взвесить 2–3 пакета для калибровки перед массовым производством.

**В6: Будут ли насадки подтекать или оставлять жидкость на горловине пакета?**  
Нет. Стандартные **нижние антикапельные положительные запирающие насадки** — после наполнения цилиндр в нижней части насадки выполняет положительное закрытие, не оставляя капель и прилипшей жидкости. Горловина пакета остается чистой и может сразу переходить к следующему этапу.

**В7: Из какого материала изготовлены контактирующие части? Какой уровень гигиены?**  
Контактирующие части — **пищевая нержавеющая сталь 304** (по запросу 316), с системой клапанов из нержавеющей стали; уплотнения — **пищевые силиконовые манжеты, рассчитанные на 200°C**. Вся машина соответствует требованиям безопасности пищевых продуктов и может использоваться непосредственно для наполнения пищевых пакетов.

**В8: Трудно ли менять тип пакета? Нужно ли менять детали?**  
Вовсе нет. Машина поддерживает переключение между **стоячим пакетом, пакетом с носиком, Doypack и обычным гибким пакетом** на одной машине; смена типа пакета обычно требует только замены соответствующего крепления / зажима пакета, а объем наполнения регулируется изменением хода поршня.

**В9: Трудно ли очищать при смене жидкостей?**  
Вовсе нет. Трубопроводы используют быстросъемные соединения, контактные части легко разбираются; для обычных жидкостей достаточно промыть чистой водой или горячей водой; для масел и соусов сначала промойте горячей водой, затем чистой. **Для сильно агрессивных жидкостей перед промывкой необходимо выдержать в соответствующем чистящем средстве.**

**Годовая гарантия на всю машину** — бесплатный ремонт или замена при неисправностях, вызванных не человеческими факторами и возникающих при нормальной эксплуатации по инструкции; клиент оплачивает доставку из Китая до места назначения. **Оплачиваемое пожизненное техническое обслуживание после окончания гарантии**; если требуется наезд инженера, клиент оплачивает расходы на проезд туда и обратно.

Доставляется в **усиленной картонной коробке**, одна машина в коробке, включены инструменты и детали. Собственная масса 50 кг, брутто 60 кг, размер упаковки 75 × 55 × 55 см; можно отправлять морским LCL, воздушной или международной курьерской доставкой. ## 6. Рабочий процесс

### 6.1 Процесс наполнения пакета

1. **Подключите воздух и питание** — убедитесь, что подключен источник питания 220 В 50/60 Гц; подключите воздушный компрессор и установите давление воздуха в стандартном диапазоне (**МПа подлежит подтверждению**); проверьте, что показания манометра, фильтра и сигнала электромагнитного клапана нормальные.
2. **Загрузите материал / подача** — налейте жидкость для наполнения в бак (или подайте из трубопровода), убедитесь, что выбраны правильные уплотнения для типа жидкости (силиконовая манжета / резиновый уплотнитель).
3. **Установите / разместите пакеты** — зафиксируйте стоячий пакет / пакет с носиком / Doypack на соответствующем креплении или зажиме пакета, выровняйте горловину пакета с головкой наполнения; автоматическое устройство подъема адаптируется к положению горловины пакета.
4. **Выберите режим / запустите** — выберите режим «педаль (полуавтоматический)» или «автоматический таймер (автоматический)» в зависимости от потребностей дня; два режима могут переключаться мгновенно на одной машине.
5. **Объемное наполнение** — после запуска источник сжатого воздуха приводит поршень и 4 антикапельные положительные запирающие насадки наполняют одновременно; производительность одной насадки около 20 мл/с, завершая дозу автоматически в диапазоне 20–1000 мл.
6. **Положительное закрытие / прекращение подтекания** — когда достигнут целевой объем, цилиндр выполняет положительное закрытие в нижней части насадки, устраняя подтекание и остаточную жидкость на горловине пакета.
7. **Снятие / перемещение вниз по потоку** — снимите наполненный пакет и переместите его на следующий этап (закрывание / закручивание / маркировка / кодирование / упаковка / картонирование).
8. **Очистка CIP / смена продукции** — при смене жидкостей снимите насадки и контактные части, промойте чистой водой или горячей водой; для сильно агрессивных жидкостей предварительно выдержите в соответствующем чистящем средстве перед промывкой. **Регулярно проверяйте силиконовые манжеты** на старение, деформацию или утечки воздуха.
