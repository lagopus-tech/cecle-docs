## 概述

- **定位**：以**活塞式容积计量**为核心技术的灌装机家族，覆盖从水状液体到高粘度膏体、从无颗粒到细粉材料的全场景包装需求。超过200个型号，按三个维度定位：物料形态 × 灌装量 × 自动化程度。
- **核心技术**：气动活塞容积灌装，配备台湾Airtac气动元件和德国SICK光电传感器。全气动机型无需电源，天然防爆。
- **灌装精度**：活塞式 ≤ ±1%；磁力泵式 ≤ ±2%；粉末与颗粒称重式 ≤ ±1%（颗粒称重±1–5%）。
- **灌装量覆盖范围**：2.5 ml（最小手压式）→ 5,000 ml（标准机型）→ 25–50 kg（大容量称重机）。
- **自动化层级**：手压式（A03）→ 半自动气动式（F6/FF6系列）→ 半自动CNC/磁力泵式（GFK-160/DF-A）→ 自动多头式（A2/A4/A6/A8, FA2/FA4/FA6）→ 全自动整线（理瓶机+灌装机+旋盖机+贴标机+输送机）。
- **畅销型号**：水平全气动单头液体 **F6**，水平全气动单头膏体 **FF6**，双头液体 **DF6**，双头膏体 **DFF6**；自动液体 **A2/A4/A6**，自动膏体 **FA2/FA4/FA6**。
- **材质标准**：201不锈钢机身，**304不锈钢接触部件（316可选）**，硅胶密封圈（耐热至200°C）或耐腐蚀橡胶，符合食品级与GMP要求。
- **定制化**：灌装量段、灌装头数量（1/2/4/6/8）、料斗类型（标准/搅拌/加热搅拌）、材质（304/316/PTFE活塞）、喷嘴口径（3–12 mm）、瓶型（按客户样品定制）、输送机长度、电压（220 V / 110 V）及防爆要求均可定制。定制设备及整线交货期：30–55个工作日。
- **典型服务行业**：日化个人护理、食品、医药、化妆品、农化、化工、香精香料、润滑油、气雾剂、电子烟油、酱料调味品。

# 1. 什么是灌装机

## 1.1 定义

灌装机是将液体、膏体、粉末或颗粒物料按预设体积或重量灌入瓶、罐、袋、杯或桶中的包装设备。它是灌装线的核心工位：上游对接理瓶与供瓶，下游连接旋盖、贴标、打码与装箱。

本系列产品按**物料形态**分为五类，每类有独立计量原理与型号系列：

| 物料形态 | 产品名称 | 型号系列 | 典型物料 |
| --- | --- | --- | --- |
| 液体 | 液体灌装机 | F系列（F2/F3/F6），DF系列（双头） | 水、油、果汁、牛奶、酒、洗手液、消毒液、液体药品 |
| 膏体/高粘度 | **膏体灌装机** | FF系列（FF2/FF4/FF5/FF6/FF9），DFF系列（双头） | 洗发水、牙膏、酱料、番茄酱、蜂蜜、面霜、指甲油 |
| 粉末 | 粉末灌装机 | PDF / ADF / SDF系列 | 奶粉、面粉、调味粉、洗衣粉、药粉、添加剂 |
| 颗粒 | 颗粒称重机 | GPM / KY系列 | 大米、味精、鸡精、种子、饲料、坚果、五金件 |
| 气雾剂 | 气雾剂灌装机 | AF系列 | 杀虫喷雾、发胶、空气清新剂、摩丝 |

## 1.2 工作原理

### 1.2.1 五种计量方式对比

| 计量方式 | 原理 | 精度 | 适用物料 | 代表型号 |
| --- | --- | --- | --- | --- |
| **活塞容积式**（主流） | 气缸驱动活塞上下运动；活塞腔产生负压吸入物料，再推动排出定量剂量 | ≤ ±1% | 液体及膏体（无颗粒或仅极细颗粒） | F6 / FF6 / DF6 / DFF6 / A2 / FA2 |
| **磁力泵/齿轮泵计量** | 进口变频器+高精度多圈电位器控制泵速；通过累积流量计量 | ≤ ±2%（重复性<0.5%） | 低粘度、耐腐蚀液体（酸碱、油、液体药） | DF-A / DF-2A / YT-1 |
| **真空吸料+液位定位** | 连续真空填充瓶体；多余物料自动回流至储罐；喷嘴插入深度决定最终液位 | ≤ ±1% | 香水、古龙水、起泡液体（对瓶高一致性无要求） | YT-2 / YT-4 / APF-500 |
| **螺杆计量** | 步进电机驱动合适尺寸螺杆；光电跟踪修正误差 | ≤ ±1% | 粉末、超细粉末、小颗粒 | PDF-500 / ADF-500 / SDF-500 |
| **电子称重** | 高精度数字称重传感器+三速（快/慢）变频送料，实时称重修正 | ±0.3%（批量）至±1–5%（小包） | 颗粒、块状物、易分层物料 | GPM-2A / GPM-2B / KY-C25KG |

### 1.2.2 标准工作流程

```
进料（手动/自动）→ 容器定位（光电/定位爪）→ 灌装头下降 → 定量灌装 → 灌装头上升
→ 出料 → [全自动线] 盖子放置 → 旋盖/压盖 → 贴标 → 打码 → 装箱
```

**半自动机型**（F6/FF6/DF6/DFF6等）：人工放瓶，脚踏开关或定时触发灌装；机身为分体式，可安装于支架或工作台；一名操作员。
**全自动机型**（A2/A4/A6, FA2/FA4/FA6, AD-5000）：PLC触摸屏设置+输送机定位+德国SICK光电“无瓶不灌”；多头同时灌装；可直接接入整线。

### 1.2.3 影响灌装质量的关键变量

- **灌装精度**取决于：物料供料压力稳定性、灌装速度、物料粘度、灌装头升降速度，以及上下阀门启闭速度（弹簧压力可调）。
- **灌装速度**取决于：物料粘度、灌装量、喷嘴口径（口径越大越快）、气缸速度及灌装头提升速度。
- **起泡物料**：降低排料速度或采用两段式灌装（快后慢）。

# 3. 常见问题与技术解答

## 3.1 选型与原理FAQ

**Q1: 液体灌装机能否灌装膏体？**
否。**膏体灌装机（FF/DFF/FA系列）可灌装液体与膏体（双用途），但液体灌装机（F/DF/A系列）只能灌装液体。** 活塞腔与阀流道设计不同——液体机流道无法通过高粘度物料。当客户物料粘稠时，应直接推荐FF/DFF/FA系列。

**Q2: 若物料含颗粒怎么办？**
标准活塞式与磁力泵机**无法处理含颗粒物料，或颗粒必须极小**。对于颗粒物料，应切换至螺杆粉末灌装机（PDF/SDF/ADF，适用于粉末与小颗粒）或颗粒称重机（GPM/KY系列）。

**Q3: 一台机器能否覆盖10 ml到5,000 ml？**
否。**每台机器的灌装量段是固定的**（由活塞孔径与行程决定）。宽量程需多台不同量段机器。对多规格客户，建议主规格选一台，搭配可换缸体。

**Q4: 实际灌装精度是多少？**
活塞容积式≤±1%；磁力泵式≤±2%（重复性<0.5%）；螺杆粉末≤±1%；批量称重±0.3%，小包颗粒±1–5%。主要影响因素为**供料压力稳定性、灌装速度、物料粘度与灌装头升降速度**。

**Q5: 气动还是电动——如何选择？**
- **全气动**：无需电源，天然防爆，适合酒精、香精、气雾剂与溶剂；客户需提供0.4–0.6 MPa空压机；结构简单，故障率低，维护成本低。
- **电动与电子（CNC/磁力泵/自动）**：需220 V电源；PLC触摸屏可精确设定参数，速度更高，易于集成整线。

**Q6: 为何水平机型为主力？**
水平全气动机型（F6/FF6系列）采用软管或料斗自吸，精度高、易清洁、设计成熟——是本系列**最常推荐机型**。垂直机型（FF4/FF5）可在范围内自由调节灌装量与速度，但水平膏体机覆盖量更大。

**Q7: 高粘度膏体有何特殊要求？**
**极粘物料必须使用PTFE活塞**（约50美元/个），否则活塞与缸壁摩擦会损坏密封，导致灌装量漂移。若物料还易分层或固化，需加**搅拌料斗（B型）** 或 **加热搅拌料斗（C型）**。

**Q8: 立袋与瓶子能否共用一台机器？**
否。立袋需专用的袋推送、袋吹开、盖悬挂与盖拧紧机构。应选择F8/DF8/DFF8（半自动）或AF8-1000/TD-1A/LGD系列（一体机与自动机型）。

**Q9: 为何香水灌装机不受瓶型限制？**
因其采用**液位定位**：喷嘴插入固定深度，多余物料自动回流至储罐。液位由插入深度决定，容器高度不一致仍能保证相同液位——香水与古龙水的标准做法。注意其**不能灌装膏体**。

## 3.3 日常维护检查清单

**“五定”润滑原则**（定人、定时、定点、定量、定油品）：

| 位置 | 润滑剂 | 频率 |
| --- | --- | --- |
| 蜗轮减速器 | 蜗轮油 / 双曲线齿轮油 / 机油 | 定期更换 |
| 滚动轴承 | 锂基润滑脂ZL-3或硅油通用润滑脂 | 定期补充 |
| 导轨与齿条 | 锂基润滑脂ZL-3 | 定期补充 |
| 气源滤油器 | 专用气动油 | 经常检查并补充 |

**每日检查：**

1. 每日开机前，检查气压（0.4–0.6 MPa；整线0.5–0.8 MPa）、电源（220 V）及急停按钮是否复位。
2. **定期排放空气过滤器中的油水**，防止水分进入管道腐蚀阀门。
3. 定期清洁**物料过滤器**与管道。
4. 定期检查所有接头与阀体是否漏气，并紧固所有紧固件消除松动。
5. 定期检查运动部件（滚动轴承、同步带）磨损情况，严重时及时更换。
6. 运行一年后或例行检修时，修补油漆以防腐蚀。
7. 停产时，停机并关闭电源与气源；切勿在机内遗留工具、抹布等异物。

**关键安全规则**：调整必须在非自动运行状态下由一人进行；严禁在机器运行时触碰运动部件；长发须遮盖，禁止佩戴可能被卷入的围巾、手镯、手表；停电后机器可能自动重启，务必远离运动部件。

## 4.2 典型定制案例

**案例1 | 高粘度酱料灌装**
需求：番茄酱、辣椒酱，粘稠且易附壁。
方案：FF6 / DFF6系列 + PTFE活塞 + 大搅拌料斗（B型） + 底部防滴喷嘴 + 吹气功能。
理由：PTFE活塞防止密封损伤；搅拌料斗防止分层；防滴喷嘴阻止物料附着滴落。

**案例2 | 防爆灌装（酒精与香精）**
需求：75%酒精消毒液，车间有防爆要求。
方案：全气动F6系列（无电源） + 316接触部件 + 耐腐蚀橡胶密封；扩展可选A4-500 + DC1 + 输送机 + AL-220整线。
理由：全气动机型无电气元件，从根本上杜绝点火源。

**案例3 | 易分层物料（蜂蜜与花生酱）**
需求：物料静置后易分层结皮。
方案：FF6C / DFF6C加热搅拌料斗机型，保持恒温与循环搅拌。

**案例4 | 立袋吸嘴袋**
需求：洗衣液与果冻吸嘴袋需灌装与旋盖一体。
方案：LGD02（单头台式旋转一体机，30–2,000 g，10–30袋/分钟，一人操作），或AF8-1000用于大批量（120次/分钟）；酱料可选水平搅拌料斗版本。

**案例5 | 整线定制（瓶装大批量）**
需求：从理瓶到贴标一体化生产线。
方案：理瓶机（瓶径≤80 mm） + FA4-1000四头灌装机 + AC1自动旋盖机 + AL-220圆瓶贴标机，87,000元，交货期30–45个工作日；可加装玻璃防护罩、316材质、瓶清洗机与喷码机。

## 4.5 定制边界（我们无法承诺）

为降低售后风险，售前必须明确以下边界：

1. **液体机无法改装为膏体机**——流道与活塞设计不同，改装成本高于新机。
2. **标准活塞与磁力泵机型无法承诺处理含颗粒物料**——需螺杆或称重方案。
3. **无法承诺过宽的量程范围**——单机量程固定，宽跨度需多型号。
4. **香水液位定位机型无法承诺灌装膏体**。
5. **定制机无法超越标准精度**——定制优化适配（容器、粘度、产能）；不能突破计量原理极限。
6. **无容器与物料样品，不承诺最终精度或产能**——精度与速度受物料粘度与容器一致性影响。
