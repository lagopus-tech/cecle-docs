## 1. 产品概述

### 产品类别

- **产品名称（英文）**：全自动四喷嘴膏体灌装机  
- **分类**：包装机械 → 活塞式全自动膏体/液体灌装机  
- **型号系列**：FA4-100 / FA4-300 / FA4-500 / FA4-1000 / FA4-2500 / FA4-3000 / FA4-5000  
- **自动化等级**：全自动化  
- **驱动方式**：气动+电动（需外接空压机）

### 应用领域

适用于**液体与膏体**物料的灌装，广泛应用于：

- **食品行业**：水、食用油、果汁、牛奶、酸奶、酱料、奶油、膏体  
- **日化行业**：液体洗涤剂、洗碗液、液体皂  
- **化妆品行业**：乳霜、膏状护肤品  
- **医药与化工行业**：液态与膏状物料的定量灌装  

**典型客户**：中小型食品厂、化妆品乳霜生产商、日化洗涤品企业、酱料与调味品生产企业。

### 核心功能

- **自动进瓶与定位**：输送带自动供瓶，皮带上设有瓶固定装置，保证灌装稳定性；标配2米输送带，规格可定制。
- **高精度定量灌装**：活塞式计量，灌装量与速度可通过人机界面（触摸屏）直接设定。
- **四喷嘴同步灌装**：四个灌装头同时工作，每个喷嘴由独立气缸驱动。
- **防滴漏系统**：底部闭合正向切断喷嘴，确保灌装过程完全无滴漏。
- **智能控制**：德国SICK光电传感器实现“无瓶不灌”逻辑，杜绝空气填充与物料浪费。
- **大容量料斗**：80 L料斗，减少长时间生产中的加料频率。
- **液态与膏体通用**：一台设备可同时处理流动性液体与高粘度膏体。

## 6. 工作流程

### 生产流程（六步标准操作）

```
步骤1              步骤2              步骤3              步骤4              步骤5              步骤6
料斗加料 & 准备   →   进瓶（输送带）   →   光电计数 & 定位   →   四喷嘴活塞计量   →   防滴漏切断   →   出瓶（下工序）
(80L料斗)         (2m皮带)          (SICK传感器)       (气电驱动)           (正向切断)       (封盖/贴标)
```

#### 步骤1 — 料斗加料与准备

- **设备**：80 L料斗 + PLC触摸屏  
- **操作**：将待包装物料倒入80 L料斗，连接空压机（0.6 – 0.8 MPa），通电，通过触摸屏设定灌装量与速度。  
- **关键点**：膏体物料需无结块、硬颗粒；启动前设定好灌装量，首循环即准确。

#### 步骤2 — 进瓶

- **设备**：2 m输送带 + 瓶固定装置  
- **操作**：空瓶置于输送带上，自动送入灌装工位；皮带上的固定装置确保灌装过程中瓶身稳定。  
- **关键点**：保持瓶距均匀、方向一致，确保光电传感器可靠计数。

#### 步骤3 — 光电计数与定位

- **设备**：德国SICK光电传感器 + 瓶停缸  
- **操作**：SICK传感器实时计数到达的瓶子。当4瓶到位后，瓶停缸伸出，精确锁定于喷嘴下方。  
- **关键点**：缺瓶时，“无瓶不灌”逻辑阻止运行，避免物料浪费。

#### 步骤4 — 四喷嘴活塞计量

- **设备**：4个灌装喷嘴，每头独立气缸  
- **操作**：四个灌装头同步下降，活塞推动物料出料，一次循环同时灌装4瓶，精度达±1%。  
- **关键点**：灌装量与速度通过人机界面调节；因每头独立气缸，四喷嘴一致性高。同一设备可处理液体与膏体。

#### 步骤5 — 防滴漏切断

- **设备**：底部闭合正向切断喷嘴  
- **操作**：每循环结束，正向切断阀瞬间关闭，喷嘴干净抬起。
