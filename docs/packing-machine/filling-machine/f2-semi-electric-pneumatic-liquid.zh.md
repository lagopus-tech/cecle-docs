## 核心概要
F2系列是温州T&D的**半自动水平电动气动液体灌装机（气动与电动一体化）**。涵盖8个型号（F2-50/100/300/500/1000/2500/3000/5000），灌装范围从 **5–50 ml** 到 **500–5000 ml**。该设备采用**电动气动一体化设计——气动驱动+电动控制**：需220V/50–60Hz电源（约 **100W**）和气压为 **0.4–0.6 MPa** 的空压机供气。配备**Airtac气动元件**，灌装速度为 **10–40 cycles/min**；电动控制系统确保周期定时稳定，批次间一致性极佳。机身采用 **201不锈钢**，所有与产品接触部件均为**食品级304不锈钢（316不锈钢可按需定制）**。活塞式容积灌装实现 **±1%精度**，并配备**底部关闭正向切断无滴漏喷嘴**（喷嘴孔径3–12 mm可选）。支持脚踏开关或自动计时器两种触发模式，操作员可自由切换半自动与全自动运行。标准配置为单灌装头；**双头、四头或六头版本可定制**。适用于水、食用油、果汁、牛奶、酒精饮料、液态药品、洗涤剂等流动性液体。

## 1. 产品概述

### 1.1 类别

- **行业：** 包装机械 / 灌装设备（灌装机）
- **产品名称：** 半自动电动气动水平液体灌装机
- **机型类型：** 半自动 · 电动气动一体化 · 水平式 · 活塞式液体灌装机
- **驱动方式：** 电动气动 —— 气动驱动 + 电动控制；需电源（220V/50–60Hz）和空压机（0.4–0.6 MPa）
- **自动化等级：** 半自动或全自动，可选（脚踏开关 / 自动计时器，可切换）
- **认证与保修：** CE认证；1年整机保修，保修期后提供终身维护服务

### 1.2 应用场景

专为**流动性好、低至中等粘度液体**的定量灌装设计。典型产品与行业应用：

- **食品饮料：** 饮用水、果汁、牛奶、酒类、食用油、液态调味品
- **日化用品：** 液体洗涤剂 —— 洗衣液、洗碗精、洗手液、沐浴露/香波
- **医药护理：** 液态药品、消毒剂、外用液体制剂
- **典型客户：** 小批量、多规格生产厂商；进行小试/中试的实验室；从手工线升级的车间；具备稳定电、气供应的工厂；对灌装速度与周期稳定性有要求的企业；频繁更换产品或包装规格的公司

### 1.3 核心功能

- **活塞式容积灌装：** 气缸驱动活塞，行程可调 —— 灌装量在型号范围内连续可调；换型无需更换零件
- **电动气动一体化控制：** 精确电动控制驱动气动执行，确保周期定时精准，灌装速度 **10–40 cycles/min**
- **双触发模式：** 脚踏开关用于人工触发（半自动），或自动计时器实现连续运行（全自动）；半自动 ⇄ 全自动可自由切换
- **无滴漏灌装：** 底部关闭正向切断喷嘴 —— 灌装结束瞬间密封，杜绝拉丝、滴漏
- **可定制灌装头：** 标准为单头；**双头（2头）、四头或六头配置可选**，以成倍提升产量
- **灌装量与速度可调：** 可匹配不同瓶型与产线节拍

## 2. 主要优势

> **电动气动一体化（气动与电动一体化）是本系列最大卖点——以下前五项优势均围绕此核心展开。**

1. **电动气动驱动——更高精度控制，更稳定周期。** 电动控制结合气动执行，由电气系统精确控制灌装周期。长时间连续运行下周期保持一致，批次重复性优异；灌装速度为 **10–40 cycles/min**，可随生产节奏灵活调节。
2. **电动控制计时器——更精细的自动模式设置。** 在自动模式下，填充间隔由电动计时器控制：调节精细、响应迅速，非常适合节奏化连续生产。
3. **Airtac气动元件。** 台湾Airtac气缸与阀门动作稳定、寿命长。全球通用，备件易采购，长期维护成本低。
4. **超低功耗——运行成本极低。** 总功耗仅约 **100W（0.1 kW）**，可在任意标准220V/50–60Hz插座上运行；电费几乎可忽略不计。耗气量与同类气动灌装机相当。
5. **操作简单——接通即用。** 连接电源（220V）和气源（0.4–0.6 MPa），即可开始生产。电动控制面板直观友好，新操作员可快速上手。
6. **201不锈钢框架 + 食品级304不锈钢接触部件；316可选。** 整机不锈钢结构，食品级接触部件符合食品安全标准（304）；**接触部件可定制为316不锈钢**，增强耐酸碱与抗腐蚀性能——适用于制药、化工及腐蚀性产品。不锈钢阀组耐腐蚀，清洁方便。
7. **±1%灌装精度 + 无滴漏喷嘴。** 活塞计量稳定可靠；底部关闭正向切断喷嘴杜绝滴漏与拉丝，保持瓶口及工作台面清洁，减少产品浪费。
8. **8款型号覆盖5–5000 ml；换型零成本。** 通过调节活塞行程即可改变灌装量——无需更换任何零件；规格变更仅需2–3分钟。
9. **水平布局，紧凑轻便。** 水平机身占地面积小，净重仅22–32 kg，可放置于桌面、工作台或现有生产线，移动便捷。
10. **食品级硅胶密封圈（耐温200°C）。** 标准配置为食品级硅胶O型圈；填充腐蚀性产品时可选耐腐蚀橡胶密封圈。
11. **半自动⇄全自动可切换，多头可扩展。** 可从脚踏半自动起步；当产量增长时，可切换至自动计时模式，或升级为**双头/四头/六头**机型——无需更换设备，投资零浪费。

### 4.2 常见问题解答（FAQ）

**Q1：这台机器需要用电吗？**  
A：**是的。** F2系列为电动气动一体化设备：电动控制部分需 **220V / 50–60Hz** 电源（功耗仅约 **100W**），而灌装动作由压缩空气驱动，因此**必须连接空气压缩机（0.4–0.6 MPa）**。

**Q2：我需要空压机吗？**  
A：是的。该设备采用气动驱动+电动控制，必须连接气压为 **0.4–0.6 MPa** 的空压机。普通小型活塞式空压机（带储气罐）即可满足；也可在订单中一并添加。

**Q3：这台机器是防爆的吗？**  
A：F2为电动气动机型（含电动控制部件），**并非防爆设备**。若车间有防爆要求，或需灌装酒精、溶剂等易燃液体，请推荐**F6全气动系列**（完全无电，本质安全，防爆适用）。

**Q4：灌装精度和速度是多少？**  
A：精度为 **±1%以内**（活塞式计量——稳定无漂移）；速度为 **10–40 cycles/min**，且可调。

**Q5：它能灌装高粘度液体或膏体吗？**  
A：适用于**流动性液体**：水、食用油、果汁、牛奶、酒类、液态药品、液体洗涤剂等。对于高粘度产品或膏体（酱料、乳霜、药膏），建议选用我们的**膏体灌装机系列**。

**Q6：接触部件是否为食品级？**  
A：机身为201不锈钢，**所有与产品接触部件均为食品级304不锈钢**，符合食品安全要求；**316不锈钢可定制**（更强耐酸碱与抗腐蚀性，适用于医药、化工及腐蚀性产品）。密封圈为食品级硅胶（耐温200°C）。

**Q7：会滴漏或拉丝吗？**  
A：不会。喷嘴采用**底部关闭正向切断设计**——灌装结束瞬间闭合，确保无滴漏。喷嘴孔径可在3–12 mm范围内选择。

**Q8：更换灌装量麻烦吗？**  
A：完全不麻烦。在型号范围内，只需**调节活塞行程**即可改变灌装量——无需更换任何零件；换型仅需几分钟。特别适合多规格、小批量生产。

**Q9：能全自动运行吗？以后需要更高产量怎么办？**  
A：可以。设备支持**脚踏开关（半自动）和自动计时器（全自动）**，可随时切换。若需更高产量，可订购**双头（2头）、四头或六头**多头版本（每头一个气缸）——无需更换整机。

**Q10：最低起订量、交货时间与保修政策？**  
A：**最低起订量1台**；工厂**现货供应**，可快速发货；出口包装为加固纸箱，每箱一台，含工具与备件。整机提供**1年保修**（非人为损坏免费维修或更换零件；国际运费由客户承担），保修期后提供**终身维护服务**。

## 6. 工作流程

### 6.1 灌装操作流程

```
① 安装
   连接220V/50–60Hz电源（约100W）
   连接空压机；调节供气压力至0.4–0.6 MPa
        │
② 上料
   将待灌装液体加入料斗/储液罐
        │
③ 设定体积
   调整活塞行程 → 设置每循环灌装量（范围内连续可调）
   必要时调整灌装速度
        │
④ 放置瓶子
   将容器置于灌装喷嘴正下方
        │
⑤ 触发灌装
   脚踏开关（半自动模式）或自动计时器（全自动模式）
        │
⑥ 灌装完成（精度±1%）
   底部关闭正向切断喷嘴 → 无滴漏，无拉丝
        │
⑦ 下一瓶 —— 重复
   重复④–⑥，速度10–40 cycles/min
        │
⑧ 清洗与停机
   停机；断开电源与气源；
   拆卸并冲洗料斗/活塞/灌装喷嘴；
   更换产品前务必清洁
```

### 6.2 销售流程（从询盘到交付）

1. **需求确认：** 确认每循环灌装量（ml）、速度要求、产品特性（流动性/腐蚀性→304或定制316）、车间供电情况（220V/50–60Hz；其他电压需与工厂确认）、**客户是否已有空压机**，以及是否需防爆（是则转推F6全气动系列）。
2. **型号推荐：** 根据4.1表格推荐对应F2-50 ~ F2-5000型号；高产量需求推荐双头/四头/六头多头版本。
3. **配套设备核查：** 确认电源匹配，客户拥有空压机（0.4–0.6 MPa，排气量满足设备耗气量），确保设备到厂即可运行。
4. **锁定技术细节：** 材质（304 / **定制316**）、喷嘴孔径（3–12 mm）、密封圈（硅胶 / 耐腐蚀橡胶）、灌装头数量（单 / 双 / 四 / 六）、脚踏开关 vs. 计时器模式。
5. **报价与条款：** 最低起订量1台；FOB宁波 / EXW温州；电汇付款；现货供应；加固纸箱包装，含工具与备件。
