## 1. 产品概述

### 1.1 分类

- **行业：** 包装机械 / 灌装设备（灌装机）
- **产品名称：** 半自动全气动膏体灌装机
- **机型类型：** 半自动 · **全气动（无电）** · 水平 · 活塞式**膏体**灌装机（也可处理液体，包括易燃/酒精基/溶剂基液体）
- **驱动方式：** **全气动——气动驱动 + 气动控制；仅需空气压缩机（0.4–0.6 MPa）；完全无需电源**
- **自动化等级：** **仅半自动**（脚踏触发；全气动架构无法实现全自动定时模式）
- **危险区域适用性：** **本质安全 / 防爆就绪——适用于易燃、酒精基或溶剂基产品及防爆区域**
- **认证与保修：** CE认证；1年整机保修，保修期后提供终身维护服务

### 1.2 应用场景

专为**膏体和高粘度产品**为主要用途设计，同时具备**流动性液体（包括易燃/酒精基/溶剂基液体）** 的次要能力——一台机器覆盖两类产品，**无需电力**。典型产品与行业：

**主要——膏体 / 高粘度（含易燃膏体）：**

- **化妆品与个人护理品（酒精基 / 易燃）：** 酒精基洗手凝胶、酒精基爽肤水、香水膏、易燃乳霜
- **食品：** 酱料、番茄酱、果酱、蜂蜜、花生酱、巧克力膏、芥末酱、蛋黄酱
- **日化用品：** 洗涤剂膏、洗碗液（浓稠型）、鞋油
- **制药：** 药膏、外用药膏、药用膏体、小体积易燃酊剂
- **化工：** 溶剂型胶水、易燃润滑剂、密封胶、油漆、油墨

**次要——流动性液体（包括易燃液体）：**

- 酒精基液体（香水、精油、酒精酊剂、消毒剂基础液）、溶剂（稀释剂、去油剂）、低粘度油漆与油墨、饮用水、果汁、牛奶、食用油、液体调味料

**典型客户：** 灌装易燃或酒精基产品的膏体/化妆品/食品生产商；**防爆区域**（禁止使用电器）的车间；**无现场电力**（偏远地区、移动工坊、电网不稳出口地区）的工厂；灌装易燃溶剂的制药与化工企业；注重最低运行成本（完全无电费）的客户；同时灌装膏体SKU与液体SKU（包括易燃SKU）且希望一台机器解决全部需求的企业。

### 1.3 核心功能

- **活塞式容积灌装，专为膏体优化：** 气缸驱动活塞，行程可调——可处理厚质产品（酱料、乳霜、药膏、溶剂型胶水）而不飞溅或拉丝；容量可在型号范围内无级调节；更换规格无需更换零件
- **液体兼容性作为附加功能（含易燃液体）：** 通过更换喷嘴并调整活塞行程，可从膏体切换至液体（包括酒精基/溶剂基液体）；一台机器覆盖两类产品，且具备完整的防爆安全性
- **全气动驱动与控制——无电：** 气动执行由气动阀控制；设备上无任何电气元件；无保险丝、无继电器、无定时器、无PLC——构造即本质安全
- **单触发模式——脚踏开关：** 操作员通过脚踏开关触发每次循环；**全自动定时模式不可用**（这是与FF2电动控制相比的权衡：失去自动定时，获得防爆安全性）
- **滴漏零残留灌装：** 底部关闭正向切断喷嘴——灌装结束瞬间即密封；**无拉丝、无滴漏、无瓶口膏体残留**（对化妆品、食品及易燃产品应用至关重要）
- **可定制灌装头：** 标准为单头；**双头（2头）、四头或六头配置可定制**，以实现更高产量
- **可调灌装量与速度：** 适配不同容器规格（小罐、大桶）和产线节拍
- **灵活的料斗/供料选项：** 标准配置**30L料斗**；可选**40L / 60L / 80L**更大料斗，减少补料次数。因设备全气动，**搅拌料斗**（气动驱动）和**加压料斗**（压缩空气辅助进料——天然匹配）是理想组合；**加热料斗**可配置蒸汽/热水夹套或本质安全型电加热，以满足防爆要求——根据产品特性选择合适的料斗配置

## 2. 核心优势

> **全气动 / 无电是本系列最大的卖点——以下前五项优势均围绕此展开。防爆安全是核心亮点。**

1. **完全无电——本质安全，构造即防爆。** FF6不含任何电气元件（无电机、无电磁阀、无定时器、无继电器、无PLC）。仅依靠压缩空气运行（0.4–0.6 MPa）。因无电气火花源，设备本质安全，**适用于防爆区域及易燃/酒精基/溶剂基产品灌装**——打开了FF2电动气动系列无法触及的市场。
2. **可直接用于易燃、酒精基或溶剂基产品。** 对于酒精基洗手液、香水、酒精酊剂、精油、溶剂型胶水、油漆、油墨、稀释剂、易燃润滑剂等产品，FF6可安全灌装，无点火风险。FF2无法做到这一点；FF6是唯一答案。
3. **无需电源——随处可用。** 设备仅需空气压缩机即可运行。可在**无现场电力**的车间、偏远地区、移动生产线、电网不稳地区及野外部署中使用。无需电工、无需电压匹配、无需接地考虑——只需连接气管即可工作。
4. **无电费——最低运行成本。** 因设备不消耗任何电能，唯一公用事业成本仅为压缩空气。对高负荷运行的工厂可显著降低运营成本；对偶尔使用者则完全消除电费预算。
5. **操作简单——接气即开。** 连接空气压缩机（0.4–0.6 MPa），即可开始生产。无须学习电气控制面板——仅需气动控制阀组和脚踏开关。新操作员几分钟内即可掌握。
6. **采用Airtac气动缸和气阀。** 台湾Airtac气缸与气阀提供稳定动作和长寿命。全球通用备件，长期维护成本低。无电意味着无电气备件、无继电器板、无传感器故障。
7. **±1%灌装精度 + 滴漏零残留喷嘴。** 活塞计量稳定可靠，适用于膏体（无少灌/多灌）；底部关闭正向切断喷嘴杜绝滴漏、拉丝和膏体残留，保持瓶口与工作台清洁——对化妆品罐、食品容器及易燃产品尤为重要，因瓶口残留物可能引发火灾。
8. **加压料斗是完美天然搭配。** 因FF6依靠压缩空气运行，**加压料斗**（压缩空气辅助进料）无缝集成——无需额外电源。对于极粘稠膏体（胶水、重油、浓巧克力膏），加压料斗将“难供料”变为“稳定供料”。
9. **8种型号覆盖5–5000 ml；规格变更零成本。** 通过调整活塞行程改变灌装量——无需更换零件；规格变更仅需2–3分钟。覆盖从样品级化妆品罐到大桶的所有规格。
10. **201不锈钢框架 + 食品级304不锈钢接触部件；316可选。** 全不锈钢框架与食品级接触部件符合食品卫生标准（304）；**接触部件可定制为316不锈钢**，以增强耐酸碱与抗腐蚀性能——适用于制药、化工及腐蚀性产品。不锈钢阀组耐腐蚀，易于清洁。
11. **灵活料斗——30L标准，40L/60L/80L可选，搅拌/加压/加热可配置。** 标准**30L**料斗；**40L、60L或80L**更大尺寸可减少高产量线的补料次数。对难以处理的产品，可配置**搅拌料斗**（气动驱动，无电）、**加压料斗**（压缩空气辅助进料——原生匹配）或**加热料斗**（蒸汽/热水夹套或本质安全型电加热，满足防爆要求）——根据产品特性选择合适料斗。
12. **水平布局，紧凑轻便。** 水平机身占地小，净重仅**22–32 kg**，可置于桌面、工作台或现有产线上，易于移动。
13. **食品级硅胶密封圈（耐温200°C）。** 标准配置食品级硅胶O形圈；填充腐蚀性或粘性产品时可选耐腐蚀橡胶密封圈。
14. **多头可扩展（2头 / 4头 / 6头）。** 从单头起步；当产量增长时，可升级为**双头/四头/六头**设备（每头一个气动缸）——无需更换设备，无投资浪费。
15. **与FF2形成交叉销售搭档。** FF2（电动气动，带自动定时）与FF6（全气动，无电，防爆）构成互补组合：向有稳定电源且非易燃产品的客户推荐FF2；向无电源、有防爆需求或灌装易燃/酒精基/溶剂基产品的客户推荐FF6。两者覆盖所有客户类型——无订单流失。

**话术要点：**

- **客户灌装易燃/酒精基/溶剂基产品**（酒精基洗手液、香水、精油、酒精酊剂、溶剂型胶水、油漆、油墨、稀释剂、易燃润滑剂）→ **主推FF6**：设备无电，本质安全，FF2无法使用。

- **客户灌装膏体/高粘度物料**（酱料、果酱、乳霜、药膏、番茄酱、蜂蜜、乳液、胶水）→ 主推FF6：活塞式设计处理厚质产品不飞溅；底部关闭正向切断喷嘴消除瓶口残留；±1%精度。**建议为极粘稠膏体配置加压料斗。**
- **客户同时灌装膏体与液体**（含易燃液体）→ FF6可覆盖两类产品，且具备完整防爆安全——更换喷嘴，调整活塞行程，几分钟内切换产品。
- **客户重视最低运行成本** → 强调“0 W电耗——仅需压缩空气”；FF6是本系列中运行成本最低的灌装机。
- **客户需要稳定周期且有稳定电源，产品非易燃** → **转为推荐FF2电动气动系列**：电动控制可保持长周期稳定，自动定时模式实现全自动灌装。FF6适用于防爆/无电/易燃产品客户；FF2适用于稳定电源/非易燃客户。
- **客户仅灌装流动性非易燃液体** → 引导其选择**F2液体灌装机**——FF6对纯液体非易燃线属于过度配置。
- **客户需灌装多种规格** → 强调“调整行程即可变体积——无需换件；一台机器替代多台。”
- **客户无空气压缩机** → 主动提醒：**此设备仍需空气压缩机（0.4–0.6 MPa）**——可主动报价加购一台，确保设备到货即可运行。（FF6并未消除空压机需求，仅消除电力需求。）

### 4.2 常见问题

**Q1: 此设备需要电力吗？**  
A: **不需要。** FF6系列为**全气动单元（全气动驱动与控制）**：设备不含任何电气元件——无电机、无电磁阀、无定时器、无继电器、无PLC。完全依靠压缩空气运行，仅需**空气压缩机（0.4–0.6 MPa）**。**全程无电，无电费，无点火源——本质安全，适用于防爆作业。**

**Q2: 我需要空气压缩机吗？**  
A: 是的。FF6为全气动，必须连接供气压力为**0.4–0.6 MPa**的空气压缩机。普通小型活塞式压缩机（带储气罐）即可满足；也可在订单中一并添加。

**Q3: 该设备是防爆的吗？能灌装酒精基或溶剂基产品吗？**  
A: **是的——这是FF6的最大卖点。** FF6不含任何电气元件，因此无点火源。**本质安全 / 防爆构造**，适用于灌装易燃、酒精基或溶剂基产品（酒精基洗手液、香水、精油、酒精酊剂、溶剂基胶水、油漆、油墨、稀释剂、易燃润滑剂等）及防爆区域作业。若客户需灌装易燃产品，FF6是本系列产品中唯一可行选项。

**Q4: 灌装精度和速度是多少？**  
A: 精度为**±1%以内**（活塞式计量——稳定，无漂移）；速度为**5–30次/分钟**（膏体调校；比纯液体灌装机慢，因膏体需更长沉降时间），且速度可调。

**Q5: 它能同时灌装膏体和液体吗？能处理易燃产品吗？**  
A: **可以——FF6专为膏体和高粘度产品优化，也适用于流动性液体，包括易燃/酒精基/溶剂基产品。** 主要用途：酱料、番茄酱、果酱、蜂蜜、花生酱、巧克力膏、芥末酱、蛋黄酱；易燃或酒精基化妆品乳霜与凝胶；药膏；易燃或溶剂基胶水、油漆、油墨、易燃润滑剂。次要用途：酒精基液体（香水、精油、酒精酊剂、消毒剂基液）、溶剂，以及水、果汁、牛奶、食用油。**一台机器覆盖膏体与液体两大类别，且具备完整防爆安全——更换喷嘴，调整活塞行程，几分钟内切换产品类别。**

**Q6: 它能实现全自动电定时运行吗？**  
A: **不能。** 因FF6为全气动，无电气元件，**自动电定时模式不可用**——仅支持**脚踏触发灌装**，即**半自动模式**。每次循环由操作员踩下脚踏开关启动。若客户需全自动运行且无需人工干预，应选择**FF2电动气动系列**（增加电定时器）——前提是车间非防爆区且产品非易燃。

**Q7: FF6与FF2膏体灌装机有何区别？**  
A: 两者均为活塞式膏体灌装机，覆盖5–5000 ml，具有相同料斗选项与喷嘴范围。主要差异：

- **FF2** 为**电动气动一体化**——需220V/50–60Hz（约100W）**加**空气（0.4–0.6 MPa）。电动控制使周期稳定，支持**自动定时模式**。更适合长周期连续运行和稳定节奏。**不适用于防爆区或易燃产品。**
- **FF6** 为**全气动**——仅需**空气（0.4–0.6 MPa）**；**完全无电**。本质安全，适用于**防爆作业及易燃/酒精基/溶剂基产品**。代价：失去自动定时模式（仅脚踏）和FF2的电动控制稳定性。

选择**FF2**：车间有稳定电源，产品非易燃，客户追求最稳定周期与自动定时模式。选择**FF6**：车间无电，处于防爆区，或产品为易燃/酒精基/溶剂基。

**Q8: 产品接触材料是否食品级？**  
A: 机架为201不锈钢，**所有产品接触部件均为食品级304不锈钢**，符合食品卫生要求；**316不锈钢可定制**（更强酸碱与耐腐蚀性——适用于制药、化工及腐蚀性产品）。密封件为食品级硅胶（耐温200°C）。

**Q9: 会滴漏、拉丝或留下膏体残留吗？**  
A: 不会。喷嘴采用**底部关闭正向切断**设计——灌装结束瞬间即关闭出料口，保证滴漏零残留。**对膏体应用至关重要**：无拉丝、无膏体尾、无瓶口残留。**对易燃产品更是防火安全优势**——无易燃残留于瓶口。喷嘴孔径可在5–25 mm范围内选择（适配膏体流动）。

**Q10: 更改灌装量或在膏体与液体间切换是否麻烦？**  
A: 完全不麻烦。在型号范围内，只需**调整活塞行程**即可改变灌装量——无需更换零件；切换仅需几分钟。**在膏体与液体间切换**也十分简单：更换喷嘴（膏体喷嘴 vs. 液体喷嘴），调整活塞行程与速度——几分钟内完成，无需工具。

**Q11: 料斗能否为难供料膏体定制？防爆设备上的加热料斗如何配置？**  
A: 可以。料斗标准为**30L**，可选**40L、60L或80L**大容量型号，适用于高产量线。因FF6全气动，**加压料斗**（压缩空气辅助进料）和**搅拌料斗**（气动驱动）天然匹配，无需额外电源。**加热料斗**可配置**蒸汽/热水夹套**或**本质安全型电加热**以维持防爆要求——订购时请与工厂确认具体加热方式。

**Q12: 最小起订量、交货时间与保修政策？**  
A: **最小起订量1台**；工厂**现货供应**，可快速发货；出口包装为加固纸箱，每箱一台，含工具与备件。设备提供**1年保修**（保修期内非人为损坏免费维修或更换零件；国际运费由客户承担），并提供**终身维护服务**。

## 6. 工作流程

### 6.1 灌装操作流程

```
① 安装
   连接空气压缩机；调节供气至0.4–0.6 MPa
   （无需电气连接）
        │
② 供料
   将膏体（或液体——含易燃/酒精基/溶剂基产品）加入料斗（标准30L；40/60/80L可选）
   （需时可配置搅拌/加压/加热料斗）
        │
③ 设置容量
   调整活塞行程 → 设置每循环灌装量（范围内无级调节）
   必要时调整灌装速度（膏体：通常5–30次/分钟）
        │
④ 放置容器
   将罐/瓶/桶直接置于灌装喷嘴下方
   （膏体：使用5–25 mm膏体喷嘴；液体：更换为5–25 mm液体喷嘴）
        │
⑤ 触发灌装
   脚踏开关（半自动模式——全气动FF6唯一模式）
        │
⑥ 灌装完成（精度±1%）
   底部关闭正向切断喷嘴 → 无滴漏、无拉丝、
   无膏体尾（且无易燃残留于瓶口）
        │
⑦ 下一个容器——重复
   重复④–⑥步骤，速度5–30次/分钟（膏体）
        │
⑧ 清洁与停机
   停止设备；断开气源；
   拆卸并冲洗料斗 / 活塞 / 灌装喷嘴；
   切换产品前务必清洁
```
