## 概述

FF4 全气动立式液体及膏体灌装机是由温州T&D包装机械厂生产的气动活塞式半自动灌装机，灌装容量范围为 5–1000 mL。整机采用 201/304 不锈钢材质，与产品接触部分可选 304 或 316 不锈钢。整机完全由压缩空气驱动，无需外部电源，特别适用于防爆车间或无电环境。可灌装低至高粘度流体，包括水、食用油、果汁、牛奶、酸奶、酱料、奶油、蜂蜜、洗发水、黄油、人造黄油、番茄酱、果酱、洗涤剂液体等，广泛应用于食品、日化及化工行业的小批量和中试生产。

### 4.2 常见问题解答

**Q1：FF4 系列需要电力吗？**  
A1：不需要。FF4 为全气动驱动，仅需 0.4–0.6 MPa 压缩空气即可运行，特别适合防爆或无电车间。

**Q2：能否灌装高粘度膏体？**  
A2：可以。FF4 采用活塞容积式灌装，适用于从水状液体到高粘度膏体（如番茄酱、蜂蜜、黄油、面霜）。对于超高粘度物料，建议选用 FF4B 系列或加热搅拌料斗。

**Q3：如何调节灌装量？**  
A3：通过机器侧面的手轮调节活塞行程来改变灌装量；灌装量与灌装速度均可无级调节。

**Q4：是否支持自动灌装？**  
A4：支持。机器可在脚阀模式与自动定时模式之间切换，在自动模式下可按预设间隔自动连续灌装。

**Q5：与产品接触的材料是什么？是否为食品级？**  
A5：标准配置为 304 不锈钢，可选 316 不锈钢；均符合食品级安全要求。密封圈为耐温 200 °C 的硅胶 O 型圈，也可选耐腐蚀橡胶密封圈。

**Q6：一台机器能否灌装多种不同规格？**  
A6：每款型号覆盖特定灌装范围，可通过调节活塞行程实现范围内调整；若跨度较大，建议更换对应型号（例如从 FF4-100 切换至 FF4-500）。

**Q7：包装方式及运输体积是多少？**  
A7：每台设备均以木箱包装，尺寸约 49 × 45 × 155 cm，重量约 50 kg，适用于拼箱海运或空运。

**Q8：保修期多长？**  
A8：整机一年保修，保修期外提供终身维修服务。

## 6. 工作流程

### 6.1 采购与交付流程

1. **需求确认**：客户提供灌装范围、物料粘度、产能需求及目标市场。
2. **型号推荐**：根据灌装量和物料特性推荐 FF4-100/200/300/500/1000 型号。
3. **报价与合同**：提供宁波 FOB 或温州 EXW 报价，含包装及付款条款，确认订单。
4. **生产与备货**：标准型号均有库存，按订单安排测试并进行木箱包装。
5. **试运行确认**：可拍摄试运行视频，确认灌装性能。
6. **发货**：从宁波港出货，提供商业发票、装箱单、原产地证书等文件。
7. **售后支持**：整机一年保修，提供终身维修服务。

### 6.2 机器操作流程

1. **连接气源**：将空压机软管接入机器进气口，调节压力至 0.4–0.6 MPa。
2. **加料**：打开料斗盖，倒入待灌装物料（建议预先过滤杂质）。
3. **设定灌装量**：旋转手轮，调节活塞行程至目标灌装量。
4. **设定灌装速度**：根据物料流动性设置合适的灌装速度与间隔。
5. **试灌**：使用空瓶进行试灌，检查灌装量与密封效果，微调至合格。
6. **批量灌装**：将瓶子置于灌装嘴下方，踩下脚阀或切换至自动模式进行连续灌装。
7. **清洗**：操作结束后，拆下灌装嘴与进料管，用水或溶剂清洗，并擦干。
