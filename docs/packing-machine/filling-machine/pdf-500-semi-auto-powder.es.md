## 6. Flujo de Trabajo

1. **Alimentación de material** — el polvo se introduce en el tolva (manualmente, o automáticamente mediante el alimentador espiral opcional con control de nivel fotoeléctrico).
2. **Configuración de dosificación** — el operario establece el peso objetivo en el teclado; el sistema de control microinformático acciona el motor paso a paso y el tornillo (tornillo de bloqueo).
3. **Llenado por espiral** — control de alimentación espiral con medición por sensor fotoeléctrico dispensa la cantidad preestablecida de polvo en el recipiente (bolsa, lata o botella).
4. **Pesaje y corrección automática** — la tecnología de pesaje electrónico verifica cada llenado; los errores provocados por cambios en la proporción del material o el nivel del tolva se rastrean y corrigen automáticamente.
5. **Conteo y memoria** — el sistema cuenta las unidades envasadas y memoriza los parámetros para ejecuciones repetidas; la función de limpieza elimina residuos de material.
6. **Manejo del recipiente y sellado** — el operario alimenta las bolsas manualmente; la boca de llenado limpia facilita el sellado.
