## 1. 产品概述

### 1.1 产品类别

- **行业：** 包装机械 / 灌装设备（灌装机）
- **产品名称：** 半自动气动水平液体灌装机
- **机型类型：** 半自动 · 全气动 · 水平式 · 活塞式液体灌装机
- **驱动方式：** 全气动驱动；**整机不使用任何电力**，由空气压缩机供能
- **自动化等级：** 半自动或全自动（脚踏开关 / 自动定时器触发，可切换）
- **认证与保修：** CE认证；整机1年保修，保修期后提供终身维护服务

### 1.2 应用场景

专为**流动性好、低至中等粘度液体**的容积式灌装设计。典型应用产品与行业：

- **食品饮料：** 饮用水、果汁、牛奶、酒类、食用油、调味液
- **日化用品：** 洗衣液、洗碗液、洗手液、沐浴露等液体清洁剂
- **医药与个人护理：** 药液、消毒剂、外用药液
- **典型客户：** 小批量多规格生产企业、实验室取样、车间产线升级、**防爆车间（无需电力，本质安全）**，以及频繁更换产品或灌装量的企业

### 1.3 核心功能

- **活塞式容积灌装：** 气缸驱动活塞，行程可调；范围内无级调节容量，换规格无需更换零件
- **全气动控制：** 无电机、无电路、无电子元件——连接空气压缩机即可启动生产
- **双触发模式：** 脚踏开关（手动触发）或自动定时器（连续触发）；可自由切换半自动与全自动
- **防滴漏灌装：** 底部关闭式正向切断喷嘴在灌装结束后立即密封出口——无拉丝、无滴漏
- **可定制灌装头：** 标准为单头；**可定制为双头（2）、四头或六头**，实现产能倍增
- **可调灌装量与速度：** 适配不同瓶型与生产节奏

## 2. 核心优势

> **全气动是本系列最大卖点——以下前五项优势均围绕此展开。**

1. **完全无需电力——全气动驱动** —— 无电机、无电子控制、无接线，从根本上消除电气故障点。连接空气压缩机（0.4–0.6 MPa）即可运行，即使车间无电源插座也可使用。
2. **需空气压缩机——换取防爆安全性** —— 所有动力来自压缩空气，使其成为**本质安全型防爆设备**，可直接用于酒精、溶剂等易燃易爆液体的灌装——这是电动灌装机无法实现的。
3. **采用Airtac品牌气动元件** —— 配备台湾Airtac气缸与阀门：动作稳定、寿命长、全球通用且配件易购，有效降低客户维护成本。
4. **无电力 = 故障率低、维护少、寿命长** —— 无烧毁电路板或电机风险；日常维护仅需空气处理单元（FRL）和密封件。总体拥有成本远低于电机驱动设备。
5. **运行成本仅为压缩空气** —— 耗气量仅约0.55–1.1 m³/h；小型活塞式空压机即可满足需求。能源成本几乎可忽略不计。
6. **201不锈钢框架 + 食品级304不锈钢接触部件，316可定制** —— 全不锈钢框架；接触部件符合食品安全标准，304为标配，**316不锈钢接触部件可定制**（更强酸碱与耐腐蚀性，适合制药、化工及腐蚀性产品）；不锈钢阀体设计耐腐蚀、易清洗。
7. **±1%灌装精度 + 防滴漏喷嘴** —— 可靠活塞计量；底部关闭式正向切断喷嘴杜绝滴漏与拉丝，保持瓶口与工作台清洁，减少物料浪费。
8. **8款型号覆盖5–5000 ml，零成本换型** —— 仅需调整活塞行程即可改变灌装量——无需更换零件，2–3分钟内完成。
9. **水平结构，紧凑轻便** —— 占地面积小，净重仅22–32 kg，可放置于桌面、工作台或生产线上，移动方便。
10. **食品级硅胶密封（耐热至200℃）** —— 硅胶O型圈符合食品级安全标准；腐蚀性产品可选耐腐蚀橡胶密封。
11. **半自动 ⇄ 全自动可切换，多头可扩展** —— 可从脚踏半自动起步；随着产量增长，可切换至自动定时模式，或升级为**双头、四头、六头**机型——无需更换设备，投资不浪费。

### 4.2 常见问题解答（FAQ）

**Q1：该设备需要电力吗？**  
A：**不需要。** F6系列为全气动设计，无电机、无电路——所有动作均由压缩空气驱动。但**必须配套空气压缩机**：气源压力0.4–0.6 MPa，耗气量约0.55–1.1 m³/h。

**Q2：空气压缩机有何要求？**  
A：普通小型活塞式空气压缩机（带储气罐）即可满足需求——将输出压力设定为0.4–0.6 MPa，并确保压缩机气流覆盖设备耗气量（约0.55–1.1 m³/h）。建议参考工厂推荐型号，也可随设备一并采购。

**Q3：该设备是否防爆？**  
A：是。全气动驱动且无电力，使其成为**本质安全型防爆设备**，适用于灌装酒精、溶剂等易燃液体的车间——这是相比电动灌装机的核心优势。

**Q4：灌装精度与速度如何？**  
A：精度为**±1%以内**（活塞计量，稳定无漂移）；速度为**10–40次/分钟**（部分型号为10–30次/分钟），且可调。

**Q5：可灌装高粘度或膏状产品吗？**  
A：本机专为**流动性液体**设计，如水、食用油、果汁、牛奶、酒类、药液、液体洗涤剂等。对于高粘度或膏状物（酱料、乳膏、药膏），建议选用工厂的**膏体灌装机系列**。

**Q6：接触部件是否食品级？**  
A：机身为201不锈钢，**接触部件为食品级304不锈钢**，符合食品安全标准；**可定制316不锈钢**（更强酸碱与耐腐蚀性，适用于制药、化工及腐蚀性产品）。密封件为食品级硅胶（耐热至200℃）。

**Q7：会滴漏或拉丝吗？**  
A：不会。灌装头采用**底部关闭式正向切断结构**，灌装结束瞬间即关闭出口，确保滴漏零发生。喷嘴直径可选3–12 mm。

**Q8：更换灌装量是否麻烦？**  
A：不麻烦。在型号范围内，只需**调整活塞行程**即可改变灌装量——无需更换零件，几分钟内完成。非常适合多规格、小批量生产。

**Q9：能否全自动运行？若产能不足怎么办？**  
A：可以。支持**脚踏（半自动）与自动定时（全自动）模式**，可随时切换。若产能不足，可定制**双头、四头或六头**机型（每缸一个头）——无需更换设备。

**Q10：最小起订量、交货期与保修政策？**  
A：**最小起订量1台**；工厂**现货供应**；加厚出口纸箱包装，含工具与备件；**整机1年保修**（非人为损坏免费维修或更换零件；国际运费由客户承担），保修期后提供**终身维护服务**。

