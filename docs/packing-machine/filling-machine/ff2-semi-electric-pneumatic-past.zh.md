## 核心概要
FF2系列是温州T&D公司的**半自动水平式电动气动膏体灌装机（气动与电动一体化）**，专为**膏体和高粘度产品**设计，同时具备灌装**流动性液体**的能力。涵盖8个型号（FF2-50/100/300/500/1000/2500/3000/5000），灌装范围从**5–50 ml**到**500–5000 ml**。该设备采用**电动气动一体化设计——气动执行+电动控制**：需220V/50–60Hz电源（约**100W**）及0.4–0.6 MPa气源。配备**Airtac气动元件**，灌装速度为**5–30次/分钟**（针对膏体调校——比纯液体灌装机慢，因膏体每冲程需更长时间稳定）。整机框架为**201不锈钢**，所有与产品接触部件均为**食品级304不锈钢（316不锈钢可按需定制）**。活塞式容积灌装实现**±1%精度**，并配有**底部关闭式正向切断无滴漏喷嘴**（喷口直径5–25 mm可选，适配膏体流速）。标准配置为**30L料斗**；可选**40L、60L或80L**更大料斗，还可根据产品特性加装**加热料斗**（保持温度敏感产品流动）、**搅拌料斗**（防止沉淀与分层）、或**加压料斗**（辅助高粘度膏体进料）。支持**脚踏开关**或**自动定时器**两种触发模式，操作员可在半自动与全自动间自由切换。标准配置为单头灌装；**双头、四头或六头版本可定制**。适用于化妆品（乳霜、乳液、凝胶）、食品（酱料、果酱、蜂蜜、番茄酱、花生酱）、日化品（洗发水、护手霜）、药品（药膏）、化学品（润滑剂、胶水）以及流动性液体。

### 1.3 核心功能

- **活塞式容积灌装，专为膏体优化：** 气缸驱动活塞，行程可调——可稳定处理厚质物料（酱料、乳霜、药膏），避免飞溅或拉丝；体积可在型号范围内无级调节；无需更换零件即可调整参数
- **液体兼容性为附加优势：** 通过更换喷嘴并调节活塞行程，可快速由膏体切换至液体灌装；一机覆盖两类产品
- **电动气动一体化控制：** 气动执行由精密电动控制驱动——循环时间精准稳定，灌装速度**5–30次/分钟**（膏体调校；比纯液体灌装机慢，因膏体每冲程需更长时间稳定）
- **双触发模式：** 脚踏开关（半自动）或自动定时器（全自动）；半自动 ⇄ 全自动可切换
- **无滴漏灌装：** 底部关闭式正向切断喷嘴——灌装结束瞬间即密封出料口；**无拉丝、无滴漏、瓶口无膏体残留**（对化妆品与食品应用至关重要）
- **可定制灌装头：** 标准为单头；**双头（2头）、四头或六头配置可定制**，以提升产量
- **可调灌装量与速度：** 适配不同容器规格（小罐、大桶）与产线节拍
- **灵活的料斗/进料选项：** 标准**30L料斗**；可选**40L / 60L / 80L**更大料斗，减少补料次数；可选**加热料斗**（温控保持产品流动）、**搅拌料斗**（防止沉淀、分层与表面结皮）或**加压料斗**（辅助高粘度膏体进料），以匹配产品特性

## 2. 主要优势

> **电动气动一体化（气动与电动一体化）是本系列最大卖点——以下前五项优势均围绕此核心展开。多功能性（一机兼顾膏体与液体）是第二项关键优势。**

1. **电动气动驱动——更高精度控制，更稳定的灌装周期。** 电动控制结合气动执行，由电气系统精确控制灌装周期。在长时间连续运行中，周期保持一致，批次重复性优异；灌装速度为**5–30次/分钟**，可随生产节奏调节。
2. **电动控制定时器——更精细的自动模式设置。** 在自动模式下，填充间隔由电动定时器控制：调节精细、响应迅速，非常适合节奏化的连续膏体灌装。
3. **采用Airtac气动元件。** 台湾Airtac气缸与阀门提供稳定动作与长寿命——对膏体应用尤为重要，因气缸需克服更高的背压。全球易购备件，长期维护成本低。
4. **超低功耗——运行成本极低。** 总功耗仅约**100W（0.1 kW）**，可接入任意标准220V/50–60Hz插座；电费几乎可忽略不计。气耗与同类气动灌装机相当。
5. **操作简单——接电通气即可启动。** 连接电源（220V）与气源（0.4–0.6 MPa），即可开始生产。电动控制面板直观，新操作员可快速上手。
6. **201不锈钢框架 + 食品级304不锈钢接触部件；316可选。** 整机不锈钢结构，食品级接触部件符合食品安全标准（304）；**接触部件可定制为316不锈钢**，耐酸碱与腐蚀更强——适用于制药、化工及腐蚀性产品。不锈钢阀组抗腐蚀，清洁方便——对膏体类残留难清理的产品尤为关键。
7. **±1%灌装精度 + 无滴漏喷嘴。** 活塞计量稳定可靠，膏体灌装无欠量或过量；底部关闭式正向切断喷嘴杜绝滴漏、拉丝与膏体尾迹，保持瓶口与工作台洁净——对化妆品罐、食品容器及药品包装至关重要。
8. **一机双用——膏体+液体，多功能与高价值。** FF2虽以膏体为主，但**也可灌装流动性液体**：更换喷嘴、调节活塞行程，即可快速切换产品类别。**一台机器替代两台专用灌装机**（仅膏体与仅液体）。
9. **8款型号覆盖5–5000 ml；换型零成本。** 通过调节活塞行程即可改变灌装量——无需更换零件；规格变更仅需2–3分钟。从小样化妆品罐到大桶皆可覆盖。
10. **灵活料斗——30L标准，加热/搅拌/加压可选。** 料斗标准容量为**30L**，可选**40L / 60L / 80L**更大容量，减少高产量线的补料停顿。针对难处理产品，可加装**加热料斗**（保持蜂蜜、巧克力膏等温敏产品流动）、**搅拌料斗**（防止颗粒酱料沉淀、分层与表面结皮）或**加压料斗**（辅助高粘度膏体稳定供料）——一台机器适应多种膏体特性。
11. **水平式、紧凑、轻便。** 水平机身占地小，净重仅22–32 kg，适合桌面、工作台或现有生产线，移动便捷。
12. **食品级硅胶密封圈（耐温200°C）。** 标准配置食品级硅胶O型圈；填充腐蚀性或粘性产品时可选耐腐蚀橡胶密封圈。
13. **半自动⇄全自动可切换，多头可扩展。** 初始可使用脚踏半自动操作；产量增长后，可切换至自动定时模式，或升级为**双头/四头/六头**机型——无需更换设备，投资不浪费。

### 4.2 常见问题解答

**Q1：这台机器需要用电吗？**  
A：**是的。** FF2系列为电动气动一体化设备：电动控制部分需**220V / 50–60Hz**电源（功耗仅约**100W**），而灌装动作由压缩空气驱动，因此**必须连接空压机（0.4–0.6 MPa）**。

**Q2：我需要空压机吗？**  
A：是的。该机采用气动执行+电动控制，必须连接供气压力为**0.4–0.6 MPa**的空压机。普通小型活塞式空压机（带储气罐）即可满足需求；也可在订单中一并添加。

**Q3：这台机器是防爆的吗？**  
A：FF2为电动气动型（含电动控制部件），**并非设计为防爆设备**。若车间有防爆要求，或需灌装酒精类溶剂等易燃液体，请推荐**FF6全气动膏体灌装系列**（无电力，本质安全，防爆）。

**Q4：灌装精度和速度是多少？**  
A：精度为**±1%以内**（活塞式计量——稳定无漂移）；速度为**5–30次/分钟**（膏体调校；比纯液体灌装机慢，因膏体每冲程需更长时间稳定），且速度可调。

**Q5：它能灌装膏体和液体吗？能处理哪些产品？**

## 6. 工作流程

### 6.1 灌装操作流程

```
① 安装
   连接220V/50–60Hz电源（约100W）
   连接空压机；调节供气压力至0.4–0.6 MPa
        │
② 上料
   将膏体（或液体）加入料斗（标准30L；40/60/80L可选）
   （需时可使用加热/搅拌/加压料斗）
        │
③ 设定灌装量
   调整活塞行程 → 设置每循环灌装量（范围内无级调节）
   必要时调整灌装速度（膏体：通常5–30次/分钟）
        │
④ 放置容器
   将罐/瓶/桶置于灌装喷嘴正下方
   （膏体：使用5–25 mm膏体喷嘴；液体：更换为3–12 mm液体喷嘴）
        │
⑤ 触发灌装
   脚踏开关（半自动模式）或自动定时器（自动模式）
        │
⑥ 灌装完成（精度±1%）
   底部关闭式正向切断喷嘴 → 无滴漏、无拉丝、无膏体尾迹
        │
⑦ 下一个容器 — 重复
   重复④–⑥步骤，速度5–30次/分钟（膏体）
        │
⑧ 清洗与关机
   停机；断开电源与气源；
   拆卸并冲洗料斗/活塞/灌装喷嘴；
   清洁后方可切换至其他产品
```
