## 6. 工作流程

1. **物料供入** — 粉末送入料斗（手动投料，或通过可选螺旋送料器配合光电液位控制实现自动供料）。
2. **计量设置** — 操作员在键盘上设定目标重量；微电脑控制系统驱动步进电机与螺杆（限位螺钉）。
3. **螺杆填充** — 螺旋供料控制结合光电传感器测量，将设定量的粉末精确送入容器（袋、罐或瓶）。
4. **称重与自动校正** — 电子称重技术验证每次填充；因物料比例或料位变化引起的误差自动追踪并修正。
5. **计数与记忆** — 系统自动计数已填充数量，并记忆参数以支持重复运行；清洁功能清除残留物料。
6. **容器处理与封口** — 操作员手动投袋；出料口洁净，便于封口。
