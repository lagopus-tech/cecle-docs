# Руководство по выбору оборудования для наполнения и обзор продукции

> Настоящий документ объединяет технические данные серии машин для наполнения Wenzhou T&D Packing Machinery (жидкости / пасты / порошки / гранулы / аэрозоли / парфюмерия / мешки-сумки / автоматические линии наполнения) для целей подбора, ответов на вопросы клиентов и обучения каналов сбыта.

## Обзор

- **Позиционирование**: семейство машин для наполнения, основанное на **объемной дозировке поршневого типа** как основной технологии, охватывающее все сценарии упаковки — от жидких материалов с низкой вязкостью до высоковязких паст, от материалов без частиц до тонких порошков. Более 200 моделей, позиционируемых по трем осям: форма материала × объем наполнения × степень автоматизации.
- **Основная технология**: пневматическое поршневое дозирование, оснащенное пневматическими компонентами из Тайваня Airtac и фотоэлектрическими датчиками немецкой SICK. Все пневматические модели не требуют электропитания и являются взрывобезопасными по умолчанию.
- **Точность наполнения**: поршневой тип ≤ ±1%; магнитный насос ≤ ±2%; весовое наполнение порошков и гранул ≤ ±1% (весовое наполнение гранул ±1–5%).
- **Охват объемов наполнения**: 2,5 мл (минимальный ручной пресс) → 5 000 мл (стандартные модели) → 25–50 кг (массовые весовые машины).
- **Ступени автоматизации**: ручной пресс (A03) → полуавтоматический пневматический (серии F6/FF6) → полуавтоматический ЧПУ / магнитный насос (GFK-160 / DF-A) → автоматический многоголовочный (A2/A4/A6/A8, FA2/FA4/FA6) → полностью автоматическая линия (разборщик бутылок + наполнитель + закручиватель + этикетер + конвейер).
- **Самые продаваемые модели**: горизонтальный пневматический одноголовочный жидкостной **F6**, горизонтальный пневматический одноголовочный пастообразный **FF6**, двухголовочный жидкостной **DF6**, двухголовочный пастообразный **DFF6**; автоматические жидкостные **A2/A4/A6**, автоматические пастообразные **FA2/FA4/FA6**.
- **Стандарт материала**: корпус из стали 201, **детали, контактирующие с продуктом — из нержавеющей стали 304 (316 по запросу)**, силиконовые уплотнители (устойчивы к нагреву до 200 °C) или коррозионностойкая резина, соответствующие требованиям пищевой безопасности и ГМП.
- **Индивидуальные заказы**: диапазон объема наполнения, количество голов наполнения (1/2/4/6/8), тип бункера (стандартный / с перемешиванием / нагреваемый и с перемешиванием), материал (304 / 316 / ПТФЭ поршня), диаметр сопла (3–12 мм), тип бутылки (по образцу клиента), длина конвейера, напряжение (220 В / 110 В) и требования к взрывобезопасности — все можно настроить. Срок изготовления индивидуальных машин и полных линий: 30–55 рабочих дней.
- **Типичные отрасли обслуживания**: бытовая химия и личная гигиена, пищевая промышленность, фармацевтика, косметика, агропромышленность, химикаты, ароматизаторы и духи, смазочные материалы, аэрозоли, электронные жидкости, соусы и приправы.

# 1. Что такое машина для наполнения

## 1.1 Определение

Машина для наполнения — это упаковочное оборудование, которое дозирует жидкости, пасты, порошки или гранулы в бутылки, банки, пакеты, стаканчики или бочки **до заданного объема или массы**. Это ключевая станция на линии наполнения: впереди она взаимодействует с разборщиком бутылок и подачей, сзади — с закручивателями крышек, этикетерами, кодировщиками и упаковщиками в коробки.

В этом ассортименте машины для наполнения делятся на пять категорий по **форме материала**, каждая с собственным принципом дозирования и модельной серией:

| Форма материала | Наименование продукта | Серия моделей | Типичные материалы |
| --- | --- | --- | --- |
| Жидкость | Машина для наполнения жидкостей | Серия F (F2/F3/F6), серия DF (двухголовочная) | вода, масло, сок, молоко, вино, средство для рук, дезинфицирующий раствор, жидкие лекарства |
| Паста / вязкая | **Машина для наполнения пасты** | Серия FF (FF2/FF4/FF5/FF6/FF9), серия DFF (двухголовочная) | шампунь, зубная паста, соус, кетчуп, мед, крем для кожи, лак для ногтей |
| Порошок | Машина для наполнения порошков | Серии PDF / ADF / SDF | молочный порошок, мука, приправа, порошковое моющее средство, лекарственные порошки, добавки |
| Гранулы | Весовая машина для гранул | Серии GPM / KY | рис, MSG, бульонный кубик, семена, корм, орехи, детали для производства |
| Аэрозоль | Машина для наполнения аэрозолей | Серия AF | аэрозольный насекомоубийца, спрей для волос, воздухоочиститель, мусс |

## 1.2 Принцип работы

### 1.2.1 Сравнение пяти методов дозирования

| Метод дозирования | Принцип | Точность | Подходящие материалы | Представительные модели |
| --- | --- | --- | --- | --- |
| **Поршневое объемное** (основной) | Цилиндр приводит поршень вверх-вниз; камера поршня создает разрежение для забора материала, затем выталкивает его, чтобы выдать дозированную порцию | ≤ ±1% | жидкости и пасты (без частиц, или только очень мелкие частицы) | F6 / FF6 / DF6 / DFF6 / A2 / FA2 |
| **Магнитный насос / шестеренчатый насос** | Импортный преобразователь частоты плюс высокоточный многооборотный потенциометр регулируют скорость насоса; дозирование по накопленному расходу | ≤ ±2% (повторяемость <0,5%) | низковязкие, коррозионностойкие жидкости (кислоты, щелочи, масла, жидкие лекарства) | DF-A / DF-2A / YT-1 |
| **Вакуумный всасывание + уровень позиционирования** | Непрерывное вакуумное заполнение бутылки; избыток материала автоматически возвращается в бак; глубина погружения сопла определяет конечный уровень | ≤ ±1% | духи, флоридская вода, пенообразные жидкости (высота бутылки не должна быть строго постоянной) | YT-2 / YT-4 / APF-500 |
| **Шнековое дозирование** | Шаговый двигатель приводит шнек нужного размера; фотоэлектрический контроль корректирует ошибку | ≤ ±1% | порошки, сверхтонкие порошки, мелкие гранулы | PDF-500 / ADF-500 / SDF-500 |
| **Электронное взвешивание** | Высокоточный цифровой датчик нагрузки плюс трехскоростная (быстрая/медленная) переменная частота подачи, корректируемая в реальном времени | ±0,3% (масса) до ±1–5% (мелкие упаковки) | гранулы, комки, материалы, склонные к расслоению | GPM-2A / GPM-2B / KY-C25KG |

### 1.2.2 Стандартный рабочий цикл

```
Подача (ручная/автоматическая) → расположение контейнера (фотоэлектрический/позиционирующий зажим) → опускание головки наполнения → дозированное наполнение → поднятие головки наполнения
→ вывод → [только для автоматической линии] установка крышки → закручивание/прижим → наклейка этикетки → кодирование → упаковка в коробку
```

**Полуавтоматические модели** (F6/FF6/DF6/DFF6 и аналогичные): бутылки устанавливаются вручную, наполнение запускается педалью или таймером; корпус машины разделен и может быть установлен на ножках или на столе; один оператор.  
**Автоматические модели** (A2/A4/A6, FA2/FA4/FA6, AD-5000): настройка через сенсорный экран ПЛК плюс позиционирование конвейера и фотоэлектрический датчик SICK «нет бутылки — нет наполнения»; многоголовочное наполнение одновременно; подключается напрямую к полной линии.

### 1.2.3 Ключевые факторы, влияющие на качество наполнения

- **Точность наполнения** зависит от: стабильности давления подачи материала, скорости наполнения, вязкости материала, скорости движения головки наполнения вверх-вниз, а также скорости открытия и закрытия верхних и нижних клапанов (давление пружины регулируемое).
- **Скорость наполнения** зависит от: вязкости материала, объема наполнения, диаметра сопла (больший диаметр наполняет быстрее), скорости цилиндра и скорости подъема головки наполнения.
- **Материалы с образованием пены**: снижайте скорость выдачи или используйте двухступенчатое наполнение (быстро, затем медленно).

## 2.6 Четырехэтапный метод выбора

```
Шаг 1 | Определите форму материала
   Чистая жидкость (водоподобная / масляная) ...... серия F
   Паста / вязкая / соус .................. серия FF (может наполнять жидкости)
   Порошок / сверхтонкий порошок ............... серия PDF / SDF / ADF
   Гранулы / комки ........................... серия GPM / KY
   Аэрозоль .................................. серия AF
   Парфюмерия / пенообразные ........................ серия YT / APF

Шаг 2 | Подтвердите диапазон объема наполнения
   2,5–50 мл → A03
   5–100 / 10–200 / 20–300 мл → -100 / -200 / -300
   50–500 / 100–1 000 мл → -500 / -1 000
   260–2 600 / 500–5 000 мл → -2600 / -5000
   * Если диапазон слишком широк, нужно менять машину; у каждой машины есть фиксированный диапазон

Шаг 3 | Выберите степень автоматизации
   Пробное производство / малые партии / бюджетный выбор ...... ручной пресс A03, ЧПУ GFK-160
   Малые и средние партии, один оператор ................ полуавтоматические F6 / FF6 / DF6 / DFF6
   Массовое производство, безлюдная работа ................ автоматические A2 / A4 / A6 / FA2 / FA4
   Требования к нескольким станциям .......................... полная линия (разборщик + наполнитель + закручиватель + этикетер)

Шаг 4 | Подтвердите специальные требования
   Взрывобезопасность (алкоголь / парфюмерия / аэрозоли) ...... полностью пневматическая, без электропитания
   Высоковязкая паста ............................... ПТФЭ поршень (примерно +50 долларов США за штуку)
   Очень коррозионно-стойкая жидкость ........................ магнитный насос DF-A / DF-2A, материал 316
   Материалы, склонные к расслоению / требуют сохранения тепла ........ FF6B (перемешивание), FF6C (нагреваемый и с перемешиванием)
   Упаковка в сумки-сумки .................................... F8 / DF8 / LGD / AF8-1000
```

# 3. Часто задаваемые вопросы и технические ответы

## 3.1 Вопросы по выбору и принципу работы

**В1: Может ли машина для наполнения жидкостей наполнять пасту?**  
Нет. **Машина для наполнения пасты (серии FF/DFF/FA) может наполнять как жидкости, так и пасты (двухфункциональная), но машина для наполнения жидкостей (серии F/DF/A) предназначена только для чистых жидкостей и не может проходить через пасту.** При вязком материале рекомендуем сразу выбрать модель серии FF / DFF / FA.

**В2: Что делать, если материал содержит частицы?**  
Стандартные поршневые и магнитные насосные машины **не могут работать с материалами, содержащими частицы, или частицы должны быть чрезвычайно мелкими**. Для материалов с частицами следует перейти на шнековую машину для порошков (PDF / SDF / ADF, для порошков и мелких гранул) или на весовую машину для гранул (серии GPM / KY).

**В3: Может ли одна машина покрыть объемы от 10 мл до 5 000 мл?**  
Нет. **У каждой машины фиксированный диапазон объема наполнения** (определяется диаметром поршня и ходом). Широкий диапазон требует машин разных диапазонов. Для клиентов с несколькими спецификациями рекомендуем одну машину для основной спецификации плюс сменные цилиндры.

**В4: Какова фактическая точность наполнения?**  
Поршневое объемное ≤ ±1%; магнитный насос ≤ ±2% (повторяемость <0,5%); шнековое наполнение порошков ≤ ±1%; массовое взвешивание ±0,3%, малые упаковки гранул ±1–5%. Основные факторы: **стабильность давления подачи, скорость наполнения, вязкость материала и скорость подъема головки наполнения**.

**В5: Пневматическая или электрическая — какую выбрать?**  
- **Полностью пневматическая**: не требует электропитания, взрывобезопасна по умолчанию, идеальна для алкоголя, духов, аэрозолей и растворителей; клиент должен предоставить воздушный компрессор (0,4–0,6 МПа); простая конструкция, низкая частота отказов и низкая стоимость обслуживания.  
- **Электрическая и электронная (ЧПУ / магнитный насос / автоматическая)**: требует 220 В; сенсорный экран ПЛК позволяет точно настраивать параметры, высокая скорость и легкая интеграция в полную линию.

**В6: Почему горизонтальные модели являются основными?**  
Горизонтальные полностью пневматические модели (серии F6/FF6) используют самовсасывающий шланг или бункер, обеспечивают высокую точность, простоту очистки и зрелую конструкцию — это **наиболее часто рекомендуемые модели** в данном ассортименте. Вертикальные модели (FF4/FF5) позволяют свободно регулировать объем и скорость в диапазоне, но горизонтальные машины для паст охватывают большие объемы.

**В7: Какие особые требования у высоковязких паст?**  
**Очень липкие материалы должны использовать ПТФЭ поршень** (примерно 50 долларов США за штуку), иначе трение между поршнем и стенкой цилиндра повреждает уплотнение и вызывает отклонение объема наполнения. Если материал также расслаивается или затвердевает, добавьте **бункер с перемешиванием (тип B)** или **нагреваемый и с перемешиванием бункер (тип C)**.

**В8: Могут ли сумки-сумки и бутылки использовать одну и ту же машину?**  
Нет. Сумки-сумки требуют специальных механизмов: толкание сумки, надувание сумки, подвешивание крышки и завинчивание крышки. Выбирайте F8 / DF8 / DFF8 (полуавтоматические) или серии AF8-1000 / TD-1A / LGD (универсальные и автоматические модели).

**В9: Почему машина для наполнения парфюмерии не ограничена формой бутылки?**  
Потому что используется **позиционирование по уровню**: сопло погружается на фиксированную глубину, избыток материала автоматически возвращается в бак. Неравномерная высота контейнеров все равно дает одинаковый уровень наполнения — стандартный подход для продуктов парфюмерии и флоридской воды. Обратите внимание, что она **не может наполнять пасты**.

**В10: Каковы MOQ, сроки и условия оплаты?**  
- **MOQ: 1 комплект** (большинство моделей в наличии).  
- **Модели в наличии**: товары в наличии, отправляются после оплаты.  
- **Индивидуальные модели и полные линии**: 30–45 рабочих дней (линия парфюмерии 45–55 рабочих дней).  
- **Оплата**: 100% Т/Т для стандартных заказов; полные линии 30% аванс + 70% перед отгрузкой (некоторые линии 60% аванс + 40% перед отгрузкой).  
- **Условия торговли**: EXW Вэньчжоу / FOB Нинбо.

**В11: Какие стандарты упаковки и доставки?**  
Полуавтоматические модели обычно отправляются в усиленных картонных коробках (некоторые — в деревянных ящиках); автоматические машины и полные линии — в деревянных ящиках; экспортные поставки упаковываются в деревянные ящики для экспорта при длительных перевозках.

**В12: Каковы гарантия и послепродажное обслуживание?**  
Одногодичная гарантия на всю машину. В течение гарантийного периода повреждения, возникшие при нормальном использовании согласно руководству, ремонтируются или заменяются бесплатно (клиент оплачивает доставку из Китая в местный пункт назначения); если требуется инженер на месте, расходы на поездку несет клиент. **Жизненная ремонтная служба** предоставляется после окончания гарантии. Продукты имеют **сертификат CE**.

## 3.3 Ежедневный чек-лист технического обслуживания

**Принцип «пяти фиксированных» смазки** (фиксированный персонал, фиксированный интервал, фиксированная точка, фиксированное количество, фиксированное качество смазки):

| Место | Смазка | Частота |
| --- | --- | --- |
| Редуктор червячной передачи | масло для червячной передачи / гипоидное масло / моторное масло | заменять периодически |
| Подшипники качения | литиевая смазка ZL-3 или универсальная силиконовая смазка | доливать периодически |
| Рельсы и зубчатые рейки | литиевая смазка ZL-3 | доливать периодически |
| Масляный ресивер воздуха | специальное пневматическое масло | проверять и доливать часто |

**Ежедневные проверки:**

1. Перед запуском каждый день проверьте давление воздуха (0,4–0,6 МПа; 0,5–0,8 МПа для полных линий), электропитание (220 В) и сброс аварийной кнопки.
2. **Регулярно сливайте воду из масляного отделителя воздуха** на входе, чтобы предотвратить попадание влаги в трубопровод и коррозию клапанов.
3. Регулярно очищайте **фильтр материала** и трубопроводы.
4. Периодически проверяйте все соединения и корпуса клапанов на утечки, и затягивайте все крепежные детали, чтобы устранить люфт.
5. Периодически проверяйте подвижные части (подшипники качения, ремни), и заменяйте их своевременно при серьезном износе.
6. Через год эксплуатации или при плановом ремонте — подкрасьте краской для защиты от коррозии.
7. Когда не производится, выключите машину, отключите питание и воздух; никогда не оставляйте инструменты, тряпки или другие посторонние предметы внутри машины.

**Ключевые правила безопасности:** настройки должны проводиться при остановленной машине, и только одним человеком; никогда не касайтесь движущихся механизмов, когда машина работает; длинные волосы должны быть прикрыты, а шарфы, браслеты или часы, которые могут зацепиться, не должны носиться; после отключения питания машина может автоматически включиться при восстановлении питания, поэтому держитесь подальше от движущихся частей.

## 4.2 Типичные случаи индивидуальной настройки

**Случай 1 | Наполнение высоковязкого соуса**  
Требование: кетчуп и соус чили, вязкие и прилипающие к стенкам.  
Решение: серия FF6 / DFF6 + ПТФЭ поршень + большой бункер с перемешиванием (тип B) + антикапельное сопло + функция продувки.  
Обоснование: ПТФЭ поршень предотвращает повреждение уплотнения; бункер с перемешиванием предотвращает расслоение; антикапельное сопло останавливает материал, прилипающий к бутылке.

**Случай 2 | Взрывобезопасное наполнение (алкоголь и духи)**  
Требование: 75%-ный дезинфицирующий раствор для рук, с требованием взрывобезопасности в цехе.  
Решение: полностью пневматическая серия F6 (без электропитания) + детали, контактирующие с продуктом, из 316 нержавеющей стали + коррозионностойкие резиновые уплотнения; для расширения — линия A4-500 + DC1 + конвейер + AL-220.  
Обоснование: полностью пневматическая машина не имеет электрических компонентов, устраняя источники искрообразования на корню.

**Случай 3 | Материалы, склонные к расслоению (мед и арахисовая паста)**  
Требование: материал расслаивается и образует корку при стоянии.  
Решение: модели FF6C / DFF6C с нагреваемым и с перемешиванием бункером поддерживают постоянную температуру и циркуляцию перед наполнением.

**Случай 4 | Сумки-сумки с носиком**  
Требование: сумки-сумки для моющих средств и желе, требующие наполнения и закручивания в одной единице.  
Решение: LGD02 (одноголовочная настольная роторная универсальная, 30–2 000 г, 10–30 сумок/мин, один оператор), или AF8-1000 для массового производства (120 циклов/мин); выберите версию с горизонтальным бункером с перемешиванием для соусов.

**Случай 5 | Полная линия индивидуальной настройки (массовое производство в бутылках)**  
Требование: интегрированная линия от разборщика бутылок до этикетирования.  
Решение: Разборщик бутылок (диаметр бутылки ≤80 мм) + четырехголовочный наполнитель FA4-1000 + автоматический закручиватель AC1 + круглый этикетер AL-220, 87 000 юаней, срок поставки 30–45 рабочих дней; можно добавить защитный экран из стекла, материал 316, мойщик бутылок и кодировщик.

**Случай 6 | Специальные контейнеры (бутылки из алюминиевых крышек и жидкие лекарства)**  
Требование: жидкие лекарства в бутылках из алюминиевых крышек.  
Решение: двухголовочная автоматическая система наполнения + система размещения крышек + одноголовочный автоматический закручиватель (специальная линия для алюминиевых крышек), или полная линия NLA-ALC-500.

## 4.5 Границы индивидуальной настройки (что мы не можем гарантировать)

Чтобы снизить риски после продажи, следующие границы должны быть четко определены до продажи:

1. **Машину для жидкостей нельзя преобразовать в машину для паст** — поток и конструкция поршня различаются, а стоимость преобразования превышает стоимость новой машины.
2. **Стандартные поршневые и магнитные насосные модели не могут гарантировать работу с материалами, содержащими частицы** — требуется решение с шнековым дозированием или взвешиванием.
3. **Нет обязательства по чрезмерно широкому диапазону объемов** — диапазон объема одной машины фиксирован, поэтому широкий диапазон требует нескольких моделей.
4. **Модели парфюмерии с позиционированием по уровню не могут гарантировать наполнение паст.**
5. **Индивидуальные машины не достигают лучшей точности, чем стандартный допуск** — настройка оптимизирует совместимость (контейнер, вязкость, производительность); она не может превышать предел точности принципа дозирования.
6. **Нет окончательной гарантии точности или производительности без образцов контейнера и материала** — точность и скорость зависят от вязкости материала и стабильности контейнера.
