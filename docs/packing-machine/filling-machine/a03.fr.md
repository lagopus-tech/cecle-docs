## VI. Processus de Travail
1.  **Montage** : Fixez le bac au sommet de la machine, en veillant à ce que l’anneau d’étanchéité soit correctement positionné.
2.  **Réglage du volume** : Ajustez la tige filetée située au bas de la machine pour verrouiller le volume de remplissage souhaité (2,5–50 ml).
3.  **Chargement du matériau** : Versez le produit dans le bac.
4.  **Purge / Test de remplissage** : Appuyez plusieurs fois sur la poignée pour évacuer l’air du cylindre de pompage et vérifiez un débit stable.
5.  **Production par lots** : Placez les bouteilles sous la buse, appuyez sur la poignée pour compléter le remplissage, puis relâchez-la pour permettre au mécanisme de ressort automatique.
6.  **Nettoyage** : Après la production, versez de l’eau chaude ou une solution de nettoyage dans le bac et appuyez plusieurs fois sur la poignée pour rincer intégralement le système interne de pompage.
