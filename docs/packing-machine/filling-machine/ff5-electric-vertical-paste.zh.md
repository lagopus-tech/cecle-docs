## 概述

FF5 电动立式液体及膏体灌装机是由温州T&D包装机械厂生产的电动活塞式半自动灌装机。本文重点介绍 FF5-1000 型号（灌装容量范围：100–1000 mL），该机型采用 220 V / 50–60 Hz 电源供电，额定功率为 500 W。整机框架采用 201/304 不锈钢材质，与产品接触部件可选 304 或 316 不锈钢。适用于水、食用油、果汁、牛奶、酸奶、酱料、奶油、蜂蜜、洗发水、黄油、人造黄油、番茄酱、果酱、洗涤剂液体等低至高粘度流体的灌装，广泛应用于食品、日化及化工行业的中小批量生产与中试阶段。与气动型 FF4 不同，FF5 仅需电源插座，无需空压机。

### 4.2 常见问题解答

**Q1：FF5 系列需要电力还是压缩空气？**  
A1：FF5 完全电动驱动，仅需 220 V / 50–60 Hz 电源，无需压缩空气。

**Q2：能否灌装高粘度膏体产品？**  
A2：可以。FF5 采用活塞容积式灌装，适用于从水状液体到高粘度膏体（如番茄酱、蜂蜜、黄油、面霜）的灌装。对于超高粘度物料，建议配备加热/搅拌料斗或选用 FF5B 系列。

**Q3：如何调整灌装量？**  
A3：通过手轮调节活塞行程来改变灌装量；灌装量与灌装速度均可无级调节。

**Q4：是否支持自动灌装？**  
A4：支持。机器可在脚踏模式与自动定时模式之间切换，自动模式按预设间隔进行连续灌装。

**Q5：与产品接触的材料是什么？是否为食品级？**  
A5：标准配置为 304 不锈钢接触部件；316 不锈钢可选。所有材料均为食品级安全。密封圈为耐温 200 °C 的硅胶 O 型圈；也可选耐腐蚀橡胶密封圈。

**Q6：一台机器能否灌装多种不同规格？**  
A6：每款型号覆盖特定灌装范围，可通过调节活塞行程实现范围内调整；若跨度较大，建议更换至匹配型号（例如从 FF5-100 切换至 FF5-500）。

**Q7：包装方式及运输尺寸是多少？**  
A7：每台设备均以木箱包装，尺寸约为 49 × 45 × 155 cm；重量依型号而异。木箱适用于拼箱海运或空运。

**Q8：保修期是多久？**  
A8：整机提供一年保修，保修期后仍可享受终身维修服务。

## 6. 工作流程

### 6.1 购买与交付流程

1. **需求确认**：客户提供灌装范围、物料粘度、产能要求及目标市场。
2. **型号推荐**：根据灌装量与物料特性推荐 FF5-100/300/500/1000 型号。
3. **报价与合同**：提供 Wenzhou EXW 或 Ningbo FOB 报价，包含包装与付款条款，确认订单。
4. **生产与备货**：标准型号有现货；按订单安排测试并进行木箱包装。
5. **试运行确认**：可拍摄试运行视频以确认灌装性能。
6. **发货**：按确认条款发货，提供商业发票、装箱单、原产地证书等文件。
7. **售后支持**：整机一年保修，提供终身维修服务。

### 6.2 机器操作流程

1. **接通电源**：将机器接入 220 V / 50–60 Hz 电源，并确保良好接地。
2. **加料**：打开料斗盖，倒入待灌装物料（建议预先过滤杂质）。
3. **设定灌装量**：旋转手轮，调节活塞行程以设定目标灌装量。
4. **设定灌装速度**：根据物料流动性设置合适的灌装速度与间隔。
5. **试灌**：使用空瓶进行试灌，检查灌装量与密封性，微调至合格。
6. **批量灌装**：将瓶子置于灌装喷嘴下方，踩下脚踏开关或切换至自动模式进行连续灌装。
7. **清洗**：操作结束后，拆下灌装喷嘴与进料管，用水或溶剂清洗并晾干。
