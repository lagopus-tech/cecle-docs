# คู่มือการเลือกเครื่องบรรจุและภาพรวมผลิตภัณฑ์

> เอกสารนี้รวบรวมข้อมูลผลิตภัณฑ์จากซีรีส์เครื่องบรรจุของ Wenzhou T&D Packing Machinery (ของเหลว / ครีม / ผง / เม็ด颗粒 / สเปรย์ / น้ำหอม / ถุงแบบยืน / สายการบรรจุอัตโนมัติ) เพื่อใช้ในการเลือกผลิตภัณฑ์สำหรับทีมขาย ตอบคำถามลูกค้า และฝึกอบรมพันธมิตรทางการค้า

---

## ภาพรวม

- **ตำแหน่ง**: ครอบครัวเครื่องบรรจุที่ใช้เทคโนโลยีหลักคือ **การชั่งปริมาตรด้วยลูกสูบลม** ครอบคลุมทุกสถานการณ์การบรรจุตั้งแต่ของเหลวบางๆ ไปจนถึงครีมหนืด ตั้งแต่วัสดุไร้อนุภาค ไปจนถึงวัสดุผงละเอียด มากกว่า 200 รุ่น จัดอยู่ตามแกนสามประการ: รูปแบบวัสดุ × ปริมาณการบรรจุ × ระดับอัตโนมัติ
- **เทคโนโลยีหลัก**: การบรรจุแบบลูกสูบลม ติดตั้งชิ้นส่วนลมจากไต้หวัน Airtac และเซ็นเซอร์โฟโตอิเล็กทริกจากเยอรมนี SICK โมเดลทั้งหมดใช้ลมไม่ต้องไฟฟ้า และมีความปลอดภัยต่อการระเบิดโดยธรรมชาติ
- **ความแม่นยำในการบรรจุ**: แบบลูกสูบ ≤ ±1%; แบบปั๊มแม่เหล็ก ≤ ±2%; ผงและเม็ด颗粒 ≤ ±1% (เม็ด颗粒 ±1–5%)
- **ขอบเขตปริมาณการบรรจุ**: 2.5 มล. (ขนาดเล็กที่สุดแบบกดมือ) → 5,000 มล. (โมเดลมาตรฐาน) → 25–50 กก. (เครื่องชั่งแบบ Bulk)
- **ลำดับอัตโนมัติ**: แบบกดมือ (A03) → แบบกึ่งอัตโนมัติลม (F6/FF6 ซีรีส์) → แบบกึ่งอัตโนมัติ CNC / ปั๊มแม่เหล็ก (GFK-160 / DF-A) → แบบอัตโนมัติหลายหัว (A2/A4/A6/A8, FA2/FA4/FA6) → สายการบรรจุอัตโนมัติเต็มรูปแบบ (เครื่องแยกขวด + เครื่องบรรจุ + เครื่องปิดฝา + เครื่องป้าย + เครื่องลำเลียง)
- **รุ่นยอดนิยม**: เครื่องบรรจุของเหลวแนวราบแบบลมทั้งหมด หัวเดียว **F6**, เครื่องบรรจุครีมแนวราบแบบลมทั้งหมด หัวเดียว **FF6**, เครื่องบรรจุของเหลวสองหัว **DF6**, เครื่องบรรจุครีมสองหัว **DFF6**; เครื่องบรรจุของเหลวอัตโนมัติ **A2/A4/A6**, เครื่องบรรจุครีมอัตโนมัติ **FA2/FA4/FA6**
- **มาตรฐานวัสดุ**: ตัวเครื่องทำจากสแตนเลส 201, **ส่วนสัมผัสวัสดุทำจากสแตนเลส 304 (เลือก 316 ได้)**, ยางซิลิโคน (ทนความร้อนได้ 200 °C) หรือยางกันสนิม ตรงตามข้อกำหนดด้านอาหารและ GMP
- **ปรับแต่งได้**: ช่วงปริมาณการบรรจุ, จำนวนหัวบรรจุ (1/2/4/6/8), รูปแบบถังเก็บ (มาตรฐาน / ผสม / อุ่นและผสม), วัสดุ (304 / 316 / PTFE ลูกสูบ), ขนาดหัวฉีด (3–12 มม.), รูปแบบขวด (ทำตามตัวอย่างลูกค้า), ความยาวสายพานลำเลียง, แรงดันไฟฟ้า (220 V / 110 V) และข้อกำหนดป้องกันการระเบิด สามารถปรับแต่งได้ทั้งหมด ระยะเวลาดำเนินงานสำหรับเครื่องปรับแต่งและสายการบรรจุครบวงจร: 30–55 วันทำการ
- **อุตสาหกรรมที่ให้บริการเป็นประจำ**: ผลิตภัณฑ์ในครัวเรือนและดูแลส่วนตัว, อาหาร, ยา, ผลิตภัณฑ์เสริมความงาม, ปุ๋ยอุตสาหกรรม, สารเคมี, กลิ่นและน้ำหอม, น้ำมันหล่อลื่น, สเปรย์, น้ำยาอิเล็กทรอนิกส์, ซอสและเครื่องปรุงรส

# 1. เครื่องบรรจุคืออะไร

## 1.1 นิยาม

เครื่องบรรจุคืออุปกรณ์บรรจุภัณฑ์ที่ปล่อยของเหลว ครีม ผง หรือเม็ด颗粒ลงในขวด กระป๋อง ถุง ถ้วย หรือถัง **ตามปริมาณหรือน้ำหนักที่ตั้งไว้ล่วงหน้า** เป็นจุดศูนย์กลางของสายการบรรจุ: ด้านหน้าเชื่อมต่อกับการแยกขวดและลำเลียงขวด ด้านหลังเชื่อมต่อกับการปิดฝา ป้าย รหัส และบรรจุกล่อง

ในชุดผลิตภัณฑ์นี้ เครื่องบรรจุแบ่งออกเป็น 5 ประเภทตาม **รูปแบบวัสดุ** แต่ละประเภทมีหลักการชั่งต่างกันและมีรุ่นเฉพาะ:

| รูปแบบวัสดุ | ชื่อผลิตภัณฑ์ | ชื่อรุ่น | วัสดุที่ใช้บ่อย |
| --- | --- | --- | --- |
| ของเหลว | เครื่องบรรจุของเหลว | ซีรีส์ F (F2/F3/F6), ซีรีส์ DF (สองหัว) | น้ำ, น้ำมัน, น้ำผลไม้, นม, ไวน์, น้ำยาฆ่าเชื้อ, น้ำยาทำความสะอาด, ยาเหลว |
| ครีม / หนืด | **เครื่องบรรจุครีม** | ซีรีส์ FF (FF2/FF4/FF5/FF6/FF9), ซีรีส์ DFF (สองหัว) | แชมพู, ยาสีฟัน, ซอส, ซอสมะเขือเทศ, น้ำผึ้ง, ครีมบำรุงผิว, น้ำยาทาเล็บ |
| ผง | เครื่องบรรจุผง | ซีรีส์ PDF / ADF / SDF | ผงนม, แป้ง, ผงปรุงรส, ผงซักฟอก, ผงยา, สารเติมแต่ง |
| เม็ด颗粒 | เครื่องชั่งเม็ด颗粒 | ซีรีส์ GPM / KY | ข้าว, MSG, ซุปไก่, เมล็ดพืช, อาหารสัตว์, ถั่ว, ชิ้นส่วนโลหะ |
| สเปรย์ | เครื่องบรรจุสเปรย์ | ซีรีส์ AF | สเปรย์กำจัดแมลง, สเปรย์ผม, น้ำหอมอากาศ, มูส |

## 1.2 หลักการทำงาน

### 1.2.1 การเปรียบเทียบวิธีชั่ง 5 แบบ

| วิธีชั่ง | หลักการทำงาน | ความแม่นยำ | วัสดุที่เหมาะ | รุ่นตัวอย่าง |
| --- | --- | --- | --- | --- |
| **ลูกสูบปริมาตร** (หลักการหลัก) | ทรงลูกสูบเคลื่อนที่ขึ้น-ลง โดยห้องลูกสูบสร้างแรงดันลบเพื่อดูดวัสดุเข้า แล้วผลักออกมาเพื่อปล่อยปริมาตรที่กำหนดไว้ | ≤ ±1% | ของเหลวและครีม (ไม่มีอนุภาค หรืออนุภาคเล็กมาก) | F6 / FF6 / DF6 / DFF6 / A2 / FA2 |
| **ปั๊มแม่เหล็ก / ปั๊มเกียร์** | ใช้ตัวควบคุมอินเวอร์เตอร์นำเข้าพร้อมโพเทนชิโอเมตรที่แม่นยำสูง ควบคุมความเร็วของปั๊ม; ชั่งโดยการสะสมปริมาณไหล | ≤ ±2% (ความซ้ำได้ <0.5%) | ของเหลวที่มีความหนืดต่ำ ทนกรด-ด่าง (กรด ด่าง น้ำมัน ยาเหลว) | DF-A / DF-2A / YT-1 |
| **ดูดด้วยแรงดูดสุญญากาศ + ตำแหน่งระดับ** | ดูดขวดต่อเนื่องด้วยแรงดูดสุญญากาศ; วัสดุส่วนเกินจะกลับเข้าถังอัตโนมัติ; ระดับสุดท้ายขึ้นอยู่กับความลึกของหัวฉีด | ≤ ±1% | น้ำหอม, น้ำหอมฟลอริดา, ของเหลวฟอง (ไม่ต้องการความสูงขวดคงที่) | YT-2 / YT-4 / APF-500 |
| **การชั่งแบบเกลียว (Auger)** | มอเตอร์สเต็ปเปอร์ขับเกลียวขนาดเหมาะสม; ระบบตรวจจับโฟโตอิเล็กทริกช่วยแก้ไขข้อผิดพลาด | ≤ ±1% | ผง, ผงละเอียด, เม็ดเล็ก | PDF-500 / ADF-500 / SDF-500 |
| **การชั่งด้วยอิเล็กทรอนิกส์** | โหลดเซลล์ดิจิทัลความแม่นยำสูง พร้อมการจ่ายแบบความเร็วสามระดับ (เร็ว/ช้า) ปรับตามการชั่งแบบเรียลไทม์ | ±0.3% (แบบ Bulk) ถึง ±1–5% (แพ็กเล็ก) | เม็ด颗粒, มวลแข็ง, วัสดุที่แยกตัวง่าย | GPM-2A / GPM-2B / KY-C25KG |

### 1.2.2 ลำดับการทำงานมาตรฐาน

```
การนำเข้า (แบบมือ / อัตโนมัติ) → จัดตำแหน่งภาชนะ (โฟโตอิเล็กทริก / ตะขอตำแหน่ง) → หัวบรรจุลงไป → บรรจุปริมาตรที่กำหนด → หัวบรรจุขึ้น
→ การส่งออก → [เฉพาะสายการอัตโนมัติ] วางฝา → ปิดฝา/กด → ป้าย → รหัส → บรรจุกล่อง
```

**โมเดลกึ่งอัตโนมัติ** (F6/FF6/DF6/DFF6 และคล้ายกัน): ใส่ขวดด้วยมือ บรรจุโดยกดเหยียบหรือตั้งเวลา; ตัวเครื่องแยกเป็นชิ้น ติดตั้งบนขาหรือโต๊ะ; ผู้ปฏิบัติงาน 1 คน  
**โมเดลอัตโนมัติ** (A2/A4/A6, FA2/FA4/FA6, AD-5000): ตั้งค่าผ่านหน้าจอสัมผัส PLC พร้อมการจัดตำแหน่งสายพานและเซ็นเซอร์โฟโตอิเล็กทริก SICK "ไม่มีขวด ไม่บรรจุ"; บรรจุพร้อมกันหลายหัว; เชื่อมต่อโดยตรงกับสายการผลิตทั้งหมด

### 1.2.3 ตัวแปรสำคัญที่ส่งผลต่อคุณภาพการบรรจุ

- **ความแม่นยำในการบรรจุ** ขึ้นอยู่กับ: ความเสถียรของแรงดันวัสดุ, ความเร็วการบรรจุ, ความหนืดของวัสดุ, ความเร็วการยก/ลดหัวบรรจุ, และความเร็วเปิด-ปิดวาล์วบน-ล่าง (แรงดันสปริงปรับได้)
- **ความเร็วการบรรจุ** ขึ้นอยู่กับ: ความหนืดของวัสดุ, ปริมาณการบรรจุ, ขนาดหัวฉีด (หัวฉีดใหญ่ บรรจุเร็ว), ความเร็วกระบอกสูบ และความเร็วการยกหัวบรรจุ
- **วัสดุที่ฟอง**: ลดความเร็วการปล่อย หรือใช้การบรรจุแบบสองขั้นตอน (เร็วแล้วช้า)

## 1.3 คุณค่าหลัก

| มิติคุณค่า | สิ่งที่มอบให้ |
| --- | --- |
| **ความแม่นยำแทนการคาดเดา** | แบบลูกสูบ ≤ ±1% แทนการบรรจุด้วยตา; ลดปัญหาการล้นหรือบรรจุน้อย ลดการสูญเสียวัสดุโดยตรง |
| **ประสิทธิภาพการผลิตเพิ่มขึ้น** | กึ่งอัตโนมัติ 10–40 รอบ/นาที; อัตโนมัติ 10–40 รอบ/นาที × 2/4/6/8 หัว; ถุงยืน 10–30 ถุง/นาที; ผงอัตโนมัติ 1,800–4,000 รอบ/ชั่วโมง; สเปรย์ 4,000–5,000 กระป๋อง/วัน |
| **สอดคล้องและปลอดภัย** | ส่วนสัมผัสวัสดุทำจากสแตนเลส 304 (เลือก 316 ได้), โอริงซิลิโคน (200 °C), สอดคล้องกับ GMP; โครงสร้างลมไม่ต้องไฟฟ้า จึงเหมาะกับงานที่ต้องป้องกันการระเบิด เช่น แอลกอฮอล์ น้ำหอม และสเปรย์ |
| **ทำความสะอาดและบำรุงรักษาง่าย** | หัวฉีดและท่อนำวัสดุแบบปลดเร็ว, การต่อเชื่อมแบบคลัมป์ระหว่างถังเก็บกับตัวปั๊ม, หัวฉีดปิดที่ด้านล่างเพื่อป้องกันหยด; ไม่ต้องใช้เครื่องมือในการเปลี่ยนหรือทำความสะอาด |
| **สถาปัตยกรรมขยายได้** | เริ่มจากเครื่องเดี่ยวแบบกึ่งอัตโนมัติ แล้วเพิ่มสายพานลำเลียง ปิดฝา และป้ายทีหลัง เพื่อปรับเป็นสายการผลิตเต็มรูปแบบ ปกป้องการลงทุนเริ่มต้น |
| **อัตราการเข้าถึงต่ำ** | เครื่องกดมือ A03 จากประมาณ 188 ดอลลาร์สหรัฐ, ปั๊มแม่เหล็ก DF-A จากประมาณ 380 ดอลลาร์สหรัฐ — จุดเริ่มต้นที่ต่ำสำหรับลูกค้าที่ผลิตแบบเล็กและทดลอง |

## 1.4 อุตสาหกรรมและวัสดุที่พบบ่อย

| อุตสาหกรรม | วัสดุที่บรรจุบ่อย | รุ่นแนะนำ |
| --- | --- | --- |

| การพิมพ์รหัส | เครื่องพิมพ์รหัส PM-168 | EXW 1,900 ดอลลาร์สหรัฐ |

# 3. คำถามและคำตอบทางเทคนิคที่พบบ่อย

## 3.1 คำถามเกี่ยวกับการเลือกและการทำงาน

**คำถาม 1: เครื่องบรรจุของเหลวสามารถบรรจุครีมได้ไหม?**  
ไม่ได้  **เครื่องบรรจุครีม (ซีรีส์ FF/DFF/FA) สามารถบรรจุทั้งของเหลวและครีมได้ (ใช้ได้สองแบบ) แต่เครื่องบรรจุของเหลว (ซีรีส์ F/DF/A) ออกแบบมาเฉพาะสำหรับของเหลวเท่านั้น และไม่สามารถผ่านวัสดุหนืดได้** เมื่อลูกค้ามีวัสดุหนืด แนะนำให้เลือกรุ่น FF / DFF / FA โดยตรง

**คำถาม 2: ถ้าวัสดุมีอนุภาคจะเป็นอย่างไร?**  
เครื่องชั่งลูกสูบและปั๊มแม่เหล็กมาตรฐาน **ไม่สามารถจัดการกับวัสดุที่มีอนุภาค หรืออนุภาคต้องเล็กมาก** สำหรับวัสดุที่มีอนุภาค ให้เปลี่ยนไปใช้เครื่องบรรจุผงแบบเกลียว (PDF / SDF / ADF สำหรับผงและเม็ดเล็ก) หรือเครื่องชั่งเม็ด颗粒 (ซีรีส์ GPM / KY)

**คำถาม 3: เครื่องเดียวสามารถครอบคลุม 10 มล. ถึง 5,000 มล. ได้ไหม?**  
ไม่ได้  **แต่ละเครื่องมีช่วงปริมาณการบรรจุที่กำหนดไว้ (กำหนดโดยเส้นผ่านศูนย์กลางลูกสูบและระยะลูกสูบ)** ช่วงปริมาณกว้างต้องใช้เครื่องหลายรุ่น สำหรับลูกค้าที่มีหลายสเปก แนะนำให้เลือกเครื่องหนึ่งสำหรับสเปกหลัก พร้อมเปลี่ยนกระบอกสูบได้

**คำถาม 4: ความแม่นยำในการบรรจุจริงคือเท่าไหร่?**  
ลูกสูบปริมาตร ≤ ±1%; ปั๊มแม่เหล็ก ≤ ±2% (ความซ้ำได้ <0.5%); ผงเกลียว ≤ ±1%; ชั่งแบบ Bulk ±0.3%, ชั่งแบบแพ็กเล็ก ±1–5% ปัจจัยหลักที่ส่งผลคือ **ความเสถียรของแรงดันวัสดุ, ความเร็วการบรรจุ, ความหนืดของวัสดุ และความเร็วการยกหัวบรรจุ**

**คำถาม 5: ควรเลือกแบบลมหรือไฟฟ้า?**  
- **ทั้งหมดเป็นลม**: ไม่ต้องการไฟฟ้า, ป้องกันการระเบิดโดยธรรมชาติ, เหมาะกับวัสดุที่ติดไฟง่าย เช่น แอลกอฮอล์ น้ำหอม สเปรย์ และตัวทำละลาย; ลูกค้าต้องจัดเตรียมคอมเพรสเซอร์ลม (0.4–0.6 MPa); โครงสร้างง่าย, อัตราความเสียหายต่ำ และต้นทุนการบำรุงรักษาน้อย  
- **ไฟฟ้าและอิเล็กทรอนิกส์ (CNC / ปั๊มแม่เหล็ก / อัตโนมัติ)**: ต้องการ 220 V; หน้าจอสัมผัส PLC ช่วยตั้งพารามิเตอร์ได้แม่นยำ, ความเร็วสูง และติดตั้งง่ายในสายการผลิตทั้งหมด

**คำถาม 6: ทำไมรุ่นแนวนอนถึงเป็นหลัก?**  
รุ่นแนวนอนแบบลมทั้งหมด (ซีรีส์ F6/FF6) ใช้การดูดซับด้วยท่อนำหรือถังเก็บอัตโนมัติ ให้ความแม่นยำสูง ทำความสะอาดง่าย และการออกแบบที่มั่นคง — นี่คือ **รุ่นที่แนะนำบ่อยที่สุด** ในซีรีส์นี้ รุ่นแนวตั้ง (FF4/FF5) สามารถปรับปริมาณการบรรจุและความเร็วได้ภายในช่วง แต่รุ่นแนวนอนครีมครอบคลุมปริมาณมากกว่า

**คำถาม 7: วัสดุครีมหนืดสูงต้องการข้อกำหนดพิเศษอะไรบ้าง?**  
**วัสดุเหนียวมากต้องใช้ลูกสูบ PTFE (ประมาณ 50 ดอลลาร์สหรัฐต่ออัน)** ถ้าไม่ใช้ จะเกิดการเสียดสีระหว่างลูกสูบกับผนังกระบอกสูบ ทำให้ซีลเสียหายและเกิดการเบี่ยงเบนปริมาณการบรรจุ หากวัสดุยังแยกตัวหรือแข็งตัว ให้เพิ่ม **ถังเก็บผสม (แบบ B)** หรือ **ถังเก็บอุ่นและผสม (แบบ C)**

**คำถาม 8: ถุงยืนและขวดสามารถใช้เครื่องเดียวกันได้ไหม?**  
ไม่ได้ ถุงยืนต้องมีกลไกเฉพาะสำหรับผลักถุง ปั๊มถุง แขวนฝา และขันฝา ให้เลือกรุ่น F8 / DF8 / DFF8 (กึ่งอัตโนมัติ) หรือรุ่น AF8-1000 / TD-1A / LGD (รวมทุกอย่างและอัตโนมัติ)

**คำถาม 9: ทำไมเครื่องบรรจุน้ำหอมจึงไม่จำกัดรูปแบบขวด?**  
เพราะใช้ **การตั้งระดับ**: หัวฉีดจมลงไปในขวดที่ลึกคงที่ และวัสดุส่วนเกินจะกลับเข้าถังอัตโนมัติ ดังนั้นระดับสุดท้ายขึ้นอยู่กับความลึกของการจม ขวดที่มีความสูงไม่เท่ากันก็ยังได้ระดับการบรรจุเท่ากัน — วิธีมาตรฐานสำหรับผลิตภัณฑ์น้ำหอมและน้ำหอมฟลอริดา โปรดทราบว่า **ไม่สามารถบรรจุครีมได้**

**คำถาม 10: ขั้นต่ำ (MOQ), ระยะเวลาดำเนินงาน และเงื่อนไขการชำระเงินคืออะไร?**  
- **MOQ: 1 ชุด** (ส่วนใหญ่รุ่นอยู่ในสต็อก)
- **รุ่นสต็อก**: สินค้ามีในสต็อก จัดส่งหลังชำระเงิน
- **รุ่นปรับแต่งและสายการผลิตครบวงจร**: 30–45 วันทำการ (สายการผลิตน้ำหอม 45–55 วันทำการ)
- **การชำระเงิน**: 100% T/T สำหรับคำสั่งซื้อทั่วไป; สายการผลิต 30% ฝาก + 70% ก่อนจัดส่ง (บางสาย 60% ฝาก + 40% ก่อนจัดส่ง)
- **เงื่อนไขการค้า**: EXW วันโจว / FOB หนิงโป

**คำถาม 11: มาตรฐานการบรรจุและจัดส่งคืออะไร?**  
รุ่นกึ่งอัตโนมัติมักจัดส่งในกล่องกระดาษแข็ง (บางรุ่นในกล่องไม้); เครื่องอัตโนมัติและสายการผลิตครบวงจรใช้กล่องไม้; การส่งออกบรรจุเป็นกล่องไม้คุณภาพส่งออกสำหรับการขนส่งระยะไกล

**คำถาม 12: รับประกันและบริการหลังการขายเป็นอย่างไร?**  
รับประกัน 1 ปี สำหรับเครื่องทั้งหมด ความเสียหายที่เกิดขึ้นภายใต้การใช้งานตามคู่มือภายในระยะเวลาประกันจะได้รับการซ่อมหรือเปลี่ยนฟรี (ลูกค้ารับผิดชอบค่าขนส่งจากจีนไปยังปลายทาง); หากต้องการวิศวกรไปที่ไซต์ ค่าเดินทางเป็นของลูกค้า บริการซ่อมตลอดชีวิตนอกระยะเวลาประกัน ผลิตภัณฑ์มี **ใบรับรอง CE**

## 3.3 รายการตรวจสอบการบำรุงรักษาประจำวัน

**หลักการหล่อลื่น "ห้าอย่างคงที่"** (บุคลากรคงที่, ช่วงเวลาคงที่, จุดคงที่, ปริมาณคงที่, คุณภาพน้ำมันคงที่):

| ตำแหน่ง | น้ำมันหล่อลื่น | ความถี่ |
| --- | --- | --- |
| กล่องเกียร์เกลียว | น้ำมันเกลียว / น้ำมันไฮพออิด / น้ำมันเครื่อง | เปลี่ยนตามช่วงเวลา |
| แบริ่งกลิ้ง | น้ำมันหล่อลื่นลิเธียม ZL-3 หรือน้ำมันหล่อลื่นซิลิโคนทั่วไป | ปรับเพิ่มตามช่วงเวลา |
| รางเลื่อนและเกียร์คันโยก | น้ำมันหล่อลื่นลิเธียม ZL-3 | ปรับเพิ่มตามช่วงเวลา |
| ตัวหล่อลื่นอากาศ | น้ำมันลมเฉพาะ | ตรวจสอบและเติมบ่อย |

**ตรวจสอบรายวัน:**

1. ก่อนเริ่มทำงานทุกวัน ตรวจสอบแรงดันลม (0.4–0.6 MPa; 0.5–0.8 MPa สำหรับสายการผลิตทั้งหมด), แหล่งจ่ายไฟ (220 V) และว่าปุ่มหยุดฉุกเฉินได้รีเซ็ตแล้วหรือไม่
2. ** Drain ตัวแยกน้ำมัน-อากาศ** ที่ทางเข้าลมเป็นประจำ เพื่อป้องกันความชื้นเข้าไปในท่อนำและกัดกร่อนวาล์ว
3. ทำความสะอาด **กรองวัสดุ** และท่อนำเป็นระยะ
4. ตรวจสอบข้อต่อและตัววาล์วทุกจุดเป็นระยะ ยึดข้อต่อทุกจุดเพื่อป้องกันการหลวม
5. ตรวจสอบชิ้นส่วนเคลื่อนที่ (แบริ่งกลิ้ง, สายพานส่ง) เป็นระยะ ถ้าสึกหรอหนัก ให้เปลี่ยนทันที
6. หลังใช้งาน 1 ปี หรือระหว่างซ่อมบำรุงทั่วไป ทาสีซ่อมเพื่อป้องกันสนิม
7. เมื่อไม่ผลิต ให้หยุดเครื่อง ปิดไฟและลม; อย่าทิ้งเครื่องมือ ผ้า หรือสิ่งแปลกปลอมอื่นๆ ไว้ภายในเครื่อง

**กฎความปลอดภัยสำคัญ:** การปรับต้องทำขณะเครื่องไม่ทำงานอัตโนมัติ และโดยบุคคลเดียวเท่านั้น; อย่าสัมผัสกลไกที่เคลื่อนไหวขณะเครื่องทำงาน; ผมยาวต้องปิด ห้ามสวมผ้าพันคอ แหวน หรือนาฬิกาที่อาจติดขัด; หลังไฟดับ เครื่องอาจเริ่มทำงานอัตโนมัติเมื่อไฟกลับมา ดังนั้นอย่าอยู่ใกล้ชิ้นส่วนที่เคลื่อนไหว

## 4.2 ตัวอย่างการปรับแต่งทั่วไป

**กรณีที่ 1 | การบรรจุซอสหนืดสูง**  
ความต้องการ: ซอสมะเขือเทศและซอสเผ็ด หนืดและติดผนัง  
แนวทาง: ซีรีส์ FF6 / DFF6 + ลูกสูบ PTFE + ถังเก็บผสมใหญ่ (แบบ B) + หัวฉีดป้องกันหยด + ฟังก์ชันเป่าลม  
เหตุผล: ลูกสูบ PTFE ป้องกันการเสียหายของซีล; ถังเก็บผสมป้องกันการแยกตัว; หัวฉีดป้องกันหยดหยุดวัสดุติดและหยดลงขวด

**กรณีที่ 2 | การบรรจุป้องกันการระเบิด (แอลกอฮอล์และน้ำหอม)**  
ความต้องการ: น้ำยาฆ่าเชื้อแอลกอฮอล์ 75% ต้องการป้องกันการระเบิดในโรงงาน  
แนวทาง: ซีรีส์ F6 ลมทั้งหมด (ไม่ต้องไฟฟ้า) + ส่วนสัมผัสวัสดุ 316 + ซีลยางกันสนิม; สำหรับขยาย ใช้ A4-500 + DC1 + สายพาน + AL-220 สายการผลิตครบวงจร  
เหตุผล: เครื่องลมทั้งหมดไม่มีชิ้นส่วนไฟฟ้า กำจัดแหล่งจุดระเบิดตั้งแต่ต้น

**กรณีที่ 3 | วัสดุที่แยกตัว (น้ำผึ้งและน้ำมันถั่วเหลือง)**  
ความต้องการ: วัสดุแยกตัวและหนังหุ้มเมื่อทิ้งไว้  
แนวทาง: รุ่น FF6C / DFF6C ถังเก็บอุ่นและผสม รักษาอุณหภูมิคงที่และผสมวนซ้ำก่อนบรรจุ

**กรณีที่ 4 | ถุงมีหัวฉีดยืน**  
ความต้องการ: ถุงซักผ้าและจิ๊บต้องการบรรจุและปิดฝาในหนึ่งหน่วย  
แนวทาง: LGD02 (ตั้งโต๊ะรวมหมุนหัวเดียว, 30–2,000 กรัม, 10–30 ถุง/นาที, ผู้ปฏิบัติงาน 1 คน) หรือ AF8-1000 สำหรับผลิตจำนวนมาก (120 รอบ/นาที); เลือกรุ่นปั๊มหมุนแนวนอนถังเก็บผสมสำหรับซอส

**กรณีที่ 5 | การปรับแต่งสายการผลิตครบวงจร (ผลิตจำนวนมากขวด)**  
ความต้องการ: สายการผลิตรวมตั้งแต่แยกขวดจนถึงป้าย  
แนวทาง: เครื่องแยกขวด (เส้นผ่านศูนย์กลางขวด ≤80 มม.) + เครื่องบรรจุ FA4-1000 4 หัว + เครื่องปิดฝา AC1 + เครื่องป้ายขวดกลม AL-220, 87,000 หยวน, ระยะเวลาดำเนินงาน 30–45 วันทำการ; สามารถเพิ่ม กระจกป้องกัน, วัสดุ 316, เครื่องล้างขวด และเครื่องพิมพ์รหัส

**กรณีที่ 6 | ภาชนะพิเศษ (ขวดแก้วฝาอะลูมิเนียมและยาดื่ม)**  
ความต้องการ: ขวดแก้วยาดื่มฝาอะลูมิเนียม  
แนวทาง: ระบบบรรจุอัตโนมัติสองหัว + ระบบตั้งฝา + ระบบปิดฝาหัวเดียว (สายฝาอะลูมิเนียมเฉพาะ), หรือสายการผลิต NLA-ALC-500 ครบวงจร

## 4.3 กระบวนการปรับแต่งและระยะเวลาดำเนินงาน

```
1 ยืนยันความต้องการ - ให้ตัวอย่างวัสดุ ตัวอย่างภาชนะ ปริมาณการบรรจุเป้าหมาย ความจุเป้าหมาย แรงดันไฟฟ้าในโรงงาน และเงื่อนไขการจ่ายลม
2 ใบเสนอราคา - ยืนยันแพลตฟอร์มรุ่น จำนวนหัว ถัง วัสดุ และการจัดวางสายการผลิต; ใบเสนอราคาใช้ได้ 30 วัน
3 ทดลองตัวอย่าง - ส่งตัวอย่างภาชนะ; ทำชุดเฟรมตามตัวอย่างและทดสอบ (สามารถให้วิดีโอทดสอบได้)
4 สั่งซื้อและผลิต - รุ่นมาตรฐานมีในสต็อก; เครื่องปรับแต่งและสายการผลิตครบวงจร 30-45 วันทำการ (สายการผลิตน้ำหอม 45-55 วันทำการ)
5 การจัดส่ง - EXW วันโจว / FOB หนิงโป; กล่องหรือกล่องไม้สำหรับการส่งออก
6 หลังการขาย - รับประกัน 1 ปีสำหรับเครื่องทั้งหมด บริการซ่อมที่ไซต์และระยะไกลตลอดชีวิต
```

## 4.5 ขอบเขตการปรับแต่ง (สิ่งที่เราไม่สามารถรับประกันได้)

เพื่อลดความเสี่ยงหลังการขาย ต้องชัดเจนก่อนการขาย:

1. **เครื่องของเหลวไม่สามารถแปลงเป็นเครื่องครีมได้** — ทางไหลและโครงสร้างลูกสูบต่างกัน การแปลงมีค่ามากกว่าการซื้อเครื่องใหม่
2. **รุ่นลูกสูบและปั๊มแม่เหล็กมาตรฐานไม่สามารถรับประกันวัสดุที่มีอนุภาคได้** — ต้องใช้โซลูชันชั่งแบบเกลียวหรือชั่ง
3. **ไม่รับประกันช่วงปริมาณที่กว้างเกินไป** — ช่วงปริมาณการบรรจุของเครื่องหนึ่งมีค่าคงที่ ดังนั้นช่วงกว้างต้องใช้หลายรุ่น
4. **รุ่นชั่งระดับน้ำหอมไม่สามารถรับประกันสำหรับครีมได้**
5. **เครื่องปรับแต่งไม่สามารถให้ความแม่นยำดีกว่าค่ามาตรฐานได้** — การปรับแต่งเพื่อให้เหมาะสม (ภาชนะ, ความหนืด, ความจุ); ไม่สามารถเกินขีดจำกัดความแม่นยำของหลักการชั่งได้
6. **ไม่รับประกันความแม่นยำหรือความจุสุดท้ายหากไม่มีตัวอย่างภาชนะและวัสดุ** — ความแม่นยำและความเร็วขึ้นอยู่กับความหนืดของวัสดุและความสม่ำเสมอของภาชนะ
