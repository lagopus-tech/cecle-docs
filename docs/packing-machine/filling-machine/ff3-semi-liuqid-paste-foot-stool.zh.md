## 1. 产品概述

### 1.1 分类

- **行业：** 包装机械 / 灌装设备（灌装机）
- **产品名称：** 半自动膏体灌装机带集成不锈钢支架（电动气动/全气动可选）
- **机型：** 半自动 · 水平式 · 活塞式 **膏体**灌装机（也可处理液体）**安装于集成201不锈钢地脚支架上**
- **驱动方式：** **两种版本可选，下单时确定：**
  - **电动气动一体化（如FF2）：** 气动执行 + 电动控制；需220V/50–60Hz电源（约100W）+ 空气压缩机（0.4–0.6 MPa）
  - **全气动（如FF6）：** 气动驱动 + 气动控制；**完全无需电力**；仅需空气压缩机（0.4–0.6 MPa）；本质安全 / 防爆
- **自动化等级：** 电动气动版：半自动或自动（脚踏开关 / 电动计时器，可切换）。全气动版：仅半自动（脚踏触发）

- **支架特性：** **集成201不锈钢地脚支架——尺寸80 × 46 × 24 cm，重量11 kg**——带可调水平脚和内置侧边容器托盘；即插即用，无需工作台
- **认证与保修：** CE认证；1年整机保修，保修期后提供终身维护服务

**主要——膏体/高粘度：**

### 1.3 核心功能

- **专为膏体优化的活塞式容积灌装：** 气缸驱动活塞，行程可调——处理厚质产品（酱料、乳霜、药膏）时不飞溅、不拉丝；体积可在型号范围内无级调节；更换规格无需更换零件
- **同一平台两种驱动版本：** 下单可选**电动气动版**（稳定电控循环 + 自动计时模式）或**全气动版**（无电力，本质安全，防爆）——相同主机，相同灌装性能，相同支架
- **液体兼容性为附加优势：** 更换喷嘴并调整活塞行程，即可从膏体切换至液体——一台机器覆盖两类物料
- **双触发模式（电动气动版）：** 脚踏开关（半自动）或自动电动计时器（全自动）——半自动 ⇄ 全自动可切换。全气动版：仅脚踏触发
- **滴漏零残留灌装：** 底部关闭正向切断喷嘴——灌装结束瞬间密封；**无拉丝、无滴漏、无瓶口残留膏体**（对化妆品和食品应用至关重要）
- **可配置灌装头：** **单头、双头（2头）、四头或多头**——按产量目标订购相应配置；多头版本可成比例提升产能
- **可调灌装量与速度：** 适配不同容器格式（小罐、大桶）和产线节拍；灌装速度 **5–30次/分钟**（膏体优化）
- **灵活料斗/供料选项：** 标准 **30L料斗**（尺寸与重量同FF2/FF6）；可选 **40L / 60L / 80L** 大容量料斗，减少补料停顿；可选 **加热料斗、搅拌料斗或加压料斗**，匹配产品特性（料斗选项同FF2/FF6）
- **集成201不锈钢地脚支架（FF3标志性升级）：尺寸80 × 46 × 24 cm，重量11 kg**——机器安装于支架上，达到落地工作高度，支持站立操作；可调水平脚确保在不平地面稳定运行；侧边托盘让操作员可将容器放置于喷嘴旁——**可直接接入生产线，无需额外工作台**

## 2. 核心优势

> **FF3与FF2（电动气动）和FF6（全气动）系列共享主机、料斗、灌装规格与重量。其两大差异化特征：(1) 集成201不锈钢地脚支架——FF3是即插即用的落地式版本；(2) 同一平台可订购两种驱动架构——客户可自由选择电动气动或全气动。**

1. **同一平台两种驱动版本——电动气动或全气动。** FF3可订购为**电动气动单元**（如FF2：220V/50–60Hz，约100W + 0.4–0.6 MPa气压，电动计时器支持自动模式）或**全气动单元**（如FF6：仅空气，无电力，本质安全，防爆）。一个产品平台覆盖稳定供电车间与防爆/无电/易燃产品应用场景——两种版本均配备同一集成地脚支架。
2. **电动气动版——更精确控制，更稳定循环。** 电动控制结合气动执行，使灌装周期精准定时；长时间连续运行下，周期保持一致，批次重复性极佳。灌装速度 **5–30次/分钟**，可随产线节奏调节。
3. **全气动版——结构防爆。** 完全无任何电气元件（无电机、无电磁阀、无计时器、无继电器、无PLC）——无点火源，本质安全。**适用于易燃、酒精基或溶剂基产品**（洗手凝胶、香水、酒精酊剂、溶剂基胶粘剂、油漆、油墨）及防爆区域——现**配备地脚支架**，危险区域车间亦可即插即用，无需工作台。
4. **Airtac气动元件。** 台湾Airtac气缸与阀门提供稳定动作与长寿命——对膏体应用尤为重要，因气缸需克服更高背压。备件全球易购，长期维护成本低。
5. **超低运行成本。** 电动气动版：总功耗仅约 **100W (0.1 kW)** ——电费几乎可忽略。全气动版：**0W电力消耗**——仅需压缩空气。两种版本的空气消耗量与同类气动灌装机相当。
6. **操作简单——连接即启动。** 电动气动版：连接电源与气源；直观的电动控制面板，学习快速。全气动版：仅连接气源——无需学习电气知识，适用任何场所，无需电压匹配，无需接地。
7. **201不锈钢框架 + 食品级304不锈钢接触部件；316可选。** 全不锈钢框架与食品级接触部件符合食品安全标准（304）；**接触部件可定制为316不锈钢**，以增强耐酸碱与抗腐蚀能力。不锈钢阀组耐腐蚀，清洁方便——对膏体应用尤其重要，因残留物更难清除。
8. **±1%灌装精度 + 滴漏零残留喷嘴。** 活塞计量稳定可靠，膏体灌装无少装或多装；底部关闭正向切断喷嘴消除滴漏、拉丝与膏体尾迹，保持瓶口与工作台清洁——对化妆品罐、食品容器及制药包装至关重要。
9. **膏体+液体一体机——多功能与高价值。** FF3专为膏体优化，但**也可灌装流动性液体**：更换喷嘴，调整活塞行程，即可切换产品类别。**一台机器替代两台专用灌装机。**
10. **8个型号覆盖5–5000 ml；换型零成本。** 通过调整活塞行程改变灌装量——无需更换零件；规格变更仅需2–3分钟。覆盖从样品小罐到大桶的所有需求。
11. **灵活料斗——30L标准，加热/搅拌/加压可选（与FF2/FF6相同）。** 标准 **30L** 料斗；**40L、60L或80L** 大容量版本可减少高产量线的补料次数。针对难处理产品，可加装 **加热料斗**（温度敏感产品）、**搅拌料斗**（防止沉淀与分层）或 **加压料斗**（辅助喂料高粘度膏体——全气动版天然适配）。
12. **集成201不锈钢地脚支架——即插即用，人体工学，一箱发货（对比FF2/FF6）。** **这是FF3区别于FF2/FF6的最关键差异。** 机器已安装于专用201不锈钢地脚支架上——**尺寸80 × 46 × 24 cm，重量11 kg**——带可调水平脚和内置侧边容器托盘：落地工作高度支持站立操作；托盘提供装载/卸载时的稳定落点；水平脚可应对不平整车间地面。**整个灌装站一箱发货**——无需另购工作台，无需额外焊接或安装。
13. **水平脚——在不平地面上保持稳定。** 可调脚可让操作员微调支架高度，使机器在轻微不平的车间地面上保持水平——对膏体线至关重要，因气缸必须垂直工作，灌装喷嘴必须精确对准容器口。
14. **食品级硅胶密封圈（耐温200°C）。** 标准采用食品级硅胶O型圈；填充腐蚀性或粘性产品时，可选耐腐蚀橡胶密封圈。
15. **单头/双头/四头/多头——可扩展无需更换设备。** 从单头起步；产量增长后，可订购双头、四头或多头配置（每头一个气缸）——或在电动气动版中将脚踏半自动切换为自动计时模式——无需设备更换，无投资浪费。

### 4.1 型号选择逻辑

下单FF3需做两个决策：**(1) 驱动版本**——电动气动（如FF2）或全气动（如FF6）；**(2) 按灌装范围选择型号**（及头数：单头/双头/四头/多头）。

| 客户灌装形式 | 推荐型号 | 客户灌装形式 | 推荐型号 |
| --- | --- | --- | --- |
| 样品级化妆品罐/小瓶（5–50 ml） | FF3-50 | 大罐/大瓶（100–1000 ml） | FF3-1000 |
| 小罐/试用装（10–100 ml） | FF3-100 | 桶级（250–2500 ml） | FF3-2500 |
| 常规化妆品/食品罐（30–300 ml） | FF3-300 | 大桶/大罐（300–3000 ml） | FF3-3000 |
| 家用罐/大瓶（50–500 ml） | FF3-500 | 大桶/大罐（500–5000 ml） | FF3-5000 |

**驱动版本选择（FF2 vs FF6决策，现统一于一个平台）：**

| 客户情况 | 推荐FF3版本 |
| --- | --- |
| 供电稳定，非易燃产品，追求最稳定循环 + 自动计时模式 | **电动气动FF3**（FF2架构） |
| 防爆区域，易燃/酒精基/溶剂基产品，或现场无电力 | **全气动FF3**（FF6架构——无电力，本质安全） |

> **FF2/FF6 vs FF3选择——唯一真实决策：** FF2（电动气动台面式）、FF6（全气动台面式）和FF3（落地支架）共享相同主机、料斗与灌装规格——**FF3的唯一区别是集成支架（80 × 46 × 24 cm，11 kg）**。**选择FF3** 若客户需要即插即用、落地式工作站，带集成托盘，可直接接入生产线，一箱发货。**选择FF2/FF6** 若客户已有工作台或仅需台面式设备。

**沟通要点：**

- **客户灌装膏体/高粘度材料**（酱料、果酱、乳霜、药膏、番茄酱、蜂蜜、乳液）→ 优先推荐FF3：活塞式设计处理厚质产品不飞溅；底部关闭正向切断喷嘴消除瓶口残留；±1%精度；**自带落地支架，集成托盘**。
- **客户需要即插即用、落地式站立操作**（大多数生产线客户）→ **优先推荐FF3**：集成支架（80 × 46 × 24 cm，11 kg）带水平脚和侧边托盘，意味着设备可立即投入生产线——**无需另购工作台，无需安装作业，一箱发货。**
- **客户需要防爆操作且需落地式工作站** → **全气动FF3是唯一答案**：无电力 + 集成支架——台面式FF6无法服务于无工作台的危险区域；FF3可以。
- **客户车间无电力供应** → 订购**全气动FF3版本**（仅空气——可随处使用，无需电压匹配）。
- **客户需要自动计时模式和稳定电控循环** → 订购**电动气动FF3版本**（220V，约100W，脚踏 ⇄ 自动计时可切换）。
- **客户同时灌装膏体和液体** → 强调“一台FF3机器覆盖两类物料——更换喷嘴，调整活塞行程，几分钟内从酱料切换至果汁。**一台机器替代两台专用灌装机。**”
- **客户需要更高产量** → 配置为**双头 / 四头 / 多头**机器——每头一个气缸；强调“从单头起步，升级至多头，无需更换机器。”
- **客户仅灌装流动性非易燃液体（无膏体）** → 引导其选择**F2液体灌装机**——FF3对纯液体线而言规格过剩。
- **客户需灌装多种规格** → 强调“通过调整行程改变体积——无需更换零件；一台机器替代多台。”
- **客户无空气压缩机** → 主动提醒：**两种FF3版本均需空气压缩机（0.4–0.6 MPa）**——可主动报价添加一台，确保机器到货即可运行。
- **客户批量大，料斗常空** → 推荐**40L / 60L / 80L** 大料斗，减少补料停顿（同FF2/FF6选项）。
- **客户产品需加热、搅拌或加压喂料**（蜂蜜、巧克力酱；含颗粒或易沉淀酱料/果酱；极高粘度难喂料膏体）→ 匹配**加热料斗、搅拌料斗或加压料斗**（加压料斗在全气动版中天然适配）。
- **客户处理制药/化学或腐蚀性产品** → 推广**定制316不锈钢接触部件**——耐腐蚀一步到位。
- **客户车间地面不平** → 强调FF3支架的可调水平脚——即使在不平整地面也能保持机器水平，喷嘴高度精准。
- **贸易条款（标准报价用语）：** 最小起订量1台；宁波FOB / 温州EXW；电汇支付；**现货供应**；加固纸箱包装，含工具与备件；**支架随机器发货**（到货仅需微调水平脚）。

### 4.2 常见问题解答

**Q1：这台机器需要电力吗？**  
A：**取决于您订购的版本。** FF3有两种驱动版本：**电动气动版**需 **220V / 50–60Hz** 电源（功耗仅约 **100W**）加空气压缩机（0.4–0.6 MPa）；**全气动版**完全无任何电气元件，**无需电力**——仅需空气压缩机（0.4–0.6 MPa）。

**Q2：我需要空气压缩机吗？**  
A：是的——**两种版本**都使用气动执行，必须连接空气压缩机，提供 **0.4–0.6 MPa** 的气压。一台普通的中小型活塞式压缩机（带储气罐）即可满足；也可在订单中一并添加。选择全气动版仅移除了电力需求，未移除压缩空气需求。

**Q3：这台机器是防爆的吗？**  
A：**全气动FF3版本是**——它不含任何电气元件，无点火源，本质安全，适用于防爆区域，以及易燃、酒精基或溶剂基产品的灌装（如洗手凝胶、香水、酒精酊剂、溶剂基胶粘剂、油漆、油墨）。**电动气动版不适用于防爆用途**——此类应用请订购全气动版本。

**Q4：灌装精度和速度是多少？**  
A：精度为 **±1%以内**（活塞式计量——稳定，无漂移）；速度为 **5–30次/分钟**（膏体优化；比纯液体灌装机慢，因膏体需更长的每行程沉降时间），且速度可调。

**Q5：它可以同时灌装膏体和液体吗？能处理哪些产品？**  
A：**是的——FF3专为膏体和高粘度产品优化，同时也可灌装流动性液体**（全气动版还可处理易燃/酒精基/溶剂基液体）。主要用途：酱料、番茄酱、果酱、蜂蜜、花生酱、巧克力酱、芥末酱、蛋黄酱；面霜、身体乳、护手霜、浓稠洗发水、沐浴露、护发素；药膏；浓稠洗涤剂；润滑剂和胶粘剂。次要用途：水、果汁、牛奶、食用油、液体调味料、液体药品、液体洗涤剂。**一台机器覆盖膏体与液体两类——更换喷嘴，调整活塞行程，几分钟内完成切换。**

**Q6：FF3与FF2和FF6有何不同？**  
A：**FF3与FF2和FF6系列共享相同的主机、料斗、灌装规格和重量**——相同活塞计量（±1%）、相同5–30次/分钟膏体优化速度、相同8型号覆盖5–5000 ml、相同30L标准料斗（40L/60L/80L可选；加热/搅拌/加压可选）、相同201不锈钢框架 + 304不锈钢接触部件（316可选）、相同喷嘴/滴漏/密封配置。**FF3的唯一区别：** 它随附**集成201不锈钢地脚支架——尺寸80 × 46 × 24 cm，重量11 kg**——带可调水平脚和侧边容器托盘，将台面式FF2/FF6转变为即用型落地式生产站。FF3可订购任一驱动方式：电动气动（FF2架构，带自动计时模式）或全气动（FF6架构，防爆）。**选择FF3** 用于即插即用的落地式操作；**选择FF2/FF6** 若您已有工作台，仅需台面式设备。

**Q7：支架的规格是什么？**  
A：FF3集成支架尺寸为 **80 × 46 × 24 cm，重量11 kg**，具备：

- **201不锈钢结构**——与机器防腐蚀特性匹配；易于擦拭清洁。
- **可调水平脚**——可微调高度，使机器在轻微不平的车间地面保持水平；对膏体线至关重要，因气缸与喷嘴必须垂直对准容器口。
- **内置侧边容器托盘/平台**——喷嘴旁的稳定落点；操作员将罐子滑至托盘，滑入喷嘴下方灌装，再滑回。**减少溢出，加快小规格装载。**
- **落地工作高度**——操作员可站立灌装；无需采购或搭建独立工作台；一箱发货。

**Q8：产品接触材料是食品级的吗？**  
A：框架为201不锈钢，**所有产品接触部件均为食品级304不锈钢**，符合食品安全要求；**316不锈钢可定制**（更强的耐酸碱与抗腐蚀性——适合制药、化工及腐蚀性产品）。密封圈为食品级硅胶（耐温200°C）。FF3集成支架与托盘也为201不锈钢。

**Q9：会滴漏、拉丝或留下膏体尾巴吗？**  
A：不会。喷嘴采用**底部关闭正向切断**设计——灌装结束瞬间关闭排料口，确保滴漏零残留。**对膏体应用至关重要：** 无拉丝、无膏体尾迹、无瓶口残留——保持化妆品罐、食品容器及制药包装清洁（对易燃产品也是防火安全益处）。喷嘴孔径可在5–25 mm范围内选择（适配膏体流量）。

**Q10：更改灌装量或在膏体与液体间切换是否麻烦？**  
A：完全不麻烦。在型号范围内，只需**调整活塞行程**即可改变灌装量——无需更换零件；换型仅需几分钟。**在膏体与液体间切换**也很简单：更换喷嘴（膏体喷嘴 vs. 液体喷嘴），并调整活塞行程与速度——几分钟内完成，无需工具。

**Q11：它能全自动运行吗？有哪些头配置可选？**  
A：**电动气动版：** 可以——支持**脚踏（半自动）和自动电动计时（全自动）**两种模式，可随时切换。**全气动版：** 仅支持脚踏触发（半自动）——因机器无电气元件，故无电动计时器；这是防爆安全的权衡。为提高产量，**所有版本均可订购为单头、双头（2头）、四头或多头**（每头一个气缸）——无需更换设备。

**Q12：最小起订量、交货时间和保修期是？**  
A：**最小起订量为1台**；工厂**现货供应**，可快速发货；出口包装为加固纸箱，每箱一台，含工具与备件；**支架随机器发货**（到货仅需微调水平脚）。机器提供**1年保修**（保修期内非人为损坏免费维修或更换零件；国际运费由客户承担），并提供**终身维护服务**。

**Q13：我可以选择料斗容量吗？能否加装加热、搅拌或加压料斗？**  
A：可以。料斗标准为**30L**（尺寸与重量同FF2/FF6），另有**40L、60L或80L**大容量选项，适用于高产量线以减少补料次数。三种料斗类型也可根据产品需求加装：**加热料斗**（控温保持蜂蜜、巧克力酱、糖浆等遇冷易凝产品流动）；**搅拌料斗**（持续搅拌防止沉淀、分层与表面结皮——适合含颗粒果酱/酱料）；**加压料斗**（压缩空气辅助稳定喂料极高粘度膏体——全气动版天然适配）。料斗选项与FF2/FF6相同——FF3唯一新增为集成支架。

## 6. 工作流程

### 6.1 灌装操作流程

```
① 安装
   将FF3置于生产线地面。
   调整水平脚使机器水平。
   电动气动版：连接220V/50–60Hz电源（约100W）
                                + 连接空气压缩机，调节至0.4–0.6 MPa
   全气动版：    仅连接空气压缩机，调节至0.4–0.6 MPa
                               （无电气连接）
        │
② 上料
   将膏体（或液体）加入料斗（标准30L；40/60/80L可选）
   （需时使用加热/搅拌/加压料斗）
        │
③ 设定容量
   调整活塞行程 → 设置每次循环的灌装量（范围内无级调节）
   如需，调整灌装速度（膏体：通常5–30次/分钟）
        │
④ 放置容器
   将罐/瓶置于侧边托盘，滑至喷嘴下方
   （膏体：使用5–25 mm膏体喷嘴；液体：切换为液体喷嘴）
        │
⑤ 触发灌装
   脚踏（两种版本，半自动模式）
   电动气动版：或自动计时器（自动模式）
        │
⑥ 灌装完成（精度±1%）
   底部关闭正向切断喷嘴 → 无滴漏、无拉丝、无膏体尾迹
        │
⑦ 下一个容器——重复
   将灌装好的容器滑回托盘，重复④–⑥步骤，速度5–30次/分钟（膏体）
        │
⑧ 清洁与关机
   停止机器；断开气源（电动气动版还需断电）；
   拆卸并冲洗料斗/活塞/灌装喷嘴；
   切换产品前务必清洁
```

### 6.2 销售流程（从询价到交付）

1. **需求确认：** 灌装量（ml/次）、速度要求、**产品类型（膏体/液体/两者；是否易燃）** → 决定型号范围与喷嘴尺寸；**驱动版本决策**（供电稳定 + 非易燃 + 要求自动计时 → 电动气动版；防爆区 / 易燃 / 酒精基 / 溶剂基产品 / 无现场电力 → 全气动版）；车间电源规格（220V/50–60Hz；其他电压需与工厂确认）；**客户是否已有空气压缩机**（两种版本均需）；**台面式还是落地式？——这是FF2/FF6 vs. FF3的选择问题**。
2. **FF2/FF6 vs. FF3选择：** **需要即插即用、落地式工作站带集成托盘？→ 选FF3**；**已有工作台或仅需台面式设备？→ 选FF2（电动气动）或FF6（全气动）**。三者共享相同主体、料斗与灌装规格。
3. **型号与配置推荐：** 根据4.1表格推荐FF3-50 ~ FF3-5000；选择驱动版本（电动气动 / 全气动）和头数（**单头 / 双头 / 四头 / 多头**）；为提高产量，推荐多头配置。
4. **配套设备检查：** 确认客户有空气压缩机（0.4–0.6 MPa，排气量覆盖机器气耗），确保机器到货即可运行；电动气动版确认电源匹配。
5. **锁定技术细节：** 材料（304 / **定制316**）、喷嘴孔径（膏体：5–25 mm / 液体：更小）、密封（硅胶 / 耐腐蚀橡胶）、灌装头数量（单头 / 双头 / 4 / 多头）、驱动版本、脚踏 vs. 计时模式（电动气动版）。**确认：支架随机器发货，到货可调水平脚。**
6. **报价与条款：** 最小起订量1台；宁波FOB / 温州EXW；电汇；现货；加固纸箱包装，含工具与备件。
7. **订单 → 发货：** 从库存发货，每箱一台（支架包含），出口加固纸箱包装。
8. **售后支持：** 1年保修（免费维修/零件更换；国际运费由客户承担），终身维护服务；提供操作视频与远程指导。
