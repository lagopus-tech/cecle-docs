### 1. Обзор продукта
* **Категория продукта**: Промышленное автоматическое настольное оборудование для этикетировки круглых бутылок.
* **Сценарии применения**: Широко применяется в парфюмерно-косметической, фармацевтической, пищевой и химической отраслях промышленности. Специально разработана для точной этикетировки цилиндрических контейнеров, таких как флаконы для антисептиков для рук, флаконы для дезинфицирующих средств, небольшие косметические флаконы, пузырьки для лекарств, банки и бутылки для приправ.
* **Основные функции**: Обеспечивает полностью автоматическую подачу этикеток, их отделение и плавное нанесение. Машина работает стабильно, обеспечивая точную этикетировку без воздушных пузырей, что значительно повышает эффективность производства. Высокомодульная конструкция поддерживает различные расширенные опции для удовлетворения сложных требований к этикетировке.

### 2. Основные преимущества
1. **Высокая степень кастомизации**:
    * **Детектирование этикеток**: Может быть оснащена **датчиком прозрачных этикеток** для обеспечения точного обнаружения даже высокопрозрачных этикеток.
    * **Кодирование с помощью риббона**: Опциональный **риббонный кодер** позволяет печатать дату производства или номер партии непосредственно на этикетке в процессе нанесения.
    * **Точное позиционирование и двойная этикетировка**: Для продуктов, требующих определенной ориентации (например, выравнивание по определенной точке на бутылке) или **нанесения двух этикеток** (спереди и сзади), может быть добавлена высокоточная **пневматическая система позиционирования** для обеспечения равномерного угла нанесения этикеток.
    * **Расширение линии**: Опциональное **шнековое устройство для разделения бутылок** для плавной подачи, а также возможность интеграции с автоматическим **ориентатором круглых бутылок** для создания полностью автоматизированной упаковочной линии.
2. **Многорежимная этикетировка**: Поддерживает режимы одинарной и двойной этикетировки для удовлетворения разнообразных требований к представлению продукта и нормативным требованиям маркировки.
3. **Компактный дизайн**: Настольная конструкция занимает минимум места, что делает ее идеальной для малых и средних производств, цехов или лабораторий для эффективного массового производства.
4. **Стабильность и эффективность**: Оснащена высокопроизводительной системой сервопривода, обеспечивающей чрезвычайно высокую точность позиционирования этикеток, эффективно предотвращая перекосы, складки и пузыри, характерные для ручной этикетировки.

#### **Часто задаваемые вопросы (FAQ)**
* **Вопрос: Может ли машина обрабатывать бутылки с определенными метками, требующими выравнивания?**
    * **Ответ: Безусловно.** Мы поддерживаем установку пневматической системы позиционирования, которая надежно фиксирует бутылку, обеспечивая точное нанесение этикетки в указанном вами месте.
* **Вопрос: Насколько четкой является печать риббонного кодера?**
    * **Ответ:** Мы используем профессиональную технологию термотрансферной риббонной печати. Печатаемые даты и номера партий очень четкие, долговечные и не несут риска растекания чернил, как у струйных кодеров.

### 6. Технологический процесс
1. **Автоматическая подача**: Бутылки размещаются на конвейере вручную или с помощью ориентатора.
2. **Позиционирование и интервалы**: При наличии шнекового устройства оно поддерживает интервалы; для позиционирования/двойной этикетировки пневматическая система автоматически захватывает бутылку для точного выравнивания.
3. **Отделение этикетки и кодирование**: Датчики запускают процесс этикетировки, в то время как риббонный кодер одновременно печатает дату или код на этикетке.
4. **Плавное нанесение**: Бутылка вращается, и этикетка наносится аппликатором, обеспечивая гладкое покрытие без складок и пузырей.
5. **Сбор готовой продукции**: Этикетированные продукты автоматически выгружаются через выходной лоток.
