### VI. Flux de travail
1. **Placement du contenant** : Placer le contenant cylindrique (pot de miel, canette, gobelet ou bouteille) sur le support à rouleaux et ajuster le guide de positionnement.
2. **Codage de date (optionnel)** : Si la machine est équipée du codeur à ruban, elle imprime le numéro de lot ou le code de date sur l'étiquette pendant l'alimentation.
3. **Activation du cycle** : Déclencher le mécanisme d'étiquetage semi-automatique.
4. **Application de l'étiquette** : La machine alimente, enroule et presse l'étiquette en douceur sur le contenant en rotation.
5. **Sortie du produit fini** : Retirer le contenant parfaitement étiqueté et vérifier la finition propre et sans plis.
