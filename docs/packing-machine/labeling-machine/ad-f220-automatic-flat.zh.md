### 一、产品概述
* **产品类别**：工业级自动台式平面贴标机
* **应用场景**：广泛应用于化妆品盒、食品袋、方瓶、纸箱、文具封面、电子产品包装盒及各类平面物品的贴标。是中小型包装线和电商发货流程的理想选择。
* **核心功能**：实现产品顶部或平面表面的精准自动贴标。设备运行稳定，贴标位置准确、无气泡，有效替代低效的人工贴标，显著提升包装外观一致性。

### 二、核心优势
1. **高度可定制性**：
    * **透明标签适配**：可定制加装**透明标签传感器**，轻松检测并精准贴附各类透明标签。
    * **色带打码**：可选配**色带打码机**，在贴标过程中直接将生产日期、批号或有效期打印在标签膜上，无需后续单独打印工序。
2. **多材质兼容性**：适用于塑料、金属、玻璃、纸张等各类平面，对不同包装厚度和材质具有优异的适应性。
3. **紧凑精简结构**：台式设计占用空间极小，可灵活部署于现有工作台，是空间优化和自动化升级的首选入门级设备。
4. **高贴标精度**：配备精密伺服控制系统，确保每张标签精准贴附，彻底消除歪斜和褶皱。
5. **操作便捷**：人机界面支持快速设置和调试，无需专业技术人员的指导，有效降低培训成本。

### 六、工作流程
1. **人工/自动放料**：将盒子或袋子放置在输送带起始位置。
2. **传感器触发**：传感器检测到产品到位后触发贴标指令。
3. **标签剥离与打码**：贴标头同步剥离标签，可选配的色带打码机即时打印日期信息。
4. **平稳压贴**：压贴机构将标签牢固贴附于平面表面，防止气泡产生。
5. **成品输出**：完成贴标的产品自动流入收集区域。
