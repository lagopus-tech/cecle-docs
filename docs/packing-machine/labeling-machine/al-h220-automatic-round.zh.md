### 一、产品概述
* **产品类别**：工业级自动卧式圆瓶及管状物贴标机
* **应用场景**：广泛应用于制药、化妆品和文具生产线，适用于在传统输送带上无法保持稳定直立状态的小型、细长或易滚动产品，包括医用西林瓶、安瓿瓶、口服液瓶、试管、口红管和蜡笔等。
* **核心功能**：采用专用卧式滚动输送机构，稳定地送料、定位并将标签平滑贴附于不稳定的圆柱形物体表面，彻底消除贴标过程中的倾倒、倾斜或卡料现象。

### 二、核心优势
1. **专为不稳定产品设计的卧式结构**：专为过于细长或重心过高而无法直立稳定贴标的小型圆管、西林瓶和安瓿瓶而设计。
2. **灵活的高速送料选项**：
   * **标准自动送料器**：稳定产能为60-150件/分钟。
   * **高产能升级配置**：针对高需求生产线，可选配提升机+离心泵送料装置，将产能提升至150-300件/分钟。
3. **量身定制的产品定制**：送料机构和整料装置根据客户具体产品的精确几何形状和尺寸进行定制工程设计。
4. **高度定制化升级选项**：
   * **透明标签传感器**：可定制加装专用光电传感器，无缝检测透明或高透光率薄膜标签。
   * **色带打码机**：支持热转印打码，可直接在标签上打印批号、生产日期或有效期代码。

### 四、销售策略与常见问题解答
#### **销售策略**
* **产能与送料评估**：评估客户的生产量需求。对于一般生产线，推荐标准自动送料器（60-150件/分钟）；对于高速工业产能需求，建议升级至提升机+离心泵送料装置配置（150-300件/分钟）。
* **增值配置**：务必确认产品尺寸以定制送料导轨，并针对可追溯性和透明薄膜需求，建议选配色带打码机和透明标签传感器。

#### **常见问题解答（FAQ）**
* **问：为什么我需要卧式贴标机而不是标准立式贴标机？**
    * 答：安瓿瓶、小型西林瓶和蜡笔等产品过于细长或呈圆形，无法在立式输送带上稳定直立。卧式设计使其侧向滚动，确保完全稳定和完美的标签贴附。
* **问：标准送料配置和高速送料配置之间的速度差异是什么？**
    * 答：标准自动送料装置产能为60-150件/分钟。对于大批量生产，我们定制的提升机和离心泵送料装置可实现150-300件/分钟的产能。

### 六、工作流程
1. **批量送料与整理**：将产品装入标准自动送料器或可选配的提升机+离心泵送料系统，实现顺畅定向。
2. **卧式输送**：滚动输送系统沿水平面平稳地固定和旋转圆柱形产品。
3. **标签剥离与打码**：传感器触发标签出标，同时可选配的色带打码机实时在标签上打印批次数据。
4. **滚贴应用**：标签被牢固且均匀地滚贴到移动中圆柱体的水平表面，消除气泡和褶皱。
5. **成品输出**：贴标完成的产品自动排出至收集区域。
