### VI. Workflow
1. **Container Placement**: Place the cylindrical container (honey jar, can, cup, or bottle) onto the roller support and adjust the positioning guide.
2. **Date Coding (Optional)**: If equipped with the ribbon coder, the machine prints the batch or date code onto the label during feeding.
3. **Cycle Activation**: Trigger the semi-automatic labeling mechanism.
4. **Label Application**: The machine smoothly feeds, wraps, and presses the label onto the rotating container.
5. **Finished Output**: Remove the impeccably labeled container and inspect the clean, wrinkle-free finish.
