### 六、工作流程
1. **自动送瓶**：瓶体通过人工或选配的理瓶机送入输送系统。
2. **间距调节与定位**：瓶距调节轮控制瓶体间隔；若配备气缸，则夹紧并旋转瓶体以实现精确定向或双面贴标。
3. **标签剥离与打码**：传感器触发标签出标机构，同时选配的色带打码机将批次数据打印在标签上。
4. **平滑贴附**：瓶体旋转，贴标单元将标签牢固压贴，确保无褶皱、无气泡的完美效果。
5. **成品输出**：贴标完成的瓶体平稳输送至收集区域。
