### 六、工作流程
1. **自动分页**：将堆叠的袋子或纸盒放入分页机进料口，设备自动将其分离并依次输送到传送带上。
2. **传感器触发**：传感器精准捕捉物料进入位置，并触发贴标指令。
3. **标签剥离与打码**：贴标头剥离标签，同时色带打码机将生产信息直接打印在标签膜表面。
4. **压贴应用**：压贴装置将标签平稳地贴附并固定于袋子或纸盒表面。
5. **成品输出**：贴标完成的产品自动进入收集区域，完成自动化包装闭环。
