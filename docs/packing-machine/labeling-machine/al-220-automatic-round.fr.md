Spécialement conçue pour l'étiquetage vertical précis de récipients cylindriques tels que les flacons de désinfectant pour les mains, les flacons pulvérisateurs de désinfectant, les petits flacons cosmétiques, les flacons de médicaments, les canettes et les bouteilles d'alcool.

### VI. Flux de Travail
1. **Alimentation Automatique** : Les bouteilles sont introduites sur le système de convoyage manuellement ou via un dévracieur de bouteilles en option.
2. **Espacement et Positionnement** : La roue d'espacement des bouteilles régule les intervalles ; si elle est équipée d'un vérin pneumatique, elle serre et fait pivoter la bouteille pour une orientation précise ou un double étiquetage.
3. **Pelage de l'Étiquette et Codage** : Les capteurs déclenchent le mécanisme de distribution des étiquettes tandis que le codeur à ruban en option imprime les données de lot sur l'étiquette.
4. **Application en Douceur** : Le récipient tourne pendant que l'unité d'étiquetage presse l'étiquette fermement, garantissant une finition sans plis ni bulles.
5. **Sortie du Produit Fini** : Les bouteilles étiquetées sont évacuées en douceur vers la zone de collecte.
