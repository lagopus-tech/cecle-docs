### 六、工作流程
1. **放置瓶子**：将圆柱形瓶子放在滚轮支架上，并调整定位挡板。
2. **调整手柄**：将标签起始边缘与瓶子表面对齐。
3. **手动操作**：轻轻转动手摇柄或滚动瓶子。
4. **贴标**：标签从底纸上剥离，并平滑地压贴到旋转的瓶子上。
5. **完成输出**：从机器上取下贴好标签的瓶子。
