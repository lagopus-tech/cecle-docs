* **产品类别**：台式半自动圆瓶贴标机（L-50）

### 六、工作流程
1. **放置容器**：将圆柱形容器（蜂蜜罐、罐子、杯子或瓶子）放置在滚轮支架上，并调整定位导向装置。
2. **日期打码（可选）**：如果配备色带打码机，设备会在送标过程中将批号或日期码打印在标签上。
3. **启动循环**：触发半自动贴标机构。
4. **贴标应用**：设备平滑地送标、包裹并将标签压贴到旋转的容器上。
5. **成品输出**：取出贴标完美的容器，检查贴标是否干净、无褶皱。
