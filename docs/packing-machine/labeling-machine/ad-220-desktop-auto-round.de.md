### 2. Kernvorteile
1. **Hohe Anpassbarkeit**:
    * **Etikettenerkennung**: Kann mit einem **Transparentetikettensensor** ausgestattet werden, um eine präzise Erkennung auch bei hochtransparenten Etiketten zu gewährleisten.
    * **Farbbandcodierung**: Optionaler **Farbbandcoder** ermöglicht das Aufdrucken von Produktionsdaten oder Chargennummern direkt auf das Etikett während des Applikationsprozesses.
    * **Präzisionspositionierung & Doppeletikettierung**: Für Produkte, die eine bestimmte Ausrichtung erfordern (z. B. Ausrichtung auf eine bestimmte Stelle der Flasche) oder eine **Doppeletikettierung** (Vorder- und Rückseite), kann ein hochpräzises **pneumatisches Positionierungssystem** hinzugefügt werden, um gleichmäßige Etikettierwinkel zu gewährleisten.
    * **Linienerweiterung**: Optionales **Flaschenabstandsrad** für eine reibungslose Zuführung; Integration mit einem automatischen **Rundflaschen-Einschwinger** möglich, um eine vollautomatische Verpackungslinie aufzubauen.
2. **Multi-Modus-Etikettierung**: Unterstützt Einzel- und Doppeletikettmodi, um vielfältige Produktpräsentations- und gesetzliche Etikettieranforderungen zu erfüllen.
3. **Kompaktes Design**: Die Tischkonstruktion benötigt nur wenig Platz und ist ideal für kleine und mittlere Fabriken, Studios oder Labore für eine effiziente Massenproduktion.
4. **Stabil & Effizient**: Ausgestattet mit einem leistungsstarken Servoantriebssystem gewährleistet es eine extrem hohe Konsistenz der Etikettenposition und vermeidet effektiv Schrägstellung, Falten und Blasen, die bei manueller Etikettierung häufig auftreten.

### 6. Arbeitsablauf
1. **Automatische Zuführung**: Flaschen werden manuell oder über einen Einschwinger auf das Förderband gelegt.
2. **Positionierung & Abstand**: Wenn ein Abstandsrad installiert ist, hält es die Intervalle ein; für Positionierungs-/Doppeletikettieranforderungen greift das pneumatische System automatisch die Flasche für eine präzise Ausrichtung.
3. **Etikettenablösung & Codierung**: Sensoren lösen die Etikettierung aus, während der Farbbandcoder gleichzeitig das Datum oder den Code auf das Etikett druckt.
4. **Glattes Aufbringen**: Die Flasche dreht sich, und das Etikett wird von der Applikationseinheit aufgebracht, was ein glattes, faltenfreies und blasenfreies Ergebnis gewährleistet.
5. **Sammlung des Fertigprodukts**: Etikettierte Produkte werden automatisch über die Austragsplatte ausgeschleust.
