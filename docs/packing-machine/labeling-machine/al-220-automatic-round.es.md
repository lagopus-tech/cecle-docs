### VI. Flujo de Trabajo
1. **Alimentación Automática**: Las botellas se alimentan al sistema de transporte manualmente o mediante una enderezadora de botellas opcional.
2. **Espaciado y Posicionamiento**: La rueda espaciadora de botellas regula los intervalos; si está equipada con un cilindro neumático, sujeta y gira la botella para una orientación precisa o doble etiquetado.
3. **Despegado de Etiqueta y Codificación**: Los sensores activan el mecanismo dispensador de etiquetas mientras el codificador de cinta opcional imprime datos de lote en la etiqueta.
4. **Aplicación Suave**: El contenedor gira mientras la unidad de etiquetado presiona la etiqueta de forma segura, garantizando un acabado sin arrugas ni burbujas.
5. **Salida del Producto Terminado**: Las botellas etiquetadas se descargan suavemente al área de recolección.
