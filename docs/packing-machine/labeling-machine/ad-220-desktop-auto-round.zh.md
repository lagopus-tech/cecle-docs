### 1. 产品概述
* **产品类别**：工业级自动台式圆瓶贴标设备。
* **应用场景**：广泛应用于日化、制药、食品及精细化工行业。专为圆柱形容器的精确贴标而设计，如洗手液瓶、消毒液瓶、小型化妆品瓶、药瓶、罐装容器及调味料瓶等。

### 2. 核心优势
1. **高度可定制性**：
    * **标签检测**：可配备**透明标签传感器**，即使对高透明度标签也能确保精准检测。
    * **色带打码**：可选配**色带打码机**，在贴标过程中直接将生产日期或批号打印在标签上。
    * **精确定位与双面贴标**：对于需要特定方向定位的产品（如对准瓶身特定位置）或**双面贴标**（正面和背面），可加装高精度**气动定位系统**，确保贴标角度一致。
    * **产线扩展**：可选配**瓶距分隔轮**以实现平稳送瓶，并可集成自动**圆瓶理瓶机**，构建全自动包装生产线。
2. **多模式贴标**：支持单标和双标模式，满足多样化的产品展示及法规贴标要求。
3. **紧凑设计**：台式结构占用空间极小，非常适合中小型工厂、工作室或实验室进行高效批量生产。
4. **稳定高效**：配备高性能伺服驱动系统，确保贴标位置具有极高的一致性，有效避免人工贴标常见的歪斜、褶皱和气泡问题。

### 6. 工作流程
1. **自动送瓶**：瓶子通过人工或理瓶机放置到输送带上。
2. **定位与分距**：如配备分距轮，可保持瓶间间隔；对于定位/双面贴标需求，气动系统会自动抓取瓶子进行精确对位。
3. **标签剥离与打码**：传感器触发贴标动作，同时色带打码机在标签上打印日期或代码。
4. **平滑贴附**：瓶子旋转，贴标单元将标签平整贴附，确保表面平滑、无褶皱、无气泡。
5. **成品收集**：贴标完成的产品通过出料板自动排出。
