### 六、工作流程
1. **自动送瓶与分距**：容器（圆瓶或方瓶）进入输送线，由分距机构按等间距排列。
2. **夹持与精确定位**：同步定位和压紧装置牢固夹持容器，确保贴标位置精准。
3. **标签剥离与打码**：传感器触发标签出标，同时色带打码机（选配）在标签上同步打印批次或日期信息。
4. **平滑贴附**：贴标滚轮和压紧机构将标签牢固贴合于容器表面，彻底消除气泡和褶皱。
5. **成品输出**：贴标完成的成品自动排出至收集区域。
