## 四、操作流程

### 1. 所需物料
* **耗材**：待印刷衣物/面料、热转印标签、热转印纸等。  
* **电源供应**：110V 或 220V 电源。  
* **气源设备**：建议工作压力 0.4 MPa（工厂标准设定）。

### 2. 标准操作流程

**步骤一：连接气源并调节压力**
1. 将气管接入气动设备，确保接头牢固且无漏气。  
2. 抬起压力阀，顺时针旋转调高压力，逆时针旋转调低压力。工厂默认压力设为 0.4 MPa，通常无需频繁调整；调整完毕后按下压力阀锁定。  
3. 调整电磁阀（出厂已设定，一般无需改动）：上方调节器用于提升加热板抬升力，下方调节器用于设定下压压力。调节正确后，加热板应能在设定压力下平稳升降。

**步骤二：控制器设置**
1. 按下“SET”键，显示屏显示 SP —— 使用上下键设定所需温度。  
2. 再次按下“SET”键，显示 St —— 使用上下键设定所需压印时间。  
3. 最后长按“SET”键约 3 秒保存设置，机器开始加热。  
4. 如需重置计数器，长按“RESET”键约 3 秒即可清零 COUNTER。

**步骤三：压印操作**
1. 当温度达到设定值后，将工件放置于其中一个固定铝制工作台的耐高温硅胶垫上（两个下方工作台固定不动，不左右移动）。  
2. 推动移动手柄，使上部加热板滑车移至指定位置；微动开关触发后，加热板自动下压，倒计时开始。  
3. 倒计时结束后，加热板自动回升。  
4. 推动手柄将上滑车移至另一工作台，取出成品，放入新工件——两面交替操作，循环往复。
