## 四、操作流程

### 1. 所需材料
* **转印介质**：需打印的小面积物品，如T恤、玩偶、鞋舌等；升华纸或热转印膜。  
* **电源供应**：110V 或 220V 电源。  
* **配件**：隔热垫、喷雾瓶、收纳袋。

### 2. 标准操作流程
1. **预热**：将机器平放于防烫底座上，插电开机，通过按钮设置温度与时间，等待LED屏幕显示达到设定工作温度。  
2. **放置材料**：将基材（如T恤局部、靠垫一角）平整置于隔热垫上，热转印纸图案面朝下并准确对齐。  
3. **施压**：手持机器，平稳将铝合金加热板压在图案上方；双高频电机自动提供持续均匀压力，保持设定时间。  
4. **完成**：计时结束后移开机器，揭下转印纸，待图案冷却后即牢固附着。  
5. **收纳**：工作完毕且机器冷却后，盖上透明防护罩，装入收纳袋，方便携带或存放。
