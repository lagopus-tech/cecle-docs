## 四、操作流程

### 1. 所需材料
* **耗材**：耐高温3D手机壳（需带升华涂层）、空白马克杯/陶瓷盘等。  
* **转印纸**：已打印好升华图案的转印纸、耐高温胶带。  
* **辅助工具**：手机壳模具、马克杯夹具等。  
* **电源供应**：220V 或 110V 电源。

### 2. 标准操作流程（以3D手机壳为例）
1. **预热**：开机，于控制面板设置温度与时间（通常为190℃，360秒），等待机器升温至设定值。  
2. **包裹图案**：使用耐高温胶带将升华图案纸固定在空白3D手机壳上。  
3. **放入腔体**：打开108°翻盖，将包裹好并置于模具中的手机壳放入腔体，关闭舱门。  
4. **真空转印**：按下 **`真空`** 键，机器自动启动抽真空，随后按下倒计时键，设备即开始自动加热转印。  
5. **排气卸料**：倒计时结束后，**机器自动排气并发出“嘀”声报警**。打开舱门，取出手机壳，撕下转印纸，转印完成。
