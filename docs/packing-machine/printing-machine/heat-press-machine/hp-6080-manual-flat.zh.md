## 四、操作流程

### 1. 所需物料
* **待压材料**：T恤/球衣/瑜伽垫、热转印纸等平面物品。  
* **电源供应**：110V 或 220V 交流电源。  
* **放置空间**：机器体积较大，请置于稳固、水平的桌面或地面上，并预留足够操作空间。

### 2. 标准操作流程
1. **预热**：连接电源，打开开关，通过数字控制器设置目标温度和时间，等待铝制加热板升至设定值。  
2. **放置材料**：将工件平整放置于底部耐高温硅胶垫上，将转印纸图案面朝下放置并准确对位。  
3. **施加压力**：双手握住双压力手柄，平稳下压加热板，机器自动开始倒计时。  
4. **完成**：蜂鸣器响起后，向上提起手柄，抬起加热板，揭去转印纸——打印完成。

### 常见问题 FAQ
* **Q：这款机器能在美国110V电压下使用吗？**  
  * **A**：完全可行。我们提供北美标准110V与欧亚标准220V两种电压配置。

* **Q：如何调节压力旋钮？如何判断压力是否合适？**  
  * **A**：通过机器上的压力旋钮进行调节。压合后，若图案边缘清晰、无缺色、无滑移，则压力适中；若转印颜色发淡或硅胶垫出现深痕，需微调。较厚材料（如褶皱裙、瑜伽垫）应相应增加压力。
