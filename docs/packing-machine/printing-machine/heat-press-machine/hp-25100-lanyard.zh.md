## 四、操作流程

### 1. 所需物料
* **基材**：待印刷的织带 / 背带 / 丝带等长条形材料。  
* **耗材**：升华墨水、升华纸、已打印图案。  
* **电源**：110V 或 220V 供电。  
* **工具**：耐高温胶带（固定图案防止移位）、隔热手套（取件时防烫伤）。

### 2. 标准操作流程
1. **预热**：连接电源并开启；在控制器上设置目标温度与倒计时时间；等待 10–15 分钟至加热板达到工作温度。
2. **调节压力**：旋转顶部压力旋钮至合适档位（正式生产前建议先做小样测试）。
3. **打印图案**：在电脑上设计图案，使用喷墨打印机 + 升华纸 + 升华墨水打印。**务必确保墨水完全干燥后方可使用**。
4. **装料**：将背带平铺于加热板上，将图案纸面朝下精准对齐，并用耐高温胶带固定两端，防止移位。
5. **施加压力**：双手稳压手柄，用力下压；机器自动启动倒计时。
6. **完成**：蜂鸣器响起后，抬起手柄，取出背带，撕下转印纸——图案已牢固附着。
7. **关机复位**：工作结束后关闭电源，待加热板冷却后再进行存放或移动。

### 常见问题（FAQ）
* **Q：如何在摄氏与华氏之间切换？**  
  * **A**：长按 **`SET`** 键数秒，直到显示屏出现 **`LOY`**；按 ▼ 键直至显示 **`88`**；再次长按 **`SET`** 数秒，直到显示 **`CF`**；按 ▲ 或 ▼ 键切换 **0（摄氏） / 1（华氏）**；长按 **`SET`** 3 秒确认并退出。
