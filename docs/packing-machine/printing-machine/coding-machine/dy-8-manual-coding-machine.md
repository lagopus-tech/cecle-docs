## 4. Operation Process
1. **Install Fonts:** Use tweezers to arrange the copper digits/letters into the print head and lock them.
2. **Thread Ribbon:** Follow the roller path to install the thermal coding ribbon.
3. **Pre-heat:** Plug in, turn on the switch, and adjust the temperature. Wait a few minutes for the head to reach working temperature.
4. **Position Material:** Place the bag or paper on the silicone pad of the base.
5. **Manual Print:** Press the handle down firmly. The heat transfers the characters to the package. Release to finish.

**Q2: Does it require an air compressor?**
A2: No. This is a purely manual electrical device. It only needs a standard power outlet.

**Q3: How many prints can one ribbon do?**
A3: A standard roll can provide thousands of prints, depending on the number of rows used.
