## VI. Workflow

1. **File Selection & Editing**: Turn on the 7-inch HD touchscreen, select or create the printing template (text, date, or variable barcode) using the WYSIWYG editor.
2. **Substrate Positioning**: Place the target product (carton, bottle, or bag) manually under the print head or align it using the optional positioning plate.
3. **Trigger Activation**: Initiate printing via manual touchscreen button, external foot pedal switch, or automatic sensor detection as the product passes.
4. **High-Resolution Jet Printing**: The MCU system executes precise thermal inkjet printing, applying crisp, high-definition characters instantly without leading-edge distortion.
5. **Quality Check & Output**: The marked product is removed or conveyed forward, while the system automatically updates the counter and remaining ink capacity.
