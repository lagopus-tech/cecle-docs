## 2. Core Advantages
1. **Solid-Ink Roller Printing:** Uses a hot ink roller instead of liquid ink or ribbon. Prints are instant-dry, clear, and highly durable. Multiple colors are available and easy to switch.
2. **Fully Automatic Operation:** Features automatic paging and counting. Simply place a stack of materials on the feeder, and the machine separates and prints them individually.
3. **High-Speed Performance:** Reaches speeds of up to 300 pieces per minute, greatly improving efficiency for mass production.
4. **Precise Positioning:** Controlled by a photoelectric sensor for automatic positioning. Printing lines can be set in advance with a stepless adjustment range of 60-250mm.
5. **Easy Maintenance:** The clear structural design allows for easy replacement of wearing parts like rubber belts, ink rollers, heaters, and brass fonts.

## 4. Operation Process
1. **Installation:** Arrange brass fonts into the type wheel and install the solid-ink roller onto the heating shaft.
2. **Pre-heating:** Turn on the power and **pre-heat for 10-15 minutes** to ensure the ink roller is fully melted.
3. **Loading:** Adjust the feeding guides and place a stack of flat boxes or labels onto the platform.
4. **Test Run:** Perform a test print to check the temperature and position. Adjust the temperature knob and position settings if necessary.
5. **Production:** Once tested, start the automatic run for continuous paging, printing, and counting.

### FAQ
**Q1: Does this machine use ribbon or liquid ink?**
A1: Neither. It uses a "Solid Hot Ink Roller." It is solid at room temperature and melts when heated, providing ink-like richness with the cleanliness of ribbon.

**Q2: Why is the print faint or unclear?**
A2: Usually due to insufficient pre-heating. Ensure the machine warms up for 10-15 minutes. If still faint, increase the temperature or replace the ink roller.

**Q3: How thick can the material be?**
A3: It works on any flat material under 3mm thickness, including paper labels, empty medicine boxes, and plastic films.

**Q4: Are the fonts compatible with the HP-241B?**
A4: Generally no. The MY-380F uses specific T-type or R-type brass fonts designed for its high-speed rotary structure.
