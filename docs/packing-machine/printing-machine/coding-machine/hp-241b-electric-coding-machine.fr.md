## 4. Processus de Fonctionnement
1. **Installer les Polices :** Insérez 1 à 3 lignes de polices en laiton dans la tête d'impression et verrouillez-les.
2. **Enfiler le Ruban :** Chargez le ruban et ajustez la vis papillon pour contrôler l'espacement du ruban et minimiser le gaspillage.
3. **Pré-chauffage :** Allumez l'appareil, ajustez la température et attendez que la tête atteigne la chaleur cible.
4. **Choisir le Mode :**
   - *Automatique :* Réglez la vitesse ; la machine imprime en continu.
   - *Pédale :* Placez le matériau et appuyez sur la pédale pour une impression unique.
5. **Achèvement :** Les impressions sont à séchage instantané et prêtes pour l'étape d'emballage suivante.

### FAQ
**Q1 : Quelle est la différence avec le codeur manuel DY-8 ?**
R1 : La HP-241B est entraînée par moteur, beaucoup plus rapide (jusqu'à 120 fois/min) et prend en charge jusqu'à 3 lignes de texte.

**Q2 : A-t-elle besoin d'un compresseur d'air ?**
R2 : Non. Elle est entièrement électrique. Il suffit de la brancher sur une prise standard.

**Q3 : Puis-je ajuster l'espacement du ruban ?**
R3 : Oui. Il existe un composant d'ajustement spécifique pour contrôler la quantité de ruban déplacée à chaque impression afin de réduire les coûts.

**Q4 : L'impression fraîche va-t-elle baver ?**
R4 : Non. Elle utilise le transfert thermique, qui est à séchage instantané. Vous pouvez la toucher immédiatement.
