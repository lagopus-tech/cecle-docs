## VI. Workflow

1. **Template Setup & Editing**: Power on the 7-inch color touchscreen, select or create the coding layout (batch number, date, or variable barcode) using the intuitive V5.3 OS.
2. **Inline Installation & Adjustment**: Mount the print head securely onto the optional industrial bracket, adjusting the position for downward or forward printing over the conveyor line.
3. **Sensor & Encoder Connection**: Connect the optical sensor and synchronizer (encoder) to synchronize printing with the speed and movement of the product stream.
4. **High-Speed Inline Coding**: As products pass continuously on the conveyor at speeds up to 75m/min, the sensor triggers the thermal inkjet head to apply crisp, high-resolution codes instantly.
5. **Quality Verification & Maintenance**: Finished products move down the line seamlessly, while operators can utilize the unique cartridge extrusion feature for quick, clean maintenance when needed.
