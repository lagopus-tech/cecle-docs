## 4. Processo de Operação
1. **Instalar Fontes:** Insira de 1 a 3 linhas de fontes de latão no cabeçote de impressão e trave-as.
2. **Enfiar a Fita:** Carregue a fita e ajuste o parafuso borboleta para controlar o espaçamento da fita e minimizar o desperdício.
3. **Pré-aquecer:** Ligue a energia, ajuste a temperatura e aguarde o cabeçote atingir o calor desejado.
4. **Escolher o Modo:**
   - *Automático:* Defina a velocidade; a máquina imprime continuamente.
   - *Pedal:* Posicione o material e pressione o pedal para uma impressão única.
5. **Conclusão:** As impressões são de secagem instantânea e prontas para a próxima etapa da embalagem.

R4: Não. Ela utiliza transferência térmica, que é de secagem instantânea. Você pode tocá-la imediatamente.
