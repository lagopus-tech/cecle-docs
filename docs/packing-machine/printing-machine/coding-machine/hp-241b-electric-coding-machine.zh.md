## 2. 核心优势
1. **热转印色带打印：** 比油墨更清洁，满足食品和药品的高卫生标准。
2. **电动双模式：** 电机驱动，支持两种模式：“脚踏”模式用于单次打印，“自动”模式用于连续操作。
3. **恒温控制：** 温度可调，适用于不同材料厚度和色带类型。
4. **卓越打印质量：** 速干、清晰、附着力强，不易污损。
5. **多行打印能力：** 支持最多3行文字，可同时打印生产日期（MFG）、有效期（EXP）和批号（LOT）。
6. **精密制造：** 结构耐用，维护简便。

## 4. 操作流程
1. **安装字模：** 将1至3行铜字模插入打印头并锁定。
2. **穿装色带：** 装入色带，调节蝶形螺丝以控制色带间距，最大限度减少浪费。
3. **预热：** 打开电源，调节温度，等待打印头达到目标温度。
4. **选择模式：**
   - *自动模式：* 设定速度，机器连续打印。
   - *脚踏模式：* 放置材料后踩下脚踏板进行单次打印。
5. **完成：** 打印内容速干，可立即进入下一道包装工序。
