## 4. Operation Process
1. **Install Fonts:** Insert 1 to 3 rows of brass fonts into the print head and lock them.
2. **Thread Ribbon:** Load the ribbon and adjust the butterfly screw to control ribbon spacing and minimize waste.
3. **Pre-heat:** Turn on the power, adjust the temperature, and wait for the head to reach the target heat.
4. **Choose Mode:**
   - *Automatic:* Set the speed; the machine prints continuously.
   - *Foot Switch:* Place the material and press the pedal for a single print.
5. **Completion:** Prints are instant-dry and ready for the next packaging step.
