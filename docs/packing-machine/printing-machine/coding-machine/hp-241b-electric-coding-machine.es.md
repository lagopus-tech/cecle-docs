## 4. Proceso de Operación
1. **Instalar Tipografías:** Inserte de 1 a 3 líneas de tipos de latón en el cabezal de impresión y asegúrelas.
2. **Enhebrar la Cinta:** Cargue la cinta y ajuste el tornillo de mariposa para controlar el espaciado de la cinta y minimizar el desperdicio.
3. **Precalentamiento:** Encienda la alimentación, ajuste la temperatura y espere a que el cabezal alcance el calor objetivo.
4. **Seleccionar Modo:**
   - *Automático:* Configure la velocidad; la máquina imprime continuamente.
   - *Pedal:* Coloque el material y presione el pedal para una impresión individual.
5. **Finalización:** Las impresiones son de secado instantáneo y están listas para el siguiente paso del envasado.
