## 一、产品概览  
Anycubic Kobra S1 组合式是一款配备 ACE Pro 耗材干燥与送丝单元的全封闭式 CoreXY 高速 FDM 3D 打印机。原生支持 4 色打印，通过增加第二个 ACE Pro 单元可扩展至 8 色打印。配备 LeviQ 3.0 自动调平系统、4.3 英寸电容式触控屏及内置 AI 监控摄像头，支持同步耗材干燥。本设备完美平衡了家用用户、创客工作室以及中小型人像与模型原型制作的需求，具备高速打印、低噪音运行和便捷维护等优势。

## 二、核心优势  
1. **高速 CoreXY 全封闭结构**：最大打印速度达 600mm/s，推荐速度 300mm/s，最大加速度 20,000mm/s²。全封闭打印舱有效减少温差波动，确保 ABS、ASA 等易翘曲材料打印更稳定。
2. **4 至 8 色打印 + 同步耗材干燥**：ACE Pro 单元在送丝与换色过程中对耗材进行加热干燥，防止因潮湿引发拉丝或堵塞。单个 ACE Pro 支持 4 色，叠加第二个单元可扩展至 8 色，实现自然渐变色彩与丰富模型细节。
3. **320℃ 高温快速更换喷嘴**：采用防堵设计，兼容 PLA、PETG、ABS、ASA 及 95A TPU 等多种耗材。喷嘴可快速更换（支持 0.2/0.4/0.6/0.8mm），维护与更换极为方便。
4. **LeviQ 3.0 智能自动调平系统**：自动补偿平台 Z 向偏移量。搭配 PEI 弹簧钢打印平台，确保模型附着牢固且轻松取件，新手友好度极高。
5. **超低噪音设计**：静音模式下仅 44dB，标准模式下 46dB。运行平稳，无刺耳噪音干扰，适合夜间打印或办公环境使用。
6. **AI 智能监控与断电续打**：内置高清摄像头，支持打印延时摄影、AI 面条检测、断料检测及断电续打功能。可通过 U 盘、云平台或切片软件远程提交打印任务。
7. **Kobra OS 触控操作系统**：配备 4.3 英寸电容式触控屏与多语言界面，与 Anycubic Slicer Next 软件完美配合，支持主流模型格式如 STL、OBJ 和 3mf，操作直观简便。

## 四、操作流程  
1. 将打印耗材放入 ACE Pro 送丝与干燥腔体中，紧闭舱门，开启耗材干燥功能，等待耗材充分干燥。  
2. 开启机器并执行 LeviQ 3.0 自动调平流程，系统将自动完成平台检测与 Z 轴偏移校准。  
3. 使用切片软件对 STL/3MF 模型进行切片，生成 G-code 文件，通过 U 盘传输或 WiFi 云平台上传至打印机。  
4. 在触控屏上选择打印任务，配置多色分配参数（多色打印时），启动打印。内置摄像头支持实时监控打印状态。  
5. 打印完成后，等待热床冷却，取下 PEI 弹簧钢平台，轻轻弯曲即可取出成品模型。  
6. 清理喷嘴与平台残留耗材。若长时间停用，请将耗材放回密封干燥环境中保存。

> **补充说明：** 多色打印前需在切片软件中提前配置多色参数。机器的 ACE Pro 单元将自动完成换色与回抽，实现模型不同部位的颜色切换。**柔性 TPU 耗材不支持 ACE Pro 多色切换，仅可在单色模式下使用。**

## 五、销售建议与常见问题解答  

### 销售建议  
1. 建议客户提前确认主要使用的耗材类型（PLA/ABS/TPU 等），提醒其柔性 TPU 仅支持单色打印。  
2. 若需 8 色打印，客户需额外购买一个 ACE Pro 送丝干燥模块。  
3. **重点推荐卖点：** 高速打印、44dB 低噪音、同步耗材干燥、AI 监控、全封闭舱体适合工程材料。  
4. **推荐配套耗材包：** PLA、PETG、ASA 等。针对潮湿地区客户，建议备置耗材干燥箱以进一步降低受潮风险。  
5. **一站式服务：** 咨询 → 下单 → 安装指导 → 发货 → 售后技术支持。

### 常见问题解答（FAQ）  
1. **问：机器是否包含打印耗材？**  
   答：不包含。耗材需由客户另行购买。

2. **问：最多支持多少种颜色？**  
   答：标配一个 ACE Pro 单元支持 4 色；增加第二个 ACE Pro 模块可升级至 8 色。请注意：TPU 耗材不支持多色切换功能。

3. **问：能否打印柔性 TPU 耗材？**  
   答：可以，支持 95A 硬度 TPU，但**仅限单色模式**。无法使用 ACE Pro 实现多色切换。

4. **问：保修期是多久？**  
   答：官方整机保修期为 1 年（不包括喷嘴、PTFE 管道等耗材件）。我们提供终身技术咨询与维护支持。

5. **问：能否远程监控打印过程？**  
   答：可以。内置高清摄像头，连接 WiFi 后，可通过 Anycubic Cloud APP 远程查看实时打印画面及延时摄影回放。

6. **问：打印时边缘出现翘曲怎么办？**  
   答：打印 ABS 或 ASA 材料时，请确保打印舱完全关闭，适当提高热床温度，并开启耗材干燥功能。这将有效改善并减少翘曲现象。
