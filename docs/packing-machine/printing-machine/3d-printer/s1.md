# S1 Combo High-Speed Multi-Color 3D Printer

The Anycubic Kobra S1 Combo is an advanced, fully enclosed CoreXY high-speed FDM 3D printer designed to revolutionize multi-color printing. It is the perfect solution for maker studios, engineering professionals, home hobbyists, and small-to-medium batch figure prototyping. The machine boasts a blazing-fast maximum print speed of 600mm/s and features the innovative ACE Pro feeding unit, which enables seamless 4-color printing (expandable to 8 colors) while synchronously drying the filament to prevent moisture-related print failures. ## I. Product Overview
The Anycubic Kobra S1 Combo is a fully enclosed CoreXY high-speed FDM 3D printer equipped with the ACE Pro filament drying and feeding unit. It natively supports 4-color printing and can be expanded to 8-color printing by adding a second ACE Pro unit. Featuring LeviQ 3.0 auto-leveling, a 4.3-inch capacitive touch screen, and a built-in AI monitoring camera, it supports synchronous filament drying. This machine perfectly balances the needs of home users, maker studios, and small-to-medium batch figure and model prototyping. It boasts fast printing speeds, low noise, and easy maintenance.

## II. Core Advantages
1. **High-Speed CoreXY Fully Enclosed Design**: Maximum print speed of 600mm/s, recommended speed of 300mm/s, and maximum acceleration of 20,000mm/s². The fully enclosed chamber reduces temperature fluctuations, ensuring more stable printing results for warp-prone materials like ABS and ASA.
2. **4 to 8-Color Printing + Synchronous Filament Drying**: The ACE Pro unit heats and dries the filament during feeding and color switching, preventing stringing and clogging caused by moisture. A single ACE Pro enables 4 colors, while stacking a second unit expands it to 8 colors, offering natural color transitions and rich model details.
3. **320℃ High-Temperature Quick-Swap Hotend**: Features an anti-clogging design and supports various filaments including PLA, PETG, ABS, ASA, and 95A-TPU. The nozzle can be quickly swapped (0.2/0.4/0.6/0.8mm options available), making maintenance and replacement highly convenient.
4. **LeviQ 3.0 Smart Auto-Leveling System**: Automatically compensates for the bed's Z-offset. Paired with a PEI spring steel build plate, it ensures excellent model adhesion and effortless part removal, making it incredibly beginner-friendly.
5. **Ultra-Low Noise Design**: Operates at a quiet 44dB in Quiet Mode and 46dB in Standard Mode. It runs stably without causing harsh noise disturbances, making it suitable for nighttime printing or office environments.
6. **AI Smart Monitoring & Power-Loss Recovery**: Built-in HD camera supports print timelapse, AI spaghetti detection, filament runout detection, and power-loss recovery. It allows remote print task submission via USB drive, cloud platform, or slicer software.
7. **Kobra OS Touch Operating System**: Equipped with a 4.3-inch capacitive touch screen and a multi-language interface. It pairs perfectly with the Anycubic Slicer Next software, supporting mainstream model formats like STL, OBJ, and 3mf for intuitive and straightforward operation.

## IV. Operation Flow
1. Load the printing filament into the ACE Pro feeding and drying chamber, close the door tightly, turn on the filament drying function, and wait for the filament to dry.
2. Power on the machine and execute the LeviQ 3.0 auto-leveling process. The system will automatically complete bed detection and Z-axis offset calibration.
3. Use the slicer software to slice the STL/3MF model and export the G-code. Transfer it to the printer via a USB drive or upload it via the WiFi cloud platform.
4. Select the print task on the touch screen, configure the color allocation parameters (for multi-color prints), and start printing. The built-in camera allows real-time monitoring of the print status.
5. Once printing is complete, wait for the heated bed to cool down. Remove the PEI spring steel plate and gently bend it to pop off the finished model.
6. Clean any residual filament from the nozzle and build plate. If shutting down for an extended period, return the filament to a sealed, dry environment for storage.

> **Supplementary Note:** For multi-color printing, multi-color parameters must be configured in the slicer software in advance. The machine's ACE Pro unit will automatically perform color switching and retraction to achieve color changes in different parts of the model. **Flexible TPU filament does not support ACE Pro multi-color switching and can only be used in single-color printing mode.**

### Frequently Asked Questions (FAQs)
1. **Q: Does the machine come with printing filament?**
   A: The machine does not include filament; it needs to be purchased separately by the customer.

2. **Q: What is the maximum number of colors supported?**
   A: The standard kit with one ACE Pro supports 4 colors. Adding a second ACE Pro module upgrades it to 8 colors. Please note that TPU filament does not support the multi-color switching feature.

3. **Q: Can it print flexible TPU filament?**
   A: Yes, it supports 95A hardness TPU, but **only in single-color mode**. You cannot use the ACE Pro for multi-color switching with TPU.

4. **Q: How long is the warranty?**
   A: The official warranty for the machine is 1 year (excluding consumable parts like nozzles and PTFE tubes). We provide lifetime technical consultation and maintenance support.

5. **Q: Can I monitor the print remotely?**
   A: Yes. It features a built-in HD camera. Once connected to WiFi, you can remotely view the live print feed and timelapse playback via the Anycubic Cloud APP.

6. **Q: What should I do if the print is warping at the edges?**
   A: When printing ABS or ASA, please ensure the enclosure is fully closed, increase the heated bed temperature, and turn on the filament drying function. This will effectively improve and reduce warping.
