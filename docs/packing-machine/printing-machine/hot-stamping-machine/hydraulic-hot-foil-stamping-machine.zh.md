# 产品名称：半自动重型液压烫金压印机  
## 系列型号：HGP-300 与 HGP-350（可定制更大尺寸）

> **核心摘要**：半自动重型液压烫金压印机（型号 HGP-300 与 HGP-350）是一款专为大型尺寸及高压力烫金与压印设计的工业级液压系统，适用于金属、钢板、铝板、肥皂块以及刚性包装材料等平面基材。提供两种坚固的标准配置——HGP-300（加热板尺寸 300×400mm，压力选项 3T/8T）和 HGP-350（加热板尺寸 350×500mm，压力选项 12T/15T），并可根据需求定制更大加热板（如 500×700mm、600×800mm 或更大），实现巨大且均匀的吨位输出，确保深凹压印与完美烫金转移效果。主要亮点包括标准光电保护开关、双按钮启动、可定制滑动工作台（气动或伺服驱动）、快速换模选项及专用蜂窝板，是重型工业品牌标识应用的终极高产能解决方案。

---

### 一、产品概览
* **产品类别**：半自动重型液压烫金压印机  
* **应用场景**：在金属制品、钢板、铝板、肥皂块、刚性包装及重工业基材上进行大尺寸烫金与压印  
* **核心功能**：通过半自动液压操作，施加高吨位压力（标准型号范围 3T 至 15T，定制机型可提供更高吨位），配合定制烫金模版与烫金箔，实现永久性、清晰锐利、深浮雕效果的品牌标识

### 二、核心优势
1. **高吨位液压动力**：标准系列提供强大液压压力选项——HGP-300（3T 或 8T）、HGP-350（12T 或 15T），即使面对坚硬、致密或大面积材料也能实现无瑕烫金转移  
2. **可定制更大加热板**：除标准尺寸外，支持完全定制化工程，可制造加热板尺寸达 500×700mm、600×800mm 甚至更大的机型，精准匹配您的超大产品需求  
3. **全面安全防护**：标配光电保护开关与双按钮启动机制；可选配安全护罩与光栅，满足严格地区安全标准  
4. **灵活工作台定制**：配备标准固定下工作台，可升级为气动滑动工作台或高精度伺服电机驱动滑动工作台，提升装卸安全性与便捷性  
5. **先进模具配置与工业级结构**：支持可定制快速更换模版及专用蜂窝板，确保在高压连续运行下实现烫金模版的稳固、快速、高效安装。（注：首次安装需注入 HM46 抗磨液压油）

### 四、销售建议与常见问题解答（FAQ）

#### **销售建议**
* **型号与尺寸选择**：推荐 HGP-300（3T/8T）用于中大型压印区域，HGP-350（12T/15T）适用于较大标准表面；若客户有超大板材或工业面板需求，重点推介我们的定制大尺寸能力（500×700mm、600×800mm 或更大）
* **定制化增值推荐**：针对注重操作效率与安全性的客户，建议升级至气动或伺服驱动滑动工作台，并搭配安全光栅、快速更换蜂窝板等配置
* **初始安装提醒**：告知客户，液压设备到货后需先加注 HM46 抗磨液压油方可启动使用

#### **常见问题解答（FAQ）**
* **Q：能否为客户定制更大加热板以适应超大产品？**  
    * A：可以！除了我们标准的 HGP-300 和 HGP-350 型号外，我们可根据您的具体要求定制更大加热板，如 500×700mm、600×800mm，甚至更大尺寸。
* **Q：HGP-300 与 HGP-350 的主要区别是什么？**  
    * A：HGP-300 配备 300×400mm 加热板，压力选项为 3T 或 8T；而 HGP-350 配备更大的 350×500mm 加热板，压力选项为 12T 或 15T。
* **Q：收到液压压印机后需要做哪些准备工作？**  
    * A：设备到货后，需在开机前添加液压油。我们推荐使用标准 **HM46 抗磨液压油**。
* **Q：工作台和安全装置是否可以定制？**  
    * A：可以！标准机型配备固定下工作台，但可选升级为气动滑动工作台、伺服电机驱动滑动工作台、防护亚克力罩、光栅、快速更换模版板及定制蜂窝安装板。

### 六、工作流程
1. **初始准备**：确认机器已注入 HM46 抗磨液压油，并连接正确的电源（220V/380V）  
2. **模具与烫金箔安装**：将定制烫金模版安装至加热板上（如需可使用蜂窝板），并将烫金箔穿过送箔路径  
3. **参数设置**：根据标准型号或定制机型规格，设定工作温度、保压时间与液压压力  
4. **产品放置**：将目标产品（金属、钢板、铝板、肥皂或刚性包装）置于工作台上（或触发可选的气动/伺服滑动台完成上料）  
5. **安全启动与压印**：按下双按钮启动，同时光电保护与光栅确保操作安全，液压压头下降执行高吨位压印  
6. **成品取出**：液压板自动回位，可安全取出高精度烫印成品
