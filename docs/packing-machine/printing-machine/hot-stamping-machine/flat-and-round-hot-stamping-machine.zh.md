## 系列型号：AGP-S-210

> **核心摘要：** 平/圆两用半自动烫金机（型号：AGP-S-210）是一款专为曲面/圆形表面（如马克杯、瓶子、圆柱形物品）和扁平产品（如标签、珠宝盒）设计的多功能气动烫印系统。适用于促销礼品加工、定制包装及手工艺行业，具备可快速切换的灵活结构，通过定制圆形模版实现平/圆模式无缝转换。配备可调加热板下降行程、稳定的0.4T气压系统以及便捷安装，本机提供卓越的多用途灵活性、高精度与清晰锐利的烫金效果，适配多种产品形状。

### 一、产品概述
* **产品类别**：平/圆两用半自动烫金机 / 双功能气动烫印压力机  
* **应用场景**：广泛用于圆柱形/曲面物品（圆形瓶盖、圆形瓶子）及扁平物品（标签、珠宝盒、卡片、平面部件）的烫印作业。  
* **核心功能**：半自动气动烫印，双功能设计。针对圆弧表面时，安装定制圆形模版；进行平面烫印时，仅需拆除圆形模版及夹具即可。加热板下降行程全可调，轻松适配不同尺寸与高度的产品。

### 二、核心优势
* **平/圆双用，灵活高效**：可在平面与曲面烫印间自由切换，最大化设备利用率，节省车间空间与设备投入成本。  
* **定制圆形模版，贴合完美**：支持根据客户产品直径定制圆形模版，确保在马克杯、瓶子等圆柱体上实现无死角、环绕式烫金效果。  
* **行程与下降深度灵活调节**：加热板下降距离可调，操作员可轻松根据产品厚度与高度精准设定压行程。  
* **稳定气动控制，精准可靠**：采用稳定气压驱动（需0.6–0.8MPa压缩空气），最大压力达0.4T，保证压力均匀一致，印迹清晰锐利。  
* **安装简便，操作友好**：流程清晰简单；连接外置空压机、安装烫印模版、穿好烫金箔后即可快速启动生产。

### 六、操作流程
1. **气源与电源连接**：将机器连接至外部空气压缩机（供气压力0.6–0.8MPa），并接入110V/220V电源。
2. **模版与烫金箔安装**：将烫印模版安装于加热板上，并将烫金箔穿过送箔路径。
3. **模式设置（平面或圆弧）**：
   * *圆弧烫印*：安装专为圆柱形产品（如马克杯、瓶子）设计的定制圆形模版。
   * *平面烫印*：拆除圆形模版及夹具，使用标准平面工作台。
4. **行程与参数调节**：调整加热板下降深度，根据材料设定合适的温度与烫印时间。
5. **烫印操作**：将产品放置于模版/工作台上，触发气动控制按钮执行烫印，完成后取出成品。
