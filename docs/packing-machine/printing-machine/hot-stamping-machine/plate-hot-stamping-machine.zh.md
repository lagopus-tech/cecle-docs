### 一、产品概述
* **产品类别**：全自动塑料餐盘烫金机 / 塑料餐具烫印设备  
* **应用场景**：广泛应用于塑料餐盘边缘烫金（金边装饰）、中心图案烫印等工艺。  
* **核心功能**：配备伺服滑台与气液增压技术，支持双按钮或脚踏开关启动，实现全自动/半自动送料、精准烫印，可选配机械臂自动卸料。

### 二、核心优势
1. **伺服滑台 + 高效操作**：配置高精度伺服滑台，操作员可安全快速放置餐盘，大幅降低劳动强度。  
2. **安全光栅标配**：标准配备安全光栅，在高速运行时全面保障操作人员安全。  
3. **灵活模具定制与更换**：通过更换对应固定模具，轻松适配不同尺寸餐盘，满足多样化生产需求。  
4. **可选机械臂自动化升级**：支持定制机械臂，自动取走烫印完成的餐盘，实现全自动上料/下料，显著提升生产效率。  
5. **强劲气液增压 + 精美效果**：采用气液增压控制，提供高达3吨的压力，确保金边与图案清晰、牢固、纹理细腻，品质卓越。

### 六、工作流程
1. **气电连接**：将机器连接至外部空压机（供气压力0.4~0.6MPa），并接入380V工业电源。  
2. **模具与耗材安装**：安装与餐盘尺寸匹配的固定模具，装入烫印模版，并正确穿引烫金箔。  
3. **手动上料**：在安全光栅保护下，操作员将待烫印餐盘放入进料位置。  
4. **启动与伺服滑动**：按下双按钮启动或踩下脚踏开关，伺服滑台平稳将餐盘送入机内。  
5. **自动烫印与卸料**：气液增压头施加3吨压力完成精密烫印；随后滑台自动滑出，成品餐盘由人工或定制自动化机械臂取出，进入下一循环。
