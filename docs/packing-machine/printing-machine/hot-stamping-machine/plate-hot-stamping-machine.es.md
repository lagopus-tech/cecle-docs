# Nombre del Producto: Máquina Automática de Estampado con Hoja Dorada para Platos Plásticos
## Modelo de Serie: PHS-320

> **Resumen Fundamental:** Esta es una máquina automática de estampado con hoja dorada para platos plásticos, diseñada específicamente para platos plásticos, ideal para la industria de fabricación de vajilla. Sus principales ventajas incluyen mesas deslizantes servo, cortinas de luz de seguridad, soporte para cambiar moldes fijos según diferentes tamaños de platos, e integración opcional de brazo robótico para descarga automática de platos, lo que aumenta significativamente la productividad. Utiliza control de presión neumohidráulica para generar una potente presión y resultados de estampado exquisitos, siendo la elección perfecta para lograr un encerado dorado eficiente, seguro y preciso.

### I. Visión General del Producto
* **Categoría del Producto**: Máquina Automática de Estampado con Hoja Dorada para Platos Plásticos / Equipo de Estampado para Vajilla Plástica
* **Escenarios de Aplicación**: Ampliamente utilizado para estampado en el borde, decoración con borde dorado o estampado de patrones centrales en platos plásticos.

### II. Ventajas Clave
1. **Mesa Deslizante Servo y Operación Eficiente**: Equipada con una mesa deslizante servo de alta precisión que permite a los operarios colocar los platos de forma segura y rápida, reduciendo drásticamente la intensidad laboral.
2. **Cortinas de Luz de Seguridad**: Incluye de serie cortinas de luz de seguridad para proteger completamente al operario durante operaciones de alta velocidad.
3. **Personalización Flexible de Moldes y Reemplazo Rápido**: Se adapta fácilmente a diferentes tamaños de platos simplemente reemplazando los moldes fijos correspondientes, cumpliendo con diversas necesidades de producción.
4. **Actualización Opcional con Automatización Robótica**: Puede personalizarse con un brazo robótico para recuperar automáticamente los platos estampados, logrando carga y descarga automatizadas y aumentando significativamente la eficiencia productiva.
5. **Presión Potente Neumohidráulica y Resultados Exquisitos**: Utiliza control de presión neumohidráulica que proporciona una fuerte presión de 3T, asegurando bordes dorados y patrones nítidos, duraderos y con textura excepcional.

### VI. Flujo de Trabajo
1. **Conexión Neumática y Eléctrica**: Conecte la máquina a un compresor de aire externo (suministrando una presión de aire de 0.4~0.6MPa) y enchúfela a una alimentación eléctrica industrial de 380V.
2. **Instalación de Moldes y Consumibles**: Instale el molde fijo correspondiente al tamaño del plato, monte el troquel de estampado y haga pasar correctamente la hoja de estampado térmico.
3. **Carga Manual**: Bajo la protección de las cortinas de luz de seguridad, el operario coloca manualmente el plato que requiere estampado en la posición de alimentación.
4. **Inicio y Deslizamiento Servo**: Presione el botón de inicio doble o pise el interruptor de pie, y la mesa deslizante servo lleva suavemente el plato hacia el interior de la máquina.
5. **Estampado y Descarga Automáticos**: La cabeza de presión neumohidráulica aplica una presión de 3T para completar el estampado preciso; posteriormente, la mesa deslizante se desliza hacia afuera, y el plato terminado se recoge manualmente o mediante el brazo robótico automatizado personalizado para entrar en el siguiente ciclo.
