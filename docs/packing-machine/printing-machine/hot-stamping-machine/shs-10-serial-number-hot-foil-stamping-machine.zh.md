> **核心摘要**：塑料封签序列号烫金机（型号：SHS-10）是一款专为高效连续编号与品牌标识设计的气动压印系统，适用于塑料安全封签上的序列号及标志烫印。专为安全封签制造商和物流标签行业量身打造，配备双头结构，可同时对封签进行标志与连续序列号烫印（通常每批次处理10个封签）。具备高速运行能力（20–30次/分钟）、定制模具匹配以及简便的气动或脚踏开关控制方式，实现卓越的生产效率、清晰锐利的编号效果和坚固可靠的性能。

### 一、产品概述
* **产品类别**：塑料封签序列号烫金机 / 安全封签印刷机  
* **应用场景**：专为安全封签制造、物流追踪标签生产、塑料标签序列化及防伪标记烫印而设计。  
* **核心功能**：采用气动驱动的批量压印系统，配备双头结构（一个用于定制烫印模版/标志，另一个用于自动编号机），支持操作员一次性对多个封签（通常为10个）进行连续编号与自定义图形的同步烫印，使用烫金箔完成作业。

### 二、核心优势
* **高效率批量处理**：专为同时处理多个塑料封签（通常每周期10件）设计，相比单件压印显著提升日产量。  
* **双头同步烫印**：配备两个独立压印头——一个专用于客户定制的标志烫印模版，另一个用于自动编号装置，可在一次按压中完成图案与序列号的双重烫印。  
* **完全可定制化模具**：根据客户提供的封签样品精确定制模具，编号机亦可根据特定序列规则与数字格式进行个性化配置。  
* **灵活双操作模式**：支持气动按钮控制与便捷脚踏开关两种模式，确保操作员在工作时获得最佳人机舒适度与操作速度。  
* **紧凑可靠，安装简便**：工业级坚固结构，配备用户友好界面。交付后仅需连接外部空气压缩机即可立即启动自动化生产。

### 六、工作流程
1. **气源与电源连接**：将机器连接至外部空气压缩机，并插入220V单相电源插座。  
2. **模具与箔材安装**：确保定制封签模具及双压印头（编号机 + 标志模版）已牢固安装，并将烫金箔正确穿过导引路径。  
3. **封签放置**：将一批塑料封签（通常为10个）整齐放入工作台上的专用定制模具中。  
4. **气动压印**：按下气动按钮或踩下脚踏开关，触发自动化压印循环。双头下降，利用烫金箔将标志与连续编号清晰地印制在封签表面。  
5. **收集与检验**：取出已完成的序列化塑料封签批次，检查印迹清晰度，随后进入包装环节。
