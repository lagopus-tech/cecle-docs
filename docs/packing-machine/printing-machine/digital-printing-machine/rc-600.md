## IV. Operation Guide & Tips

### Standard Workflow
1. **File Processing**: Import client design artwork into professional RIP software, adjusting dimensions and color modes.
2. **Equipment Preparation**: Check the ink circuit system, ink levels, and printhead status. Turn on the Win10 control terminal and establish gigabit network/fiber optic connections.
3. **Adjust Printhead Height**: Based on the cardboard/medium thickness (2mm–100mm), adjust the printhead height to between 2mm and 4mm.
4. **Feeding & Infrared Positioning**: Place the cardboard to be printed onto the automatic feeding tray and use infrared positioning for alignment.
5. **Start Printing**: Activate the vacuum adsorption transfer platform, send the print task from the computer, and the machine will automatically execute high-speed full-color printing in a single pass.
6. **Quality Inspection**: Inspect the printed finished products for color saturation.
