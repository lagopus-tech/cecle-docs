## 一、产品概述
*   **产品类别**：包装与印刷设备 - 热转印设备  
*   **应用场景**：主要用于各类塑料桶/塑料罐表面的多色图形热转印印刷（如油漆桶、化工桶、润滑油桶、食品桶、水桶等）。  
*   **核心功能**：利用加热滚筒产生的热量，结合气压压力，将热转印膜上的油墨图案高精度地转移到圆柱形或轻微锥度的桶体表面。

## 二、核心优势
1.  **高精度送膜系统**：配备高精度光电感应送膜控制系统，确保图案定位精准，有效减少膜材浪费。  
2.  **耐腐蚀耐磨**：所有关键机械部件均经过铬化处理，不仅提升设备外观质感，更显著增强在高强度作业下的耐用性。  
3.  **强大气动驱动**：全气动驱动系统，提供均匀稳定的压力输出，轻松应对大面积转印需求。  
4.  **灵活操作模式**：采用半自动设计，人工上料与自动旋转、转印协同工作，兼顾生产灵活性与操作效率。

## 六、工作流程 / 操作步骤
1.  **通电与供气**：连接220V电源及0.4～0.6MPa气源。  
2.  **装膜与对位**：安装热转印膜，并通过光电开关调整图案位置。  
3.  **参数设定**：根据桶体材质设置合适的加热温度（通常为160°C～220°C）和转印压力。  
4.  **手动上料**：将塑料桶平稳放置于支撑滚轮或专用夹具上。  
5.  **启动转印**：踩下脚踏开关或按下启动按钮，橡胶滚筒下压并带动桶体同步旋转。  
6.  **废膜回收**：转印完成后，机器自动收卷废膜，准备下一循环的新膜段。  
7.  **取件与质检**：手动取出成品，检查转印图案质量。
