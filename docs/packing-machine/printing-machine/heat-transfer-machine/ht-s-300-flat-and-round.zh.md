## 一、产品概述
* **产品类别：** 热转印包装机械 / 工业印刷设备  
* **应用场景：**  
    * **平面产品：** 手机壳、文具盒、打火机、化妆品盒盖、平面工件等  
    * **圆形/锥形产品：** 笔杆、化妆品瓶、水杯、管状物、圆柱容器等  
* **核心功能：** 通过气动驱动与精密温控技术，将热转印膜上的图案精准转移至塑料、金属或木质等各种形状工件表面。

## 二、核心优势
1. **平面与圆形双用（多功能）：** 核心技术配备内置 Shuttle Vector 装置，可根据生产需求快速切换平面与圆形转印模式，有效节省设备采购成本。  
2. **高精度薄膜进给系统：** 配备精密箔材进给控制机构，确保图案步进精准，大幅减少热转印膜浪费。  
3. **工业级抗腐蚀与耐磨性：** 所有核心部件均经过铬酸盐处理，显著提升设备耐用性与机械性能。  
4. **运行稳定可靠：** 纯气动驱动设计，压力均匀且可调；搭配数字时间继电器，参数设置精准，操作逻辑简洁明了。  
5. **结构坚固耐用：** 整机重量达230kg，运行平稳无振动，确保转印图案不偏移、不重影。

## 六、工作流程 / 操作步骤
1. **开机与调试：** 连接电源与气泵，设定加热板温度（通常为150°C – 200°C，根据膜材材质调整）。  
2. **安装膜卷：** 将热转印膜放入进给系统，并调节光电传感器位置。  
3. **放置工件：** 将待打印产品置于定位夹具上。  
4. **启动转印：** 按下启动按钮，机器将自动完成“下压 - 转印 - 薄膜进给 - 复位”循环。  
5. **质量检查：** 取出成品，检查图案完整性，并根据结果微调压力、时间与温度参数。
