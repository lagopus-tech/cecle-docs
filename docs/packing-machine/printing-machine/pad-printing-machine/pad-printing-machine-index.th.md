# เครื่องพิมพ์ปั๊ม — คู่มือการเลือกใช้งานและภาพรวมผลิตภัณฑ์

## I. เครื่องพิมพ์ปั๊มคืออะไร?

เครื่องพิมพ์ปั๊มเป็นอุปกรณ์พิมพ์แบบไม่ตรง (indirect gravure printing) ที่ใช้แผ่นเหล็กแกะสลัก (หรือแผ่นเหล็กเฉพาะ) ซึ่งมีลวดลายงานศิลป์เป็นแผ่นพิมพ์; บล็อกดูด (doctor blade) หรือถังหมึก (ink cup) ขัดสีหมึกเข้าไปในร่องที่แกะไว้ จากนั้น **แผ่นส่งหมึก (Silicone Pad)** ที่ทำจากซิลิโคนเฉพาะจะกดลงเพื่อเก็บหมึก แล้วนำไปส่งและกดลงบนพื้นผิวของผลิตภัณฑ์ เพื่อให้ได้ลวดลายการพิมพ์สมบูรณ์

* **คุณค่าหลัก**: ให้ความยืดหยุ่นในการพิมพ์บนพื้นผิว 3 มิติอย่างยอดเยี่ยม ความยืดหยุ่นสูงของแผ่นซิลิโคนช่วยให้สามารถปรับตัวได้กับพื้นผิวเรียบ พื้นผิวโค้งเล็กน้อย และช่องแคบ — งานที่การพิมพ์แบบหน้าจอ (screen printing) ไม่สามารถเข้าถึงได้ — ผลลัพธ์คือการพิมพ์คมชัด ละเอียด สำหรับข้อความขนาดเล็ก (เช่น ตัวอักษร 1 มม.) โลโก้ และกราฟิกเส้นบาง
* **อุตสาหกรรมที่ใช้**: ใช้กันอย่างแพร่หลายในอุตสาหกรรมอิเล็กทรอนิกส์และเครื่องใช้ไฟฟ้า (ปุ่ม แผงควบคุม โครงสร้าง), อุปกรณ์รถยนต์, การผลิตแว่นตา, ของเล่นและของที่ระลึก, ตัวปากกา, ฝาขวดเครื่องสำอาง, ปุ่มควบคุมและเครื่องมือวัด และอีกหลายอุตสาหกรรม

### ภาพรวมกระบวนการหลัก

การพิมพ์ปั๊มเกิดขึ้นจากการประสานงานอย่างแม่นยำระหว่างเครื่องหลัก ฟิกซ์เจอร์ และวัสดุสิ้นเปลือง โดยกระบวนการมาตรฐานแบ่งออกเป็น 3 ขั้นตอน:

1. **การเตรียมและตั้งค่าก่อนพิมพ์ (ขั้นตอนก่อน)**
   * **การสร้างแผ่นพิมพ์**: ใช้ภาพงานเวกเตอร์เป็นฐาน แล้วใช้การแกะสลักทางเคมีเพื่อสร้างร่องลวดลายที่มีความลึกระดับไมโครเมตรบนแผ่นเหล็กผสมเฉพาะ
   * **การผสมหมึก**: ตามวัสดุผลิตภัณฑ์ (ABS, PC, เม็ดโลหะ, แก้ว เป็นต้น) เลือกหมึกพิมพ์ปั๊มเฉพาะ และเติม **ตัวเจือจาง (Thinner)** ในสัดส่วนที่เหมาะสมเพื่อปรับความหนืด; สำหรับวัสดุแข็ง เช่น โลหะ/แก้ว อาจต้องเติมตัวเร่งปฏิกิริยาเพื่อเพิ่มการยึดเกาะ
   * **การติดตั้งและการปรับตำแหน่ง**: ติดตั้งแผ่นเหล็กและถังหมึก/ถังหมึก ติดตั้งฟิกซ์เจอร์เฉพาะรูปทรง (Fixture) สำหรับผลิตภัณฑ์ที่ต้องการพิมพ์ และปรับตำแหน่งโดยใช้กลไกปรับละเอียดตามแกน X/Y/Z

2. **การส่งหมึกและพิมพ์ (ขั้นตอนหลัก)**
   * **การเติมหมึกและขัดสี**: บล็อกกระจายหมึกไปยังบริเวณลวดลายบนแผ่น แล้วบล็อกดูด (หรือแหวนเซรามิกของถังหมึก) ขัดสีหมึกส่วนเกินออกจากพื้นผิวแผ่น ทิ้งไว้เฉพาะหมึกในร่องลวดลาย
   * **การเก็บหมึก**: แผ่นซิลิโคนกดลงที่ร่องลวดลาย ดูดซับฟิล์มหมึก แล้วยกขึ้น; ระหว่างการส่งหมึกในอากาศ ตัวทำละลายบนผิวจะระเหยทันที ทำให้เกิดความเหนียว
   * **การส่งหมึก**: แผ่นเคลื่อนขึ้นเหนือผลิตภัณฑ์ แล้วกดลง ทำให้แผ่นยืดหยุ่นและปรับตัวตามรูปร่างผลิตภัณฑ์ ปล่อยลวดลายออกมาอย่างสมบูรณ์และส่งไปยังพื้นผิวงาน

3. **การบำรุงรักษา (ขั้นตอนหลัง)**
   * **การดูแลแผ่นพิมพ์และแผ่นซิลิโคน**: หลังการใช้งาน ใช้สารล้างหน้าจอ / ตัวทำละลายเฉพาะเพื่อล้างหมึกที่ค้างอยู่ในร่องแผ่นพิมพ์อย่างหมดจด เพื่อป้องกันการแห้งตัวและอุดตัน; ทำความสะอาดฝุ่นบนผิวแผ่นซิลิโคนด้วยน้ำมันขาวหรือเทปใส แล้วเก็บไว้ในที่ไกลแสง

### 2. ถังหมึกเปิด vs ถังหมึกปิด — เลือกแบบไหนดี?
* **ถังหมึกเปิด (หลักในซีรีส์ YYD/YYC/YYS)**:
  * *ข้อดี*: โครงสร้างง่ายมาก ราคาต่ำมาก; การล้างหมึกและเปลี่ยนสีใช้เวลาเพียงไม่กี่นาที; การปรับความหนืดหมึกทำได้เข้าใจง่าย เหมาะกับงานผลิตจำนวนน้อย หลากหลายรุ่น ต้องเปลี่ยนสีบ่อย
* **ถังหมึกปิด (หลักในรุ่น YYD-150-100)**:
  * *ข้อดี*: หมึกถูกปิดในถังเซรามิก ลดการระเหยของตัวทำละลายมากกว่า 80% ไร้กลิ่น ปลอดภัยต่อสิ่งแวดล้อม ความหนืดหมึกคงที่เป็นเวลานาน เหมาะกับการทำงานต่อเนื่องสีเดียวเป็นเวลานาน หรือห้องทำงานที่มีข้อกำหนดด้านสิ่งแวดล้อมเข้มงวด

### 3. แก้ไขปัญหาการพิมพ์ทั่วไป
* **Q: ทำไมขอบลวดลายพิมพ์ถึงมีรอยไหม้ / ดึงเป็นเส้น?**
  * **A**: มักเกิดจากหมึกหนืดเกินไปหรือแห้งช้าเกินไป ให้เติมตัวเจือจางเล็กน้อยเพื่อลดความหนืด หรือปรับวาล์วอากาศเพื่อเพิ่มความเร็วการยกแผ่น (การปล่อยหมึก)
* **Q: ทำไมลวดลายตรงกลางจึงเบลอ ขาดหาย (pinholing) หรือมีฟองเล็ก?**
  * **A**: ① ฝุ่น/น้ำมันบนผิวแผ่นซิลิโคน (ลบด้วยเทป); ② แรงกดแผ่นมากเกินไปทำให้อากาศหลุดยาก (ลดระยะกดลง); ③ การเลือกแบบแผ่นซิลิโคนไม่เหมาะสม (แผ่นซิลิโคนรูปกลมหรือปลายแหลมช่วยให้อากาศหลุดได้ดีกว่า)

## IV. ความสามารถในการปรับแต่งของผู้ผลิตและระบบนิเวศสนับสนุน

ในฐานะโรงงานผู้ผลิตต้นฉบับ เราไม่เพียงแต่ให้เครื่องพิมพ์ปั๊มมาตรฐาน แต่ยังเสนอบริการปรับแต่งครบวงจรและวัสดุสิ้นเปลืองแบบปิดวงจรสำหรับลูกค้าทั่วโลก:

1. **ฟิกซ์เจอร์ปรับแต่ง**: ลูกค้าส่งตัวอย่างชิ้นงานมา ทางเราสามารถผลิตฟิกซ์เจอร์เฉพาะสำหรับยึดชิ้นงานได้
2. **การแกะสลัก Cliché**: ให้แผ่นเหล็กโครเมียมแข็งและแผ่นเหล็กบางด้วยบริการแกะสลักเชิงเคมีความแม่นยำสูง; การจุดสีระดับไมโครเมตรทำให้ตัวอักษรเล็กๆ ปรากฏได้อย่างสมบูรณ์
3. **แผ่นซิลิโคน**: มีสต็อกแผ่นซิลิโคนรูปต่างๆ หลายรูปแบบ ทั้งปลายแหลม กลม และยาว พร้อมบริการปรับความแข็ง Shore ตั้งแต่ 20°~60° เพื่อให้เหมาะกับพื้นผิวโค้งไม่สมมาตร
4. **การปรับแรงดันไฟฟ้า**: รองรับการปรับแรงดัน 110V / 60Hz (อเมริกาเหนือ / ปลั๊ก NEMA) หรือ 220V / 50-60Hz (ยุโรป / อังกฤษ เป็นต้น) ตั้งค่าโรงงานตามปลายทางของลูกค้า
