# Машина для шелкографии — руководство по выбору и обзор продукции

## I. Что такое машина для шелкографии?

Машина для шелкографии — это косвенное устройство для гравировочной печати. Она использует стальную пластину (или лист стали) с выгравированным рисунком в качестве печатной формы; ползунок / чашка для краски снимает излишки краски с поверхности, оставляя краску только в вырезах рисунка, затем специальная силиконовая **переносная подушка (силиконовая подушка)** опускается, чтобы собрать краску, а затем переносит её на поверхность изделия, завершая процесс печати.

* **Основная ценность**: обеспечивает исключительную адаптацию к 3D-поверхностям. Высокая эластичность силиконовой подушки позволяет легко приспосабливаться к плоским поверхностям, слегка изогнутым поверхностям и узким зазорам — неподходящим для трафаретной печати деталям, что позволяет получать чёткие, мелкие отпечатки идеально подходящие для микротекста (например, шрифт 1 мм), логотипов и тонких графических элементов.
* **Применимые отрасли**: широко используется в электронике и бытовой технике (кнопки, панели, корпуса), автомобильной промышленности, производстве очков, игрушках и подарках, ручках для канцелярских товаров, крышках для косметики, ручках управления и приборах, а также во многих других отраслях.

### Общая схема рабочего процесса

Шелкография осуществляется за счёт тесной координации основной машины, приспособлений и расходных материалов; стандартный процесс делится на три этапа:

1. **Подготовка и настройка перед печатью (подготовительный этап)**
   * **Изготовление пластины**: на основе векторного изображения с помощью химического травления создаются выемки рисунка глубиной в микронные единицы на специальной сплавной стальной пластине.
   * **Смешивание краски**: в зависимости от материала изделия (ABS, PC, металл, стекло и др.) выбирается соответствующая краска для шелкографии и добавляется **разбавитель** в нужной пропорции для регулирования вязкости; для твёрдых материалов, таких как металлические детали/стекло, может быть добавлен соответствующий отверждающий агент для улучшения сцепления.
   * **Установка и выравнивание**: установите стальную пластину и чашку для краски, закрепите специальное профильное приспособление (приспособление) для изделия, которое будет печататься, и выполните выравнивание с помощью механизма микронастройки по осям X/Y/Z.

2. **Перенос шелкографии (основной этап)**
   * **Нанесение краски и полировка**: ползунок равномерно распределяет краску по области рисунка пластины, затем ползунок (или керамическое кольцо чашки для краски) снимает излишки краски с поверхности пластины, оставляя краску только в выемках рисунка.
   * **Сбор краски**: силиконовая подушка опускается на поверхность пластины, собирает тонкий слой краски и поднимается; во время полёта в воздухе растворитель мгновенно испаряется, создавая липкость.
   * **Перенос**: подушка перемещается над изделием и опускается, деформируясь, чтобы соответствовать форме изделия, полностью снимает рисунок и переносит его на поверхность заготовки.

3. **Обслуживание (пост-этап)**
   * **Обслуживание подушки и пластины**: после работы тщательно очистите остатки краски из выемок пластины с помощью средства для мытья сетки / специального растворителя, чтобы предотвратить высыхание и засорение; очистите пыль с поверхности подушки белым спиртом или скотчем и храните вдали от света.

## III. Технические вопросы и распространённые проблемы (FAQ)

### 1. Быстрый выбор модели (трёхэтапный метод)
* **Шаг 1: Количество цветов печати**
  * Одноцветная печать: выберите **серии YYD одноголовочные** или **серии YYD2 двухголовочные** (если требуется удвоенная производительность);
  * Двухцветная печать: выберите **серии YYC двухцветные транспортные**;
  * Четырёхцветная печать: выберите **четырёхцветную машину YYC-130-80**.
* **Шаг 2: Форма изделия и препятствия**
  * Обычные плоские / слегка изогнутые мелкие детали: подходят стандартные модели;
  * **Рамки очков / печать внутренней дужки**: необходимо выбрать **специальную машину YYD-125-100Y**;
  * **Полная окружность шкалы маленькой ручки (≤Φ20 мм)**: необходимо выбрать **машину YYS-100-100**.
* **Шаг 3: Условия установки и бюджет**
  * Нет электропитания / дома / мобильная будка: выберите **ручную машину YYD-150-100**;
  * Настольные пробы / ограниченное пространство: выберите **настольную машину YYD-125-100T**;
  * Промышленная линия серийного производства: выберите **напольные вертикальные серии YYD / YYC**.

### 2. Открытая чашка для краски против запечатанной чашки — какой выбрать?
* **Открытая чашка для краски (основа серий YYD/YYC/YYS)**:
  * *Преимущества*: чрезвычайно простая конструкция, очень низкая стоимость; очистка краски и смена цвета занимают всего несколько минут; регулировка вязкости краски интуитивно понятна, подходит для малых партий, множества видов, частой смены цветов.
* **Запечатанная чашка для краски (основа модели YYD-150-100)**:
  * *Преимущества*: краска герметично заключена внутри керамического кольца, испарение растворителей снижено более чем на 80%, без запаха и более экологична, вязкость краски остаётся стабильной длительное время, подходит для длительной постоянной одноцветной работы или мастерских с строгими экологическими требованиями.

### 3. Устранение распространённых дефектов печати
* **Вопрос: Почему края печатного рисунка имеют заусенцы / нити?**
  * **Ответ**: Обычно краска слишком густая или слишком медленно сохнет. Добавьте немного разбавителя, чтобы снизить вязкость, или настройте воздушный клапан, чтобы повысить скорость подъёма подушки (снятие краски).
* **Вопрос: Почему центр рисунка размыт, отсутствует (дырочки) или имеет мелкие пузырьки?**
  * **Ответ**: ① Пыль/жир на поверхности подушки (удалите скотчем); ② Избыточное давление подушки, вызывающее плохое выделение воздуха (уменьшите ход опускания); ③ Неправильный выбор формы подушки (подушки с закруглённым или острым верхом лучше помогают выйти воздуху).
