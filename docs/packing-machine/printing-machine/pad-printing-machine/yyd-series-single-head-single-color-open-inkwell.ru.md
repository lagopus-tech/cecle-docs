Подходит для широкого диапазона вязкостей чернил, является наиболее экономичным решением для малых партий и частой смены заказов, с значительно более низкой стоимостью обслуживания по сравнению с герметичными чашками.

## III. Работа и технологический процесс

### 1. Необходимые материалы
* **Основание (подложка)**: Ткань, металл, автомобильные детали, канцелярия, повседневные товары, электронные компоненты, игрушки, инструменты и другие изделия среднего и малого размера с плоской или слегка изогнутой поверхностью.
* **Расходные материалы**: Стальной лист, фиксатор, резиновая головка, чернила, растворитель, ползун.
* **Давление воздуха**: 5 бар. Требуется воздушный компрессор.
* **Электропитание**: 110 В или 220 В, заводская настройка в соответствии с напряжением страны покупателя.

### 2. Стандартный рабочий процесс
1. **Подключение воздуха**: Подключите сжатый воздух 5 бар, проверьте на утечки, затем включите питание.
2. **Установка стального листа и резиновой головки**: Установите травленый стальной лист в основание открытого чернильного резервуара, закрепите резиновую головку для печати, налейте необходимое количество подготовленных чернил в открытый резервуар.
3. **Пробная печать и настройка**: Разместите образец изделия, нажмите кнопку запуска на панели управления для пробной печати, отрегулируйте ход ползуна, положение печатающей головки и рабочего стола в зависимости от четкости изображения.
4. **Массовое производство**: После настройки начните основную печать; счетчик автоматически накапливает количество отпечатанных изделий для удобного контроля производства.
5. **Остановка и техническое обслуживание**: После окончания работы отключите воздух и питание, очистите остатки чернил из открытого резервуара, протрите резиновую головку и стальной лист чистящим средством, оставьте оборудование сухим.
