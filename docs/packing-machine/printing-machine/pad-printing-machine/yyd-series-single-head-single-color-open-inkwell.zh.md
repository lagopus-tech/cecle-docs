## 三、操作流程与工作步骤

### 1. 所需物料
* **基材**：布料、金属、汽车零件、文具、日用品、电子元件、玩具、仪器等小型至中型平面/微弧面/不规则工件。
* **耗材**：钢板、夹具、硅胶头、油墨、稀释剂、刮刀。
* **气压要求**：5 bar。需配备空气压缩机。
* **电源供应**：110V 或 220V，按客户目的地电压出厂配置。

### 2. 标准操作流程
1. **接通气源**：连接5 bar压缩空气，检查有无漏气后通电开机。
2. **安装钢板与硅胶头**：将蚀刻钢板放入开放式墨盘底座，安装丝印硅胶头，并倒入适量已调配好的油墨。
3. **试印与调整**：放置样品基材，按下控制面板启动按钮进行试印，根据图案清晰度调节墨盘刮刀行程、印刷头位置及工作台位置。
4. **批量生产**：调整完成后开始正式印刷；计数器自动累计印刷数量，便于生产管理。
5. **停机与保养**：工作结束后关闭气源与电源，清理墨盘残留油墨，用清洁剂擦拭硅胶头与钢板，保持机器干燥。
