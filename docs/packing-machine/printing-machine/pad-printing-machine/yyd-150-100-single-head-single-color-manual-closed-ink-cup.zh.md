## 四、操作流程与工作步骤

### 1. 所需物料
* **基材**：金属、玻璃、陶瓷、木材、皮革等材质的小型或中型平面或轻微曲面工件。
* **耗材**：钢版、夹具、橡胶头、油墨、稀释剂、墨杯刮刀环。

### 2. 标准操作流程
1. **安装钢版与橡胶头**：将蚀刻好的钢版平整放置并固定在钢版底座上，再安装对应尺寸的橡胶头。
2. **加墨**：将适量调配好的油墨倒入密封墨杯中，安装墨杯，并确认陶瓷刮刀环与钢版贴合良好。
3. **放置工件**：将待印工件置于工作台上，完成对位。
4. **试印与调整**：下压手柄完成一次试印，观察图案清晰度，必要时进行微调。
5. **批量生产**：调整完成后，持续手动下压手柄进行印刷；建议每几轮打印后检查墨杯油墨量及橡胶头清洁度。
6. **停机与维护**：工作结束后，清除墨杯内残留油墨，用清洁剂擦拭橡胶头、钢版及墨杯，保持机器干燥整洁。

## 五、销售技巧与常见问题

### 销售建议
* **突出“无需电力或气源”**：针对家庭作坊、移动摊位、电力不稳地区或小批量客户，强调本机无需空压机或电源——**即放即用，部署成本为零**。
* **推荐“封闭式墨杯”**：对于注重环保、油墨成本及车间洁净度的客户，重点介绍封闭墨杯的优势：**环保、低挥发、省墨**。

### 常见问题（FAQ）
* **Q：这台机器需要连接电源或空压机吗？**  
  * **A**：不需要。YYD-150-100 为纯手动操作，无需电源或压缩空气——只需放在桌面上即可使用。
* **Q：墨杯式与墨盘（油盘）式有何区别？**  
  * **A**：墨杯式采用密封墨杯+陶瓷刮刀环结构，更加环保，溶剂挥发少、油墨消耗低；墨盘式为开放式结构，通常价格较低但溶剂挥发较多。小批量客户及环保要求较高的用户更适合选择墨杯式。
