# YYS-100-100 เครื่องพิมพ์แบบปั๊มสกรีนอัตโนมัติแบบหมุนรอบที่ตั้งพื้น หัวเปิด สำหรับงานพิมพ์เส้นรอบวง

> **สรุปใจความสำคัญ**
> YYS-100-100 เป็นเครื่องพิมพ์แบบปั๊มสกรีนอัตโนมัติแบบหมุนรอบที่ตั้งพื้น หัวเปิด แบบสีเดียว ออกแบบมาเฉพาะเพื่อการพิมพ์แบบเต็ม 360° บนชิ้นงานทรงกระบอกขนาดเล็กที่มีเส้นผ่านศูนย์กลางเท่ากันทุกจุด ใช้งานได้ดีในอุตสาหกรรมเครื่องใช้ไฟฟ้าในครัวเรือน รถยนต์ บรรจุภัณฑ์เครื่องสำอาง อุปกรณ์วัดค่า ของใช้ในการเขียน และอุปกรณ์เหล็ก โดยเน้นงานพิมพ์โลโก้ หน่วยวัด และข้อความแบบเส้นรอบวงสีเดียวบนทรงกระบอกที่มีเส้นผ่านศูนย์กลางไม่เกิน Φ20 มม. จุดเด่นหลัก ได้แก่ กลไกการถ่ายโอนแบบลูกกลิ้งเชิงเส้นที่ไม่มีการบิดเบี้ยวหรือเลือนขอบ; โครงสร้างตัวเครื่องแบบตั้งพื้นด้วยอลูมิเนียมหล่อ คงที่ ลดเสียงรบกวนแม้ทำงานที่ความเร็ว 1,700 ชิ้น/ชม.; ระบบหัวเปิดสำหรับการเติมหมึกที่ทำความสะอาดง่ายและเปลี่ยนสีได้รวดเร็ว ใช้ต้นทุนต่ำกว่าระบบหัวปิด; ควบคุมด้วยไมโครคอมพิวเตอร์ พร้อมตัวนับจำนวนแบบดิจิทัล และรองรับการเริ่มต้นจากแผงควบคุมหรือสวิตช์เท้า เพื่อการใช้งานอย่างสะดวก

## I. ภาพรวมผลิตภัณฑ์

### 1. ประเภทผลิตภัณฑ์

- **ชื่ออุปกรณ์**: เครื่องพิมพ์แบบปั๊มสกรีนอัตโนมัติแบบหมุนรอบที่ตั้งพื้น หัวเปิด แบบสีเดียว
- **รุ่น**: YYS-100-100
- **ตำแหน่งของอุปกรณ์**: ใช้กลไกกลศาสตร์แม่นยำ "โต๊ะเลื่อนเชิงเส้น + การสัมผัสแบบหมุน" โดยออกแบบเฉพาะเพื่อการพิมพ์แบบเต็ม 360° หรือพื้นที่โค้งใหญ่ บนชิ้นงานทรงกระบอกขนาดเล็กที่มีเส้นผ่านศูนย์กลางเท่ากัน และผิวตรง (ไม่เอียง) เช่น ปุ่มหมุนของเครื่องใช้ไฟฟ้า ฝาขวดแบบผนังตรง ตัวแท่งปากกา และการระบุระดับของเข็มฉีดยา ความเร็วสูงสุดของเครื่องเดียวอยู่ที่ 1,700 รอบ/ชม. *(หมายเหตุ: ฟิกซ์เจอร์ใช้เพื่อจัดตำแหน่งชิ้นงานเท่านั้น เครื่องจะส่งออกโดยไม่รวมฟิกซ์เจอร์เฉพาะชิ้นงาน)*

### 2. การประยุกต์ใช้งาน

- **อุตสาหกรรมที่ใช้**: ใช้กันอย่างแพร่หลายในอุตสาหกรรมเครื่องใช้ไฟฟ้าในครัวเรือน ชิ้นส่วนรถยนต์ บรรจุภัณฑ์เคมีประจำวัน อุปกรณ์วัดค่า ของใช้ในการเขียน และอุปกรณ์เหล็ก
- **ขอบเขตการพิมพ์**: ใช้เฉพาะงานพิมพ์แบบเส้นรอบวงสีเดียวบนทรงกระบอกขนาดเล็กที่มีเส้นผ่านศูนย์กลางเท่ากัน และผิวตรง (ไม่เอียง) เช่น ปุ่มเลือกแบบทรงกระบอกของเตาอบ/เตาแก๊ส ป้ายฝาขวดแบบผนังตรง ข้อความทั้งหมดบนตัวแท่งปากกา และการระบุระดับของเข็มฉีดยาที่มีเส้นผ่านศูนย์กลางเท่ากัน ขนาดพิมพ์สูงสุด Φ20 มม.
- **ข้อจำกัดรูปร่างชิ้นงาน**: เหมาะเฉพาะกับทรงกระบอกที่มีเส้นผ่านศูนย์กลางเท่ากัน (ผิวตรง); ไม่เหมาะกับชิ้นงานแบบกรวยที่มีความเอียงชัดเจน (มีความลาดชัน)

### 3. ฟังก์ชันหลัก

- **กลไกการถ่ายโอนแบบลูกกลิ้งเชิงเส้นบริสุทธิ์**: เมื่อหัวยางกดลงบนชิ้นงานทรงกระบอก โต๊ะเลื่อนจะเคลื่อนที่เชิงเส้น ขับให้ทรงกระบอกหมุนและหมุนเอง ทำให้รูปแบบยาวๆ ถูกถ่ายทอดราบเรียบไปบนผิวข้างโดยไม่บิดเบี้ยว
- **การควบคุมอัจฉริยะด้วยไมโครคอมพิวเตอร์**: แผงควบคุมไมโครคอมพิวเตอร์ที่มีตรรกะการทำงานชัดเจน รองรับการเคลื่อนที่แบบจุดเดียว (Jogging) และการทำงานอัตโนมัติเต็มรูปแบบ ตั้งค่าได้ง่ายและรวดเร็ว
- **ตัวนับจำนวนแบบดิจิทัลในตัว**: ตัวนับแสดงผลดิจิทัลที่รวมอยู่ในตัวเครื่อง นับจำนวนรอบการพิมพ์แบบเรียลไทม์ ช่วยสนับสนุนการจัดส่งตามคำสั่งซื้อและการคิดเงินตามจำนวนชิ้น
- **โหมดเริ่มต้นแบบสองทาง (แผงควบคุม / ปุ่มเท้า)**: รองรับทั้งการเริ่มต้นด้วยมือผ่านแผงควบคุม และการกระตุ้นต่อเนื่องด้วยสวิตช์เท้า ทำให้สลับระหว่างการตั้งค่า/ตรวจสอบและดำเนินการผลิตจำนวนมากได้อย่างราบรื่น

## II. ข้อได้เปรียบหลัก

- **การลูกกลิ้งเชิงเส้นแบบบริสุทธิ์ — หน่วยวัดปุ่มเล็กที่คมชัดสมบูรณ์ (การหมุนแบบกระบอกจริง)**: การเคลื่อนที่เชิงเส้นของโต๊ะเลื่อนขับให้ชิ้นงานหมุนเอง สร้างการสัมผัสแบบเส้นต่อเนื่อง ซึ่งแก้ปัญหาการเบลอ บิดเบี้ยว หรือยืดตัวของขอบด้านข้างที่พบบ่อยในเครื่องพิมพ์แบบกดลงแบบแบนทั่วไป; ข้อความขนาดเล็กจะคมชัดและเต็มทั้งพื้นที่
- **โครงสร้างตัวเครื่องแบบตั้งพื้น**: เครื่องใช้เสาแนวตั้งและฐานพื้น จุดศูนย์ถ่วงต่ำ ความแข็งแรงสูง ยังคงมั่นคง ต้านการสั่นสะเทือน และเสียงเบาแม้ทำงานที่ความเร็วสูง 1,700 รอบ/ชม.
- **ระบบเติมหมึกแบบหัวเปิด**: ใช้หัวเปิดแยกต่างหากพร้อมใบมีดป้องกัน (Doctor Blade) สำหรับการเติมหมึก — โครงสร้างที่มองเห็นชัดเจน ถอดประกอบและทำความสะอาดได้ง่ายมาก ต้นทุนการเปลี่ยนสีต่ำ; ใช้กับหมึกที่มีความหนืดหลากหลาย ต้นทุนการใช้และบำรุงรักษาน้อยกว่าระบบหัวปิดมาก

## IV. การใช้งานและกระบวนการปฏิบัติงาน

### 1. วัสดุที่ต้องใช้

- **วัสดุพื้นฐาน**: ชิ้นงานทรงกระบอกขนาดเล็กที่มีเส้นผ่านศูนย์กลางเท่ากันที่ต้องการพิมพ์ (เส้นผ่านศูนย์กลาง ≤20 มม. เช่น ปุ่มแบบผนังตรง ฝาขวดขนาดเล็ก)
- **วัสดุสิ้นเปลือง**: แผ่นเหล็ก ฟิกซ์เจอร์ หัวยาง หมึก ตัวเจือจาง ใบมีดป้องกัน
- **แรงดันอากาศ**: 4–6 บาร์ ต้องใช้เครื่องอัดอากาศ
- **แหล่งจ่ายไฟ**: 110V หรือ 220V ตั้งค่าตามแรงดันไฟฟ้าปลายทางของลูกค้า

### 2. ขั้นตอนการทำงานมาตรฐาน

1. **การเชื่อมต่อแหล่งอากาศ**: เชื่อมต่ออากาศอัด 4–6 บาร์ ตรวจสอบการรั่ว แล้วเปิดไฟ
2. **การติดตั้งแผ่นเหล็กและหัวยาง**: ใส่แผ่นเหล็กที่มีการกัดลายลงในฐานหัวเปิด ติดตั้งหัวยางแบบยาวเฉพาะรุ่น และเทหมึกผสมปริมาณพอเหมาะลงในหัวเปิด
3. **การติดตั้งฟิกซ์เจอร์และปรับตำแหน่ง**: ติดตั้งฟิกซ์เจอร์จัดตำแหน่งชิ้นงานบนโต๊ะเลื่อน วางชิ้นงานที่ต้องการพิมพ์ (ฟิกซ์เจอร์ใช้เพื่อจัดตำแหน่งชิ้นงาน); ปรับความสูงของโต๊ะให้หัวยางกดผิวชิ้นงานด้วยแรงที่เหมาะสมเมื่อเคลื่อนลง
4. **การทดลองพิมพ์และปรับแต่ง (การปรับการลูกกลิ้งเชิงเส้น)**: กดปุ่มเท้าเพื่อเริ่มพิมพ์ตัวอย่างหนึ่งครั้ง ตรวจสอบการเคลื่อนไหว — โต๊ะเลื่อนเคลื่อนที่ หัวยางกดผิวชิ้นงาน และชิ้นงานถูกกดให้หมุนและหมุนเองขณะเคลื่อนที่ เพื่อถ่ายโอนภาพ; หลังพิมพ์ หัวยางยกขึ้น และโต๊ะเลื่อนหยุด; สังเกตความชัดเจนของพิมพ์ด้านข้าง ปรับความสูงโต๊ะ (แรงกดหัวยาง) ให้แน่ใจว่าพิมพ์เต็มไม่ลื่น และจุดเริ่มต้น-สิ้นสุดติดกันเรียบ
5. **การผลิตจำนวนมาก**: หลังปรับแต่งเสร็จ ให้เริ่มการผลิตแบบเป็นชุด; ผู้ปฏิบัติงานโหลด/ถอดชิ้นงานได้รวดเร็ว และตัวนับดิจิทัลจะสะสมปริมาณผลิตอัตโนมัติ
6. **การปิดเครื่องและบำรุงรักษา**: หลังทำงาน ปิดอากาศและไฟ ทำความสะอาดหมึกที่เหลือในหัวเปิด ใช้สารทำความสะอาดเช็ดหัวยางและแผ่นเหล็ก แล้วเก็บเครื่องให้แห้ง

## V. เคล็ดลับการขายและคำถามที่พบบ่อย

### เคล็ดลับการขาย

- **เน้นตำแหน่ง “ผู้เชี่ยวชาญงานพิมพ์หน่วยวัดปุ่มขนาดเล็ก”**: แสดงผลการพิมพ์แบบ 1–6 ตำแหน่งของปุ่มจากวิดีโอให้ลูกค้าในอุตสาหกรรมเครื่องใช้ไฟฟ้าและรถยนต์ โดยเน้น **“การพิมพ์แบบเต็ม 360° บนทรงกระบอกผนังตรง ขนาดเส้นผ่านศูนย์กลางไม่เกิน 20 มม.”** — ตรงเป้าหมายสูง ความเข้ากันได้สูง
- **ตรวจสอบรูปร่างชิ้นงานก่อน**: เมื่อได้รับคำขอ ต้องยืนยันว่าชิ้นงานเป็น “ทรงกระบอกผนังตรงที่มีเส้นผ่านศูนย์กลางเท่ากัน” และ “เส้นผ่านศูนย์กลาง ≤20 มม.” แจ้งชัดเจนว่าชิ้นงานแบบกรวยไม่เหมาะ แสดงความเป็นมืออาชีพ
- **คำแนะนำการขายแบบแพ็กเกจ**: จัดแพ็กเกจกับวัสดุสิ้นเปลือง เช่น แผ่นเหล็ก ฟิกซ์เจอร์ หัวยาง และใบมีดป้องกัน เพื่อเพิ่มมูลค่าคำสั่งซื้อเฉลี่ยและเพิ่มความผูกพันลูกค้า

### คำถามที่พบบ่อย

- **Q: เครื่องนี้พิมพ์ชิ้นงานที่มีเส้นผ่านศูนย์กลางสูงสุดเท่าไร?**
  - **A**: ขนาดเส้นผ่านศูนย์กลางที่พิมพ์ได้สูงสุดคือ Φ20 มม. สำหรับปุ่มขนาดเล็กและฝาขวดกลมที่มีเส้นผ่านศูนย์กลางไม่เกิน 20 มม. ระยะเลื่อนของโต๊ะและความยาวพื้นที่พิมพ์ 100 มม. ของแผ่นเหล็กสอดคล้องกันอย่างสมบูรณ์ ทำให้ได้หน่วยวัดแบบปิดสนิททั้งวงกลม

- **Q: ต้องใช้เครื่องอัดอากาศไหม? รองรับแรงดันไฟ 110V ได้ไหม?**
  - **A**: ใช่ กลไกการเคลื่อนที่ของเครื่องขับเคลื่อนด้วยกระบอกลม ต้องใช้เครื่องอัดอากาศภายนอก 4–6 บาร์ วงจรไฟฟ้ารองรับการตั้งค่าทั่วโลก (110V หรือ 220V) และเครื่องมีปลั๊กไฟที่สอดคล้องกับมาตรฐานการรับรองในท้องถิ่นที่โรงงานผลิต
