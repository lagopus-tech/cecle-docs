## 四、操作流程与工作步骤

### 1. 所需物料
* **承印物**：小型工件，如汽车零件、文具、日用商品、电子元件、玩具、仪器仪表、服装标签等。
* **耗材**：钢版、夹具、胶头、油墨、稀释剂、刮刀。
* **气压要求**：5–6 bar。需配备空气压缩机。
* **电源供应**：110V 或 220V，根据客户所在国家/地区出厂前预设电压，并配备符合当地标准的插头。

### 2. 标准操作流程
1. **气源连接**：连接5–6 bar压缩空气，检查有无泄漏后通电开机。
2. **钢版与胶头安装**：将蚀刻钢版放入开放式墨盘底座，安装丝印胶头，向墨盘倒入适量调配好的油墨。
3. **试印与调整**：放置样品工件，踩下脚踏开关或按下控制面板启动按钮进行试印，根据图案清晰度微调印刷头位置。
4. **批量生产**：调整完成后开始正式印刷；数字计数器自动累计印刷数量，便于生产管理。
5. **关机与保养**：工作结束后关闭气源与电源，清理墨盘残留油墨，用清洁剂擦拭胶头与钢版，保持机器干燥。
