## IV. Работа и технологический процесс

### 1. Необходимые материалы
* **Основа (подложка)**: Мелкие детали — автомобильные части, канцелярские товары, повседневные предметы, электронные компоненты, игрушки, приборы, этикетки для одежды.
* **Расходные материалы**: Стальная пластина, приспособление, резиновая головка, чернила, растворитель, скребок.
* **Давление воздуха**: 5–6 бар. Требуется воздушный компрессор.
* **Питание**: 110 В или 220 В, заводская настройка в соответствии с напряжением страны покупателя.

### 2. Стандартный рабочий процесс
1. **Подключение источника сжатого воздуха**: Подключите сжатый воздух под давлением 5–6 бар, проверьте на утечки, затем включите питание.
2. **Установка стального шаблона и резиновой головки**: Установите травленую стальную пластину в основание открытого чернильного резервуара, смонтируйте резиновую печатающую головку, налейте подходящее количество разбавленных чернил в открытый резервуар.
3. **Пробная печать и настройка**: Разместите образец подложки, нажмите педаль или кнопку на панели управления для тестового отпечатка, отрегулируйте положение печатающей головки в зависимости от чёткости изображения.
4. **Массовое производство**: После настройки начните основную печать; цифровой счётчик автоматически считает количество отпечатанных изделий, что упрощает контроль производства.
5. **Остановка и техническое обслуживание**: После окончания работы выключите воздух и питание, очистите остатки чернил из открытого резервуара, протрите резиновую головку и стальную пластину средством для очистки, храните машину в сухом месте.
