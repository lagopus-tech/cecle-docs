# 转移印刷机 —— 选型指南与产品概览

## 一、什么是转移印刷机？

转移印刷机是一种间接凹版印刷设备。它使用蚀刻钢版（或钢板）作为印版，承载图文；通过刮刀/墨杯将油墨刮入蚀刻的凹坑中，再由特制的硅胶**转移垫（硅胶垫）** 压下，吸取油墨，最终将油墨转移到产品表面完成图案印刷。

* **核心价值**：实现卓越的三维曲面适应性。硅胶垫极高的弹性使其能轻松贴合平面、轻微弧面及狭窄缝隙——普通丝网印刷无法触及的异形工件——可呈现清晰细腻的印刷效果，特别适合微文字（如1mm字体）、标志和细线图形。
* **适用行业**：广泛应用于电子电器（按钮、面板、外壳）、汽车零部件、眼镜制造、玩具礼品、文具笔杆、化妆品瓶盖、旋钮仪表等众多领域。

### 核心工作流程概述

转移印刷通过主机、夹具与耗材的紧密配合完成；标准化流程分为三个阶段：

1. **压印前准备与调试（预处理阶段）**
   * **制版**：根据矢量图稿，采用化学蚀刻在特种合金钢版上制作出微米级深度的图文凹坑。
   * **调墨**：根据产品材质（ABS、PC、金属、玻璃等），选用专用转移印刷溶剂油墨，并按比例添加**稀释剂**调节粘度；对于硬质材料如五金/玻璃，可加入配套固化剂以增强附着力。
   * **安装与对位**：安装钢版与墨盒/墨杯，固定针对待印产品的专用轮廓夹具（Fixture），并通过X/Y/Z轴微调机构进行对位校准。

2. **转移印刷过程（核心阶段）**
   * **上墨与刮墨**：涂墨条将油墨均匀铺满印版图文区域，随后刮刀（或墨杯陶瓷环）刮除版面多余油墨，仅保留凹坑内的油墨。
   * **拾取**：硅胶垫向下压向印版凹坑，吸附油墨膜后抬起；在空中转移过程中，表面溶剂瞬间挥发，形成粘性。
   * **转印**：硅胶垫移至产品上方并下压，发生形变以贴合产品表面，完全剥离图案并将其精准转移至工件表面。

3. **维护保养（后期阶段）**
   * **垫与版维护**：操作结束后，用网洗液/专用溶剂彻底清洗印版凹坑内残留油墨，防止干结堵塞；用白电油或包装胶带清洁硅胶垫表面灰尘，并避光存放。

## 三、技术问答与常见问题（FAQ）

### 1. 快速型号选择决策（三步法）
* **第一步：印刷颜色数量**
  * 单色：选择 **YYD单头系列** 或 **YYD2双头系列**（若需加倍产能）；
  * 双色套印：选择 **YYC双色滑台系列**；
  * 四色套印：选择 **YYC-130-80四色滑台机**。
* **第二步：工件形状与干涉情况**
  * 普通平面/轻微弧面小件：通用机型即可；
  * **眼镜框/内镜腿印刷**：必须选择 **YYD-125-100Y专用间隙机**；
  * **小旋钮外壁全圆周刻度（≤Φ20mm）**：必须选择 **YYS-100-100圆周机**。
* **第三步：现场条件与预算**
  * 无电源/家庭/移动摊位：选择 **YYD-150-100手动墨杯机**；
  * 小型桌面打样/空间敏感：选择 **YYD-125-100T桌面机**；
  * 工业线批量生产：选择 **YYD / YYC落地竖直系列**。

### 2. 开放式墨盘 vs 密封墨杯 —— 如何选择？
* **开放式墨盘（YYD/YYC/YYS系列主流）**：
  * *优点*：结构极其简单，成本极低；清洗与换色仅需数分钟；粘度调节直观，适合小批量、多品种、频繁换色的生产场景。
* **密封墨杯（YYD-150-100主流）**：
  * *优点*：油墨密封于陶瓷环杯内，溶剂挥发减少超80%，无味更环保，粘度长期稳定，适合长时间单一颜色连续作业或对环境要求严格的车间。

### 3. 常见印刷缺陷排查
* **问：为何印刷图案边缘出现毛刺/拉丝？**
  * **答**：通常因油墨过稠或干燥过慢所致。适量添加少量稀释剂降低粘度，或微调气阀提高硅胶垫抬升（脱墨）速度。
* **问：为何图案中心模糊、缺墨（针孔）或有小气泡？**
  * **答**：① 硅胶垫表面有灰尘/油污（用胶带清除）；② 硅胶垫下压力过大导致排气不良（减小下压行程）；③ 硅胶垫形状选择不当（圆顶或尖顶垫更利于排气）。
