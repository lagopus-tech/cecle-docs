## 四、操作流程与工作步骤

### 1. 所需物料
* **基材**：凹凸面工件，如文具、玩具、礼品、家电、电子产品等。
* **耗材**：钢版、夹具、硅胶头、油墨、稀释剂、刮刀。
* **气压要求**：5–7 bar，需自备空气压缩机。
* **电源供应**：110V 或 220V，出厂前根据客户目的地电压配置。

### 2. 标准操作流程
1. **连接气源与电源**：接入5–7 bar压缩空气并接通电源；检查有无漏气后开机。
2. **安装钢版与硅胶头**：将四块蚀刻好的钢版分别放入对应墨盘底座，并安装四只匹配的丝印硅胶头。
3. **加墨**：将各色预先调配好的油墨倒入四个开放式墨盘中，并安装刮墨装置。
4. **工件夹持**：将工件固定于穿梭工作台夹具上，进行校准，完成首色基准对位。
5. **试印与调整**：进行试印，观察套印精度，微调工作台及印刷头位置。
6. **正式生产**：调整完成后开始批量印刷；穿梭工作台自动将工件依次送至各印刷头下方，完成四色顺序印刷。
7. **停机与维护**：工作结束后关闭气源与电源，清理各墨盘残留油墨，用清洁剂擦拭硅胶头、钢版及刮刀，并保持机器干燥。
