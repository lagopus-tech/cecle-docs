## 三、操作流程

### 1. 所需物料
* **基材**：待印刷工件及其配套定位夹具。
* **耗材**：钢板、夹具、硅胶头、油墨、稀释剂、刮刀。
* **气压要求**：4–6 bar。需配备空气压缩机。
* **电源供应**：110V 或 220V，根据客户所在地区出厂前配置对应电压，并配备符合当地标准的插头。

### 2. 标准操作流程
1. **接通气源**：连接4–6 bar压缩空气，检查有无泄漏，再开启电源。
2. **安装钢板与硅胶头**：将两块蚀刻好的钢板分别放入对应的开放式墨盘底座中，上方安装对应的丝印硅胶头。
3. **注入双色油墨**：将调配好的第一色与第二色油墨分别倒入左右开放式墨盘，安装刮墨机构。
4. **夹持工件并基准对齐**：将样品固定在穿梭工作台夹具上，手动先将首色（基准色）印刷头与工作台位置对齐。
5. **试印与定位校准**：踩下脚踏开关启动单次双色试印；观察第二色相对于第一色的定位精度，通过第二印刷头的微调旋钮精确调整，直至两色完全重合。
6. **批量生产**：设定锁定后，切换至自动/半自动模式连续生产；穿梭工作台自动往返输送工件，完成双色转移，数字计数器自动累计成品数量。
7. **停机、维护与清洁**：生产结束后切断电源与气源，倒出开放式墨盘内残留油墨，使用清洗剂彻底清洁两块钢板、硅胶头、墨盘及刮刀。
