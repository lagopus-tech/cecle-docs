## 四、工作流程

### 标准工作流程
1. **放置**：将行李直立放置在转盘中央。
2. **固定膜头**：手动拉出膜头并将其压在行李底部。
3. **开始缠绕**：点击触摸屏启动；机器根据预设层数自动缠绕并感应高度。
4. **断膜取件**：包装完成后，机器自动复位。手动切断薄膜并取出行李。
