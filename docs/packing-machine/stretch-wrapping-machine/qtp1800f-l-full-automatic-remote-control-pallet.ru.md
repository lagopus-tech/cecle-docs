## IV. Эксплуатация и рабочий процесс

### 1. Подготовка (Критически важно)
* **Подготовка источника воздуха**: Для работы данной машины необходимо подключение к воздушному компрессору.
* **Пульт дистанционного управления**: Убедитесь, что в пульте достаточно заряда батареи и он правильно направлен на приемник.

### 2. Стандартный рабочий процесс
1. **Загрузка**: Вилочный погрузчик размещает паллетированный груз в центре поворотного стола.
2. **Дистанционный запуск**: Водитель нажимает кнопку запуска на пульте, не покидая сиденья погрузчика.
3. **Автоматический процесс**: Пневматическое управление автоматически захватывает пленку -> Машина выполняет обмотку согласно заданным оборотам -> Автоматически определяет высоту груза.
4. **Автоматическая обрезка пленки**: После завершения обмотки электрическая нагревательная проволока автоматически обрезает пленку, а цилиндр автоматически приглаживает хвостовую часть пленки.
5. **Разгрузка**: Поворотный стол возвращается в исходное положение, и вилочный погрузчик забирает паллет.
