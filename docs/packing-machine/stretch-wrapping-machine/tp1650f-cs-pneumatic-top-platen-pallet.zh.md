## 四、操作与工作流程

### 1. 所需材料
* **拉伸膜**：使用15~35μm规格的预拉伸机用缠绕膜（推荐25μm）。
* **电源**：110V/220V电压。
* **⚠️ 气源**：必须连接外接空气压缩机，提供0.4-0.7Mpa的稳定气压。

### 2. 标准工作流程
1. **上货**：叉车将轻质托盘货物放置在转盘中央。
2. **气动压顶**：按下启动开关，气缸推动压顶板下压，稳固压住货物顶部。
3. **挂膜与缠绕**：手动挂膜后，机器按照程序设定的参数开始缠绕。
4. **自动复位**：顶部和底部缠绕达到设定圈数后，气缸自动上升，转盘自动复位至原始位置。
5. **断膜与卸货**：手动断膜，取下包装完成的成品。
