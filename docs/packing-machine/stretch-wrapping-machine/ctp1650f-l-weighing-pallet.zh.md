## 四、工作流程

### 标准工作流程
1. **定位货物**：使用叉车将码垛货物平稳放置在转盘中央。此时，称重仪表将自动显示货物毛重。
2. **固定薄膜**：手动拉出缠绕膜一端，将其固定在货物底部。
3. **启动**：在触摸屏上操作，按下启动按钮。
4. **缠绕过程**：机器自动旋转，膜架按程序上下移动，完成缠绕。
5. **完成**：缠绕完成后，转盘自动复位，记录称重仪表上的最终数据。手动切断薄膜，叉车运走货物。
