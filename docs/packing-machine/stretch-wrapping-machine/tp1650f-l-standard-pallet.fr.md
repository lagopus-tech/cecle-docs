## IV. Fonctionnement et flux de travail

### 1. Matériaux requis
* **Film étirable** : Utiliser un film étirable machine de type pré-étirement de spécification 15~35 μm (25 μm recommandé).
* **Alimentation électrique** : Tension 110 V/220 V.

### 2. Flux de travail standard
1. **Chargement** : Un chariot élévateur place les marchandises palettisées au centre du plateau tournant.
2. **Fixation du film** : Tirer manuellement une extrémité du film étirable et l'attacher au bas des marchandises.
3. **Démarrage** : Utiliser l'écran tactile et appuyer sur le bouton de démarrage.
4. **Processus d'emballage** : La machine tourne automatiquement, et le chariot porte-film monte et descend selon le programme pour terminer l'emballage.
5. **Fin** : Une fois l'emballage terminé, le plateau tournant se réinitialise automatiquement, couper manuellement le film, et un chariot élévateur déplace les marchandises.
