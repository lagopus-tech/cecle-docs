## IV. Operação e Fluxo de Trabalho

### 1. Materiais Necessários
* **Filme Estirável**：Use filme estirável de máquina tipo pré-estiramento com especificação de 15~35μm (25μm é recomendado).
* **Fonte de Alimentação**：Voltagem de 110V/220V.

### 2. Fluxo de Trabalho Padrão
1. **Carregamento**：Uma empilhadeira coloca as mercadorias paletizadas no centro da mesa giratória.
2. **Fixação do Filme**：Puxe manualmente uma extremidade do filme estirável e amarre-a na parte inferior das mercadorias.
3. **Início:**：Opere a tela de toque e pressione o botão de início.
4. **Processo de Envolvimento**：A máquina gira automaticamente, e o carro do filme se move para cima e para baixo de acordo com o programa para completar o envolvimento.
5. **Conclusão**：Após a conclusão do envolvimento, a mesa giratória é reajustada automaticamente, corte o filme manualmente e uma empilhadeira remove as mercadorias.
