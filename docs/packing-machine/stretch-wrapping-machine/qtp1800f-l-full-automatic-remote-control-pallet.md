## IV. Operation & Workflow

### 1. Preparation (Critical)
* **Air Source Preparation**: This machine needs to be connected to an air compressor for use.
* **Remote Control**: Ensure the remote controller has sufficient battery and is pointed correctly.


### 2. Standard Workflow
1. **Loading**: A forklift places the palletized goods in the center of the turntable.
2. **Remote Start**: The driver presses the start button on the remote controller from the forklift seat.
3. **Automatic Process**: Pneumatic control automatically attaches the film -> Machine wraps according to the set turns -> Automatically senses the load height.
4. **Automatic Film Cutting**: After wrapping ends, the electric heating wire automatically cuts the film, and the cylinder automatically smooths the tail film.
5. **Unloading**: The turntable resets, and the forklift directly takes the pallet away.
