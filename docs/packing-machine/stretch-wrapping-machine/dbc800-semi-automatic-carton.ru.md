## IV. Порядок работы

### Стандартный порядок работы
1. **Регулировка положения**: Отрегулируйте ограничительные стойки для обмотки на поворотном столе в соответствии с шириной коробки.
2. **Размещение**: Поместите коробку в центр поворотного стола.
3. **Крепление пленки**: Вытяните стретч-пленку и прижмите ее под товаром.
4. **Пуск**: Установите необходимое количество оборотов на панели и нажмите ножной педальный переключатель.
5. **Завершение**: Машина автоматически останавливается по достижении заданного количества оборотов (или останавливается вручную), отрежьте пленку и снимите товар.
