## 四、操作与工作流程

### 1. 准备工作（关键）
* **气源准备**：本机需连接空气压缩机方可使用。
* **遥控器**：确保遥控器电量充足，并对准设备方向。

### 2. 标准工作流程
1. **上货**：叉车将码垛货物放置在转盘中央。
2. **遥控启动**：驾驶员在叉车座位上按下遥控器上的启动按钮。
3. **自动运行**：气动控制自动上膜 → 设备按设定圈数缠绕 → 自动感应货物高度。
4. **自动断膜**：缠绕结束后，电加热丝自动断膜，气缸自动抚平尾膜。
5. **卸货**：转盘复位，叉车直接取走托盘。
