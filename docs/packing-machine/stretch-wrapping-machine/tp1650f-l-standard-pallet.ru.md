## IV. Эксплуатация и рабочий процесс

### 1. Необходимые материалы
* **Стрейч-пленка**：Используйте машинную стрейч-пленку для предварительного растяжения толщиной 15~35 мкм (рекомендуется 25 мкм).
* **Электропитание**：Напряжение 110 В / 220 В.

### 2. Стандартный рабочий процесс
1. **Загрузка**：Вилочный погрузчик размещает паллетированный груз в центре поворотного стола.
2. **Крепление пленки**：Вручную вытяните один конец стрейч-пленки и закрепите его у основания груза.
3. **Пуск**：Управляйте сенсорным экраном и нажмите кнопку пуска.
4. **Процесс обмотки**：Машина вращается автоматически, каретка с пленкой перемещается вверх и вниз по программе, завершая обмотку.
5. **Завершение**：После завершения обмотки поворотный стол автоматически возвращается в исходное положение, вручную отрежьте пленку, и вилочный погрузчик перемещает груз.
