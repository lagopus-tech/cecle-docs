## 四、工作流程

### 标准工作流程
1. **放置货物**：将小型行李或纸箱平稳放置在转盘中央两根金属导杆之间。
2. **侧向夹持**：调节转盘上立式导杆的位置，从两侧稳固夹紧固定货物。
3. **缠绕膜固定**：拉出缠绕膜并将其固定在货物底部或导杆周围。
4. **启动缠绕**：按下面板上的启动按钮，机器将按照预设圈数自动完成缠绕。
5. **断膜取货**：机器停止后，手动切断薄膜，松开导杆，取出已包装好的货物。
