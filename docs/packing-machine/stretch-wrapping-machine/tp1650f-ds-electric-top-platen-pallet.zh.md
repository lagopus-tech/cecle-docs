## 四、工作流程

### 标准工作流程
1. **上货**：叉车将轻质托盘货物放置在转盘中央。
2. **压顶启动**：打开开关后，压顶板自动下降压住货物顶部。
3. **挂膜缠绕**：人工挂膜后，机器自动感应货物高度并开始缠绕，膜架自动上下移动。
4. **自动复位**：缠绕结束后，压顶板上升，转盘回到初始位置。
5. **断膜卸货**：人工切断薄膜，叉车取走成品。
