## 四、操作与工作流程

### 1. 所需材料
* **缠绕膜**：使用15~35μm规格的预拉伸型机用缠绕膜（推荐25μm）。
* **电源**：110V/220V电压。

### 2. 标准工作流程
1. **上料**：叉车将托盘货物放置在转盘中央。
2. **固定膜端**：手动拉出缠绕膜一端，固定在货物底部。
3. **启动**：操作触摸屏，按下启动按钮。
4. **缠绕过程**：机器自动旋转，膜架按程序上下移动，完成缠绕。
5. **完成**：缠绕完成后，转盘自动复位，手动切断薄膜，叉车将货物移走。
