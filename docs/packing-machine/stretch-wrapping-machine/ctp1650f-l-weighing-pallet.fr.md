## IV. Processus de travail

### Processus de travail standard
1. **Positionnement des marchandises** : Utilisez un chariot élévateur pour placer en douceur les marchandises palettisées au centre du plateau tournant. À ce moment, l'indicateur de pesage affichera automatiquement le poids brut des marchandises.
2. **Fixation du film** : Tirez manuellement une extrémité du film étirable et attachez-la à la base des marchandises.
3. **Démarrage** : Opérez sur l'écran tactile et appuyez sur le bouton de démarrage.
4. **Processus d'emballage** : La machine tourne automatiquement et le chariot porte-film monte et descend selon le programme pour terminer l'emballage.
5. **Fin** : Une fois l'emballage terminé, le plateau tournant se réinitialise automatiquement. Enregistrez les données finales sur l'indicateur de pesage. Coupez manuellement le film et le chariot élévateur transporte les marchandises.
