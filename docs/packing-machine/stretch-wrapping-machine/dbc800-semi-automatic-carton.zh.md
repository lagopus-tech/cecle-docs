## 四、工作流程

### 标准工作流程
1. **调整位置**：根据纸箱宽度调整转盘上的缠绕限位立柱。
2. **放置货物**：将纸箱放置在转盘中央。
3. **固定薄膜**：拉出拉伸膜并将其压在货物底部。
4. **启动**：通过面板设定所需缠绕圈数，踩下脚踏开关。
5. **完成**：达到预设圈数后机器自动停止（或手动停止），切断薄膜，取出货物。
