## 四、工作流程

### 标准作业流程
1. **放置货物**：将待包装的纸箱平稳放置在黑色转盘中央。
2. **手动缠膜**：拉出缠绕膜的一端，固定在货物底部或边缘。
3. **启动机器**：打开机器侧面的电源开关，转盘开始匀速旋转。
4. **缠绕包装**：操作人员将手压式顶部转盘按压在货物顶部。底部转盘带动纸箱旋转时，一只手握住顶部转盘手柄以稳定货物，使薄膜缠绕得更紧实、更致密。
5. **断膜取件**：达到所需缠绕层数后，关闭电源，手动切断薄膜，取出包裹。
