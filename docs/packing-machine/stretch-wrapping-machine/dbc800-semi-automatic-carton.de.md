## IV. Arbeitsablauf

### Standardarbeitsablauf
1. **Position einstellen**: Stellen Sie die Wickel-Begrenzungsstangen auf dem Drehtisch entsprechend der Kartonbreite ein.
2. **Platzierung**: Legen Sie den Karton in die Mitte des Drehtisches.
3. **Folie anbringen**: Ziehen Sie die Stretchfolie heraus und drücken Sie sie unter das Gut.
4. **Start**: Stellen Sie die gewünschte Anzahl der Umdrehungen über das Bedienfeld ein und betätigen Sie den Fußpedalschalter.
5. **Fertigstellung**: Die Maschine stoppt automatisch nach Erreichen der voreingestellten Umdrehungen (oder stoppt manuell), schneiden Sie die Folie ab und entnehmen Sie das Gut.
