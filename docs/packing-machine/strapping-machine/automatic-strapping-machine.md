## IV. Operation Guide

### 1. Preparation
* **Power Connection:** Connect to a **380 V 3-phase power supply**, confirming correct phase sequence and grounding; turn on the power switch, and the power indicator will light up.
* **Load Strap Reel:** Mount the PP strap coil onto the dispenser reel (reel width 160–180 mm, inner diameter 200–210 mm, outer diameter 400–500 mm), and thread the strap along the track into the arch.
* **Select Mode:** Toggle the knob to select **Sensor / Manual / Automatic** modes; choose Sensor for inline setups, Manual for small batches, and Automatic for high-volume batches.

### 2. Standard Workflow
1. **Position Package:** Place the package onto the tabletop (keep load within 80 KG) and push it into the arch.
2. **Trigger Strapping:** Automatically triggers based on the selected mode—the machine executes **feeding ➔ tensioning ➔ hot-weld sealing ➔ cutting**, completing a single cycle in ≤2.5 seconds.
3. **Inspect Joint:** A qualified joint should feature complete fusion across the entire width, zero cold welds, and zero skewing (sealing position deviation within ≤2 mm).
4. **Remove Package:** Take away the package and proceed to the next cycle.
5. **Shutdown:** Turn off power and retract residual strap; clear the strap track and disconnect power for long-term storage to prevent moisture damage.

### 3. Tension Adjustment
* Tension force is **adjustable from 0 to 60 KG**: lower tension for light cartons to prevent crushing deformation; higher tension for heavy cargo to prevent loosening. Ensure joints are fully fused without package deformation.

### FAQ
* **Q: What is the actual difference between fully-automatic and semi-automatic machines?**
  * **A:** Semi-automatic machines require **operators to manually insert the strap into the track** before the machine activates; fully automatic units **feed straps automatically**, strapping instantly upon package placement in ≤2.5 seconds. That single strap-insertion step dictates your total labor headcount during high-volume periods.
* **Q: How do I choose between the three operating modes?**
  * **A:** Use **Sensor Mode** for conveyor line integration or automatic package positioning; use **Manual Mode** for small batches requiring precise per-strap control; use **Automatic Mode** for high-volume continuous operations. Switch effortlessly via knob without rewiring.
* **Q: What if my boxes are larger than the arch frame?**
  * **A:** The standard arch frame measures W 800 × H 600 mm, but can be **non-standard customized** according to your package dimensions; minimum package size must exceed W 80 × H 60 mm.
