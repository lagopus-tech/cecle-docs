## 4. 操作步骤
1. 手动将胶囊、药片等产品放入PVC泡罩中。  
2. 将装有产品的PVC泡罩放入机器模具内。  
3. 按下按钮，机器自动下压完成封合。  
4. 机器自动完成铝箔的展开与收卷。  
5. 用剪刀裁切泡罩并修整边缘。  
6. 取出成品密封包装产品。
