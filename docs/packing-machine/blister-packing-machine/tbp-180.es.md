## 4. Pasos de Operación
1. Coloque manualmente cápsulas, tabletas u otros productos dentro del blister de PVC;  
2. Introduzca el blister de PVC con productos en el molde de la máquina, luego coloque la película de lámina de aluminio;  
3. Presione el interruptor del equipo; la máquina se bajará automáticamente para completar la operación de sellado;  
4. Corte el exceso de película de aluminio en los bordes del blister con tijeras para obtener un paquete de blister completamente sellado.
