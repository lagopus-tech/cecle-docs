# Руководство по выбору и полное описание продукции для упаковки в блистеры
## 1. Что такое машина для упаковки в блистеры
### 1.1 Основное определение
Машина для упаковки в блистеры, также известная как машина для упаковки Алу-Пластик, — это специальное упаковочное оборудование, которое герметизирует таблетки, капсулы, мелкие детали оборудования между оболочками из ПВХ/ПЭТ и алюминиевой фольгой с помощью термосварки. Используются процессы: термопрессование, намотка фольги, вырубка, чтобы получить отдельные герметичные упаковки. Готовые упаковки обладают свойствами защиты от влаги, света, пыли, ударов и прозрачного отображения содержимого. Оборудование охватывает лабораторные образцы, небольшие партии на производстве и массовое непрерывное производство в фармацевтической промышленности, широко применяется в фармацевтике, пищевой промышленности, электронике и оборудовании, ежедневных косметических образцах и других отраслях для малогабаритных изделий.

### 1.2 Принцип работы
Весь ряд делится на три категории: настольные ручные/полуавтоматические, вертикальные полуавтоматические и полностью автоматические плоские DPP-машины, с двумя основными процессами:
1. Полуавтоматические настольные и вертикальные серии (MTBP / TBP / ETBP / BP / CP / DP)  
   Операторы вручную загружают материалы в готовые блистеры ПВХ и помещают их в формы, затем покрывают алюминиевой фольгой листами или рулонами. Электрические нагревательные плиты или пневмоцилиндры прикладывают постоянную температуру и давление для соединения фольги и блистера. Операторы обрезают лишнюю фольгу, чтобы получить готовую продукцию. У высококлассных моделей DP установлен фотоэлектрический датчик цветной метки для точной регистрации печатной алюминиевой фольги.
2. Полностью автоматические серии DPP (DPP-80 / 150 / 260 / 140E / 250E)  
   Интегрированная непрерывная производственная линия «с рулона на рулон»: размотка ПВХ → формование блистера под нагревом → автоматическая подача → термосварка алюминиевой фольги → кодирование партии → вырубка → повторная намотка отходов. У высококлассных моделей поддерживаются как холодное формование Алу-Алу, так и горячее формование Алу-Пластик, а также контроль отсутствия частиц и автоматическая маркировка. Управление всеми параметрами осуществляется через сенсорный экран PLC, машины могут подключаться к автоматическим сборочным линиям.

### 1.3 Основные преимущества
- Превосходная защита герметичного соединения: полностью герметичная структура Алу-Пластик / Алу-Алу изолирует влагу, свет и пыль, увеличивает срок годности лекарств и продуктов питания, предотвращает повреждение во время транспортировки.
- Гигиеничность и удобство одноразовой упаковки: индивидуальные блистеры исключают перекрестное загрязнение после частичного использования, соответствуют базовым стандартам GMP гигиены для фармацевтической продукции.
- Гибкая адаптация к площадкам: настольные модели можно установить на столах и доставить воздушным/курьерским транспортом; вертикальные полуавтоматические машины занимают умеренное пространство; полностью автоматические плоские машины подходят для стандартизированных производственных цехов.
- Низкий порог эксплуатации: ручные машины можно освоить за 5 минут; полуавтоматические машины поддерживают запуск одним нажатием кнопки; полностью автоматические машины хранят предустановленные параметры.
- Совместимость с глобальными напряжениями: все модели поддерживают 110 В / 220 В 50/60 Гц. Мощные полностью автоматические машины поддерживают трёхфазное промышленное напряжение 380 В.
- Высокая степень настройки: доступны индивидуальные формы. Дополнительно возможна маркировка партии, двухпроцессное Алу-Алу, многообразные многокамерные и многоплиточные конструкции.

### 1.4 Применяемые отрасли
- Фармацевтическая промышленность: таблетки, жёсткие/мягкие капсулы, пилюли, расходные материалы, одноразовые медицинские изделия
- Пищевая промышленность: молочные таблетки, конфеты, замороженные закуски, товары для здоровья
- Электроника и оборудование: микроскребы, аксессуары для наушников, батарейки, точные мелкие детали
- Ежедневная косметика: образцы уходовых средств, капсулы с эссенцией, маленькие упаковки для личного ухода
- Сценарии применения: лабораторные исследования, пробная упаковка в аптеках, небольшие производственные мастерские, крупные фармацевтические производственные линии

## 3. Основные рекомендации по выбору
### 3.1 Выбор по дневному объему
1. Дневная выработка < 100 упаковок для пробной упаковки и заполнения: модель MTBP-180 с ручным настольным управлением
2. Дневная выработка 100–500 малых партий: настольные модели TBP-180 / ETBP-180
3. Дневная выработка 500–2000 регулярных партий: вертикальные полуавтоматические модели BP / CP / DP
4. Дневная выработка > 2000 непрерывное массовое производство: все модели серии DPP полностью автоматические

### 3.2 Выбор по наличию компрессора
- Без компрессора, доступна только городская электросеть: модели MTBP-180, ETBP-180 с полностью электрическим приводом (подключи и работай)
- Уже есть компрессор 0,6–0,8 МПа: доступны все пневматические настольные, вертикальные и полностью автоматические модели серии DPP

### 3.3 Выбор по типу алюминиевой фольги
1. Непечатные алюминиевые листы для недорогой простой упаковки: MTBP, TBP, BP-180
2. Непечатные рулоны алюминия, которые нужно резать вручную: ETBP, CP-180
3. Цветная печатная алюминиевая фольга, требующая точной ориентации рисунка: DP-180, все модели серии DPP полностью автоматические
4. Лекарства, чувствительные к свету, требующие холодного формования Алу-Алу: двухфункциональные модели DPP-140E / DPP-250E

### 3.4 Выбор по условиям места и уровню автоматизации
1. Установка на столе, мобильное малое пространство: настольные модели MTBP / TBP / ETBP
2. Фиксированное производство, средние партии, ограниченный бюджет: вертикальные полуавтоматические модели BP / CP
3. Стандартизированный цех, 24 часа непрерывной работы, снижение затрат на труд: полностью автоматические плоские серии DPP
4. Фармацевтические заводы с требованиями GMP и контроля частиц: модели DPP-150 / 260 / 140E / 250E

### 3.5 Выбор по материалам упаковки
1. Обычные ПВХ + фармацевтическая алюминиевая фольга (таблетки и капсулы): совместимы со всеми сериями
2. Экологичные ПЭТ-барьерные листы: поддерживаются модели DP и полностью автоматические серии DPP
3. Алу-Алу холодное формование для защиты от света: доступны только модели DPP-140E / DPP-250E

## 4. Общие технические вопросы и ответы
### 4.1 Соответствие питания и воздуха
**В: Какие технические характеристики по питанию и напряжению у всей серии?**  
О: Мощность настольных моделей 180: 500 Вт / 1000 Вт; полуавтоматические вертикальные: 1000–1500 Вт; полностью автоматические DPP: 2,8–8,5 кВт. Все модели поддерживают 110 В / 220 В 50/60 Гц. Большие модели DPP можно настроить под трёхфазное промышленное напряжение 380 В, совместимо со стандартной электросетью фабрики.

**В: Какой компрессор нужен для пневматических моделей?**  
О: Все пневматические настольные, вертикальные и полностью автоматические модели серии DPP совместимы с компрессором 1200 Вт / 50 л, обеспечивающим стабильное давление 0,6–0,8 МПа для нормальной работы.

**В: Могут ли пневматические машины работать без компрессора?**  
О: Нет, пневмоцилиндры зависят от давления воздуха. Клиенты без компрессора должны выбрать настольные модели MTBP или ETBP с полностью электрическим приводом.

### 4.2 Настройка форм
**В: Входят ли формы в стандартную комплектацию?**  
О: Все машины не включают формы. Формы изготавливаются индивидуально на основе образцов продукции. Клиент должен предоставить 6–8 шт. образцов блистеров ПВХ для проектирования формы до заказа.

**В: Формы взаимозаменяемы? Нужны ли новые формы для новых продуктов?**  
О: Формы можно использовать на машинах с одинаковым размером рабочего стола. Новые формы необходимы при изменении размера, формы или глубины блистера. Доступны 1–4-камерные многокамерные формы для увеличения выхода за один цикл.

**В: Можно ли делать маркировку номера партии и даты производства на формах?**  
О: Модули маркировки можно интегрировать в формы для настольных и вертикальных полуавтоматических машин. Все полностью автоматические модели серии DPP имеют отдельное устройство кодирования, которое печатает номер партии и срок годности во время термосварки.

### 4.3 Расходные материалы и устранение проблем при сварке
**В: Какие упаковочные материалы совместимы?**  
- Полуавтоматические настольные и вертикальные: готовые блистеры ПВХ / ПЭТ, алюминиевые листы и рулоны  
- Полностью автоматические DPP: рулоны ПВХ / ПЭТ, алюминиевая фольга для термосварки, холодноформованная Алу-Алу пленка  

**В: Как исправить неполную сварку, пузыри и смещение фольги?**  
1. Неполная сварка / пузыри: увеличить температуру нагрева и время удержания, проверить стабильность давления воздуха  
2. Сморщивание и смещение алюминиевой фольги: отрегулировать натяжение намотки, выровнять параллельность направляющих роликов  
3. Несоответствие печатного рисунка: активировать компенсацию фотоэлемента на моделях DP и DPP, перенастроить датчик цветной метки  

### 4.4 Обслуживание и гарантия
**В: Какие изнашиваемые запчасти доступны и можно ли их купить отдельно?**  
О: Нагревательные плиты, термостойкие клейкие ленты, уплотнительные кольца, фотоэлектрические датчики (DP/DPP), высокочастотные электронные компоненты (полностью автоматические) доступны для самостоятельной покупки. Предоставляем дистанционные инструкции по замене.

**В: Какова политика гарантии на машины?**  
О: Все машины имеют 1-летнюю гарантию на весь аппарат. Износостойкие детали (нагревательная плита, уплотнительное кольцо, электронные компоненты) не входят в гарантию. Предоставляем пожизненную техническую поддержку, ремонт форм и услуги по на месте пусконаладке.

**В: Как очистить остатки алюминиевого клея с нагревательной плиты?**  
О: Отключите питание и дайте полностью остыть, протрите мягкой тканью, смоченной безводным спиртом. Не используйте стальную вату или острые лезвия, чтобы не повредить покрытие, что может вызвать неравномерную сварку.

## 5. Полная возможность индивидуальной настройки
### 5.1 Основная настройка форм
1. Настройка размера и глубины: индивидуальные одно- и многокамерные формы по размерам изделия и глубине блистера
2. Настройка формы: уникальные формы для круглых, квадратных, нестандартных капсул и суппозиториев
3. Интеграция функций: формы с модулем маркировки номера партии, логотипа и срока годности, чтобы исключить вторичную обработку

### 5.2 Дополнительные улучшения для машин
1. Улучшение системы подачи: базовая модель BP может быть модернизирована с автоматической намоткой алюминиевой фольги
2. Улучшение системы управления: базовые пневматические машины можно обновить до системы PLC + фотоэлектрическая регистрация
3. Опциональный контроль: фармацевтические машины серии DPP поддерживают контроль отсутствия частиц и автоматическую маркировку
4. Расширение процессов: модели DPP-140E / 250E поддерживают обновление процесса холодного формования Алу-Алу
5. Настройка напряжения и панели: для зарубежных заказов доступна настройка 110 В и английский сенсорный экран

### 5.3 Оптимизация по отраслям
1. Фармацевтическая промышленность: все контактирующие с продуктом части из нержавеющей стали, формы без заусенцев. Серии DPP соответствуют базовым требованиям GMP для упаковки стерильных лекарств
2. Пищевая промышленность: поверхности нагрева пищевого класса, оптимизированная кривая температуры для предотвращения повреждения вкуса при высокой температуре
3. Электроника и оборудование: глубокие и усиленные формы с повышенной силой зажима для предотвращения царапин и повреждений мелких деталей
4. Экспортная настройка: усиленная деревянная упаковка для экспорта, двуязычные руководства (китайский и английский), адаптация к зарубежному напряжению

### 5.4 Полный процесс индивидуальной настройки
1. Клиент предоставляет образцы продукции / чертежи блистеров, уточняет дневной объём, тип алюминиевой фольги, условия подачи воздуха и электропитания на производстве
2. Поставщик выдает предложение по комплектации машины и проекту формы, согласует все размеры и функции с клиентом
3. Производство машины и изготовление форм идут параллельно. Проводятся несколько тестов на сварку перед отправкой с завода
4. Машина доставляется с поддержкой дистанционной видео-наладки; доступна установка на месте и обучение операторов

## 6. Общий стандартный рабочий процесс (пример вертикального полуавтомата)
1. Подключите питание и компрессор, стабилизируйте давление воздуха на уровне 0,6–0,8 МПа. Включите питание, прогрейте нагревательную плиту, установите температуру 80–150 °C, время сварки 3–6 секунд
2. Зафиксируйте индивидуальную форму на рабочем столе, загрузите таблетки / капсулы в блистеры ПВХ
3. Уложите алюминиевый лист или активируйте систему автоматической подачи рулона алюминиевой фольги
4. Нажмите педаль или кнопку панели для автоматического прессования при постоянной температуре
5. Поднимите нагревательную плиту после сварки, извлеките пластину с блистерами и обрежьте лишнюю алюминиевую фольгу ножницами
6. Повторите загрузку и сварку для непрерывного производства
7. После окончания работы отключите нагрев, подачу воздуха и питание. После полного остывания очистите остатки клея с формы, регулярно обслуживайте направляющие рейки и цилиндры
