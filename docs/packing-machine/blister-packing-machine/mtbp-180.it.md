## 4. Processo di Funzionamento
1. Inserire manualmente capsule, compresse e altri prodotti nei blister in PVC;
2. Posizionare il blister in PVC caricato nello stampo della macchina, quindi aggiungere la pellicola in alluminio;
3. Accendere l’interruttore del dispositivo e premere la leva manuale per completare il sigillo;
4. Tagliare l’eccesso di alluminio intorno al blister con un coltello o forbici per ottenere un imballaggio finito.
