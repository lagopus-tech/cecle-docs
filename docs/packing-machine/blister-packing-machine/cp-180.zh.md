## 4. 操作流程
1. 手动将胶囊、片剂等产品放入PVC泡罩中。  
2. 将装有产品的PVC泡罩放入机器模具内。  
3. 踩下脚踏开关，机器自动下压完成热封。  
4. 机器自动回卷/供送铝箔。  
5. 使用剪刀或切边机裁切泡罩并修整边缘。  
6. 取出已完成密封的产品。

### 5.2 常见问题与解决方案

#### 1. 泡罩成型不良（变形、穿孔、不完整）
- **原因**：加热温度不足或过高、气压不稳定、模具不平行、冷却不足。  
- **解决方法**：校准温度（140–160℃）、稳定气压至0.6–0.8MPa、调整模具平行度、清理气路通风口、优化冷却水流速。

#### 2. 热封强度弱（漏气、起泡、易撕裂）
- **原因**：加热时间过短、温度偏低、压力不足、铝箔粘合层损坏、加热板表面有污垢。  
- **解决方法**：延长加热时间至4–5秒，温度提升5–10℃，调节气动压力，更换高质量铝箔，清洁加热板表面污渍。

#### 3. 铝箔褶皱与偏移
- **原因**：铝箔进给张力不均、导辊不平行、压力杆高度不平衡、铝箔质量差。  
- **解决方法**：调节铝箔进给张力旋钮，校准导辊平行度，微调压力杆高度，更换无褶皱、厚度均匀的铝箔。

#### 4. 生产速度低、效率差
- **原因**：参数设置不合理、人工供料缓慢、模具适配性差。  
- **解决方法**：优化加热/封口参数，培训员工快速供料，定制兼容性更高的模具（最大180×140mm / 7.09×5.51英寸）。

#### 5. 机器无法启动 / 加热板不加热
- **原因**：电源连接不良、温控器故障、加热管损坏、未连接气源。  
- **解决方法**：检查电源线路与插头，校准或更换温控器，修复加热管，确保空压机供气正常且无泄漏。
