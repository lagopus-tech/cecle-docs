## 1. 产品概述  
TBP-180 是一款台式气动泡罩包装机，专为胶囊、药片、小型五金件及电子元件等小物件的PVC泡罩+铝箔封合而设计。采用气缸压合 + 数字显示时间控制，运行稳定，操作简便。适用于小批量生产、实验室、门店、工厂以及小型外贸订单。

## 2. 主要优势  
- **气动压合**：压力均匀，封口牢固，省力高效  
- **数字时间控制**：加热时间精准，封合质量稳定  
- **紧凑桌面设计**：占地面积小，便于摆放与移动，可直接置于桌面使用，支持空运或快递，降低物流成本  
- **可定制模具**：可根据客户提供6–8个泡罩样品定制模具，更换快速，适配多种产品  
- **宽电压兼容**：支持110V/220V，50/60Hz，全球通用  
- **需配备空压机**：气压稳定，效率更高

## 4. 操作步骤  
1. 手动将胶囊、药片等产品放入PVC泡罩中；  
2. 将装有产品的PVC泡罩放入机器模具内，再覆盖铝箔膜；  
3. 按下设备开关，机器自动下压完成封合操作；  
4. 用剪刀修剪泡罩边缘多余的铝箔膜，获得完整的密封泡罩包装。
