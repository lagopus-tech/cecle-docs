## 4. Passaggi Operativi
1. Inserire manualmente capsule, compresse e altri prodotti nel soffietto in PVC;
2. Posizionare il soffietto in PVC con i prodotti nello stampo della macchina, quindi aggiungere la pellicola in alluminio;
3. Premere l’interruttore dell’apparecchio: la macchina si abbasserà automaticamente completando l’operazione di sigillatura;
4. Tagliare il materiale in eccesso sulla parte esterna del soffietto con delle forbici per ottenere un pacchetto soffietto completamente sigillato.
