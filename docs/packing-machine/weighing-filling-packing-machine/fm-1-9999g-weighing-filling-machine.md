## 4. Operation Process
1. **Power On:** Plug the machine into a standard 110V or 220V power supply and turn on the main power switch on the side/back.
2. **Parameter Setting:** Through the front "Smart Control Panel", input your desired single bag target weight (grams) and select the appropriate feeding speed based on material characteristics.
3. **Feed Material:** Pour the dry materials to be filled (such as tea, screws, powder, etc.) into the large-capacity stainless steel hopper on the top.
4. **Foot Pedal Discharge:** Place an empty packaging bag under the discharge outlet. When the panel indicates the set weight is reached, step on the foot switch, and the machine will accurately discharge the weighed material into the bag.
