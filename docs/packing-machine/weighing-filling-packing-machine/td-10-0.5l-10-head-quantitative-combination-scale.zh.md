## 4. 操作流程  
1. 物料通过配套的斗式提升机送入组合秤中央顶部漏斗。  
2. 主振动槽振动，将物料均匀分配至10个直线振动槽。  
3. 直线槽将物料送入缓冲料斗，再落入下方10个独立称重料斗。  
4. 计算机主板瞬间读取10个料斗的重量，并进行高速排列组合计算。  
5. 系统选择总和最接近预设目标重量（如500g）的料斗组合。  
6. 被选中的料斗同时开启，将物料排入集料槽，再落入下方的包装机。
