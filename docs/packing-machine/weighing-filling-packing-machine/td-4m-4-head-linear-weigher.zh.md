## 1. 产品概述  
TD-4M 是一款配备四个称重单元的线性称重设备，相比双头机型效率更高，组合方式更灵活。  
适用于切片、卷曲或规则形状的产品，如糖、盐、种子、大米、芝麻、味精、奶粉、咖啡及调味粉等。四个独立料斗协同运作，显著提升单一物料的称重速度，并可轻松实现多种物料的精准混合出料。

## 2. 核心优势  
1. **全新模块化控制系统**：优化的系统算法确保精准控制，模块化主板设计使维护更加便捷。  
2. **无级振动供料系统**：无级调速振动设计，保障物料输送平稳流畅，有效保护易碎物料。  
3. **混合批量功能**：4头设计特别适用于不同产品的比例混合称重，可在一次出料中完成配方混合。  
4. **参数灵活调节**：可根据生产线需求及物料密度，自由调整供料速度与重量参数。

## 4. 操作流程  
1. 将一种或多种待包装物料分别放入上方储料斗中。  
2. 在触摸屏上设置目标重量、批次比例（如需混合）、振动频率等参数。  
3. 四个送料滑槽通过无级振动，同时或交替将物料送入对应的称重料斗。  
4. 主板实时监测各料斗重量，达到目标值后自动停止供料。  
5. 接收到出料信号后，对应称重料斗同时或依次打开，将物料排入袋/容器中。  
6. 一次出料完成后，系统自动循环进入下一轮称重流程。
