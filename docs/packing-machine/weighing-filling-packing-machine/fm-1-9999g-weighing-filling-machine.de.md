## 4. Bedienungsablauf
1. **Ein-/Ausschalten:** Stecken Sie die Maschine in eine Standardstromquelle (110 V oder 220 V) und schalten Sie den Hauptstromschalter an der Seite oder hinten ein.
2. **Parameter einstellen:** Geben Sie über das vordere „Smart-Steuerungspanel“ Ihr gewünschtes Einzelbeutel-Gewicht (in Gramm) ein und wählen Sie je nach Materialbeschaffenheit die passende Füllgeschwindigkeit.
3. **Material zuführen:** Gießen Sie die zu füllenden trockenen Materialien (z. B. Tee, Schrauben, Pulver usw.) in den großvolumigen Edelstahl-Hopper oben.
4. **Fußpedal-Ausgabe:** Legen Sie einen leeren Verpackungsbeutel unter die Ausgabemündung. Sobald das Display das eingestellte Gewicht anzeigt, treten Sie leicht auf das Fußpedal – die Maschine gibt das gewogene Material genau in den Beutel aus.
