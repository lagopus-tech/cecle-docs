## 4. 操作流程  
1. 启动设备，通过触摸屏调取对应产品的配方（重量、振动幅度等参数）。  
2. 物料经斗式提升机进入中央主振动盘，并均匀分配至外围14个线性振动盘。  
3. 经缓冲料斗暂存后，物料被送入14个高精度称重料斗中。  
4. 模块化计算机主板在毫秒级内完成14个料斗重量的所有排列组合运算。  
5. 系统自动选择总和最接近目标重量的料斗组合（误差控制在0.1~1克内）。  
6. 所选料斗瞬间开启出料门，完成一次超高精度投料，并自动循环复位。
