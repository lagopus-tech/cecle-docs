## 1. Обзор продукта
Модель TD-14-0.5L — это высококлассная 14-головочная микрокомпьютерная комбинированная весовая машина. Чем больше голов, тем экспоненциально больше вариантов комбинаций для компьютера, что позволяет достичь максимальной точности и скорости на более широком диапазоне весов.  
Подходит для точного взвешивания сыпучих материалов, таких как ломтики, рулончики или регулярные формы: сахар, соль, семена, рис, кунжут, MSG, молочный порошок, кофе, приправы. Это предпочтительное оборудование для предприятий среднего и крупного масштаба в пищевой промышленности, обеспечивающее высокоэффективную автоматизированную производственную линию.

## 2. Ключевые преимущества
1. **Максимальный расчет комбинаций 14 голов:** По сравнению с 10-головочной машиной, увеличенная база комбинаций обеспечивает более широкий диапазон взвешивания (50–2000 г). Легко достигается целевое значение с средней точностью до 0,1–1 г.
2. **Новая модульная система управления:** Алгоритмы системы полностью обновлены для стабильной, без задержек работы. Модульные платы управления упрощают диагностику и обслуживание.
3. **Бесступенчатая вибрационная система подачи материала:** Равномерное распределение по всему периметру обеспечивает плавный поток и сохраняет целостность материала.
4. **Мощная способность к смешиванию нескольких материалов:** 14 голов можно разделить на несколько зон, что делает машину особенно эффективной при высокоточном взвешивании 2–4 и более различных материалов.
5. **Гибкая настройка параметров:** Для материалов разной плотности можно в любой момент вызвать соответствующие рецептурные параметры и свободно их изменить.

## 4. Процесс работы
1. Запустите оборудование и через сенсорный экран выберите соответствующий рецепт продукта (вес, амплитуда вибрации и т.д.).
2. Материал поступает в центральный основной вибрационный бункер через элеватор и равномерно распределяется по 14 внешним линейным вибрационным бункерам.
3. Пройдя через буферные бункеры, материал временно хранится в 14 высокоточных взвешивающих бункерах.
4. Модульная плата компьютера за миллисекунды рассчитывает все возможные комбинации весов 14 бункеров.
5. Система автоматически выбирает бункеры, суммарный вес которых наиболее точно соответствует заданному (ошибка контролируется в пределах 0,1–1 г).
6. Выбранные бункеры мгновенно открываются, выпуская содержимое, завершая один чрезвычайно точный дозированный цикл, после чего автоматически возвращаются в исходное положение.
