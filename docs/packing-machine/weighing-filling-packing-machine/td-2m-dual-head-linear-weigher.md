## 4. Operation Process
1. Load the material to be weighed into the top storage hopper.
2. Set the target weight (e.g., 500g) and parameters like vibration feeding intensity on the touch screen.
3. The machine starts, and the two weighing hoppers alternately feed and weigh via the stepless vibration system.
4. The control system calculates in real-time; when the preset weight is reached, the vibration stops.
5. The operator places a bag under the discharge outlet (or the machine receives a discharge signal if connected to an auto-packer), and the weighing hopper opens to release the material.
6. The weighing hopper closes, immediately starting the next weighing cycle.
