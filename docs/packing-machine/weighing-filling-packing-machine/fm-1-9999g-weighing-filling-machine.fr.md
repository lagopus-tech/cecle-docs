## 4. Processus de fonctionnement
1. **Mise sous tension :** Branchez la machine sur une alimentation standard 110V ou 220V, puis allumez l’interrupteur principal situé sur le côté ou à l’arrière.
2. **Configuration des paramètres :** Via le "Panneau de contrôle intelligent" à l’avant, saisissez le poids cible souhaité par sachet (en grammes) et sélectionnez la vitesse de remplissage appropriée selon les caractéristiques du matériau.
3. **Alimentation du matériau :** Verse le matériau sec à remplir (thé, vis, poudre, etc.) dans le grand trémie en acier inoxydable situé en haut.
4. **Déversement par pédale :** Placez un sac vide sous la sortie de déversement. Lorsque le panneau indique que le poids cible est atteint, appuyez doucement sur la pédale, et la machine déverse précisément le matériau pesé dans le sac.
