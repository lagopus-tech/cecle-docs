## 1. 产品概述  
TD-2M 是一款适用于中小规模生产需求的双头直线式称重设备，可实现颗粒状或规则形状物料的自动定量称重。  
广泛应用于切片、卷状或规则形态的产品，如糖、盐、种子、大米、芝麻、味精、奶粉、咖啡及调味粉等。双称重头交替工作，有效提高出料效率并保持称量精度，是食品与农产品包装领域的理想入门级称重设备。

## 4. 操作流程  
1. 将待称重物料放入上方储料斗。  
2. 在触摸屏上设定目标重量（如500g）及振动供料强度等参数。  
3. 机器启动后，两个称重斗通过无级振动系统交替进料与称重。  
4. 控制系统实时计算；当达到预设重量时，振动停止。  
5. 操作员将包装袋置于出料口下方（或连接自动包装机并接收出料信号），称重斗开启释放物料。  
6. 称重斗关闭后，立即开始下一周期的称重。
