## 1. Aperçu du produit
La TD-2M est une balance linéaire à double tête adaptée au pesage automatique quantitatif de granulés et de matériaux réguliers, destinée aux capacités de production modérées.
Elle convient particulièrement aux produits tranchés, roulés ou réguliers tels que le sucre, le sel, les graines, le riz, la sésame, le MSG, la poudre de lait, le café et les épices en poudre. Les deux têtes fonctionnent de manière alternée, améliorant efficacement l’efficacité de décharge tout en maintenant une grande précision. C’est ainsi un équipement idéal pour débuter dans le conditionnement alimentaire et agricole.

## 4. Processus de fonctionnement
1. Chargez le matériau à peser dans le silo supérieur.
2. Définissez le poids cible (ex. : 500 g) et les paramètres comme l’intensité de vibration sur l’écran tactile.
3. La machine démarre ; les deux bacs de pesage alimentent et pesent alternativement grâce au système de vibration sans palier.
4. Le système de contrôle calcule en temps réel ; lorsque le poids prédéfini est atteint, la vibration s’arrête.
5. L’opérateur place un sac sous la sortie de décharge (ou la machine reçoit un signal de décharge si connectée à un emballage automatique), puis le bac de pesage s’ouvre pour libérer le matériau.
6. Le bac de pesage se referme immédiatement, déclenchant le cycle de pesage suivant.
