## 4. 操作流程
1. **開機啟動**：將機器接入標準 110V 或 220V 電源，打開側面或背面的主電源開關。
2. **參數設定**：透過前方「智慧控制面板」輸入所需單包目標重量（克數），並根據物料特性選擇合適的進料速度。
3. **投料**：將待填充的乾性物料（如茶葉、螺絲、粉末等）倒入頂部的大容量不鏽鋼料斗中。
4. **腳踏排料**：在排料口下方放置空包裝袋。當面板顯示已達設定重量時，輕踩腳踏開關，機器將精確地將稱量好的物料排入袋中。
