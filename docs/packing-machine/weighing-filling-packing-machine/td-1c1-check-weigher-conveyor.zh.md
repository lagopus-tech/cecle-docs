> **核心摘要：**  
TD-1C1 动态检重输送机是用于确保最终包装重量准确性的关键在线质量控制设备。广泛应用于制药、食品、电子及保健产品行业，作为最后一道质量关卡，可有效检测药片、说明书或干燥剂等缺失部件。具备每分钟10–60袋的高速动态称重能力，精度高达0.5~1.5克，可无缝集成至现有自动化包装生产线。内置50组预设程序，支持快速换型，确保出厂产品100%合规，彻底杜绝客户投诉。

## 1. 产品概述  
TD-1C1 动态检重机用于在线检测成品包装是否符合预设合格重量标准。  
广泛应用于电子、制药、食品、饮料及健康产品领域，特别适用于检测袋装或瓶装产品中是否存在药片、胶囊、说明书或干燥剂等缺失部件，是产品出厂前的最后一道质量保障。

## 2. 核心优势  
1. **高精度动态称重**：平均精度达0.5~1.5克，在传送带运行过程中实现快速精准称重。  
2. **高速检测能力**：检测速度最高可达10–60袋/分钟，完美匹配主流自动包装线。  
3. **多程序记忆功能**：内置50组预设程序，可快速切换不同产品的重量标准，无需频繁校准。  
4. **广泛应用适应性**：可处理从轻质药品胶囊到日常食品包装的欠重检测，适用范围广。  
5. **紧凑结构设计**：占地面积小，便于与客户现有包装线实现无缝集成。

## 4. 操作流程  
1. 将设备安装于现有包装生产流水线末端。  
2. 在控制面板上调用或创建当前产品的预设程序，设定标准重量及允许的上下限误差范围。  
3. 启动设备，上游已完成包装的产品依次通过检重机传送带。  
4. 产品经过时，系统立即进行动态称重。  
5. 系统自动判断：若重量在合格范围内，则正常通过；若超重或欠重，设备将触发报警或启动剔除装置（如已配置），将其从产线上移除。
