## 4. Processo Operativo
1. Integrare la macchina alla fine di una linea di produzione di imballaggio esistente.
2. Richiamare o creare un programma preimpostato per il prodotto corrente dal pannello di controllo, impostando il peso standard e i limiti consentiti di errore superiore/inferiore.
3. Accendere la macchina. I pacchi finiti provenienti dall’upstream passano uno alla volta sul nastro del controllo peso.
4. La macchina pesa dinamicamente il prodotto nel momento in cui lo attraversa.
5. Il sistema giudica automaticamente: se il peso è entro i limiti accettabili, il prodotto passa normalmente; se è sovrappeso o sottopeso, la macchina attiva un allarme o un dispositivo di espulsione (se presente) per rimuoverlo dalla linea.
