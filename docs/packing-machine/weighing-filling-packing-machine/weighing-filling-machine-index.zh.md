# 称重与定量填充机系列选型指南及产品概览

## 一、什么是自动定量称重填充机？
### 1.1 核心定义
自动定量称重填充机（或组合秤）是一种采用微电脑控制系统和高精度传感器的自动化设备，能够根据预设目标重量，精准快速地将散装物料（颗粒、粉末、不规则固体）分装至包装袋或容器中。我们的系列产品涵盖完整的称重解决方案，从单头桌面微型填充机、多头高速组合秤，到重型大包机以及产线末端动态检重仪。

### 1.2 工作原理
根据机型不同，核心称重逻辑分为三大类：
1. **单/双/4头线性振动称重（FM系列，TD-2M/4M）：** 物料通过无级振动盘送入称重料斗。负载传感器实时监测重量，当接近目标值时，振动速度减慢（细喂料），并在达到设定重量时精确停止，随后开启闸门排料。
2. **多头计算机化组合称重（TD-10 / TD-14）：** 物料被分配至10或14个独立称重料斗。微电脑在毫秒内读取所有料斗重量，计算所有可能组合，并立即选出总重量最接近目标值的那一组，实现极致精度与高速度的完美平衡。
3. **动态在线检重（TD-1C1）：** 产品在运动的输送带上经过称重模块，系统动态采集重量并与预设上下限对比，若超出公差范围，则触发报警或剔除装置。

### 1.3 核心价值
- **极致省料：** 消除传统人工称重误差。高精度组合秤（误差低至0.1g）可防止高价值物料“多给”，直接提升利润空间。
- **效率飞跃：** 速度范围从每分钟几袋至最高60袋。可仅用脚踏开关独立操作，也可无缝对接全自动立式包装机。
- **灵活生产：** 智能控制面板/HMI触摸屏可存储多种产品配方。换品只需一键调用预设参数。
- **应用广泛：** 适用于食品、农业、化工、五金等行业，几乎适用于所有不粘连且流动性良好的物料。

### 1.4 适用行业
- **食品与农业：** 大米、谷物、坚果、糖、盐、咖啡豆、种子、茶叶、调味粉。
- **工业与五金：** 螺丝、螺母、螺栓、塑料件、小型紧固件。
- **化工与医药：** 化肥颗粒、中药材片、胶囊、粗粉。
- **质量控制（QC）：** 成品包重量检验（检测缺说明书/干燥剂或重量不足的袋子）。

## 三、核心选型建议

### 3.1 按物料特性选型
1. **流动性良好晶体/粗颗粒物料（大米、豆类、糖、盐）：** 本目录所有机型均适用。
2. **有一定流动性的干粉（调味粉、洗衣粉）：** FM系列与TD线性秤适用。
3. **超细、粉尘多或粘性粉末（面粉、细乳粉）：** **[警告]** 此类物料不适用于本目录中的振动进料设备，因易结块、架桥或严重污染传感器。请选用我们的 **“螺旋计量填充机（Auger Filler）”**。
4. **易碎、高价值物料（冻干食品、优质草药）：** 强烈推荐 **TD-10 / TD-14 多头秤**。其平滑进料与极致精度可保护物料完整性，最大限度减少重量溢出。

### 3.2 按产能与自动化程度选型
1. **初创企业 / 电商 / 低频填充：** 选择FM系列独立使用。投入低、占地小、操作简单（脚踏控制）。搭配手动封口机即可。
2. **中型工厂 / 配方混合需求：** 选择TD-2M / TD-4M线性秤。中等速度，满足基本自动化升级与混合需求。
3. **现代化自动化产线 / 无人车间：** 选择TD-10 / TD-14多头秤。可对接Z型提升机与VFFS（立式成型充填封口）设备，实现全天候高速无人化生产。

### 3.3 按每袋目标重量选型
1. **微量装填（<50g）：** 选择FM-50。
2. **标准袋装（50g - 2000g）：** 中等规格FM系列或任意TD系列。若对精度要求极高，建议选择10/14头多头秤。
3. **重袋装填（3kg - 10kg）：** 选择FM-5000或FM-9999。
4. **编织袋/牛皮纸袋批量包装（25kg级别）：** 必须选择A-25重袋包装秤。

## 四、通用技术常见问答

### 4.1 设备应用与限制
**问：这台机器能否剔除重量错误的产品？**  
答：填充机（FM/TD系列）仅负责按目标重量下料。如需对**已封口成品包**进行重量检测并剔除不合格品，请选购 **TD-1C1动态检重仪**，并可选配剔除装置（如推杆或气吹）。

**问：为何说面粉不能用于这些机器？**  
答：本目录设备采用“振动进料”原理。超细粉末如面粉、可可粉在振动作用下会压实结块（架桥），无法正常流动，或产生严重粉尘污染电子传感器。细粉物料必须使用“螺旋（螺杆）计量填充机”。

### 4.2 操作与维护
**问：混合投放如何实现？（针对TD-4M/10/14头机型）**  
答：在智能触摸屏上可对不同称重头进行分组设置。例如在TD-4M上，可设定头1为50g核桃，头2为30g杏仁，头3为20g葡萄干。触发后，机器将一次性排出一份精确混合的100g能量棒混合料。

**问：机器是否容易清洁？**  
答：所有接触部件均采用食品级不锈钢材质。TD系列多头秤的料斗采用快拆设计，操作员可徒手无需工具拆卸，方便用水冲洗与消毒，极为便捷。

### 4.3 电源与保修
**问：电压与气源需求是什么？**  
答：标准配置支持单相220V（部分小型FM机型支持110V）。重型设备如A-25支持三相380V。纯称重设备通常无需空压机；但若配套气动包装机或特定夹袋装置，则客户需自行提供气源。

**问：保修政策是怎样的？**  
答：全系列标配1年整机保修（耗材如皮带、加热管除外），并提供终身技术支持与维护服务。

## 六、标准操作规程（SOP — 以TD多头秤为例）

1. **自检与预热：** 接通电源，HMI系统启动并自动对所有传感器执行零点校准。
2. **配方设置/调用：** 在触摸屏上调出预设产品程序（包括目标重量如500g、上下限公差、主/线性振动盘振幅等参数）。
3. **自动进料：** 启动同步斗式提升机，持续将物料送至秤体顶部中央主振动盘。
4. **智能分配与称重：** 主盘将物料均匀分配至周围线性盘，再由线性盘落入各独立称重料斗。
5. **毫秒级计算：** 主板在毫秒内读取所有料斗数据，自动选出总重量恰好等于500g的最佳组合。
6. **同步排料：** 收到下游包装机“就绪”信号后，选定料斗瞬间开启闸门，将物料精准投入袋中，完成一个循环。
7. **停机与清洁：** 生产结束后，使用一键“清空物料”功能，断电后徒手拆卸料斗进行清洗。
