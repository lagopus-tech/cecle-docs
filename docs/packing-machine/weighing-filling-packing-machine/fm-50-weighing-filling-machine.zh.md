## 4. 操作流程
1. **加料**：确认电源连接正常后，打开开关，将待填充物料（如茶叶、颗粒或粉末）倒入顶部不锈钢料斗。
2. **设置重量**：在智能控制面板上输入目标填充重量（1g–50g之间）。
3. **自动称重**：机器内部振动盘开始工作，将物料输送至称重料斗，当达到设定重量时自动停止振动。
4. **脚踏排料**：将包装袋或容器置于不锈钢出料口下方，踩下脚踏开关，挡板开启，物料精准落入包中，完成一次填充循环。

### 常见问题 FAQ
**Q1：该机器可以包装哪些物料？**  
A1：适用于干燥、不粘连的物料，如坚果、玉米、豆类、茶叶、粉末，以及螺丝等小型五金件。不适用于潮湿、高度粘连或流动性极差的物料。

**Q2：填充误差大吗？**  
A2：机器误差范围为 ±0.2g 至 2g，具体误差取决于物料颗粒大小、均匀度和流动性（物料越均匀、流动性越好，精度越高）。

**Q3：排料是如何工作的？**  
A3：当控制面板显示称重完成时，操作员只需踩下提供的脚踏开关，机器将自动打开阀门进行排料。

**Q4：机器容易清洁吗？**  
A4：整机主通道与料斗均采用不锈钢材质，通道结构相对开放，可用刷子清理或干布擦拭，清洁非常方便。

**Q5：是否即插即用？需要空压机吗？**  
A5：是的，直接插电即可使用（支持 110V/220V 标准市电）。纯电气控制，无需空压机。
