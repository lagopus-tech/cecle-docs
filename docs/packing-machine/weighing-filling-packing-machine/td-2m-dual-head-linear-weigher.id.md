TD-2M adalah timbangan linear dual-head yang sesuai untuk penimbangan kuantitatif otomatis bahan berbentuk butiran dan bentuk teratur dalam kapasitas produksi kecil hingga menengah.

## 4. Proses Operasi
1. Isi material yang akan ditimbang ke hopper penyimpanan bagian atas.
2. Atur berat target (misalnya 500g) dan parameter seperti intensitas getaran pengumpanan melalui layar sentuh.
3. Mesin mulai beroperasi, kedua hopper penimbangan bekerja bergantian menggunakan sistem getaran tanpa batas.
4. Sistem kontrol menghitung secara real-time; ketika berat yang telah ditentukan tercapai, getaran berhenti.
5. Operator meletakkan kantong di bawah outlet pengeluaran (atau mesin menerima sinyal pengeluaran jika terhubung ke mesin kemas otomatis), lalu hopper penimbangan membuka untuk melepaskan material.
6. Hopper penimbangan menutup, langsung memulai siklus penimbangan berikutnya.

### FAQ
**Q1: Bisakah mesin ini menimbang bubuk?**  
A1: Cocok untuk butiran, potongan kecil dengan aliran baik (seperti beras, gula, kacang), serta beberapa bubuk kasar yang mengalir bebas. Untuk bubuk halus dan debu, disarankan menggunakan mesin metering screw (auger).

**Q2: Seberapa akurat hasil penimbangan?**  
A2: Presisi rata-rata sekitar 1–2g (tergantung ukuran unit dan aliran material).

**Q3: Berapa lama masa garansi?**
