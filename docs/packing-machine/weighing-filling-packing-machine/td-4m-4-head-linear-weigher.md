## 4. Operation Process
1. Load one or more materials to be packaged into the top storage hoppers respectively.
2. Set the target weight, batching ratio (if mixing is needed), and vibration frequency parameters on the touch screen.
3. The four feed chutes simultaneously or alternately feed material into their corresponding weighing hoppers via stepless vibration.
4. The mainboard monitors the weight of each hopper in real-time and stops feeding once the target is reached.
5. Upon receiving the discharge signal, the respective weighing hoppers open simultaneously or sequentially to release materials into the bag/container.
6. After one discharge, the system automatically loops back to start the next weighing cycle.
