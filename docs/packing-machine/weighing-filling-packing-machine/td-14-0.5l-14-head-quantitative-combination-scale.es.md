## 4. Proceso de Operación
1. Encienda el equipo y cargue la receta correspondiente del producto (peso, amplitud de vibración, etc.) mediante la pantalla táctil.
2. El material cae en la bandeja principal vibratoria central mediante el elevador de cubos y se distribuye uniformemente a las 14 bandejas vibratorias lineales exteriores.
3. Al pasar por tolvas amortiguadoras, el material se almacena temporalmente en 14 tolvas de pesaje de alta precisión.
4. La placa principal modular computa las permutaciones y combinaciones de los pesos de las 14 tolvas en milisegundos.
5. El sistema selecciona automáticamente las tolvas cuya suma sea la más precisa (error controlado dentro de 0.1~1g).
6. Las tolvas seleccionadas abren instantáneamente sus compuertas para descargar, completando una dosis increíblemente precisa, y se reinicia automáticamente.
