### I. Обзор продукта
* **Категория продукта**: Промышленная полностью автоматическая машина для тиснения с рулонов и выдавливания (машина для печати бейджей)
* **Сценарии применения**: Широко используется для производства лент, аксессуаров для одежды, подарочной упаковки, художественных мастерских и предприятий по печати бейджей. Идеально подходит для непрерывного тиснения с рулонов горячей фольгой и выдавливания на тканевых лентах, рулонах шелковых лент, рулонах подарочных лент, бейджах и рулонах этикеток.
* **Основные функции**: Использует передовую систему подачи и намотки с рулонов, применяя нагревательные пластины (штампы) и фольгу для выполнения чёткого, стойкого металлического тиснения или выдавливания. Стандартная комплектация обрабатывает одну ленту за раз, с возможностью настройки для одновременной обработки 2, 3 или более лент. Может быть интегрирована с опциональным фотоэлектрическим датчиком для точной печати и позиционирования рулонов этикеток.

### II. Ключевые преимущества
1. **Полностью автоматическая система с рулонов**: Безупречно интегрирует автоматические механизмы подачи и намотки, значительно снижает ручное вмешательство и повышает производительность.
2. **Настройка многополосности**: Хотя стандартная модель обрабатывает одну полосу ленты, она может быть глубоко настроена для одновременной обработки 2, 3 или нескольких лент с целью масштабирования массового производства.
3. **Высокоточная позиционировка (по запросу)**: Может быть оснащена высокочувствительным фотоэлектрическим датчиком для точного отслеживания и позиционирования при печати рулонов этикеток.
4. **Многофункциональное тиснение и выдавливание**: Использует индивидуальные нагревательные пластины (штампы) и фольгу для создания премиум-эффектов металлического блеска или тактильного выдавливания на плоских текстильных материалах.
5. **Прочный промышленный корпус**: Разработана с прочной конструкцией, стабильным однофазным контролем нагрева (2 кВт) и оптимальным размером нагревательной пластины 140 мм × 180 мм для стабильного, высококачественного вывода.

### VI. Процесс работы
1. **Загрузка материала**: Установите рулон ленты, бейджа или этикетки на вал размотки системы с рулонов.
2. **Установка фольги**: Пропустите фольгу для горячего тиснения через точные направляющие с натяжением и подачей над зоной тиснения.
3. **Установка и калибровка штампа**: Зафиксируйте индивидуальную нагревательную пластину (штамп) на нагревательной пластине, установите желаемую температуру и отрегулируйте позиционирование (при необходимости используйте опциональный фотоэлектрический датчик для рулонов этикеток).
4. **Автоматическое тиснение и выдавливание**: Машина автоматически опускает нагретую пластину, прижимая фольгу к поверхности ленты со скоростью 10–30 циклов в минуту, формируя стойкий, чёткий рисунок.
5. **Намотка рулона**: Завершённая тиснёная лента или бейдж автоматически протягивается и аккуратно наматывается обратно на вал намотки.
