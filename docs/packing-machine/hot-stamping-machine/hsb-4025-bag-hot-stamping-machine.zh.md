### 六、工作流程
1. **模具与烫金箔安装**：将定制烫金模版（冲头）牢固安装于400×250mm加热板上，并将烫金箔穿过导向装置。  
2. **袋体定位**：将纸袋放置于定制工装板上，确保平整且位置准确对齐。  
3. **安全启动**：启动烫印循环（可选光幕与亚克力护罩处于激活状态，保障操作员安全）。  
4. **气动/液压压印**：加热板在1T气动压力（或可选2T液压压力）作用下下降，将烫金箔压印至袋面。  
5. **成品取出**：压印完成后加热板自动回位，取出已烫印完成的定制品牌购物袋，准备后续包装。
