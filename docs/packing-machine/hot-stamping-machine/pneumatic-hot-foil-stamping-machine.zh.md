### 四、销售建议与常见问题解答（FAQ）

#### **销售建议**
* **按产品尺寸选型**：小钱包和皮革标签推荐使用GP-180或GP-210；中大型平面表面烫印推荐选用GP-300或GP-350。
* **定位精度与自动化升级建议**：对高定位精度有要求的客户，推荐配置“微调工作台”；追求高效批量生产与省力的客户，推荐“气动滑台”或“伺服滑台”。
* **配套准备提醒**：提醒客户，气动烫印机在收货后需连接匹配的空气压缩机才能正常运行。

### 六、工作流程
1. **气源与电源连接**：将机器连接至空气压缩机以保证稳定气压，并插入对应电源插座。
2. **模具与箔片安装**：将定制烫印板安装至加热板（或蜂窝板）上，并正确穿引烫印箔片。
3. **参数与定位调整**：设定工作温度与烫印时间，利用微调工作台调节产品与烫印板至最佳对位状态。
4. **双按钮安全启动**：将产品放置于工作台（或通过可选气动/伺服滑台送入），同时按下两个按钮启动设备。
5. **气动压印与取件**：气动压头自动下降完成烫印后回退，取出成品进行质量检查并进入后续包装环节。
