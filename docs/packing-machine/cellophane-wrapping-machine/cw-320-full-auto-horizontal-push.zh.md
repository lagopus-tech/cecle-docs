## 1. 产品概述
*   **产品类别**：全自动玻璃纸三维透明膜包装机 / 烟盒包装机。
*   **应用场景**：广泛应用于医药、食品、保健品、化妆品、文具、音像制品等行业各类盒装物品的单件自动包装。
*   **核心功能**：
    *   **高效包装**：采用全自动平推式结构，支持连续高速运行，显著提升包装效率。
    *   **精美成型**：采用BOPP薄膜卷料，对矩形物品实现紧贴式三维透明膜包装，封口整齐美观。
    *   **多功能配置**：支持卷膜运行，可选配防伪易拉线装置，提升产品档次和防伪能力。

## 2. 核心优势
1.  **高效平推驱动**：全自动平推式设计遵循科学运动轨迹，专为长时间、高负荷连续运行而打造。
2.  **灵活定制**：模具根据客户盒子尺寸精密定制。更换模具过程快速简便，在适应多种规格时最大限度减少停机时间。
3.  **多点温控技术**：兼容**点烫**与**六面烫**功能，确保包装薄膜紧贴盒体，无气泡、无褶皱。
4.  **智能人机界面**：采用PLC和WEINVIEW触摸屏控制，具备全面的自诊断和实时报警功能。
5.  **稳定机械联动**：采用一系列重载凸轮与连杆机械传动结构，结构坚固、维护成本低、使用寿命长。

## 6. 工作流程
1.  **上电自检**：连接220V电源和空压机，然后打开主开关。
2.  **温度设置**：在触摸屏上设置烫板温度，等待系统预热至目标值。
3.  **安装薄膜**：安装薄膜卷和易拉线，确保薄膜正确穿过所有张力辊并对齐。
4.  **物料输送**：将盒子放置在输送带上；传感器检测到盒子后触发推料动作。
5.  **循环运行**：平推裹包 -> 薄膜切断 -> 侧面折叠封口 -> 整形点烫 -> 六面烫。
6.  **成品输出**：包装精美的成品自动推出至出料口。
