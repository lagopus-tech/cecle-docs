# 玻璃纸包装机选型指南与产品概述

## 一、什么是玻璃纸包装机？

玻璃纸包装机，又称外包装机或“烟盒包装机”，使用BOPP薄膜（可选配易拉线）为刚性长方体物品提供紧密的三维包装。

*   **核心价值：** 防潮、防伪、美观提升及成本节约（无需热收缩通道，避免对热敏内容物造成损伤）。
*   **目标行业：** 广泛用于香烟、茶叶盒、化妆品、香水、药品、保健品、文具及小礼品盒包装。

### 核心工作流程
与传统全自动机型相比，我们的设备采用**模块化创新**设计，将整机分为两个独立部分：**裹包单元**（前端）和**折叠单元**（后端），灵活性更高。

#### 1. 裹包单元（前端工序）
完成薄膜包裹、裁切及初封：人工将BOPP薄膜围绕产品360°包裹。设备自动裁切薄膜并热封切口，完成半成品包装。
*   **代表机型：** `ACW-88`、`ACW-88A`

#### 2. 折叠单元（后端工序）
完成侧面折叠与封口：将已完成360°包裹的半成品盒放入本单元，设备自动完成剩余两端面的折叠、折角及热封，实现三维立体包装。
*   **代表机型：** `3DP-88`、`A3DP-88`

### 产品命名规则
1.  **基于ACW-88裹包单元：**
    *   **T** = 易拉线装置
    *   **F** = 废膜收集装置
    *   **D** = 点封加热装置
2.  **基于3DP-88折叠单元：**
    *   **A** = 自动（气动驱动）
    *   **H** = 加热板（上/下加热）
    *   **D** = 点封加热装置

## 三、常见问题解答

### 1. 耗材
*   **问1：可以使用普通PE/POF薄膜吗？**
    *   **答：** 不可以。必须使用**BOPP热封薄膜**。
*   **问2：推荐薄膜厚度是多少？**
    *   **答：** 21μm - 25μm为最佳。
*   **问3：易拉线如何粘附？**
    *   **答：** 易拉线带有热激活胶层；机器张力器将其送至薄膜上，在热封过程中完成粘合。

### 2. 调节与质量
*   **问4：为什么会出现褶皱？**
    *   **答：** 通常是由于温度过低、运行速度过快或薄膜张力不均匀所致。
*   **问5：“点封”和“六面热封”有什么区别？**
    *   **答：** 点封是在折叠过程中固定形状（防止移位），而六面热封是在上下两面实现最终的“镜面效果”。

### 3. 硬件与选型
*   **问6：气动机型需要空压机吗？**
    *   **答：** 需要，一台小型静音无油空压机（0.6-0.8MPa）即可满足要求。
*   **问7：哪些机型需要模具？**
    *   **答：** ACW系列和A3DP-88A无需模具。3DP-88及工业系列通常需要定制模具。
