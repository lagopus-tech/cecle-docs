> La **CW-320** es una máquina envolvedora 3D de celofán totalmente automática de empuje plano, diseñada para el envasado de alta velocidad y ajustado con película BOPP de artículos en caja. ### Preguntas Frecuentes (FAQ):
*   **P: ¿La CW320 requiere moldes?**
    *   **R:** Sí, se requieren moldes personalizados. Diferentes tamaños de caja necesitan diferentes moldes.
*   **P: ¿Es difícil cambiar los moldes?**
    *   **R:** La máquina está diseñada con un mecanismo de posicionamiento rápido; reemplazar un juego completo de moldes toma solo de 20 a 30 minutos.
*   **P: ¿Cuál es el rango de tamaño de caja para la CW320?**
    *   **R:** Largo: 60–280mm, Ancho: 50–160mm, Alto: 15–60mm.
*   **P: ¿Puede envolver cajas de diferentes tamaños?**
    *   **R:** Sí. Dentro del rango de tamaño admitido, simplemente reemplace los moldes personalizados correspondientes para lograr "una máquina con múltiples usos".
*   **P: ¿La CW320 puede equiparse con envasado por calentamiento de seis caras?**
    *   **R:** Sí, la función de calentamiento (planchado) de seis caras se puede instalar.
*   **P: ¿Qué otras funciones se pueden añadir a la CW320?**
    *   **R:** Se puede instalar una cinta transportadora en la CW320 como opción.
*   **P: ¿Cuáles son los requisitos para el compresor de aire?**
    *   **R:** Un compresor de aire industrial estándar es suficiente, utilizado principalmente para proporcionar presión neumática estable para accionar los actuadores.

## 6. Flujo de Trabajo
1.  **Autocomprobación de Encendido**: Conecte el suministro eléctrico de 220V y el compresor de aire, luego encienda el interruptor principal.
2.  **Configuración de Temperatura**: Configure las temperaturas de la placa de planchado en la pantalla táctil y espere a que el sistema se precaliente a los valores objetivo.
3.  **Instalación de la Película**: Instale el rollo de película y la cinta de rasgado, asegurándose de que la película pase correctamente alineada por todos los rodillos de tensión.
4.  **Alimentación de Material**: Coloque las cajas sobre la cinta transportadora; el sensor activa el empuje una vez que se detecta una caja.
5.  **Operación Cíclica**: Envoltura por empuje plano -> Corte de película -> Sellado de pliegues laterales -> Planchado por puntos de forma -> Planchado de seis caras.
6.  **Salida del Producto Terminado**: Los productos terminados bellamente envueltos se empujan automáticamente hacia el puerto de descarga.
