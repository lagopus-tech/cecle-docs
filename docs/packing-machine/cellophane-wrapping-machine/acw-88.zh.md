### 六、标准操作流程
1. **预热**：打开电源，设定目标温度，等待加热板升温。
2. **裹膜与切膜**：手动拉出薄膜包裹盒体长边，使用电热丝切刀裁切薄膜。
3. **长边封口**：将盒体上薄膜重叠的接缝处置于加热板上，压平封合。
4. **手动折角**：将盒体两端多余的薄膜整齐折叠，如同包装礼盒一样。
5. **侧面封口**：将折叠好的侧边逐一贴靠加热板，完成最终封合。
