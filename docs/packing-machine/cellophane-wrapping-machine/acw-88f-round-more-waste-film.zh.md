### **六、工作流程**

1. **安装与上料**：首先完成机器组装，按说明书顺序装入包装膜卷和易撕带。
2. **切刀调节与定位**：根据包装盒宽度，手动移动并锁定切刀至合适位置。
3. **废料收卷设置**：引导裁切后的多余边膜进入自动废膜收卷装置并固定。
4. **温度设定**：通电后设定所需包装温度（建议 110–130°C），等待铝板加热至设定值。
5. **裹包与封口**：向前拉膜，使用热丝切断，将盒子放置于工作台进行初步热封。
6. **成品完成**：像包礼物一样折叠盒子两侧的膜边，并对侧边进行最终热封，获得整齐美观的成品包装。
