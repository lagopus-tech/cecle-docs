### **六、工作流程**

1. **安装与装膜**：首先完成机器组装。按照说明书依次装入包装薄膜卷和易拉线。
2. **切刀调节与定位**：根据包装盒的宽度，手动移动并将切刀锁定到合适位置。
3. **废料收卷设置**：将裁切后的多余膜边引导并固定到自动废膜收卷机构上。
4. **温度设定**：打开电源，设定包装所需温度（建议110-130°C）。等待铝板加热至预设值。
5. **包裹与热封**：向前拉出薄膜，使用热丝进行切割，然后将盒子放置在工作台上进行初步热封。
6. **成品完成**：像包装礼品一样将盒子两侧的膜边折叠，并在侧面进行最终热封，即可获得整洁美观的成品包装。
