# 产品手册：A3DP-88H 气动六面熨烫玻璃纸裹包机

> **核心摘要：** A3DP-88H 是一款半自动、电气动玻璃纸三维裹包机，专为化妆品、药品、保健品、茶叶和烟草行业的方形盒装产品设计。配备上下双加热板，对盒体六个面进行熨烫，消除薄膜松弛和气泡，实现镜面般紧致效果，包装速度可达15–20次/分钟，适用盒型尺寸最大为220 × 140 × 110 mm。

### 一、产品概述
*   **产品类别：** 电气动三维裹包机 / 香烟包装机 / 玻璃纸裹包机
*   **目标应用：** 专为高端化妆品、药品、保健品、茶叶和香烟等方形盒装产品设计。适用于对薄膜贴合度和紧致度有极致要求的品牌。
*   **核心功能：** 采用电气动控制系统，超越传统的折叠封口裹包方式。配备特别设计的**上下大面积加热板**，对盒体顶面和底面进行整面熨烫（折边热封），实现完美平滑的六面裹包效果。

### 二、核心优势
1.  **完美六面整面熨烫：** 不同于仅封合侧面的传统机型，本机对盒体六个面全部进行熨烫，彻底消除薄膜松弛和气泡，实现紧致、镜面般光滑的效果。
2.  **电气动驱动：** 电气控制与气动压力相结合（需外接空压机），提供更均匀的封合压力及更精准的机械联动，显著提升运行稳定性。
3.  **大盒型兼容性：** 支持最大**220 × 140 × 110 mm**的盒型尺寸，满足市面上大多数中大型礼盒的需求。
4.  **稳固的立式机身：** 63 kg加固底盘配合符合人体工学的1.21米操作高度，确保长时间连续运行的稳定性。
5.  **无缝工艺衔接：** 可与ACW-88系列切膜机配套使用，完成从精准切膜到完美封合的完整工艺流程。

### 六、工作流程

1.  **切膜：** 使用**ACW-88 / ACW-88A**切膜机，根据盒体尺寸拉出并精准裁切薄膜。
2.  **裹膜：** 手动或借助辅助工具，将裁切好的薄膜包裹在盒体四周。
3.  **侧面封合：** 将盒体推入A3DP-88H，对侧边进行热封，形成牢固的**筒状套膜**。
4.  **端面折角：** 机器自动（或辅助）将盒体两端面的薄膜折角。
5.  **六面整面熨烫（核心步骤）：** 盒体通过上下加热区域时，顶面和底面受到整面压合（折边热封），使薄膜紧密贴合盒体。
6.  **成品输出：** 裹包完成的产品输出——光滑、无褶皱、无气泡。
