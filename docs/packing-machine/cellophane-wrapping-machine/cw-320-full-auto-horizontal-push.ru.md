## 1. Обзор продукта
*   **Категория продукта**: Полностью автоматическая целлофановая трехмерная оберточная машина / Машина для упаковки сигаретных пачек.
*   **Области применения**: Широко используется для автоматической упаковки отдельных изделий в коробках в таких отраслях, как фармацевтика, пищевая промышленность, товары для здоровья, косметика, канцелярские товары и аудиовизуальная продукция.
*   **Основные функции**:
    *   **Высокоэффективная упаковка**: Использует полностью автоматическую конструкцию с плоским толкателем, обеспечивающую непрерывную высокоскоростную работу, что значительно повышает эффективность упаковки.
    *   **Изысканное формование**: Использует рулоны BOPP-пленки для достижения плотной, трехмерной обертки прямоугольных изделий, создавая аккуратные и элегантные швы.
    *   **Многофункциональные конфигурации**: Поддерживает работу с рулонной пленкой и может быть дополнительно оснащена устройством для нанесения защитной ленты разрыва, повышая класс продукта и его защитные свойства.

## 2. Ключевые преимущества
1.  **Высокоэффективный привод с плоским толкателем**: Полностью автоматическая конструкция с плоским толкателем следует научной траектории движения, рассчитана на длительную работу с высокими нагрузками в непрерывном режиме.
2.  **Гибкая настройка**: Пресс-формы изготавливаются с высокой точностью под размеры коробок клиента. Процесс замены пресс-форм быстрый и простой, что минимизирует простои при адаптации к нескольким спецификациям.
3.  **Технология многоточечного контроля температуры**: Совместима с функциями **точечной проглажки** и **шестисторонней проглажки**, обеспечивая плотное прилегание упаковочной пленки к коробке без пузырей и складок.
4.  **Интеллектуальный HMI**: Управление на базе ПЛК и сенсорного экрана WEINVIEW с функциями комплексной самодиагностики и оповещения в реальном времени.
5.  **Стабильная механическая кинематика**: Использует серию тяжелых кулачково-рычажных механических передач, обеспечивающих прочную конструкцию, низкие затраты на обслуживание и длительный срок службы.

### Часто задаваемые вопросы (FAQ):
*   **Вопрос: Требуются ли для CW320 пресс-формы?**
    *   **Ответ:** Да, требуются индивидуальные пресс-формы. Для разных размеров коробок нужны разные пресс-формы.
*   **Вопрос: Сложно ли менять пресс-формы?**
    *   **Ответ:** Машина оснащена механизмом быстрого позиционирования; замена полного комплекта пресс-форм занимает всего 20–30 минут.
*   **Вопрос: Каков диапазон размеров коробок для CW320?**
    *   **Ответ:** Длина: 60–280 мм, Ширина: 50–160 мм, Высота: 15–60 мм.
*   **Вопрос: Может ли машина упаковывать коробки разных размеров?**
    *   **Ответ:** Да. В пределах поддерживаемого диапазона размеров достаточно заменить соответствующие индивидуальные пресс-формы, чтобы добиться «одна машина — множество применений».
*   **Вопрос: Можно ли оснастить CW320 шестисторонней термоупаковкой?**
    *   **Ответ:** Да, функция шестистороннего нагрева (проглажки) может быть установлена.
*   **Вопрос: Какие еще функции можно добавить к CW320?**
    *   **Ответ:** На CW320 может быть установлен конвейерная лента в качестве опции.
*   **Вопрос: Каковы требования к воздушному компрессору?**
    *   **Ответ:** Подойдет стандартный промышленный воздушный компрессор, который в основном используется для обеспечения стабильного пневматического давления для привода исполнительных механизмов.

## 6. Технологический процесс
1.  **Самопроверка при включении**: Подключите источник питания 220 В и воздушный компрессор, затем включите главный выключатель.
2.  **Настройка температуры**: Установите температуры нагревательных плит на сенсорном экране и дождитесь предварительного нагрева системы до целевых значений.
3.  **Установка пленки**: Установите рулон пленки и ленту разрыва, убедившись, что пленка правильно проходит через все натяжные ролики.
4.  **Подача материала**: Поместите коробки на конвейерную ленту; датчик запускает толкатель при обнаружении коробки.
5.  **Циклическая операция**: Обертка плоским толкателем -> Резка пленки -> Загибка боковых сторон -> Точечная проглажка формы -> Шестисторонняя проглажка.
6.  **Вывод готовой продукции**: Красиво упакованные готовые изделия автоматически выталкиваются к разгрузочному отверстию.
