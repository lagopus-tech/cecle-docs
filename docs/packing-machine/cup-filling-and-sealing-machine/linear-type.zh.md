### 一、产品概述
* **产品类别**：工业级全自动直线式填充与封口系统（直线自动杯装填充与封口机）
* **应用场景**：专为大型食品加工企业、大型咖啡连锁工厂及饮料制造商设计，适用于各类咖啡胶囊（K-Cup/Nespresso）、酸奶、饮品、调味粉、茶叶及颗粒状产品的连续化生产线。
* **核心功能**：采用直线同步输送结构，实现多工位同时进行杯体投放、UV杀菌、多头精密填充、自动盖子放置/膜材封口、恒温热封以及成品输出。具备高度可定制性，可根据客户杯型及产能需求，支持4至16条生产线同步作业。

### 二、核心优势
1. **超大产能配置**：采用直线同步填充技术，标准提供4/6/8通道选项，支持定制10/12/14/16通道，显著缩短批次生产周期。
2. **高度定制化模具**：所有工位模具均根据客户提供样品杯尺寸量身定制，即使在高速运行下也能确保精准填充与密封效果。
3. **多样化的封口解决方案**：
    * **包装形式**：支持“预切盖”放置或“卷膜”拉伸裁切。
    * **成品匹配**：可选配二次按压盖装置（盖+密封膜），满足高端产品包装需求。
4. **功能集成化**：
    * **氮气保鲜**：可在填充前后加装氮气冲洗系统，有效保护对氧气敏感的产品（如咖啡）的新鲜度。
    * **智能编码**：可在卷膜封口位置加装条码机，同步打印生产日期、批号或条形码。
5. **安全与洁净**：配备全封闭防护罩，有效防止异物进入，保障生产环境清洁与操作人员安全。

### 六、工作流程
1. **自动杯体投放**：杯体堆叠后装入设备，自动送入定制模具工位。
2. **（可选）杀菌与氮气冲洗**：工位内进行UV消毒，填充前后注入氮气以置换空气。
3. **同步精密填充**：多头填充泵同步注入物料，实现高速高精度作业。
4. **膜材/盖子放置与编码**：自动完成膜材贴附（预切/卷膜）或加盖；若使用卷膜，则同步完成在线编码。
5. **高速热封**：恒温压合，实现杯口平整紧密封合。
6. **自动成品输出**：成品沿轨道自动排出，进入后续包装或装箱工序。
