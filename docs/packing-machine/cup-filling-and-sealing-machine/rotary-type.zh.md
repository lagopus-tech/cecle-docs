### 一、产品概述
* **产品类别**：工业级全自动旋转式填充与封口设备（全自动旋转杯体填充封口机）。  
* **应用场景**：广泛适用于咖啡胶囊（K-cup/Nespresso）、酸奶、果汁、饮料、酱料（如鹰嘴豆泥）、调味粉、茶叶及各类颗粒状食品。是咖啡烘焙厂、乳制品加工厂、中央厨房和食品包装企业的理想生产线核心设备。  
* **核心功能**：采用高精度旋转分度台，集成自动落杯、UV杀菌、精准容积计量填充、自动盖子放置/膜材封口、恒温热封以及成品自动排出等功能。支持深度定制，可根据不同物料特性与容器杯型进行个性化调整。

### 二、核心优势
1. **深度模具定制**：所有设备模具均根据客户提供的实际杯体尺寸精确制造，确保填充与封口过程完美贴合，无缝对接现有包装容器。
2. **灵活封口方案**：支持自动预切盖放置与封口，或卷膜自动拉伸、切割与封口。卷膜方案可加装色带编码机，实现生产日期、批次号或代码的在线打印。
3. **灵活产能配置**：CF-1采用单工位填充，适合研发及小批量生产；CF-2采用双工位填充，产能翻倍，满足规模化量产需求。
4. **可选功能配置**：
    * **安全防护罩**：全封闭防尘/安全护罩，保障生产环境洁净与操作人员安全。
    * **氮气置换保鲜功能**：专为对氧气敏感的产品（如咖啡）设计，填充后注入氮气，显著延长产品保质期。
5. **多材质兼容性**：通过更换计量填充系统（活塞泵/螺杆式填充器/量杯式填充器），轻松适配液体、粉末、颗粒等多种形态物料。

### 四、销售建议与常见问题解答（FAQ）
#### **销售建议**
* **需求确认要点**：沟通时需重点确认：1. 具体杯体尺寸；2. 是否需要氮气保鲜功能；3. 偏好预切盖还是卷膜封口；4. 是否需要在线打印生产日期。

    * A：可以，我们可在封口工位上方安装色带编码机，实现封口与日期/代码打印同步完成。

### 六、工作流程
1. **自动落杯**：杯体堆叠后装入机器，自动送入定制模具工位。
2. **（可选）杀菌与氮气置换**：杯内进行UV消毒，填充前后执行氮气保护。
3. **精准填充**：根据物料特性，计量装置将产品精确注入杯中。
4. **盖子放置与编码**：自动取用预切盖或牵引卷膜；若选用卷膜，则同步完成色带日期打印。
5. **恒温封口**：加热板下压，实现杯口平滑紧密的热封。
6. **自动出料**：成品自动排出并输送至收集区，进入下一工序。
