> **核心摘要：**  
> **QDFW-125** 是一款多功能气动超声波软管封尾机，专为化妆品、制药、食品和化工行业的中小型企业及实验室设计。适用于牙膏、洗面奶、胶水等膏体及浆料产品，利用冷超声波振动实现牢固、无热量的封口，不会烧焦热敏性成分。主要特点包括多材料兼容性（铝管、塑料管、复合管）、实时数字频率监测、紧凑的台式/立式设计以及同步日期压印。

---

### 1. 产品概述
* **类别：** 包装机械 / 软管封尾设备
* **应用：** 广泛应用于化工、日化、食品、制药等行业。适用于膏体及浆料产品（如牙膏、洗面奶、胶水等）软管的封尾。
* **核心功能：** 利用高频超声波振动原理，对铝管、塑料管或复合管的管尾进行封口，同时完成生产日期或批号的打印。

### 2. 核心优势
1. **多材料兼容性：** 适用于铝管及多种复合管。封口美观牢固，无烧焦、无烫伤。
2. **灵活布局设计：** 可选水平（台式）或垂直封尾方向，完美适配不同工作台高度。
3. **智能数字监控：** 配备高精度数显仪表，实时显示工作频率和压力，操作直观，初学者也能快速上手。
4. **高性价比：** 工厂直供价格，结构紧凑，占地面积小，非常适合中小企业或实验室小批量生产。
5. **封口压印一体化：** 封尾时自动压印日期块。字迹清晰、防伪、永久。

### 6. 工作流程
1. **准备工作：** 连接220V电源和0.4-0.6 MPa气源，将超声波频率调整至正常范围。
2. **手动上管：** 将灌装好的软管放入机器的工作夹具中。
3. **触发封尾：** 按下启动按钮或踩下脚踏开关，封口模具闭合。
4. **超声波熔接：** 机器瞬间发出超声波，使管口内壁熔化，同时将日期块压印在管尾上。
5. **冷却出料：** 模具保压约0.5 - 1秒完成定型，然后自动打开，即可取出成品。
