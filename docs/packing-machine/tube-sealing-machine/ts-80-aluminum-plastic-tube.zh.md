# 产品规格书：软管封尾机（TS-80）

![TS-80 软管封尾机](https://cdn.shopify.com/s/files/1/0010/4982/1242/files/17834930212181.png?v=1783493300)

> **核心摘要：**  
> **TS-80** 是一款半自动气动软管封尾机，专为化妆品、制药、食品和化工行业的铝管冷折边及尾部压合而设计。非常适合处理膏体、软膏、牙膏和乳霜等产品，其特点是采用高效的双工位设置（左侧用于压合/折叠，右侧用于日期/批号压印），通过便捷的气动脚踏板进行操作。生产能力为10-20支/分钟，并支持定制水平或垂直封尾方向，为中小型工厂和实验室提供耐用、专业的包装解决方案。

---

### 1. 产品概述
* **类别：** 包装机械 / 气动软管封尾机
* **应用：** 广泛用于化工、化妆品、制药和食品行业中铝管的封尾。特别适用于软膏、牙膏和化妆品乳霜等产品的加工。
* **核心功能：** 专为铝管设计，实现自动管尾折叠/封尾以及生产日期/批号压印。

---

### 2. 核心优势
1. **高效双工位分工：** 配备独立的左右工作台。左侧工位负责管尾压合/折叠，右侧工位负责日期压印，确保流程清晰、精简。
2. **气动脚踏板控制：** 只需踩下气动脚踏开关即可触发。相比纯手动型号更省力，相比全自动型号具有更大的操作灵活性。
3. **可选封尾方向：** 支持定制水平或垂直封尾方向，以满足不同产品包装的美观要求。
4. **数字化智能监控：** 配备高精度数字显示仪表，实时监控工作参数，确保封尾质量的一致性。
5. **工业级耐用性：** 结构坚固，维护简单，是中小型工厂和实验室的首选设备。

#### 4.2 常见问题解答（FAQ）
* **问：这台机器可以封塑料管吗？**
    * 答：不可以。TS-80 是专为铝管设计的冷折边封尾机。塑料管需要加热或超声波类型的设备。
* **问：压印字符可以更换吗？**
    * 答：可以。模具字码块是可拆卸和可更换的，方便调整生产日期和批号。

### 6. 工作流程
1. **准备：** 连接电源和气源。根据铝管的材质和厚度，在数字显示屏上调整工作参数。
2. **放置物料：** 操作员将灌装好的铝管放入相应的模具槽中。
3. **触发加工：**
    * **第一步：** 踩下脚踏开关，触发左侧气缸，完成铝管的**尾部压合和折叠**动作（多层折叠）。
    * **第二步：** 将折叠好的管子移至右侧，再次触发开关。右侧工位将完成**日期码压印**。
4. **成品收集：** 取出成品，检查封尾的平整度和压印字符的清晰度，然后进入下一个循环。
