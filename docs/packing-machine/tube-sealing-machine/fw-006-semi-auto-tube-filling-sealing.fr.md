## VI. Processus de Travail
1. **Chargement Manuel** : Les opérateurs insèrent manuellement les tubes dans les gabarits du plateau rotatif.
2. **Marquage (Orientation)** : Le capteur détecte le code couleur du tube, et le moteur rotatif calibre automatiquement la direction de scellage.
3. **Remplissage** : La pompe à piston exécute automatiquement le remplissage quantitatif ; la tête de remplissage est dotée d'une conception anti-goutte.
4. **Scellage** : Le système à ultrasons excite des vibrations haute fréquence pour souder instantanément la paroi interne de la queue du tube.
5. **Codage** : Le moule de scellage estampe simultanément la date de production ou le numéro de lot.
6. **Coupe** : Le couteau automatique coupe l'excédent de matière irrégulier à la queue du tube.
7. **Évacuation** : Le produit fini est automatiquement éjecté du gabarit et tombe dans la goulotte de collecte.
