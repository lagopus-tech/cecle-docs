## 4. 操作流程
1. 根据使用场景选择合适的供水方式（连接纯净水桶、水泵或市政自来水）；
2. 将即溶咖啡粉或其他粉状原料加入机器料箱，并将适配尺寸（Φ73–Φ74mm）的纸杯放入杯仓；
3. 插入指定类型的硬币，或通过操作面板选择所需饮品；
4. 机器自动落杯、冲泡并加热，完成后取出香气四溢的即溶咖啡。
