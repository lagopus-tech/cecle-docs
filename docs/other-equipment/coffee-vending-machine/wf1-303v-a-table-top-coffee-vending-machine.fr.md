## 4. Processus d'opération
1. Sélectionner la méthode d’alimentation en eau appropriée selon le contexte d’utilisation (connexion à un seau d’eau purifiée, pompe ou robinet municipal) ;
2. Ajouter la poudre de café instantané ou tout autre matériau brut en poudre dans la boîte à matière première, et charger des gobelets en papier de taille adaptée (Φ73-Φ74 mm) dans le compartiment à gobelets ;
3. Insérer la pièce requise ou sélectionner la boisson désirée via le panneau de commande ;
4. La machine distribue automatiquement le gobelet, prépare et chauffe l’eau. Une fois terminé, retirer le café instantané aromatique.
