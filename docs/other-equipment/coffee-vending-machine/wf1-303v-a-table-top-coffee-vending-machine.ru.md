# WF1-303V-A Настольный автомат для продажи кофе

> **Основная суть:**  
> WF1-303V-A — компактный настольный автомат для приготовления напитков, предназначенный для приготовления различных порошковых напитков, таких как кофе и молочный чай. Идеально подходит для офисов, мини-магазинов, интернет-кафе и других небольших общественных мест. Обладает гибкими вариантами подачи воды, интеллектуальной системой автоматического выдачи стаканчиков (до 60 шт.), вместительным баком для воды объёмом 8 л и резервуаром горячей воды на 1,6 л. Работает легко с монетами или кнопками управления. Этот 1000 Вт аппарат обеспечивает надёжное, простое в использовании и эффективное решение для самодействующих горячих напитков.

## 2. Ключевые преимущества
1. Разнообразные способы подачи воды: поддержка подключения сверху/снизу к бутылке с водой, всасывание насосом, подключение к центральному водопроводу.
2. Высокая совместимость: подходит для различных порошковых сырьевых материалов, чтобы удовлетворить разнообразные потребности в напитках.
3. Интеллектуальная система выдачи стаканчиков: опциональная 3-монетная система распознавания (автоматическая выдача стаканчиков), оснащена отсеком для хранения до 60 стаканчиков (подходит для стаканчиков объёмом 6,5 унций или 9 унций, диаметром Φ73–Φ74 мм).
4. Большой объём: оснащён баком для воды объёмом 8 л + резервуаром горячей воды на 1,6 л, что позволяет непрерывно выпускать напитки.
5. Гибкая адаптация к напряжению: поддерживает 220 В / 50 Гц и 110 В / 60 Гц, что позволяет использовать в разных странах и регионах.
6. Прямая поставка с завода: стабильное и надёжное качество.
7. Компактная настольная конструкция: умеренные размеры, малая площадь, удобно размещать и перемещать.
8. Подключение «вилка в розетку»: простое и удобное использование без сложного обучения.

## 4. Процесс эксплуатации
1. Выберите соответствующий способ подачи воды в зависимости от условий использования (подключите к бутылке с очищенной водой, насосом или центральным водопроводом);
2. Добавьте порошковое сырьё (например, молотый кофе или другой порошок) в бункер для материала, загрузите бумажные стаканчики нужного размера (диаметром Φ73–Φ74 мм) в отсек для стаканчиков;
3. Вставьте требуемую монету или выберите нужный напиток через панель управления;
4. Автомат автоматически выдаёт стаканчик, заваривает напиток и нагревает воду. После завершения процесса возьмите ароматный готовый напиток.
