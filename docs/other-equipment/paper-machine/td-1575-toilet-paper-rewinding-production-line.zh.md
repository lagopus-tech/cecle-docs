## 二、核心优势
1. **PLC智能可编程控制系统：** 配备可升级的计算机编程系统，变频调速，自动电子刹车功能。全工序通过触摸屏设置参数，支持自动故障报警，操作门槛低。
2. **无芯卷绕成型技术：** 采用气柱成型技术，实现快速卷绕与紧凑美观的卷状结构。支持带芯与无芯双模式生产，灵活适应多样化产品线。
3. **新型尾部滑移与边角修整工艺：** 自动完成边角修剪、涂胶与封口一体化作业。成品保留10–15毫米纸尾，便于撕开，减少原材料浪费，降低生产成本。
4. **由紧到松的卷绕逻辑：** 采用渐进式张力控制逻辑（卷绕过程中由紧变松），防止长期储存时卷芯松动或脱落，确保产品存储稳定性优异。
5. **断纸自动停机保护：** 实时监控纸张状态，一旦发生断纸立即自动停机，最大限度减少材料浪费，保障高速运行稳定性。
6. **高精度打孔与压纹：** 采用螺旋打孔刀具，噪音低，打孔间距可调；搭配钢制-羊毛压纹辊，呈现清晰立体图案（可选加香装置）。
7. **气动供纸与张力调节：** 三层同步供纸框架，配备气动大卷提升机构。每层纸张均可独立调节张力，并具备点动穿纸模式，换卷操作简便安全。

## 四、操作流程
1. **供电与供气：** 连接三相380V电源及外部空压机，确保气压稳定在0.5Mpa。
2. **上料与穿纸：** 使用气动装置将大卷母卷安装至后部支架，完成穿纸操作，并为各层纸张配置张力参数。
3. **参数设定：** 在触摸屏上输入目标成品卷直径、打孔间距、生产速度及带芯/无芯模式；配置压纹与涂胶参数。
4. **自动卷绕生产：** 设备自动完成卷绕、打孔、压纹。达到目标直径后，自动进行边缘修整、涂胶封尾、排出成品卷，并自动复位进入下一循环。
5. **后处理：** 将产出的大卷输送至圆木锯切机进行单卷分切，再送入自动包装机完成最终包装与入库。

### 常见问题解答
**Q1：插电后能否立即开始生产？**  
A1：不能。本设备为气动辅助型，客户需自备空压机，确保提供0.5Mpa气压，并准备大卷母纸。

**Q2：能否生产无芯卫生纸卷？**  
A2：可以。设备内置无芯卷绕系统，可通过触摸屏直接切换带芯/无芯模式，无需额外改装。

**Q3：打孔间距是否可调？**  
A3：可以。打孔间距可在80–220mm和150–300mm两个范围内通过简单触摸屏参数调整，适配多种卷径规格。

**Q4：完整生产线还需哪些设备？**  
A4：TD-1575为主机，输出大卷。若需获得单卷产品，需搭配TD-BSP01圆木锯切机；如需自动化包装，则需增加TD-JZ自动包装机。
