# 自动指甲珠固定串珠机选型指南与产品概述

## 一、什么是自动指甲珠固定串珠机？
### 1.1 核心定义
自动指甲珠固定串珠机是广泛应用于服装、鞋类、皮革制品及家纺行业的专用自动化气动加工设备。该设备通过高频振动板自动分选并输送珠子与四爪钉，利用气缸产生的强大向下压力，将金属四爪钉从布料下方穿透至上方，并在上模中以圆形或特殊形状的珠子进行压紧锁定。此设备基本替代了传统手工串珠工艺，具有高效、耐用、美观以及优异的面料保护性能。

### 1.2 工作原理
整机运行依赖于两大核心系统的协同作用：**“气动压合 + 自动供料”**：
1. **自动供料：** 操作员将珠子倒入上方储料罐/料斗，四爪钉放入底部轨道。机器通过变频振动板自动分选并输送珠子和钉子至工作位。
2. **红外定位 + 气动压合：** 操作员使用红外标记对准布料上的目标位置与模具头对齐。踩下脚踏开关后，下缸推动四爪钉穿过布料向上运动，同时上缸（或上模）提供缓冲压合力，使钉脚弯曲，牢固咬住珠子（单次操作时间小于0.5秒）。

### 1.3 核心价值
- **极致效率：** 全自动供料系统，单头串珠速度高达每分钟150–180颗，大幅节省人力成本。
- **高穿透性 & 面料保护：** 工业级气动双缸提供平稳均匀的压力，轻松穿透多层厚牛仔布与真皮，同时有效保护娇嫩面料及脆弱珠子。
- **低操作门槛：** 配备数字显示屏或PLC智能触摸屏，新手易上手；分体式双/多脚踏控制设计，安全系数高。
- **高精度：** 红外定位辅助聚焦，彻底解决手工缝制常见的偏移、错位问题。

### 1.4 适用行业
- **服装制造：** 定制婚纱、街头风牛仔、重绣女装及童装。
- **鞋类与皮具：** 高端皮鞋鞋面装饰、奢侈包袋、机车皮具加工。
- **其他周边领域：** 家纺厂、蕾丝厂、手工艺品制造企业。

## 三、核心选型建议

### 3.1 按珠子形状（首要评估因素）
1. **纯标准圆珠：** 选择 **TD-198**（单头）或 **TD-198D**（双头）。其采用中心化物料分选优化设计，专为球形珠子打造，速度最快。
2. **包含异形/特殊形状（半圆、方形、五角星、尖头铆钉等）：** 必须选择 **TD-168**（单头）或 **TD-168D**（双头）。这些型号配备专用重型振动板、防堵合金导轨及缓冲保护模块，有效解决普通机型常见的卡料、压碎痛点。

### 3.2 按工艺复杂度与产能需求
- **单一规格连续作业：** 若预算有限或订单以单一尺寸/简单图案为主，**单头系列（198/168）** 已足够。
- **高频多规格交替 / 大量拼接：** 若服装频繁需要“大珠+小珠”或“圆珠+星形珠”的交替布局，强烈推荐 **双头系列（198D/168D）**。不仅免除频繁拆装模具/导轨的时间损耗，还能减少超过50%的人工操作时间，显著提升高利润订单的交付效率。

### 3.3 按面料厚度与材质
- 全系列标配 **500W（0.67HP）** 动力驱动与重型气缸。无论是单层薄雪纺、多层厚牛仔布、不平整硬皮革还是帆布，均能保持出色的穿透力与稳定性（远超市场上普通电动/手动机型表现）。

## 四、通用技术常见问答

### 4.1 电源与气源
**问：机器需要什么电压？是否需要空压机？**  
答：所有型号支持220V或110V宽电压（50~60Hz），可直接接入家用或工业用电。**必须自备空压机**，因机器下压动力来自高压气动缸。需外部稳定气源，工作压力0.5~0.6MPa（推荐小型静音空压机）。

### 4.2 模具更换与耗材
**问：换模是否复杂？是否需要专业技师？**  
答：更换极为简便，只需松开固定螺丝，即可在1–2分钟内完成上下模具的更换（适配4–12mm尺寸）。单人操作即可轻松完成调整。
**问：对珠子材料和四爪钉是否有要求？**  
答：我们建议使用塑料或ABS树脂环保珠。对于水钻、合金边、脆弱天然/玻璃珠，特殊珠机型（TD-168系列）可通过精确设定压合缓冲力与时间，避免压碎。四爪钉需匹配底部轨道宽度。若需穿透极厚材料而延长钉身，请提前确认轨道弹簧夹的兼容性。

### 4.3 故障排除（卡料问题）
**问：机器是否会频繁出现珠子卡料或供料失败？**  
答：只要使用无明显毛刺的标准尺寸珠子，圆珠机型（198系列）极少卡料。针对特殊珠子，TD-168系列配备反向识别筛网，可自动识别倾斜或方向错误的特殊珠子并将其推回，有效保障高连续运行率。

## 五、全面定制化能力

### 5.1 专属“一对一”定制调校复杂特殊珠子
由于特殊珠子形状多样（金字塔、大方块、不规则水钻等），我们强烈建议客户在购买前**寄送样品珠子及目标面料**至我司工厂。我们将为客户定制专属振动板、特殊导轨与冲压模具，确保发货前实现无卡料、零故障的完美运行。

### 5.2 混合导轨双工位定制
针对 **TD-168D / TD-198D 双头机型**，支持高度灵活配置。例如，仅需更换一侧滑块与模具头，即可将机器改造为双核强力机——**左侧固定标准圆珠 + 右侧处理复杂特殊珠子**，完美满足高端拼接设计的加工需求。

### 5.3 扩展尺寸模具配件套装
标准机型通常适用于主流5、6、8、10mm尺寸。如遇特殊应用，可单独开模提供4mm（超小）或12mm（超大）定制模具头及送料槽组件，确保未来业务拓展无忧。

## 六、标准操作规程（以双头机型为例）

1. **上料与通电/供气连接：**
   - 将不同尺寸/形状的珠子分别倒入左右两侧大容量上料仓（或重型振动料斗）。
   - 将四爪钉倒入对应下方的钉轨中。
   - 接入电源，开启空压机，打开机器主开关及双侧气阀。
2. **参数设置与测试：**
   - 在PLC控制面板（或数码显示屏）上，根据面料厚度精细调节左右气缸的下行行程、压合时间与缓冲压力，防止压碎脆弱珠子。选择“单头”或“双头”工作模式。
3. **红外辅助定位：**
   - 将服装、鞋类或包袋平铺于上下模具之间。使用对应红外十字/点状标记，精准对齐珠子固定位置。
4. **脚踏气动压合：**
   - 踩下珠子定位脚踏（部分机型），上轨道将珠子与钉子送至工作位。
   - 踩下对应侧的工作脚踏，下压气缸立即启动，驱动四爪钉穿出布料并牢固锁紧珠子。
   - 如需交替图案，只需踩下另一侧脚踏，完成第二种珠子的固定，循环操作即可。
