## 4. Processus de Fonctionnement
1. Appliquer manuellement la colle sur la semelle et l’empièce, les aligner, puis les placer sur la station de pression de la machine ;
2. Allumer l’alimentation électrique et l’arrivée d’air, observer le manomètre et ajuster la pression d’air de travail appropriée (0,2–0,6 MPa) ;
3. Commander l’équipement via le panneau de commande simple pour lancer le programme de pression à double baril afin d’obtenir une fixation solide ;
4. Retirer les chaussures après pression, inspecter l’effet de collage, puis passer à l’étape suivante de production.
