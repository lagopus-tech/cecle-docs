## 4. 操作流程
1. 手动在鞋底和鞋面上涂抹胶水，对齐后放置于机器压合工位；  
2. 接通电源与气源，观察气压表，根据需求调整至合适的运行气压（0.2–0.6 Mpa）；  
3. 通过简易操作面板控制设备，启动双桶压合程序，实现强力粘合；  
4. 压合完成后取出鞋品，检查粘合效果，进入下一生产环节。
