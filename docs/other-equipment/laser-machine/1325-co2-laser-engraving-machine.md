## III. Operation Process

1. **Artwork Preparation & Import**: Prepare artwork in CorelDraw, AutoCAD, or Photoshop. Export files in supported formats (DXF, PLT, AI, BMP) and transfer them to the Ruida offline controller via USB or direct cable.
2. **Material Setup & Zero Pointing**: Place the sheet flat onto the blade cutting table using mechanical aids or manual positioning. Set the workpiece origin using the red dot pointer.
3. **Focal Alignment & Pre-Run Inspection**: Adjust nozzle clearance using the focus gauge. Turn on the industrial water chiller, verify water temperature is between 5°C and 35°C, and start air assist and ventilation blowers.
4. **Execution & Direct Unloading**: Run the job directly via the Ruida control panel. Once completed, remove finished parts from the open flatbed without enclosure obstructions.

* **Q: Can this machine handle full-size 4ft × 8ft panels directly?**

  * A: Because there is no top cover, operators should wear certified CO2 laser safety goggles, keep clear boundary walkways around the perimeter, and use dedicated fume extraction hoods.
