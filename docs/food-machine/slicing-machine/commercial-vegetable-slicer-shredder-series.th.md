## 1. ภาพรวมผลิตภัณฑ์

### 1. ข้อมูลอุปกรณ์พื้นฐาน

* **ชื่อผลิตภัณฑ์:** เครื่องสับและหั่นผลไม้และผักแบบหลายฟังก์ชันเชิงพาณิชย์ / เครื่องตัดชิปมันฝรั่ง / เครื่องสับกะหล่ำปลี (เครื่องตัดมันฝรั่งผักแบบเชิงพาณิชย์ เครื่องสับผัก หั่นกะหล่ำปลี)
* **รุ่น:** **YF-20** (รุ่นมาตรฐานความจุสูงเชิงพาณิชย์)
* **ประเภทอุปกรณ์:** เครื่องหั่นและสับแบบแนวตั้ง ไฟฟ้า หมุนด้วยแรงเหวี่ยงรวมทุกฟังก์ชัน
* **ตำแหน่งตลาด:** ออกแบบมาสำหรับห้องครัวเชิงพาณิชย์ บาร์สลัด ห่วงโซ่ฟาสต์ฟู้ด สถานีเตรียมอาหารซาวเออร์ครอต/บาร์บีคิว โรงงานผลิตชิปมันฝรั่ง และศูนย์กระจายผักสด รองรับการหั่นและสับจำนวนมากของมันฝรั่ง คะน้า หัวหอม และหัวบีท แทนที่แรงงานคนได้ 6–8 คน

**จุดเด่นด้านการออกแบบและผลิต:**

* **ระบบขับเคลื่อนอุตสาหกรรม 1.1 กิโลวัตต์ ทองแดงบริสุทธิ์:** ติดตั้งมอเตอร์ทองแดงบริสุทธิ์กำลัง 1.1 กิโลวัตต์ ให้แรงบิดต่อเนื่อง แม้ต้องตัดผักหนาแน่นอย่างมันฝรั่งแก่ แครอท และมันเทศอย่างต่อเนื่อง ใบมีดยังคงหมุนคงที่โดยไม่ชะลอหรือติดขัด
* **ชุดใบมีดคอมโพสิตสแตนเลสเกรดอาหารแบบแม่นยำ:** ใบมีดถูกขึ้นรูปด้วยสแตนเลสเกรดอาหารที่แข็งแรง คม ทนต่อการสึกหรอ และป้องกันการกัดกร่อน รูปทรงการตัดที่ปรับแล้ว ผลิตแผ่นมันฝรั่งบางๆ ไม่ฉีกขาด และเส้นกะหล่ำปลีบางๆ ไม่ขาด ช่วยเพิ่มผลผลิตและให้รูปลักษณ์สม่ำเสมอ
* **ตัวเครื่องสแตนเลสเกรดอาหารที่แข็งแรง:** ตัวเครื่องภายนอกและห้องตัดสัมผัสอาหารทำจากแผ่นสแตนเลสเกรดอาหาร ผิวขัดเรียบ ต้านทานการกัดกร่อนจากน้ำผลไม้และแป้ง ไม่เป็นสนิมแม้ใช้งานนาน ตรงตามมาตรฐานความปลอดภัยและสุขาภิบาลอาหารระดับสากล
* **ถาดรับวัตถุดิบขนาดใหญ่และท่อปล่อยวัตถุดิบแบบเอียงเรียบ:** ช่องรับวัตถุดิบขนาดใหญ่ รับมันฝรั่งทั้งลูกหรือก้อนคะน้าขนาดใหญ่ได้โดยไม่หยุดชะงัก ท่อปล่อยเอียงช่วยให้วัตถุดิบหลุดออกเร็ว ไม่ติดค้าง ไม่กระจาย หรืออุดตัน
* **โครงสร้างแนวตั้งประหยัดพื้นที่พร้อมขาตั้งดูดซับสั่นสะเทือน:** พื้นที่วางเพียงเล็กน้อย วางได้ยืดหยุ่น ขาตั้งยางดูดซับสั่นสะเทือนแบบหนัก ช่วยลดการสั่นสะเทือนและเสียงรบกวนขณะทำงานที่ความเร็วสูง

### 2. หลักการทำงานหลัก

เครื่องใช้การตัดแบบหมุนแรงเหวี่ยงความเร็วสูงร่วมกับการนำวัตถุดิบด้วยแรงโน้มถ่วงตามรูปทรงเรขาคณิต:

* **การนำวัตถุดิบด้วยแรงโน้มถ่วง:** มันฝรั่ง แครอท หรือก้อนคะน้าที่ล้างและปอกเปลือกแล้ว ถูกปล่อยลงมาผ่านช่องรับวัตถุดิบเข้าสู่ห้องตัด
* **การตัดแบบหมุนแรงเหวี่ยง:** มอเตอร์ขับใบมีดหมุนความเร็วสูง แรงเหวี่ยงดันวัตถุดิบแน่นกับพื้นผิวตัดภายใน ใบมีดที่หมุนเร็วจะตัดผ่านผักได้อย่างสะอาด
* **การปล่อยวัตถุดิบอย่างราบรื่นและคงความชื้น:** ชิปหรือเส้นสับหล่นลงทันทีผ่านท่อปล่อยเข้าสู่ภาชนะรับด้วยแรงโน้มถ่วงและลมแรงเหวี่ยง ใบมีดความเร็วสูงคมเฉียบ ปกป้องโครงสร้างเซลล์ ป้องกันการบี้ รอยขีดข่วน และการไหลของน้ำ ทำให้ผักที่ผ่านการประมวลผลยังคงกรอบและสดใหม่ได้นานขึ้น

### 3. คุณค่าหลัก: ทำไมต้องเลือกอุปกรณ์นี้?

* **ความสามารถสูงสุด (สูงสุด 400 กิโลกรัม/ชั่วโมง):** ผลผลิตต่อชั่วโมงสูงถึง **400 กิโลกรัม/ชั่วโมง** จัดการปริมาณมันฝรั่งหรือคะน้าทั้งวันได้ในเวลาไม่กี่นาที ช่วยเร่งกระบวนการเตรียมวัตถุดิบในห้องครัว
* **ใช้งานได้หลากหลายพร้อมความสม่ำเสมอมาตรฐาน:** เหมาะกับชิปมันฝรั่ง แผ่นมันฝรั่งสำหรับต้ม ผักสับสำหรับสลัด หรือเส้นหัวหอมดอง ความหนาสม่ำเสมอและรอยตัดสะอาด ช่วยให้จานอาหารดูดีขึ้น และลดความไม่สม่ำเสมอจากการใช้มีดมือที่มีทักษะไม่เท่ากัน
* **พื้นที่ใช้งานเล็กและทำความสะอาดง่าย:** ห้องตัดมีจุดตายด้านสุขอนามัยน้อย และออกแบบให้ถอดประกอบได้รวดเร็ว หลังเลิกงาน แค่ล้างด้วยน้ำก็เสร็จ ลดภาระงานทำความสะอาดตอนปิดร้าน

## 2. ขั้นตอนการปฏิบัติงานมาตรฐาน (SOP) และลำดับการผลิต

ปฏิบัติตามแนวทางการใช้งานเหล่านี้เพื่อรักษาคุณภาพการตัด ยืดอายุการใช้งานใบมีด และรับประกันความปลอดภัยของผู้ปฏิบัติงาน:

### 1. ข้อกำหนดการเตรียมวัตถุดิบ

* **การทำความสะอาดและการเตรียมเบื้องต้น:** ล้างผักชนิดราก (มันฝรั่ง มันเทศ แครอท) ให้สะอาด ปอกเปลือกตามต้องการ ตัดหัวคะน้าขนาดใหญ่เป็นครึ่งหรือสี่ส่วน เพื่อให้พอดีกับช่องรับวัตถุดิบ
* **ป้องกันวัตถุดิบแข็ง:** ตรวจสอบวัตถุดิบอย่างละเอียด เพื่อให้แน่ใจว่า หิน ลวดเหล็ก อุปกรณ์ครัว หัวเมล็ด หรือเศษแข็งอื่น ๆ ไม่เข้าไปในช่องรับวัตถุดิบ เพราะวัตถุดิบแข็งจะทำลายใบมีดหมุนความเร็วสูงได้

### 2. การตรวจสอบและตั้งค่าก่อนเริ่มใช้งาน

1. วางเครื่องบนพื้นราบ แห้ง ระนาบ หรือโต๊ะแข็งแรง ให้ขาตั้งยางแต่ละข้างสัมผัสพื้นอย่างสมดุล
2. ตรวจสอบสายไฟและปลั๊กว่าไม่มีความเสียหาย และต่อเข้ากับแหล่งจ่ายไฟที่มีการต่อพื้นดินอย่างเหมาะสม **220V (หรือตัวเลือก 110V)**
3. ตรวจสอบว่า螺栓ภายในห้องตัดแน่นทุกจุด และใบมีดหมุนได้อย่างอิสระโดยไม่มีเสียงผิดปกติหรือการขัดข้อง
4. วางภาชนะสแตนเลสขนาดใหญ่ หรือกล่องอาหารเกรดอาหารที่มีรูรับใต้ท่อปล่อยวัตถุดิบ

### 3. การปฏิบัติงานตัดมาตรฐาน

1. **เปิดเครื่องว่าง:** เปิดสวิตช์ไฟ ให้เครื่องทำงานว่าง 2–3 วินาที เพื่อให้แน่ใจว่าทำงานราบรื่น สมดุล
2. **การใส่วัตถุดิบอย่างต่อเนื่องและสม่ำเสมอ:** ใส่วัตถุดิบเข้าไปในช่องรับเป็นชุด (รักษาระดับความเร็วให้สม่ำเสมอ อย่าบีบวัตถุดิบจำนวนมากเข้าพร้อมกัน)
3. **เก็บวัตถุดิบที่ผ่านการตัด:** เนื่องจากวัตถุดิบปล่อยออกมาเร็ว ควรเปลี่ยนภาชนะที่เต็มทันที เพื่อป้องกันการสะสมหรืออุดตันภายในท่อ
4. **คำเตือนด้านความปลอดภัย:** **อย่าใส่ปลายมือเข้าไปในช่องรับวัตถุดิบขณะเครื่องกำลังเปิดไฟ! ใช้ที่ผลักที่แถมมาเสมอเมื่อใส่วัตถุดิบ**

### 4. การปิดเครื่อง ทำความสะอาด และการบำรุงรักษาประจำวัน

* **ความปลอดภัยด้านพลังงาน:** ต้องดึงปลั๊กไฟออก และรอให้มอเตอร์หยุดหมุนสมบูรณ์ก่อนทำความสะอาดหรือดูแลรักษา
* **ทำความสะอาดใบมีดและห้องตัด:** เปิดฝาครอบห้องตัด ล้างเศษอาหารและแป้งออกจากใบมีดและผนังด้านในด้วยน้ำสะอาดและแปรงนุ่ม ใช้ผ้าสะอาดเช็ดให้แห้ง และทาแว็กซ์อาหารเกรดบางๆ ที่ขอบใบมีดเพื่อป้องกันสนิม
* **เก็บช่องไฟให้แห้ง:** ใช้ผ้าชุบน้ำเช็ดภายนอก อย่าฉีดน้ำตรงเข้าช่องระบายอากาศของมอเตอร์ ตัวเครื่องไฟฟ้า หรือสวิตช์ไฟเด็ดขาด!
