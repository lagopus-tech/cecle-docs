## 1. 产品概述

### 1. 基本设备信息

* **产品名称**：商用多功能小型双速蔬菜切片机 / 商用蔬菜切片双速切割机 / 电动洋葱切片 shredder
* **型号**：**OC-20**（商用双速可调型号）
* **设备类型**：台面式电动离心旋转双速果蔬切片切段机
* **市场定位**：专为西餐中餐餐厅、披萨汉堡店、火锅蘸料站、饺子包子馅料工坊及大型食堂设计，彻底消除切丁切片洋葱、切碎香葱、切圈辣椒、切段芹菜等工序的高人力成本与耗时负担。

**工程与制造亮点**：

* **双速可调机械控制**：配备双速调节旋钮。低速适用于柔软、娇嫩、高含水量的叶类蔬菜或熟食原料（如香葱、香菜、韭菜），避免压伤；高速则可干净利落地处理密集型根茎类蔬菜和洋葱（如洋葱、彩椒、胡萝卜、黄瓜），杜绝水分渗漏。
* **食品级硬化高碳不锈钢旋转刀盘**：刀片采用优质食品级不锈钢精密打磨而成，具备极高的硬度、韧性和持久锋利度。刀刃角度经过空气动力学优化，实现干净、均匀的切割效果，减少细胞过度损伤，防止汁液渗出。
* **加厚SUS304食品级拉丝不锈钢机身**：整机外壳及所有食品接触部位均采用食品级不锈钢冲压成型，耐受果蔬汁、蒜素及洋葱酸腐蚀。防锈设计，边缘光滑圆润，表面为细腻拉丝质感，清洁轻松无残留。
* **加宽进料斗 & 防溅出料槽**：宽口进料斗可直接投入整颗洋葱或大把长香葱；斜坡式出料槽确保食材顺畅排出，避免堵塞或刀盘周围堆积。
* **紧凑台面设计 + 抗震吸盘脚垫**：占地面积小，适配各类商用厨房空间。四组加固防滑减震橡胶吸盘脚垫，确保高速运转时稳定静音，不晃动不移位。

### 2. 核心工作原理

本机基于高速旋转离心切割与可调机械传动原理运行：

* **连续稳定进料**：去皮洗净后的洋葱、香葱、彩椒等蔬菜通过顶部宽口进料斗送入切割腔。
* **双速旋转切片**：根据食材质地选择高速或低速。电机驱动旋转刀盘高速运转，利用超锋利刃口以高线速度快速切入食材。
* **离心力与重力排料**：切好的片、段或丝在离心力与重力作用下沿出料斜坡滑入下方收集箱，实现即时、连续的“进料-出料”输出。
* **洁净切口锁住新鲜**：快速机械切割形成整齐断面，有效保留内部水分与芳香风味物质，显著延长预处理食材的冷藏保质期。

## 2. 标准操作流程（SOP）与生产作业流程

为确保最佳切割质量、延长刀具使用寿命并保障操作员安全，请严格遵守以下操作指南：

### 1. 原料准备要求

* **预处理**：大型根茎类蔬菜或整颗洋葱应先去皮修剪。若原料尺寸超过进料口，需预先对半切开。
* **清除硬质异物**：投料前务必检查并剔除石块、铁丝、果核、硬籽、骨头等硬物。硬物进入刀腔可能严重损坏刀刃。

### 2. 开机前检查与设置

1. 将机器稳固放置于平整、干燥、坚实的台面上，确保四个橡胶吸盘脚牢固吸附。
2. 检查电源线与插头有无破损，连接至匹配的 **110V 或 220V 接地插座**。
3. 检查切割腔体，确认刀盘固定螺母已紧固，内部无异物。
4. 在出料槽下方放置一个干净的不锈钢盆或食品级收纳箱。

### 3. 标准切割操作

1. **根据原料选择速度**：
   * **低速**：适用于香葱、香菜、韭菜、菠菜等娇嫩绿叶菜，防止压伤及过度出水。
   * **高速**：适用于洋葱、彩椒、胡萝卜、黄瓜、土豆及坚硬根茎类蔬菜。
2. **启动机器**：打开电源开关，让机器空转2–3秒，确认旋转平稳无异常。
3. **均匀持续进料**：将食材平稳送入进料口（切勿伸手深入进料斗；长条状食材可自然滑入）。
4. **及时收集成品**：观察出料槽，一旦收集箱装满立即更换。
5. **安全警告**：**机器通电运行期间，严禁使用手指、筷子或金属工具强行推压进料斗内的食材！**

### 4. 关机、清洁与日常维护

* **电源安全**：清洁或维护前务必拔掉电源线，并确认刀盘完全停止转动。
* **快速拆卸刀盘清洗**：打开前盖，取出刀盘，用清水和温和食品级洗涤剂冲洗刀片与切割腔，彻底晾干后涂抹一层薄薄的食品级润滑油，防止表面氧化。
* **保护电气部件防水**：用湿布擦拭外壳。**严禁使用高压喷枪或直接用水冲洗电机风栅和电源开关面板！**

## 4. 常见问题解答（FAQ）

* **Q：双速可调功能的实际优势是什么？**
  * **A**：不同蔬菜纤维密度与含水量差异显著。如洋葱、胡萝卜等坚硬蔬菜需高速切割才能瞬间穿透纤维，避免水分溢出；而香葱、香菜、韭菜等娇嫩绿叶菜在高速下易压伤或飞散，调至低速可有效保护其脆嫩质地、保持完整形态与天然水分平衡。
* **Q：真的能切洋葱而不流泪、不挤出汁液吗？**
  * **A**：是的。切洋葱流泪源于钝刀挤压细胞壁释放挥发性硫化物。OC-20采用超锋利食品级旋转刀片配合高扭矩电机，可在毫秒级完成切割，最大限度减少细胞破坏，切面干净干燥，显著降低刺激性气味释放。
* **Q：清洁方便吗？更换或清洗刀片需要特殊工具吗？**
  * **A**：非常方便。前盖与刀盘安装结构采用人性化快拆设计。断电后打开舱体，取下刀盘，即可在流动水下用软刷清洗。不锈钢机身不易残留异味。
