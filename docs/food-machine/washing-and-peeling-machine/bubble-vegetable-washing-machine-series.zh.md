## 一、产品概述

### 1. 基本设备信息

* **产品名称**：商业工业气泡果蔬清洗流水线 / 多功能连续果蔬清洗机（商业气泡水清洗机多功能果蔬流水线）
* **产品型号**：CBW-2500（2.5米机身） / CBW-3000（3米标准型） / CBW-4000（4米高产能型） / CBW-5000（5米超大工业型）
* **设备类型**：连续水浴气泡涌动与倾斜网带二次高压冲洗一体化流水线
* **市场定位**：面向现代农业产业园、高校及企业中央厨房、鲜切沙拉加工厂以及冷冻/脱水食品制造商，解决日均高吞吐量需求、人工清洗成本上升、砂石与漂浮物清除无效、农药残留积聚等痛点。

**工程与制造亮点**：

* **高功率工业鼓风机 & 微孔曝气阵列**：在水槽底部布置多通道不锈钢曝气管。高压鼓风机将空气通过微孔强制注入，形成密集上升气泡流。这些气泡模拟剧烈沸腾状态，利用流体动力学原理从各个角度温柔包裹并冲刷物料，剥离夹杂的泥沙与杂质，同时避免对脆弱叶片或柔软果皮造成压伤。
* **VFD驱动食品级SUS304网带输送机**：由高扭矩减速电机与变频驱动器（VFD）驱动，可通过控制面板平滑调节输送速度。网带稳定向前并沿出料斜坡提升，防止产品间挤压，消除皮带磨损，实现连续自动化进料与出料。
* **倾斜段二次高压清水喷淋**：当物料从清洗槽升起时，会经过独立的洁净水冲洗区。高压增压泵通过多角度扇形喷嘴将清水喷洒而出，彻底清除残留槽水与松散杂质。此清洁冲洗水可直接回流至主槽，维持水质清洁，形成高效的阶梯式循环系统。
* **双层污泥沉降斗与溢流过滤副槽**：主槽底部设有倾斜锥形沉降斗，使重质砂石自然沉降脱离活跃清洗区。外部溢流过滤副槽配备可拆卸多级细筛与浮渣刮除装置，持续拦截漂浮的果壳、碎叶与纤维。经净化后的水被泵回主槽，整体节水率达 **50%–60%以上**。

### 2. 核心功能与工作原理

该流水线通过四种水力机制实现连续运行：高压气泡微爆破、湍流推进、浮力分离与阶梯喷淋冲洗：

* **进料与湍流推进**：原物料从前端进料口投入。底部曝气立即分散结块物料，防止产品堆积。同时，定向循环水流使物料轻柔翻滚，并以恒定速度推向出料端。
* **气泡爆破微冲击去污**：数百万个密集微气泡持续撞击并破裂于物料表面，产生的微观剪切力可深入叶片褶皱与茎秆凹陷处，比静态浸泡更有效地清除沙粒、灰尘、虫卵及表面化学残留。
* **重杂质沉降与浮渣溢流**：高密度颗粒如砂砾、石子穿过网带落入底部沉积斗，处于非扰动区域；轻质漂浮物如干叶、泡沫则被表面水流引导至侧向溢流口，进入过滤副槽。
* **斜坡提升与二次清水冲洗**：洁净物料沿倾斜网带升出水面，经过上方的清水扇形喷嘴进行最终冲洗，彻底清除携带的脏水。
* **无缝下游线集成**：产品从出料滑道平稳排出，可直接连接 **高流量风刀脱水干燥机、商用蔬菜切片机、金属探测仪或自动化包装线**，构建完整、无污染的加工流程。

### 3. 核心价值：为何选择此设备？

* **工业化规模产能（1条线替代15–20名工人）**：连续作业可实现 **500 至 3000 kg/h** 的高效清洗，彻底解决大型中央厨房与配送中心早间准备环节的瓶颈问题。
* **零损伤、零压伤**：相比摩擦性强的刷辊或滚筒式清洗机，气泡水浴清洗是目前最温和的清洗方式：草莓保留蒂柄，叶类蔬菜保持脆嫩，番茄完好无损，有效保障新鲜度与货架寿命。
* **环保节水**：双槽循环过滤系统持续净化并重复利用清洗水，辅以二次清水喷淋补给，整体用水量较传统连续自来水清洗减少 **超过60%**。

## 二、生产流程与标准操作规程（SOP）

请遵循以下标准化流程，确保最佳清洗效果，预防管道堵塞，并保障电气安全：

### 1. 原料准备与预分拣

* **预分拣异物**：
  * **严禁将未解绑的绳索、捆扎铁丝、破损塑料袋或大块石头直接投入生产线！** 长条物可能缠绕内部轴杆与传动链条。
  * 对根部泥块严重的蔬菜（如菠菜、芹菜根部），建议预先修剪根尖或松散结块，可大幅提升清洗效率。
* **供水检查**：确保进水压力不低于 **0.2 MPa**，以保证斜坡喷淋区喷雾分布均匀、完整。

### 2. 启动前检查与公用设施连接

1. 确认流水线水平稳固安装于加厚防滑混凝土地面，支撑脚受力均衡；主电控柜已可靠接地至三相电源。
2. 确保底部污泥排放蝶阀与砂粒排空阀 **完全关闭并锁定**。
3. 打开主水源阀门，向主槽注水直至达到溢流口位置（少量溢流进入副槽即表示水位已满）。
4. 检查副槽内所有多级可拆卸不锈钢滤网是否清洁且已牢固锁紧。

### 3. 标准操作指南

1. **顺序启动**：
   * 启动主电源隔离开关；
   * 启动 **水循环泵**，确认水面有稳定方向流动；
   * 启动 **高压涡旋鼓风机**；观察主槽确认产生剧烈、均匀的白色气泡曝气；
   * 启动 **网带输送机电机**，将VFD电位器调至目标处理速度（根据物料类型通常为15–35 Hz）；
   * 打开 **二次冲洗水阀**，确认整个提升段的所有扇形喷嘴均均匀喷射出清洁水。
2. **连续均匀进料**：将物料平稳、均匀地送入进料口（手动或通过自动进料升降机）。**切勿一次性倾倒大量物料集中投放**，以免压垮曝气层，阻碍气泡渗透。
3. **运行监控**：根据进料泥土负荷动态调整网带速度（重泥负载时降低速度以延长浸泡时间；轻度污染物料则提高速度以提升每小时产量）。
4. **定期清理浮渣**：生产过程中定期检查过滤副槽收集篮。及时提起并清空积累的浮叶与泡沫，以维持循环通畅。

### 4. 停机、清洗、排水与日常维护

* **清空物料**：停止前端进料的同时，保持设备继续运行，直至所有物料完全从出料斜坡排出。
* **停机与排水**：按顺序按下停止按钮：鼓风机 → 喷淋泵 → 循环泵 → 输送机驱动。切断主电源。打开主槽底部排水闸门，将废水与积砂排入地面排水沟。
* **内部槽体冲洗**：使用低压冲洗软管清洗槽体内壁、网带下方磨损轨道及污泥斗，清除所有蔬菜残渣与沉积物。
* **传动部件润滑**：每周检查输送机传动链条、轴承与张紧链轮。涂抹食品级防水润滑脂，并在链条松弛时调节尾部张紧螺栓。
* **电气安全警告**：**切勿用高压喷枪直射主控制箱、VFD数字显示屏或电机外壳！**

## 四、常见问题解答（FAQ）

* **问：为何气泡水浴清洗特别适合草莓、番茄、菠菜等娇嫩食材？是否会压坏叶片或软果？**
  * **答**：传统旋转滚筒或摩擦刷洗机依靠硬性机械冲击与摩擦，易撕裂叶类蔬菜、脱落草莓花萼、压伤番茄表皮，导致快速腐烂与外观不佳。而本气泡清洗线使物料完全悬浮于浮力水浴中，依靠气泡破裂产生的微冲击波，温和清除缝隙中的污垢，无刚性接触，彻底杜绝压伤与撕裂。

* **问：清洗重度污染蔬菜时，积聚的泥沙与漂浮叶片是否会污染清洗水并造成二次污染？**
  * **答**：不会。本线采用三级分离设计：
    1. **底部沉积隔离**：重质砂石穿过网带落入底部锥形斗——死水区，水流扰动无法将其重新搅起。
    2. **侧向溢流撇渣**：轻质漂浮物（杂草、碎叶）随表面水流导向侧向溢流口，被外部副槽的细滤网捕获。
    3. **二次高压清水冲洗**：物料在出料斜坡上接受高压扇形喷嘴的最终冲洗，彻底清除残留脏水，防止带出。

* **问：如何将此清洗线与切片机、脱水机或包装设备集成，构建完整的中央厨房加工线？**
  * **答**：本线设计标准化高度与倾斜角度，可无缝对接自动化产线：
    * **上游进料**：可连接自动料箱倾倒器或分拣检测输送机，实现连续供料。
    * **下游出料**：出料滑道直接对接高流量环境风刀脱水机，吹除表面水分后，蔬菜可进入商用多功能切片/切丁机或气调包装（MAP）系统。整条产线仅需2至3名操作员即可每日处理数吨物料。
