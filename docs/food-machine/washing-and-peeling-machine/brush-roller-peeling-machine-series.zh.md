## 一、产品概述

### 1. 基本设备信息

* **产品名称**：商用全自动刷辊清洗去皮机 / 水平多功能蔬菜海鲜清洗去皮机（土豆、木薯、山药及牡蛎清洗去毛辊去皮机）
* **产品型号**：Model 45（45cm） / Model 60（60cm） / Model 80（80cm） / Model 100（100cm）
* **设备类型**：水平多辊研磨滚搓+高压喷淋冲洗一体化设备
* **市场定位**：专为现代预切蔬菜加工工厂、脱水蔬菜基底生产、海鲜批发摊位、大型机构餐饮中央厨房及连锁餐厅前处理区设计，解决人工清污劳动强度大、易碎长条食材破损严重、牡蛎壳附着泥藻难以清除等痛点。

**工程制造亮点**：

* **全食品级SUS304不锈钢结构**：整机机身、进料槽、出料门、防护驱动罩及支撑框架均采用加厚食品级SUS304不锈钢制造。耐酸、碱、盐腐蚀性强，在长期接触水和盐水环境下不易生锈，完全符合商业厨房及出口级食品厂卫生标准。
* **耐磨高弹食品级尼龙刷辊**：多组刷辊呈半圆形布置于清洗槽内。采用进口耐磨尼龙丝，通过专业植绒工艺制成，具备高柔韧性、零掉毛、优异回弹性能。可根据需求定制：**软毛刷辊**（用于清洁泥土同时保留薄皮，如新鲜莲藕、胡萝卜、菱角）或 **硬毛刷/碳化硅磨料辊**（用于强力研磨去皮，如土豆、老姜、木薯、红薯）。
* **循环高压喷淋与污泥分离槽**：顶部不锈钢高压喷淋主管道喷射宽幅扇形水雾覆盖整个滚搓区域。底部设有倾斜式水-泥导流槽，可将沉积物、沙粒及剥落皮屑直接排入废料出口，避免堆积或交叉污染。
* **双排链条传动与高扭矩纯铜电机**：采用精密大节距链轮链条传动机构，运行平稳静音。搭配纯铜防水防过载电机，即使在满负荷重载下也能提供充足扭矩，不发生卡滞。

### 2. 核心功能与工作原理

本设备结合水平多轴刷辊旋转摩擦与高压液体冲洗：

* **槽体批量投料**：可直接将装有泥泞土豆、覆土莲藕、木薯或附着藻类/沙粒的牡蛎整箱投入水平清洗槽，随后打开喷淋阀门。
* **多辊滚搓与表面摩擦**：电机驱动刷辊同步旋转，使物料以波浪状方式缓慢滚动。数百万根弹性尼龙刷丝持续摩擦产品表面每一个角度与凹槽，快速剥离顽固泥垢与表皮层。
* **对长条形食材的非破坏性保护**：不同于垂直离心式去皮机造成的剧烈撞击，水平多辊布局使莲藕、山药、木薯等长条食材平躺滚动，温柔翻转，防止尖端折断、开裂或产生淤血色斑。
* **高压喷淋冲洗**：顶部持续喷淋水流同时清洁物料与刷丝表面，迅速将脱落的泥沙、皮屑、颗粒冲刷穿过刷辊间隙，流入底部沉淀槽。
* **侧门快速卸料**：清洗或去皮完成后，只需在刷辊继续运转时松开末端出料门手柄，旋转运动即可将物料平稳推送至接料筐中，几秒内完成卸料。

### 3. 核心价值：为何选择此设备？

* **脆弱长条作物的终极解决方案**：突破垂直去皮机对莲藕、山药、牛蒡等食材造成的物理限制，完整保留自然长形外观，提升商品视觉品质，助力高端市场定价。
* **多功能一体应用（清洗 / 去皮 / 贝壳清洁）**：既可用于根茎类去皮（使用硬毛/碳化硅辊），也可仅作清洗（使用软毛辊），同时在不破裂外壳的前提下，高效清除牡蛎、扇贝、蛤蜊等双壳类海产品的泥沙与藻类。
* **低肉损、零压伤**：尼龙刷丝微磨削作用仅去除极薄表皮，不切入深层纤维组织，相比碳化硅盘式去皮机，加工损耗降低 **10%–18%**。

## 二、生产流程与标准操作规程（SOP）

### 1. 原料准备与预处理

* **异物筛选**：
  * **务必仔细检查并剔除钉子、大石块、砖头及其他硬质杂物！** 嵌入的石块可能卡住辊筒，导致电机停转或刷丝损坏。
  * 对于表面附着厚重干泥的作物（如田间红薯、木薯），建议预先喷水润湿，软化土壤，显著加快处理速度。
* **海产检查**：清洗牡蛎或贝类时，应提前丢弃已死亡破裂的外壳，防止尖锐碎片卡入刷丝之间。

### 2. 启动前检查与供水连接

1. 将机器放置于水平坚固地面，确保所有支撑脚稳固到位，并连接至安全可靠的 **110V 或 220V 电源**。
2. 将清水进水管牢固连接至顶部喷淋管接头，并用不锈钢管夹固定。
3. 将底部排水口引向地漏或沉淀池，防止沙粒堵塞市政管道。
4. **锁紧出料门**：关闭侧向出料舱门，并确认锁扣手柄已牢固锁定。

### 3. 标准清洗与去皮操作指南

1. **先启水后开机**：按下绿色启动按钮使设备空转，然后将水阀完全打开，湿润并润滑刷辊。
2. **均匀投料**：根据机型额定容量，将物料均匀倒入清洗槽（Model 45：10–12 kg；Model 60：15–20 kg；Model 80：35–40 kg；Model 100：40–50 kg；严禁超过上辊高度线）。
3. **处理时间**：
   * **清洗模式（软毛刷）**：约 **1–3分钟**；待排水变清即可卸料。
   * **去皮模式（硬毛刷/碳化硅辊）**：约 **3–5分钟**；待表皮均匀剥离后即可卸料。
4. **自动卸料**：**在设备运行状态下**，将带孔收集筐置于侧边出料口下方，掀开卸料锁扣，让滚搓辊自动将物料推出。立即关闭并锁紧舱门，准备下一周期。
5. **安全警告**：**设备运行期间，严禁将手、铁铲或金属棒伸入辊筒之间！**

### 4. 关机、清洁与维护

* **槽体冲洗**：每班次结束后，保持设备空转并开启喷淋水，持续运行2分钟，彻底冲洗刷丝间残留的皮屑、泥浆或纤维。
* **沉淀罐清理**：定期打开底部清掏盖，冲洗积聚的沉积物，防止细菌滋生或异味产生。
* **电气防水提示**：用湿布擦拭不锈钢外表面；**切勿直接用高压水冲洗电机、链条传动室或电控箱！**
* **链条润滑**：每月打开侧边驱动护罩，检查链条张力，并对链轮与传动链条涂抹食品级防水润滑脂。

## 四、常见问题解答（FAQ）

* **Q：刷辊机与垂直圆柱研磨去皮机的主要区别是什么？为何莲藕和山药必须使用刷辊机？**  
  * **A：** 垂直圆柱研磨去皮机依靠高速离心旋转，将物料甩向磨料衬里。这种方式适合圆形或椭圆形物品（如普通土豆、芋头）。但对于长条且脆弱的莲藕、山药、木薯而言，高速撞击会立即造成断裂和粉碎，导致灾难性损失。而刷辊机采用水平多辊床设计，物料平躺滚动，经由柔软或中等硬度刷丝温和摩擦，能彻底清除深缝中的顽固泥垢，而不会造成断裂或压伤。

* **Q：软毛与硬毛刷辊有何区别？能否根据我们的加工需求更换？**  
  * **A：** 两者在刷丝硬度与应用场景上存在差异：
    * **软毛刷（细密波浪丝）**：专为“去泥去污但保留外皮”设计，适用于脆嫩莲藕、新土豆、胡萝卜、菱角等无需去皮的食材。
    * **硬毛刷 / 碳化硅辊（加粗刚性丝或磨料颗粒）**：专为“强力去皮与刮擦”设计，适用于老土豆、坚韧红薯、成熟生姜、木薯等需要彻底去皮的原料。
    * 客户可根据实际加工需求，直接向CECLE定制刷辊配置方案。

* **Q：这台机器可以清洗生牡蛎、扇贝等贝类吗？会不会弄破外壳？**  
  * **A：** 可以。牡蛎及贝类清洗是本机最广受赞誉的商用应用之一。贝类常附着顽固泥沙、藤壶与海藻，手工清洗既费力又危险。密集高弹性的尼龙刷丝配合高压水射流，可从各个角度彻底清除外壳深沟内的污物。由于刷丝具有天然缓冲作用，不会击裂外壳，最终产出洁净无瑕的牡蛎，适用于高端生食吧、牡蛎烧烤及海鲜供应链。
