### 一、产品概述

#### 1. 基本设备信息
* **产品名称**：商用工业气泡果蔬清洗装配线 / 多功能连续果蔬清洗机
* **产品型号**：CBW-2500（2.5m 机身） / CBW-3000（3m 标准） / CBW-4000（4m 高容量） / CBW-5000（5m 超大工业线）
* **设备类型**：连续水浴气泡涌动与倾斜网带二次高压冲洗集成装配线
* **市场定位**：针对现代农业工业园区、大学及企业中央厨房、鲜切沙拉加工设施以及冷冻/脱水食品制造商，解决高日吞吐量需求、不断上升的人工清洗成本、无效的沙粒/漂浮物清除及顽固农药残留积累问题。

**工程与制造亮点**：
* **高功率工业鼓风机与微孔曝气阵列**：多通道不锈钢曝气管铺设于槽底。高压鼓风机将空气通过微孔强制注入，产生密集的上升气泡。这些气泡模拟剧烈沸腾状态，利用流体动力学原理从各个角度温柔包裹并擦洗产品，剥离夹杂的泥土和杂质，而不会损伤娇嫩叶片或软果表皮。
* **VFD 驱动食品级 SUS304 网带输送机**：由高扭矩减速电机和变频驱动（VFD）驱动，可通过控制面板平滑调整输送速度。网带稳定向前并沿出料斜坡提升，防止产品间挤压磨损，同时消除皮带磨损，实现连续自动化进料与卸料。
* **升降斜坡上的二次高压清水喷淋**：当产品从清洗槽升起时，会经过独立的清洁水冲洗区。高压增压泵通过多角度扇形喷嘴输送清水，彻底清除残留槽水和松散杂质。此清洁冲洗水直接回流至主槽，维持清洁水位并形成高效的级联循环系统。
* **双层污泥沉降斗与溢流过滤副槽**：主槽底部设有倾斜锥形沉降斗，使重砂砾和碎石脱离活跃清洗区。外部溢流过滤副槽配有可拆卸多级细筛和浮渣刮板，持续捕获漂浮的外壳、松散叶片和纤维。循环清洁水被泵回主槽，整体耗水量减少 **50%–60%** 以上。

#### 2. 核心功能与工作原理
该生产线通过四个水动力机制连续运行：高压气泡微爆破、湍流推进、浮力分离和级联喷淋冲洗：
* **进料与湍流水推进**：原料从前端进料区投入。底部曝气瞬间分散紧密团块，防止产品堆积。同时，定向循环水流轻轻翻滚产品，将其以稳定速度推向出料端。
* **气泡爆破微冲击波去污**：数百万密集微气泡持续撞击并破裂于产品表面。由此产生的微观剪切力穿透叶脉褶皱和茎秆凹陷，比静态浸泡更有效地剥离沙粒、灰尘、虫卵和表面化学残留物。
* **重杂质沉降与浮游杂质溢流**：高密度颗粒、石子和沙粒穿过丝网带落入底部沉积斗，与湍流隔绝。轻质漂浮杂质、干叶和泡沫被导向侧向溢流口进入过滤副槽。
* **斜坡提升与二次清洁水冲洗**：清洁产品沿倾斜网带升出浴槽，经过上方的清水扇形喷嘴，接受最终洁净冲洗，完全消除脏水携带。
* **无缝下游线集成**：产品从出料槽平稳排出，可直接连接高速空气刀脱水干燥机、商用蔬菜切片机、金属探测器或自动化包装线，形成完整、未受干扰的加工流程。

#### 3. 核心价值：为何选择此设备？
* **工业化规模吞吐量（1条线替代15–20名工人）**：连续处理能力达 **500 至 3000 kg/h** 的彻底清洗产品，消除大型中央厨房和配送中心早间准备瓶颈。
* **零损伤与零压痕**：不同于摩擦刷辊或翻滚滚筒清洗机，气泡水浴清洗提供了最温和的清洁方式：草莓保留茎蒂，叶菜保持脆嫩，番茄完好无损，保持新鲜度和货架寿命。
* **环保节水**：双槽循环与过滤系统持续净化并重复使用清洗水，通过二次清水喷淋补充动态平衡，相比传统连续自来水清洗，整体耗水量减少 **超过 60%**。

### 二、生产流程与标准操作程序（SOP）

#### 1. 原料准备与预分拣
* **预分拣异物**：
  * **切勿将未捆扎的绳索、捆扎铁丝、破损塑料袋或大石头倒入生产线！** 长条物可能缠绕内部轴和传动链。
  * 对于根部有硬块泥土的蔬菜（如菠菜或芹菜根），预先修剪根尖或松解团块可显著提高清洗效率。
* **供水检查**：确保进水清洁水供应压力不低于 **0.2 MPa**，以保证斜坡冲洗区喷雾模式均匀完整。

#### 2. 启动前检查与公用设施连接
1. 确认装配线稳固地安装在加固防滑混凝土地板上，支撑腿平衡，主电气柜已接地至可靠的三相电源。
2. 确保底部污泥排水蝶阀和砂粒排空阀 **完全关闭并锁定**。
3. 打开主水阀，填充主槽直至水位达到溢流口（轻微溢流至副槽表示已满）。
4. 确认副槽内所有多级可拆卸不锈钢滤网清洁并锁紧到位。

#### 3. 标准操作指南
1. **顺序启动**：
   * 打开主电源隔离开关；
   * 启动 **水循环泵**，确认水面有稳定方向流动；
   * 启动 **高压涡旋鼓风机**；观察主槽确认剧烈均匀的白色气泡曝气；
   * 启动 **网带输送机电机**，并将 VFD 电位器调至目标处理速度（通常为 15–35 Hz，视产品类型而定）；
   * 打开 **二次冲洗水阀**，确认所有斜坡段喷嘴均匀喷洒清洁水。
2. **连续均匀进料**：将产品均匀、稳定地送入进料区（手动或通过自动进料提升机）。**避免一次性倾倒大量箱装物料**，以免过载曝气床，阻碍气泡渗透。
3. **运行监控**：根据进料土壤负荷调整网带速度（重泥负载时降低速度以延长浸泡时间；轻度污染时提高速度以增加每小时产量）。
4. **定期清理浮渣**：生产期间定期检查过滤副槽的收集篮。及时提起并清空收集的浮叶和泡沫，以维持无阻滞的循环。

#### 4. 停机、清洗、排水与日常维护
* **清空物料**：在前端停止进料的同时，保持生产线运行，直到所有产品从出料斜坡退出。
* **停机与排水**：按顺序按下停止按钮：鼓风机、喷淋泵、循环泵和输送机驱动。切断主电源。打开主底部排水闸阀，将废水和积砂排入地面排水沟。
* **内部槽体冲洗**：使用低压冲洗软管冲洗内壁、网带下方磨损轨道和污泥斗，清除所有蔬菜残渣和沉积物。
* **驱动与链条润滑**：每周检查输送机驱动链条、轴承和张紧链轮。涂抹食品级防水润滑脂，并在链条松弛时调整尾部张紧螺栓。
* **电气安全警告**：**切勿将高压喷枪直接对准主控制箱、VFD 数码显示屏或电机外壳！**

### 四、常见问题解答（FAQ）

* **Q：为何气泡水浴清洗特别适合草莓、番茄和菠菜等娇嫩物品？会压碎叶子或软果吗？**
  * **A：** 传统的旋转滚筒或摩擦刷洗机使用硬性机械冲击和摩擦，会撕裂叶菜、脱落草莓花萼并压伤番茄表皮，导致快速腐烂和外观不佳。相比之下，气泡清洗线让产品完全悬浮在浮力水中。塌陷气泡产生的微冲击波温和地剥离污垢和表面杂质，完全避免刚性机械接触，彻底消除压伤和撕裂。
* **Q：清洗重度污染蔬菜时，累积的泥沙和漂浮叶片是否会污染清洗水并造成再污染？**
  * **A：** 不会。该线具备三重分离设计：
    1. **底部沉积隔离**：重砂石落入网带下方的底部锥形斗——一个死流区，水湍流无法将其搅起。
    2. **侧向溢流刮除**：轻质漂浮杂草和叶片碎片被表面水流引导至侧向溢流口，被外部副槽中的细滤网捕获。
    3. **二次清洁喷淋**：蔬菜在出料斜坡上出现时，高压扇形喷嘴提供最终冲洗，冲走任何残留脏水，防止脏水携带。
* **Q：如何将此清洗线与切片机、脱水机或包装单元集成，构建完整的中央厨房加工线？**
  * **A：** 该线设计有标准化高度和倾斜角度，可直接连接自动化加工线：
    * **上游进料**：可连接自动料箱倾倒器或分拣检验传送带，实现连续进料。
    * **下游出料**：出料槽直接排入高速环境空气刀脱水机，吹走表面水分，然后蔬菜进入商用多功能切片/切丁机或改良气氛包装（MAP）系统。一条完整生产线仅需 2 至 3 名操作员即可每日处理数吨产品。

* **产品名称**：商用自动超声波大米与谷物清洗机 / 多功能谷物清洗机与除石机

* **设备类型**：垂直超声振动与水力浮选一体化多谷物清洗与杂质去除机
* **市场定位**：专为解决商业餐食准备中心、连锁餐厅、即食餐工厂及酿酒或大豆加工企业的核心痛点：每日清洗大量谷物带来的高人工成本、传统水洗机高石子泄漏率、机械损伤导致的粘手、破碎米饭，以及难以去除顽固表面微尘和农药残留。

**工程与制造亮点**：
* **工业级压电超声换能器阵列**：多个高功率超声换能器（28 kHz / 40 kHz 复合声场）嵌入槽底和侧壁，产生均匀密集的微空化气泡。当这些气泡坍塌时，数千个微射流喷射进谷物表面微孔，剥离细尘、麸皮粉、虫卵和化学残留物，而不进行物理刮擦。
* **双锥离心比重除石漏斗**：利用谷物与矿物杂质的密度差异（砂石密度通常为 2.5–3.0 g/cm³，而浸水谷物约为 1.3–1.4 g/cm³）以及循环水的浮力。重石子和金属碎片迅速沉入底部沉积陷阱并被隔离阀锁住，确保除石率超过 99%。
* **多孔阶梯式溢流废料槽**：设有宽阔的顶部溢流口和浮动废料收集篮。微气泡自然将空心糠秕、轻质外壳、植物纤维和虫害残留物托至水面，经堰口排出，实现重轻杂质的同步分离。
* **食品级 SUS304 构造与节水循环**：所有与物料接触的表面、管道阀门和脱水篮均采用重型钝化 SUS304 不锈钢，耐酸碱腐蚀，无卫生死角。内置过滤与循环回路将耗水量减少 **40%–55%**。

#### 2. 核心功能与工作原理
* **快速加载与自动注水**：将袋装大米、玉米、大豆或绿豆直接倒入进料仓。微电脑控制的电磁阀自动注水至预设操作液位。
* **即时深层声学空化**：启动后，高频超声系统生成数百万个微小气泡，猛烈膨胀并爆裂于谷物表面。这种微冲击波作用剥离顽固表面胶体，乳化残留表面糖原，并清除松散淀粉粉尘，使谷物变得透明洁净。
* **三维水力流化翻滚**：低剪切循环泵从底部切向注入水，使谷物床呈向上向内的环形循环翻滚。这种流化确保每颗谷物都获得均匀的超声暴露，防止底部死区沉积或结块。
* **同步重除石与浮选刮除**：翻滚过程中，高密度砾石随向上水流沉入底部锥形陷阱。轻质糠秕和泡沫沿表面流动，通过外围溢流堰排出。
* **快速排放与高效脱水**：清洗周期完成后（通常为 90–180 秒），排放门开启。洗净的谷物连同水流入移动脱水车或烹饪容器。洗涤水排出或过滤回流，完成排放仅需数秒。

### 二、生产流程与标准操作程序（SOP）

#### 1. 原料准备与预处理
* **物料兼容性**：适用于干白米、黑米、糙米、高粱、大麦、脱粒甜玉米、大豆、黑豆、红豆、绿豆、鹰嘴豆及类似颗粒主粮。
  * **切勿将未捆绑的包装绳、大捆稻草、金属块或异质木材倒入机器！** 纤维绳可能缠绕循环泵叶轮，必须事先筛选剔除。
* **水压验证**：确保市政或专用清洁水源压力稳定在 **0.15–0.35 MPa**，以实现快速自动注水。

#### 2. 启动前检查与连接
1. 将机器放置在厨房准备区平整坚固的地面上。调平四脚，并连接至专用 **110V 或 220V 接地插座，带漏电保护**。
2. 牢固连接清洁水源软管（1/2″ 或 3/4″ 接口）至后部水入口电磁阀接头。
3. 确认底部石子排放阀和主排水阀 **牢固关闭并锁定**。
4. 将顶部溢流管和底部排水管接入地面排水沟或油/砂拦截器。
5. 在出料槽下方放置一个带孔的不锈钢脱水车或托盘。

#### 3. 标准操作指南
1. **通电**：打开控制箱主电源开关；微电脑 LCD 屏幕将亮起。
2. **配置清洗参数**：
   * **标准大米 / 寿司米**：设置清洗时间为 **90–120 秒**；超声功率调至 70%–80%（防止剥离天然 B 族维生素）。
   * **陈年谷物 / 粗粮 / 玉米粒**：设置清洗时间为 **120–180 秒**；超声功率设为 100%。
   * **大豆 / 绿豆 / 红豆**：设置清洗时间为 **150–200 秒**；激活增强水力涡流模式。
3. **注水与装料**：按“自动注水”。当水位达到溢流边缘以下约 5 cm 时，将原料均匀倒入槽内（不要超过最大容量线）。
4. **一键清洗**：按“开始”。机器启动内部水循环和超声阵列。谷物将在流化状态下翻滚，泡沫和糠秕通过顶部溢流堰排出。
5. **石子排空（自动/手动）**：在周期最后 30 秒，短暂打开底部排空阀 3–5 秒，将积聚的沙子冲入沉积坑。
6. **排放谷物**：计时器归零后，超声功率自动关闭。打开谷物排放闩锁（或按气动排放按钮）。干净谷物连同残留水顺利流入脱水车进行排水。

#### 4. 清洁与常规维护
* **腔体自冲洗**：每个工作班次结束后，打开底部排水阀排空所有水。用低压喷枪冲洗内壁和换能器表面，清除残留淀粉或豆皮。切勿让淀粉在腔底干燥。
* **超声干烧预防**：**绝对禁止在清洗腔无水时运行超声功能！** 干运行超过 10 秒将永久损坏压电陶瓷换能器。
* **控制箱防潮警告**：用湿布擦拭外壳；**切勿将高压水直接喷向触摸屏面板、通风百叶窗或电机外壳！**
* **泵检查**：每季度检查循环泵密封和底部进水筛，清除细纤维积聚，确保足够的泵头压力。

### 四、常见问题解答（FAQ）

* **Q：超声波谷物清洗相比机械搅拌器或水射流清洗机的核心优势是什么？超声波会裂开米粒吗？**
  * **A：** 机械搅拌器依赖旋转桨叶物理敲打谷物，常导致高破损率（3%–8%）。这会破坏谷物几何形状并释放自由淀粉，使煮熟的米饭变得黏糊、粘手。超声清洗是一种微观物理空化过程：坍塌的微气泡剥离表面灰尘和麸皮，无机械冲击，从而实现**几乎零破碎**。清洗后的米粒保持透明，胚芽完整，煮后成为蓬松有弹性的颗粒，在热保温器中不易发黄。
* **Q：该设备如何分离细沙/砾石和漂浮糠秕？**
  * **A：** 它基于比重的双重分离原理：
    1. **重除石**：石子和沙子（>2.5 g/cm³）比浸水谷物（~1.35 g/cm³）密度大。底部漩涡水流使谷物悬浮，而砾石克服水升力下沉至底部沉积锥，被隔离于循环回路之外。
    2. **轻糠秕刮除**：空壳、草屑和虫卵（<1.0 g/cm³）附着于上升的超声微气泡，浮至水面，通过外围溢流堰连续排出至收集筛。
* **Q：在切换大米、大豆、绿豆和玉米粒时，机器是否需要硬件变更？**
  * **A：** 不需要硬件变更。URW 系列具有广泛的作物兼容性。清洗较大或较重的物品（如大豆、玉米、鹰嘴豆）时，只需在触摸屏上调整两个设置：将清洗时间增加 30–60 秒，并略微调高泵频率旋钮以增加向上提升力。超声空化也穿透豆类表面孔隙，清除种脐深处的污垢，同时激活豆细胞通透性，加速水合 15%–20%，提升豆浆和豆腐产量。

### 二、生产流程与标准操作程序（SOP）

#### 1. 原料准备与预处理
* **分拣异物**：
  * **仔细检查并移除钉子、大石头、砖块和混合在泥土中的硬质杂物！** 嵌入的石头可能卡在辊之间，导致电机停转或损坏刷毛。
  * 对于有厚厚干泥的作物（如田间红薯或木薯），预先喷水或润湿有助于软化土壤，显著加快处理速度。
* **海鲜检查**：清洗牡蛎或贝类时，提前丢弃死亡的裂壳，以防尖锐碎片卡在刷毛间。

#### 2. 启动前检查与水管连接
1. 将机器放置在水平坚固的地板上，确保所有支撑脚稳固，连接至安全、可靠接地的 **110V 或 220V 电源**。
2. 牢固连接清洁水进水管至顶部喷淋管接头，并用不锈钢管夹固定。
3. 将底部排水口导向地面排水沟或沉淀池，防止沙粒堵塞市政管道。
4. **锁紧出料门**：关闭侧向出料舱门，并检查锁扣手柄是否牢固锁紧。

#### 3. 标准清洗与去皮指南
1. **先启水后开机**：按下绿色按钮使机器空转，然后将水阀完全打开，湿润并润滑刷辊。
2. **均匀进料**：根据机器额定值，将产品均匀倒入清洗槽（型号 45：10–12 kg；型号 60：15–20 kg；型号 80：35–40 kg；型号 100：40–50 kg；切勿超过辊顶高度线）。
3. **处理时间**：
   * **清洗模式（软毛刷）**：约 **1–3 分钟**；待排水清澈后即可卸料。
   * **去皮模式（硬毛/氧化铝辊）**：约 **3–5 分钟**；待表皮均匀剥落即可卸料。
4. **自动卸料**：**在机器运行时**，将带孔收集箱置于侧槽下方，打开出料门手柄，让翻滚辊自动将产品推入。立即重新关闭并锁好门，以处理下一批次。
5. **安全警告**：**切勿在设备运行时将手、铁铲或金属杆伸入辊之间！**

#### 4. 停机、清洗与维护
* **冲洗槽体**：每次作业后，保持设备空转并喷水 2 分钟，以冲洗刷毛间的残留皮屑、泥沙或纤维。
* **沉积槽清洁**：定期打开底部清空盖，冲洗积聚的沉积物，防止细菌滋生或异味。
* **电气防水警告**：用湿布擦拭不锈钢外壳；**切勿将高压水直接喷向电机、链条驱动室或电气控制箱！**
* **链条润滑**：每月打开侧驱护罩，检查链条张力并为链轮和驱动链条涂抹食品级防水润滑脂。

  * **A：** 垂直圆柱研磨去皮机依靠高速离心旋转将产品甩向研磨衬里。这对圆形或椭圆形物品（如普通土豆和芋头）效果良好。然而，长条且脆弱的物品如莲藕、山药和木薯会在高速撞击下立即断裂，造成灾难性损失。刷辊机采用水平多辊床，物品平放并缓缓滚动在软或中等硬度的刷毛上。它能彻底清洁深部关节的顽固泥沙，而不会折断或压伤长条作物。
* **Q：软毛刷辊与硬毛刷辊有何区别？能否根据我们的加工需求互换？**

### 二、生产流程与标准操作程序（SOP）

#### 1. 原料准备与预处理
* **分拣与异物清除**：
  * **仔细检查并移除大石头、钉子、碎石、砖块和混入的硬金属杂物！** 硬质异物进入高速旋转的桶内可能击碎研磨氧化铝衬里或损坏圆盘。
  * 为获得最佳效果，每批处理大小相对均匀的蔬菜，以确保均匀接触，避免小件过度去皮。
* **湿润干燥土壤**：对于严重干结、结块的泥土（如红薯或芋头），应预先轻喷水软化土壤，加快去皮周期并保护研磨衬里。

#### 2. 启动前检查与水管连接
1. 将机器放置在平坦稳定的地面上（确保四脚平衡），并连接至正确接地的 **110V 或 220V 电源插座**。
2. 牢固连接清洁水源软管至顶部进水口喷嘴，并用管夹固定。
3. 将底部废水排水管导入地面排水沟、沟渠或沉淀池。
4. **锁紧前排料门**：确保前舱门紧密关闭，并牢固锁紧锁扣手柄，防止运行时因离心力而弹开。

#### 3. 标准去皮操作指南
1. **先启动后进料**：按下绿色按钮启动电机，然后打开水龙头让水喷淋并润滑内筒。
2. **批量进料**：将蔬菜均匀倒入桶内（**切勿超载**；建议批次容量为 CPP-350 的 10–15 kg，CPP-450 的 20–30 kg；产品水平不得超过内部填料线）。
3. **监控去皮（约 60–120 秒）**：通过顶部开口观察翻滚过程。当表皮被完全剥离且排水水清澈时，批次即准备就绪。
4. **自动离心排料**：**在电机持续运行时**，将接收箱放在出料槽下方，一手松开前门锁扣，另一手打开舱门。离心力会自动将去皮后的蔬菜在数秒内排出至箱中。一旦空置，立即关闭并锁好舱门。
5. **安全警告**：**切勿在机器运行或停止时，将手、铲子、金属杆或其他工具插入顶部桶或排料门！**

#### 4. 清洁与常规维护
* **冲洗残留物**：处理完毕后，让机器空转运行 1–2 分钟，同时喷水，以冲洗掉盘底和排水槽中残留的淀粉、皮屑或泥沙。当流出清水后关闭电源。
* **使用后清洁**：按下红色停止按钮并拔掉电源。用软刷清洁难以触及的角落和排料门，并用干净干布擦拭外部不锈钢外壳。
* **电气防潮警告**：**切勿将高压水直接喷向电机基座、通风百叶窗或防水开关盒！**
* **轴承润滑**：每 6 个月在机器下方为主驱动轴承涂抹高品质食品级轴承润滑脂，以保持安静平稳的运行。
