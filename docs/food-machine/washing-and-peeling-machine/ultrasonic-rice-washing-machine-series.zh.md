## 一、产品概述

### 1. 基本设备信息

* **产品名称**：商用全自动超声波米粮清洗机 / 多功能谷物清洗脱石机（商用全自动超声波米、玉米、大豆、绿豆清洗机）
* **产品型号**：URW-25（紧凑标准型） / URW-50（商用高效型） / URW-100（中央厨房高容量型）
* **设备类型**：垂直超声空化振动与流体浮选一体化多谷物清洗除杂机
* **市场定位**：针对商业餐食预制中心、连锁餐饮、即食餐工厂、酿酒或大豆加工企业等核心痛点进行工程优化：每日清洗大量谷物的人工成本高、传统水洗机石子泄漏率高、机械损伤导致米饭粘稠碎裂、难以去除顽固表面微尘与农药残留。

**工程与制造亮点**：

* **工业级压电式超声换能器阵列**：在罐体底部与侧壁嵌入多个高功率超声换能器（28 kHz / 40 kHz 复合声场），产生均匀密集的微空化气泡。当这些气泡破裂时，数千个微射流猛烈冲击谷物表面微孔，剥离细尘、麸皮粉、虫卵及化学残留物，而无需物理刮擦。
* **双锥旋风比重除石漏斗**：利用谷物与矿物杂质之间的密度差异（砂石密度通常为 2.5–3.0 g/cm³，浸泡后谷物约为 1.3–1.4 g/cm³），结合循环水流浮力作用。重质石块与金属碎片迅速沉入底部沉淀区，并由隔离阀锁闭，确保除石率超过 99%。
* **多孔阶梯式溢流废料槽**：配备宽大顶部溢流口与浮动废料收集篮。微气泡自然将空心谷壳、轻质外壳、植物纤维及虫残物托举至水面，通过堰口排出，实现重杂质与轻杂质的同时分离。
* **食品级 SUS304 构造与节水循环系统**：所有接触物料的表面、管道阀门及脱水篮均采用高强度钝化 SUS304 不锈钢，耐酸碱腐蚀，无卫生死角。内置过滤与循环回路可使用水量比连续自来水冲洗减少 **40%–55%**。

### 2. 核心功能与工作原理

本设备融合声化学空化、流体动力学流态化与比重分离技术：

* **快速进料与自动注水**：将袋装大米、玉米、大豆或绿豆直接倒入进料仓。微电脑控制的电磁阀自动注水至预设运行液位。
* **即时深层声学空化**：启动后，高频超声系统生成数百万个微小气泡，在谷物表面剧烈膨胀与爆裂。这种微冲击波作用可剥离顽固表面胶体、乳化残留表面糖类，并清除松散淀粉粉尘，使谷物呈现透明洁净状态。
* **三维流体化翻滚运动**：低剪切循环泵从底部切向注入水流，使谷物床呈向上向内环形流动。此流态化过程确保每颗谷物均获得均匀超声暴露，防止底部死区堆积或结块。
* **同步重质除石与浮选撇渣**：在翻滚过程中，高密度砂石穿过向上水流沉入底部锥形陷阱；轻质谷壳与泡沫则沿表面流动，经周边溢流堰排出。
* **快速排料与高效脱水**：清洗周期完成后（通常为 90–180 秒），排料门开启。清洗后的谷物连同水分流入移动脱水车或烹饪容器中。洗涤水可排水或过滤回用，排料过程仅需数秒完成。

### 3. 核心价值：为何选择本设备？

* **零破损损失，卓越谷物质地与出成率**：无机械螺旋或旋转打板，几乎杜绝颗粒破碎与豆类开裂。煮熟后米饭颗粒分明、饱满弹润，适合高端寿司、煲仔饭及罐头粥品。完整大豆吸水均匀，无深色种脐残渣，最大化提取蛋白用于豆奶与豆腐生产。
* **高效率与人力节省（1 台机器替代 4–6 名工人）**：全自动化定时定量运行，单名操作员即可完成上料与卸料。每 10 分钟可清洗 200–500 kg 谷物，彻底解放厨房人员免于手工清洗。
* **保障食品安全（无石、无沙、无虫）**：消除顾客投诉饭菜中夹杂砂石的问题，防止硬质矿物损坏后续研磨石、粉碎机或烹饪阀门。

## 二、生产流程与标准操作规程（SOP）

为保持清洁效率、部件密封性与电气安全，请严格遵循以下标准化操作流程：

### 1. 原料准备与预处理

* **物料兼容性**：
  * 适用于干白米、黑米、糙米、高粱、大麦、脱粒甜玉米、大豆、黑豆、红芸豆、绿豆、鹰嘴豆及类似颗粒主粮。
  * **严禁将未拆封的包装绳、大捆秸秆、金属块或异质木材投入机器！** 纤维类物质可能缠绕循环泵叶轮，必须提前筛选剔除。
* **水压验证**：确保市政或专用洁净水源压力稳定在 **0.15–0.35 MPa**，以保证快速自动注水。

### 2. 启动前检查与连接

1. 将机器放置于厨房准备区平整坚固的地面上。调平四个支脚，并接入专用 **110V 或 220V 接地插座，带漏电保护**。
2. 牢固连接洁净水源软管（1/2″ 或 3/4″ 接口）至后部水进口电磁接头。
3. 确认底部石子排出口阀与主排水阀**牢固关闭并锁定**。
4. 将顶部溢流管与底部排水管接入地面排水沟或油污/砂石拦截器。
5. 在排料滑道下方摆放一个穿孔不锈钢脱水车或托盘。

### 3. 标准操作指南

1. **通电开机**：打开控制箱主电源开关；微电脑 LCD 屏幕将亮起。
2. **设置清洗参数**：
   * **标准大米 / 寿司米**：设定清洗时间 **90–120 秒**；超声功率调至 70%–80%（避免过度剥离天然 B 族维生素）。
   * **陈年谷物 / 粗粮 / 玉米粒**：设定清洗时间 **120–180 秒**；超声功率设为 100%。
   * **大豆 / 绿豆 / 红豆**：设定清洗时间 **150–200 秒**；启用增强型流体涡流模式。
3. **注水与投料**：按下“自动注水”。当水位达到距溢流口约 5 cm 时，将原料均匀倒入罐体（不可超过最大容量线）。
4. **一键清洗**：按下“开始”。机器启动内部循环与超声阵列。谷物将在流态化状态下翻滚，泡沫与谷壳通过顶部溢流堰排出。
5. **石子冲刷（自动/手动）**：在清洗周期最后 30 秒，短暂打开底部排渣阀 3–5 秒，将积聚的沙粒冲入沉淀区。
6. **排料**：计时归零后，超声功率自动关闭。打开谷物排料锁扣（或按气动排料按钮）。清洁谷物连同余水平稳流入脱水车进行沥水。

### 4. 清洁与日常维护

* **腔体自冲洗**：每班次结束后，打开底部排水阀排尽全部水。使用低压喷枪冲洗内壁与换能器表面，清除残留淀粉或豆皮。**切勿让淀粉干燥附着于腔体底部**。
* **超声空载防护**：**绝对禁止在无水状态下运行超声功能！** 超过 10 秒的空载运行将永久损坏压电陶瓷换能器。
* **控制箱防潮提示**：可用湿布擦拭外壳；**切勿直接向触摸屏面板、通风百叶窗或电机外壳喷洒高压水**。
* **水泵检查**：每季度检查循环泵密封圈与底部进水滤网，清除细纤维积聚，确保泵头压力充足。

## 四、常见问题解答（FAQ）

* **Q：超声谷物清洗相比机械搅拌或水射流清洗的核心优势是什么？超声波会裂开米粒吗？**
  * **A：** 机械搅拌清洗依赖旋转桨叶撞击谷物，常导致破碎率高达 3%–8%。这破坏谷物结构并释放过多游离淀粉，使煮熟后米饭变得黏糊。超声清洗是一种微观物理空化过程：破裂的微气泡剥离表面灰尘与麸皮，无机械冲击，因此**几乎零破碎率**。清洗后米粒透明，胚芽完整，煮后口感蓬松有弹性，保温不易发黄。

* **Q：该设备如何分离细沙/石子与漂浮谷壳？**
  * **A：** 采用基于比重的双重分离原理：
    1. **重质除石**：石子与沙粒（>2.5 g/cm³）密度高于浸泡谷物（~1.35 g/cm³）。底部漩涡水流使谷物悬浮，而砂石克服水升力下沉至底部锥形沉淀区，被隔离于循环回路之外。
    2. **轻质谷壳撇除**：空心外壳、草屑、虫卵（<1.0 g/cm³）附着上升的超声微泡，浮至水面，持续通过周边溢流堰进入收集筛。

* **Q：切换清洗大米、大豆、绿豆、玉米粒时，是否需要更换硬件？**
  * **A：** 无需任何硬件变更。URW 系列具备广泛的作物兼容性。清洗较大或较密的物料（如大豆、玉米、鹰嘴豆）时，只需在触摸屏上调两个参数：将清洗时间增加 30–60 秒，并略微调高泵频率旋钮以增强向上推力。超声空化还可深入豆类表面孔隙，清除种脐深处污垢，同时激活豆细胞通透性，使后续浸泡速度提升 15%–20%，显著提高豆奶与豆腐出率。
