## III. คำถามที่พบบ่อย (คำถามยอดนิยมของชุด)

* **Q: เครื่องเหล่านี้สามารถผลิตแผ่นห่อที่มีความหนาต่างกันได้หรือไม่?**
  * **A**: ได้ ความหนาของแผ่นห่อ (ตั้งแต่ 0.3 มม. ถึง 2.0 มม.) สามารถปรับได้ง่ายโดยการเปลี่ยนความเข้มข้นของแป้ง (อัตราส่วนน้ำต่อแป้ง) และปรับความเร็วการหมุนตลับอบผ่านแผงควบคุมไมโครคอมพิวเตอร์
