## ❓ 综合常见问题解答（FAQ）

### 类别一：设备选型与烘焙工艺

* **问1：如果我的面包房既生产面包又生产蛋糕/甜点，应该购买哪台机器？**
  * **答**：如果您的核心产品是**面包、吐司或披萨**，我们强烈建议优先选择**N系列螺旋和面机**（快速面筋形成且不升温）。如果您主要生产**蛋糕、泡芙、蛋挞、馅料或轻质面糊**，**EB系列行星搅拌机**是理想选择。产量较高的商用面包房通常会各配备一台（N系列专用于面团，EB系列专用于打发奶油和蛋液）。

* **问2：N系列螺旋和面机在高含水量面团（如夏巴塔、含水量70%-80%以上的酸面团）中表现如何？**
  * **答**：表现非常出色。双动螺旋系统快速建立面筋网络以锁住水分。在高速运转（200转/分）时，能快速将水融入面粉中，非常适合高含水量或工匠面包面团。

* **问3：EB系列行星搅拌机可以揉制硬质面团（如贝果、拉面面团）吗？**
  * **答**：**不建议。** EB系列采用行星传动结构。使用和面钩持续揉制含水量低的重型硬面团会对变速箱造成较大负荷。对于硬质或重型面团，请始终选择**N系列双动螺旋和面机**。

* **问4：N系列的"双动"设计如何防止面团过热？**
  * **答**：传统搅拌机仅旋转螺旋钩，迫使面团与静止的料桶和中心柱摩擦，产生大量摩擦热，降低酵母活性。N系列采用**料桶（16转/分）与螺旋钩同步旋转**的设计。这确保了受力均匀，消除了死角，使面团温度比传统搅拌机低3-5°C。

### 类别二：操作、维护与故障排除

* **问5：为什么严禁在机器运行中换挡？**
  * **答**：商用搅拌机采用**重型机械变速箱**。在电机高速旋转时换挡会导致严重的齿轮碰撞和打齿。**正确操作流程：按下停止键 ➔ 等待旋转完全停止 ➔ 换挡 ➔ 重新启动。**

* **问6：如何清洁机器？可以用高压水枪直接冲洗整机吗？**
  * **答**：**切勿将高压水直接喷向控制面板、电气元件或电机外壳！** 接触食品的部件（不锈钢料桶、螺旋钩、打蛋器）均为304不锈钢材质，可擦拭或拆卸清洗。机身外壳及内部线路请使用湿布擦拭。

* **问7：运行中抬起安全防护罩会发生什么？**
  * **答**：两个系列均配备**微动开关安全联锁装置**。运行中抬起安全防护罩会使机器**立即停止**，以保护操作人员的手部安全。放下防护罩并按下启动键即可恢复运行。

* **问8：机器运行中突然停机怎么办？**
  * **答**：请按以下故障排查清单操作：
    1. 检查红色**急停按钮**是否被按下（如已按下，顺时针旋转复位）。
    2. 确保**安全防护罩**已完全放下到位。
    3. 检查是否缺相（适用于380V三相电源机型）或电压过低导致热过载保护跳闸。

* **问11：包装是否适合国际海运？**
