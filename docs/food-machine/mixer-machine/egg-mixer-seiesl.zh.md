## 2. 生产流程与标准操作规程（SOP）

基于实际机器调试和运行测试得出的核心操作步骤和参数指南：

### 1. 操作前检查与配件安装

* 检查电源线和接地保护，确保**110V**电源稳定。
* 根据生产需求选择合适的配件（打蛋网、搅拌桨或和面钩），将其插入搅拌轴接口，向上推并旋转锁定到位。
* 将不锈钢搅拌碗放置在托架上，升起搅拌碗并锁定固定手柄。

### 2. 原料装载与速度选择

* **原料装载**：将蛋液、奶油或面粉倒入搅拌碗中。请勿超过最大额定容量（例如EB-15最大面团3.5kg，EB-40最大8kg）。
* **速度选择**：
  * **打发蛋液/奶油**：使用打蛋网，选择**高速**（例如EB-15为390 rpm，EB-20/30为408 rpm）。
  * **搅拌面糊/馅料**：使用扁平搅拌桨，选择**中速**（例如160–180 rpm）。
  * **揉制面团**：使用和面钩，选择**低速**（例如80–110 rpm）。

### 3. 搅拌碗升降与操作

* **升降控制**：转动手轮或拉动升降杆，将搅拌碗升至最高工作位置。
* **启动设备**：关闭安全防护罩，按下启动按钮。机器将按所选速度开始运行。
* **换挡警告（关键）**：**切勿在机器高速运行时切换速度档位！** 务必先完全停止机器，等待搅拌轴完全停止转动后，调整速度杆，然后重新启动。

### 4. 监控与卸料

* 监控搅拌/打发状态。当蛋白达到湿性/干性发泡状态或面团达到适当的面筋扩展程度时，按下停止按钮。
* 降下搅拌碗托架，解锁并取下配件，移出搅拌碗进行卸料或进入下一道烘焙工序。

### 5. 紧急停止与安全功能

* 控制面板中央设有红色**紧急停止按钮**。紧急情况下按下该按钮可立即切断所有电源。顺时针旋转按钮即可复位。

## 4. 常见问题解答（FAQ）

* **问：该机器能否处理不同的蛋液或面团配方（例如高/低筋面粉、不同含水量）？**
  * **答**：完全可以。EB系列配备3速调节和三种专用配件。通过调整速度档位和更换配件，可轻松适应从高流动性蛋液和轻质面糊到高粘度面团的各种配方。
* **问：机器运行过程中可以切换速度档位吗？**
  * **答**：不可以。为保护齿轮传动系统并延长机器使用寿命，必须先停止机器。等待搅拌轴完全停止转动后再切换速度档位，然后重新启动。
* **问：奶油打发和面团揉制的容量限制是多少？**
  * **答**：各型号最大额定揉面能力分别为3.5kg（EB-15）、5kg（EB-20）、6kg（EB-30）和8kg（EB-40）。请在规定的额定容量范围内操作，以确保最佳搅拌性能并延长机器寿命。
