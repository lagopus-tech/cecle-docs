## 二、生产流程与标准操作规程（SOP）

以下是开机调试、浆料调配、蒸煮、切割及日常维护的标准操作流程：

**1. 开机前准备与检查**

* 将机器平稳放置于坚实平坦的商用操作间或后厨地面。
* 检查水管连接是否正常（用于蒸汽生成与冷却），并接入对应电压的电源。
* 检查传送带、浆料入口及切刀口内是否有干结残留物，确保工作区域清洁卫生。
* 启动加热系统预热，直至蒸汽温度达到设定生产标准。

**2. 浆料调配与自动铺展操作**

* **浆料预处理**：按标准黄金水米比，将浸泡后的米粒研磨成细腻无颗粒的米浆（或配置淀粉浆）。
* **启动设备与投料**：打开机器主传动开关，传送带开始平稳运行；开启料斗阀门，使米浆均匀流入传送带上的浆料分配器。
* **厚度调节（核心）**：通过调节浆料入口阀大小及传送带运行速度，精细调整米线片至理想厚度。

**3. 蒸煮、定型、冷却与切割**

* 米浆随传送带进入高温蒸箱，观察米线片成熟程度（完全熟透时应呈半透明且有光泽）。
* 成熟后的米线片自动进入冷却区（Cooler）迅速降温，使表面光滑。
* **自动切割**：米线片平稳送入高速切刀进料口，机器立即切割出清晰分明的河粉或冷面条。
* 在出料口下方放置周转箱或托盘，整齐收集成品。

**4. 停机清洗与日常维护**

* 生产结束后，先关闭浆料入口阀与加热系统，保持传送带运转，用清水彻底冲洗其表面残留浆料。
* 待机器冷却后，按下停止按钮并断开电源。
* **安全警告**：**停机后蒸箱内部及周围仍存有高温余热，请务必佩戴防烫手套清洁！** 严禁用水龙头直接冲洗机器内部电机与电子控制配电箱。外部不锈钢机身可用湿布擦拭干净。
