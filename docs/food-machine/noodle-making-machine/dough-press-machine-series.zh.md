## 一、产品概述

**1. 基本设备信息**

* **设备名称**：商用重型全自动面团压延与揉捏机  
* **产品型号**：PRE系列（含 **PRE-350** / **PRE-500**）  
* **型号命名解析**：
  * **PRE**：压延与滚轧设备（重型面团压延与揉捏设备）
  * **350 / 500**：代表辊筒宽度等级（PRE-350有效辊宽：330 mm；PRE-500有效辊宽：460 mm）
* **设备定位**：落地式重型设备，专为高强度、大批量面团处理而设计。广泛应用于面包烘焙、中式传统面点（蒸包、包子、千层饼）、饺子/馄饨皮面团制备及鲜面条面团压延。

**外观示例与核心技术亮点**：

* **114毫米超大实心合金辊筒**：大辊径提供柔和压延曲率与高咬合力，避免重压过程中撕裂面团内部面筋网络，快速排出气泡，形成丝滑平整的面片。
* **5–20毫米宽范围厚度调节**：配备精密调节手轮，辊距可无级调节于5毫米至20毫米之间，满足从批量揉捏到面片定型的多阶段工艺需求。
* **强化单齿轮链条传动**：彻底消除传统皮带传动在重载下常见的打滑、发热与断裂问题。3.0千瓦高扭矩通过工业合金链轮与链条直接传递，即使处理干硬面团也能保持满功率输出。

**2. 重型连续压延与面筋形成工艺**

该设备自动化实现传统手工反复折叠压延流程：

* **快速大块面团薄化**：将大块混合面团（每批10–25公斤）直接置于不锈钢进料托盘上，重型辊筒将其拉入并一次压成均匀厚片。
* **多层折叠与均质化**：将排出的面片对折后重新喂入，重复4–6次。此过程紧密排列面筋网络，彻底消除内部气孔，确保蒸制或烘烤制品具有弹韧口感与光滑不塌陷表面。

## 二、生产流程与标准操作规程（SOP）

以下是设备安装、厚度校准、面团压延及日常维护的标准操作流程：

**1. 开机前检查与准备**

* 将设备放置于水平承重地面，调整水平脚使整机完全稳定。
* 确认电源（220V或380V）已正确接地，安全防护罩与急停开关功能正常。
* 检查辊筒表面与接收托盘，确保清洁无异物。

**2. 厚度间隙校准（5–20毫米）**

* 旋转机器侧面的调节手轮，根据刻度标尺设定辊距。
* **操作提示**：初次处理大块未加工面团时，建议将间隙设为最大值（约15–20毫米）。随着面片逐渐平滑致密，逐步缩小间隙至目标厚度（5–10毫米）。

**3. 连续压延与折叠**

* 按下启动按钮，开始低速辊筒运转。
* 将准备好的面团置于进料托盘，引导前端进入辊隙。设备将自动拉入并压延成片。
* 在出料托盘接收面片，轻撒干粉，对折后重新喂入。重复3–6次，直至面片光滑、有光泽且富有弹性。

**4. 关机维护与日常保养**

* 操作完成后，按下停止按钮并断开主电源。
* 使用干刷或刮刀清除辊筒与托盘上的残留面粉与面屑，再用湿布擦拭外表面。
* **安全警告**：**切勿直接向电机外壳或电气控制箱喷水！** 定期（每月）检查传动链条，并适量涂抹食品级润滑脂。

## 四、常见问题解答（FAQ）

* **Q：如何在PRE-350与PRE-500之间进行选择？**  
  * **A**：两款机型均配备3.0千瓦电机与114毫米辊筒。主要区别在于**压延宽度**与**电压配置**：若厨房空间有限或仅具备220V单相电源，选择**PRE-350（330毫米宽，220V）**；若运营高产量食品厂或中央厨房且拥有380V三相电源，则选择**PRE-500（460毫米宽，380V）**，其更宽辊筒可处理更大面团批次，提升产出效率。

* **Q：5–20毫米间隙是否可直接用于制作极薄饺子皮或细面条？**  
  * **A**：PRE系列定位为**大块面团的重型初压与揉捏设备**（适用于5–20毫米厚面片），特别适合包子、蒸面包、扁平面团及夹层酥皮。如需制作1–2毫米超薄饺子皮或细面条，请先使用PRE机完成初步面筋发育与压延，再将面片送入下游精密设备（如BD系列或SK-080包皮机）进行最终成型与切割。

* **Q：单齿轮链条传动相比皮带传动有何优势？**  
  * **A**：重质面团压延产生巨大机械阻力，皮带传动易打滑、过热、拉伸甚至断裂。PRE系列采用工业级单齿轮链条传动，实现链轮直接啮合，100%正向动力传递，零滑移，确保多年高强度商业运行下的可靠性能。
