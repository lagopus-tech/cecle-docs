* **设备类型：** 商用旋转锅切碎机 / 差速蔬菜馅料与馅料混合机
* **市场定位：** 专为高销量饺子、包子（蒸包）、馄饨、锅贴、蛋卷餐厅、商业配餐中心、餐饮机构及需要快速大批量制备蔬菜与混合肉馅的食品加工厂设计。

**工程与制造亮点：**

* **60厘米（23英寸）重型食品级不锈钢旋转锅：** 由加厚SUS304食品级不锈钢冲压并抛光制成，具有宽大深邃的容积，防止原料飞溅或溢出。锅体稳定旋转，持续将新鲜食材送入切割区域。
* **相对运动差速旋转切割组件：** 采用高强度、食品级硬化不锈钢曲线切刀。锅体与高速刀轴之间的差速运动可实现清洁剪切而非挤压，有效保护细胞壁，保持蔬菜脆嫩口感，避免过度出水。
* **1.5 kW（2 HP）工业级高扭矩纯铜动力系统：** 内置重型工业纯铜电机，搭配精密减速齿轮组，提供持续强劲扭矩，可轻松应对密集纤维蔬菜和坚硬肉块，运行中不会出现卡顿。
* **坚固重型框架（130公斤 / 286磅）：** 采用工业铸铁内部骨架包裹抛光不锈钢外壳。高自重带来低重心，有效吸收所有机械振动，确保在任何地面上运行时都稳固、静音、无晃动。
* **卫生安全防护罩带互锁装置：** 在旋转锅与刀组上方设有重型保护盖，防止操作过程中意外手部接触，完全符合国际厨房安全与卫生标准。

### 2. 核心工作原理

本机通过同步差速相对运动实现高效作业：

* **旋转锅输送：** 将食材（如白菜叶、芹菜、洋葱、胡萝卜、预绞肉等）装入**60厘米旋转锅**中。随着锅体缓慢旋转，食材被持续引导至安全罩下方的切割区。
* **高速剪切：** 高速旋转的弧形刀片垂直于移动的锅底高速运转，每分钟数百次以优化角度精准切割食材。
* **均匀馅料成型：** 由于相对运动作用，整批食材均匀通过刀组。通常在**1–3分钟内**，即可达到所需粒度（从粗粒丁状到细碎饺子馅），且不会变成令人反感的稀烂浆糊。

## 2. 标准操作程序（SOP）与生产流程

遵循以下标准化流程，以维持最佳切碎性能、保障操作安全，并延长刀片使用寿命：

### 1. 原料准备要求

* **清洗与沥干：** 所有蔬菜需彻底清洗。使用离心脱水机（如SC系列）去除表面多余水分后再进行切碎，防止馅料过水。
* **预切过大食材：** 将整颗白菜或大型根茎类蔬菜切成四份，以便顺畅通过刀罩。
* **严格异物筛查：** 仔细检查原料，清除硬骨、石块、牙签或金属碎片，以免划伤或磨损精密刀片。

### 2. 启动前检查与安装

1. 将机器放置于平整、坚实、水平的地面上，确保四个底脚均牢固、均衡接触地面。
2. 检查电源线与插头是否完好，连接至专用的**220V 或 380V 接地插座**。
3. 降下安全护罩，确认锅体与刀组旋转自如，无干涉或异常摩擦。
4. 准备干净的食品级收集容器及塑料刮刀。

### 3. 分步切碎操作流程

1. **向锅内投料：** 将处理好的蔬菜放入60厘米不锈钢锅中（切勿超过锅口边缘）。
2. **降下安全罩并启动：** 确保安全盖完全闭合后，按下启动按钮。
3. **监控颗粒大小：** 通过安全罩观察切碎过程。每批次通常仅需**60至120秒**：
   * **较粗切法（如卷心菜卷、锅贴）：** 大约60–90秒后停止。
   * **精细馅料（如蒸包、精致饺子）：** 运行约120–180秒。
4. **停机与卸料：** 按下停止开关。待刀片与锅体完全停止后，抬起护罩，使用食品级刮刀或勺子取出成品馅料。
5. **安全规则：** **严禁在机器运行时用手、刮刀或勺子伸入旋转锅内！必须先停机再卸料。**

### 4. 清洁与日常维护

* **断电操作：** 任何清洁或维护前务必拔掉电源。
* **清洗锅体与刀组：** 用温水、温和食品级洗涤剂及软刷擦拭并冲洗不锈钢锅体、刀片及内侧安全罩，擦干即可。
* **保持电机外壳干燥：** 用微湿毛巾擦拭外层不锈钢外壳。**切勿直接向电机底部、通风百叶窗或电源开关喷射高压水！**
* **润滑保养：** 定期检查齿轮箱油位及传动轴承润滑情况，确保长期安静、耐用运行。

## 4. 常见问题解答（FAQ）

* **Q：CP-30是否会把多汁蔬菜（如白菜或中式绿叶菜）打成液体汤？**
  * **A：不会。** 与常规搅拌机或立式刀片料理机通过剧烈撞击将食材捣碎不同，CP-30利用旋转锅与锋利差速弧形刀片的相对运动，实现干净剪切而非挤压，有效保持细胞结构完整，防止馅料出水。

* **Q：这台机器能否同时混合肉和蔬菜？**
  * **A：可以。** 可将预绞肉、蔬菜、调味料和食用油一同加入旋转锅中。锅体与刀片的同步旋转可在切碎蔬菜的同时，将肉与蔬菜充分混合，形成均匀一致、可直接包制的馅料。

* **Q：60厘米不锈钢锅和刀片清洁起来困难吗？**
  * **A：非常简单。** 60厘米的大口径锅体提供开阔操作空间。机器断电后，内部可用温水和食品级清洁剂配合软刷快速清洗，再用布擦干，几分钟即可完成。
