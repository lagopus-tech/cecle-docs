## 1. 产品概述

### 1. 基本设备信息

* **产品名称：** 商用不锈钢蔬菜脱水机 / 离心式食品去油机（商用不锈钢蔬菜脱水机用于食品去油 / 离心式脱水与去油一体机）
* **型号：** **SC-20**（标准商用型号，1.8 kW / 20 kg/h） / **SC-30 (SC-40)**（大容量商用型号，3.0 kW / 40 kg/h）
* **设备类型：** 立式电动变频离心表面脱水与油炸食品去油一体化机器
* **市场定位：** 专为沙拉餐厅、中央厨房蔬果包装线、饺子/馄饨馅料备餐厨房、炸鸡与薯条店铺、花生/坚果烘烤坊、油炸蒜片生产商等设计，旨在消除多余水分、降低油脂含量，并替代耗时且占空间的自然风干方式。

**工程与制造亮点：**

* **先进变频与光电技术：** 配备现代化智能电气控制系统，支持无级变频调速与精确计时设置。低速运行适合娇嫩叶类蔬菜（防止撕裂或压伤），高速运行可高效处理根茎类硬质块状物及油炸食品，快速提取油脂。集成光电安全联锁系统，一旦开盖立即切断电源，确保操作人员绝对安全。
* **重型纯铜高功率传动系统：** 采用工业级纯铜绕组电机（SC-20达1.8 kW / 2 HP；SC-30达3.0 kW / 4 HP）。提供快速加速与强劲扭矩，即使满载也能保持平稳旋转，支持连续商业运行。
* **加厚SUS304食品级拉丝不锈钢机身与内篮：** 外壳、顶盖及旋转穿孔内篮均采用食品级不锈钢精制而成。耐蔬菜酸、哈喇油及高温蒸汽腐蚀，长期使用不生锈，内壁光滑，便于快速冲洗。
* **三点悬挂式动态减震结构：** 特设动态平衡减震弹簧与防振橡胶脚垫，专为高速离心负载设计。整机在满载高速运转时依然稳固如山，大幅降低振动与运行噪音。
* **大口径平滑排水与排油导槽：** 底部侧面设有专用不锈钢排水口，排出的水或热油即时流出，无积聚或回流现象，支持连续容器收集。

### 2. 核心工作原理

本设备基于高频驱动离心分离与重力排水原理运行：

* **投料：** 将洗净的叶类蔬菜、切丝/切丁蔬菜或刚出锅的热食放入可选食品级网袋或直接倒入穿孔不锈钢旋转篮中。
* **平稳离心加速：** 关闭顶盖并启动机器。VFD系统平稳加速至预设转速。在巨大离心力作用下，自由表面水分或热油滴瞬间被甩出，通过篮体孔洞向外飞溅至外壁。
* **排水排放与自动制动：** 排出液体沿内壁流下，经底部排水口排出。当设定运行时间结束（通常仅需 **30–90秒**），电源断开，电磁辅助制动使篮体平稳完全停止。
* **保持质地与新鲜度：** 均匀离心力确保蔬菜出料后清脆、新鲜、无压损或萎蔫。油炸食品去除多余表层油脂后，口感更酥脆，更轻盈，保质期显著延长。

### 3. 核心价值：为何选择此设备？

* **卓越效率（自然干燥从数小时缩短至数秒）：** 手工晾晒蔬菜或饺子馅料需数小时跨多张桌子完成。本机单批次处理时间 **不足一分钟**，释放宝贵厨房空间与台面面积。
* **显著提升食品品质：**
  * **蔬菜脱水：** 去除多余表面水分，防止高温爆油，改善沙拉酱附着性，避免饺子馅料过湿。
  * **食品去油：** 去除30%–50%多余表面油脂，消除油腻口感，契合健康低脂饮食趋势，同时帮助操作员回收清洁油品，降低原料成本。
* **双功能通用性与安全操作：** 清晰直观的操作界面搭配多重电气联锁，任何厨房员工均可安全便捷地操作。

## 2. 标准操作程序（SOP）与生产流程

遵循以下操作指南，以最大化脱水/去油效率，维持机械平衡，并确保安全：

### 1. 原料准备要求

* **均匀投放与动态平衡（成功关键）：**
  * 投料时，**请将原料均匀分布在篮壁四周，切勿集中堆放在一侧！**
  * 均匀分布对维持高速运转下的动态平衡至关重要，避免剧烈机身振动。
* **容量限制：** 不得将原料装至旋转篮上缘以上，留足自由离心运动空间。

### 2. 启动前检查与准备

1. 将机器放置于平整、干燥、水平且坚固的地面上，确保所有橡胶减震脚均衡接触地面。
2. 检查电源线与插头是否损坏，并连接至专用接地的 **110V 或 220V 插座**。
3. 检查内篮是否有松动部件或异物，手动旋转篮体确认无摩擦异响。
4. 在侧边排水口下方放置接液桶或耐热油箱。

### 3. 标准脱水 / 去油操作步骤指南

1. **投料并闭合盖板：** 将原料均匀放入内篮，牢固关闭安全盖板。
2. **设置定时器与转速：**
   * **叶类蔬菜脱水：** 使用低至中速，定时设置为 **30–45秒**（防止高速撕裂娇嫩叶片）。
   * **蔬菜馅料 / 切丁根茎类：** 使用中至高速，定时设置为 **45–60秒**。
   * **油炸食品去油：** 出锅后立即投入，保持高温状态，中至高速旋转 **30–60秒**（热油流动性最佳，易于提取）。
3. **启动运行：** 按下启动按钮。VFD系统平稳升速。观察排水口液体排出情况。
4. **停止与卸料：** 定时结束后，篮体在辅助制动下平稳停止。打开盖板，取出处理后的食品。
5. **安全规则：** **严禁在旋转过程中强行开启盖板或伸手进入篮内！**

### 4. 清洁与日常维护

* **班后清理：** 拔掉电源线。用清水、温和食品级洗涤剂及软刷彻底冲洗内篮（尤其去油后需用温热肥皂水清洗）。废液通过底部出口排出。
* **电气保护：** 用湿布擦拭外壳。**切勿将高压水直接喷入电机通风口、百叶窗或电控面板！**
* **例行检查：** 定期检查主轴轴承是否旋转顺畅，确认减震支架紧固，以保障持续静音运行。

## 4. 常见问题解答（FAQ）

* **Q：该设备能否同时处理蔬菜脱水和油炸食品去油，且不会造成串味污染？**
  * **A：** 完全可以。SC系列专为双用途脱水与去油设计。整机及内篮均采用优质食品级SUS304不锈钢，表面光滑致密，不吸油也不吸味。完成油炸食品去油后，仅需用温热肥皂水冲洗内篮，彻底漂洗并擦干，即可立即切换至蔬菜脱水，无异味传递。
* **Q：高速离心脱水是否会压碎或撕裂生菜、菠菜等娇嫩叶类蔬菜？**
  * **A：** 不会。设备配备精密变频控制技术。对于娇嫩绿叶，操作员可调低转速，设定约30秒周期。柔和均匀的离心力仅去除表面水珠，不损伤脆弱植物细胞壁，使蔬菜保持清脆、新鲜、完整。
* **Q：设备启动时为何有轻微震动？如何确保最大运行稳定性？**
  * **A：** 所有高速离心设备依赖良好旋转平衡。**请避免将物料集中在一侧，务必均匀分布在内篮四周。** 本机配备工业级悬挂式减震系统。只要物料分布相对均匀，设备达到高速后即可平稳、稳定、安静运行。
