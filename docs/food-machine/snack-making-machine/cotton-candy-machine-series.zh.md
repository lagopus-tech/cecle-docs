## 二、生产流程与标准操作规程（SOP）

以下是基于本系列商用棉花糖机的标准启动与拉丝操作规范：

**1. 启动前准备**

* 将机器平稳放置于坚固干燥的台面，确保底部吸盘牢固贴合。
* 检查不锈钢糖碗卡扣是否锁紧，确认旋转盘中心无异物残留。
* 连接对应电压电源（110V 或 220V），打开主电源开关。

**2. 预热与投料**

* **预热**：开启加热开关，让机器空载预热约2-3分钟，观察旋转盘运转平稳，无异常噪音。
* **定量加糖**：待机器转速稳定后，使用专用不锈钢糖勺取适量白砂糖或彩色果味糖粉（约15-20g），平稳倒入中央旋转出料口。

**3. 拉丝与塑形**

* 加糖后数秒内，细密白色糖丝将从旋转盘四周喷出。
* 手持竹签，在碗内以恒定速度顺时针或逆时针水平旋转。当糖丝完全包裹竹签后，略微倾斜竹签，缓缓向上抽出，即可制成饱满蓬松的云朵状棉花糖。
* 可分批加入不同颜色的调味糖粉，打造分层彩虹棉花糖或创意花卉造型。

**4. 关机清洁与保养**

* 工作结束后，**先关闭加热开关**。待电机仍在旋转时，向旋转头内倒入少量清水，利用离心力与余热自动冲洗并排出残余糖液。
* 待旋转头不再喷出水雾后，切断主电源，等待机器自然冷却。
* 解开卡扣，取下不锈钢糖碗，用温水清洗干净，擦干后放回主机。
* **警告：严禁将主机本体浸入水中清洗！电气底座只能用微湿布擦拭！**

## 四、常见问题解答（FAQ）

* **Q：我该如何在 TD-530 和 TD-550 之间进行选择？**  
  * **A**：若您经营的是车载摊位，频繁更换地点，且对便携性与省空间有较高要求，推荐选择**TD-530**（紧凑型，轻2kg）。若您在固定店铺、大型游乐园或人流量巨大的步行街运营，追求更高视觉冲击力与防飞糖体验，则推荐**TD-550**大碗型号。

* **Q：我能使用普通白砂糖吗？还是必须使用专用糖？**  
  * **A**：市面上常见的粗颗粒白砂糖、冰糖颗粒或专用彩色果味硬糖均可使用。粗糖加热后拉丝效果更佳，不易粘连，成本优势明显。

* **Q：如果糖出口堵塞或停止出丝怎么办？**  
  * **A**：通常因关机前未进行水洗，残留糖分碳化堵塞所致。开机预热后，缓慢滴入少量热水至旋转头中心，利用高温蒸汽自然软化糖垢以恢复流动。若严重堵塞，可拆下旋转头，放入热水中彻底浸泡清洗。
