## 2. 标准操作程序（SOP）

为保持最佳绞肉效率并延长内部部件使用寿命，请严格遵守以下操作流程：

### 2.1 食材准备与预处理

* **去骨与检查**：绞肉前务必彻底清除硬骨、软骨及厚重结缔组织。（严禁喂入硬骨或未解冻的冷冻肉，否则可能导致刀片崩裂或电机过载。）
* **预切片**：将新鲜肉类切成宽约2.5–4厘米的条状，确保能顺畅滑入进料管。如制作香肠，请提前调味肉糜，并预先浸泡肠衣。

### 2.2 组装与开机前检查

1. 确保电源线已拔下，电源开关处于 **关闭** 状态。
2. 将绞肉筒插入前壳插座，并牢固拧紧侧边锁紧螺丝。
3. 将螺旋轴滑入筒体，确保后端六角驱动销完全嵌入电机传动接口。
4. 将十字刀片安装至传动轴上，**刀刃朝外对准孔板方向**，并将绞肉板紧贴刀片安装到位。
5. 顺时针旋紧前端固定环至手拧紧状态。（切勿使用机械工具过度拧紧，以免造成刀片过早磨损。）

### 2.3 绞肉操作

* 连接匹配的电源（110V 或 220V）。
* 打开开关启动电机。让机器空转几秒，确认运转平稳且无异常噪音。
* 将预切肉条送入料斗。**必须始终使用随附的安全食品推杆**推进肉条下落。**严禁用手或餐具伸入进料口。**
* 在出料口下方放置干净容器，用于承接挤出的肉糜。

### 2.4 香肠灌肠操作

* 拆除十字刀片与绞肉板。安装香肠灌肠隔圈/法兰，并选择合适的灌肠喷嘴，然后锁紧前端环。
* 将浸泡好的肠衣套在灌肠管上，拉出一小段尾部并打结固定。
* 启动机器，将调味肉糜缓缓送入进料槽。用手引导肠衣控制灌装密度，随后扭结或绑扎成段。

### 2.5 停机、拆卸与维护

* 关闭机器并拔掉电源插头。
* 松开前端锁紧环，按顺序依次拆除压板、十字刀片、螺旋轴与绞肉筒。
* 使用温水和中性食品级洗涤剂清洗所有可拆卸接触食材部件。彻底擦干或自然晾干。
* 清洗干燥后，在十字刀片与绞肉板表面涂抹一层薄薄的食品级矿物油或食用油，防止表面氧化，存放于干燥通风处。

## 4. 常见问题解答（FAQ）

* **Q：CMG-150 的 150 kg/h 处理能力适合商用还是家用？**
  * **A**：CMG-150 是一款多功能跨界机型。其高达150 kg/h（约330 lbs/h）的输出能力，足以胜任餐厅、饺子馆、肉铺及小型农场的日间肉类准备工作。同时，其紧凑的台面尺寸也特别适合家庭用户，定期处理鹿肉、季节性香肠或宠物食品等大批量食材。

* **Q：CMG-150 能否处理带有少量软骨或筋膜的肉？是否会卡顿？**
  * **A**：搭载800W电机与170 / 220 r/min切割速度，CMG-150具备强大的剪切扭矩，可顺畅处理含少量筋膜与软结缔组织的肉类，不会发生卡顿。但请勿喂入大块硬骨或坚硬冻结块，以免损伤刀片锋利度及齿轮寿命。

* **Q：如何清洁与保养绞肉部件以防生锈？**
  * **A**：绞肉头组件（筒体、螺旋轴、十字刀片、孔板）可手动秒拆。使用温水与温和洗洁精清洗所有部件，彻底擦干。干燥后，在刀片与孔板表面涂抹一层薄薄食用油，可长期有效防止氧化。
