## 一、产品概述

### 1. 基础设备信息

* **产品名称**：商用自动汉堡压饼机 肉饼成型机
* **型号**：MPS-30L
* **设备类型**：垂直连续式商用/工业自动肉饼分量成型机
* **市场定位**：专为解决常见加工难题而设计，如手工肉饼尺寸不规则、肉粘模严重、成型速度慢、高峰需求时供料不足等。广泛应用于西式快餐预处理中心、合同式冷冻汉堡制造厂、牛排与鸡排加工车间、大型餐饮连锁体系及现代化中央厨房。

**工艺与工程亮点**：

* **食品级304不锈钢结构**：整机外壳、料斗、传动系统及所有与物料接触表面均采用厚壁食品级不锈钢，焊接无缝，耐腐蚀、防锈，可轻松应对日常酸碱清洁与冲洗，符合国际严格食品安全标准。
* **耐磨聚合物成型模具 + 气动脱模**：模具经精密加工，采用高密度耐磨食品级复合板材，并配备**6 Bar高精度气动脱模系统**，确保压制牢固、脱模干净，杜绝粘模、边角撕裂或毛边现象。
* **30L深料斗 + 集成输送带**：配置超大30L不锈钢料斗，保障持续供料；成型后的肉饼平稳落入一条**130 mm宽食品级不锈钢网带**上，可无缝对接下游裹粉机、面包糠机、连续油炸机或速冻隧道。

### 2. 核心工作原理与功能模块

机器通过精密齿轮电机与电控气动逻辑协同运行，完成连续标准化成型循环：

* **自动化物料进料**：将调配均匀的牛肉、鸡肉或蔬菜混合物倒入30L不锈钢料斗，内部桨叶搅拌器持续向下推送，确保下料腔内无空气空洞。
* **往复式模具压缩**：高精度模具滑块来回运动，在封闭腔体内对肉料进行强力压实，保证每块肉饼密度一致，重量偏差极小。
* **气动脱模与输送转移**：当模具到达出料位时，释放瞬时压缩空气脉冲，将肉饼平稳推出至网带，实现全程无手操作。
* **广泛原料兼容性**：适用于细碎或粗碎牛肉、绞猪肉、混合香肠肉馅，也兼容乳化鸡肉泥（nuggets/tenders）、鱼虾糜、土豆泥饼、南瓜饼及植物蛋白配方（如Beyond Meat风格汉堡基底）。

### 3. 核心价值：为何选择此设备？

* **高产能输出（替代6–8名人工）**：稳定产出达每分钟35个（2,100个/小时），快速满足大批量订单需求，显著降低厨房人力成本与培训支出。
* **灵活直径与厚度控制**：模具直径可定制范围为**28至120 mm**（圆形、方形、椭圆或自定义形状），厚度可在**8至20 mm间无级调节**，轻松切换迷你滑道饼、经典餐厅汉堡或厚切 gourmet 牛排汉堡。
* **统一形态与保水性能**：均衡机械压力防止肉饼变形、过度收缩或在煎烤过程中破裂，保持内部多汁口感与整洁商业外观。

## 二、生产流程与标准操作程序（SOP）

为确保成型质量稳定并延长内部气缸与模具使用寿命，请严格遵守以下操作流程：

### 1. 原料准备与预处理

* **混合物质地与温度**：肉馅需充分混合并冷藏处理；**推荐工作温度为-2°C至4°C**。略带冰晶的微冷肉馅能获得最清晰的边缘与最低粘模率。
* **杜绝硬质异物**：**严禁将骨屑、硬软骨碎片、坚硬冻块或金属紧固件投入料斗！** 硬物会划伤精密模具表面或损坏机械进料机构。
* **气源要求**：确保作业区供应洁净干燥的压缩空气，压力稳定在**6 Bar**，管路连接牢固可靠。

### 2. 启动前检查与安全确认

1. 将设备放置于水平坚固地面，调整防滑减震脚使其平衡。
2. 检查电源是否正确接地（支持110V/220V/380V可选），确认气路已升压至6 Bar工作阈值。
3. 检查模具固定装置、网带张力及刮刀是否安装到位且锁紧。
4. 进行空载试运行15–30秒，验证模具往复动作顺畅、脱模时机准确、输送带运转正常，无异常摩擦声。

### 3. 标准化肉饼成型操作指南

1. 打开主气阀，开启控制面板电源，启动自动循环。
2. 将预处理好的肉馅加入30L料斗（保持料位高于1/3容量，以维持稳定的下压头压力）。
3. 检查前几块成品肉饼的形状与厚度；根据重量要求，微调厚度调节滑块（可在8–20 mm范围内调节）。
4. 成型肉饼连续从输送带输出后，可将其收集至转运托盘，直接导入自动裹粉/裹面包糠线，或用蜡纸间隔叠放用于包装。
5. **安全红线**：**运行期间严禁将手、手指或刚性工具伸入料斗底部或模具往复路径！** 如遇喂料问题或堵塞，立即按下急停按钮，切断电源，泄放气压后再清理。

### 4. 下班后清洁与维护

* **上锁挂牌安全**：任何清洁或维护前，**务必关闭主电源开关，拔掉电源插头，并排放气动管路压力**。
* **部件拆卸与清洗**：松开料斗快拆螺栓，取下30L料斗、搅拌桨、成型模具组件及输送滴盘。使用温水与中性食品级洗涤剂清洗，清除残留油脂与肉渣。
* **电气防护**：避免高压水流直接喷向控制面板、电气箱接缝或电机通风口。
* **干燥与润滑**：清洗后，用干净无绒布彻底擦干所有金属部件，并**在气缸导轨与滑动模具表面涂抹一层薄薄的食品级白矿物油或植物油**，防止氧化，确保下次开机运行顺畅。

## 四、常见问题解答（FAQ）

* **Q：肉饼大小和形状可以定制吗？能否生产鸡块或方形肉饼？**
  * **A**：可以。肉饼的形状与尺寸完全由可更换模具决定。本机支持直径28至120 mm的定制模具，包括标准圆形、方形、圆角矩形、椭圆形、三角形鸡块，以及各类创意定制造型。通过快拆卡扣，整个模具滑块可在5至10分钟内完成更换。
* **Q：高速压缩时肉饼是否会粘在模具腔内？**
  * **A**：不会。设备采用食品级防粘聚合物模具材料，并配合同步6 Bar气动吹脱系统。当模具精准对准出料位时，定时释放空气脉冲，将肉饼干净地推至网带，边缘光滑无撕裂或变形。
* **Q：需要外接空压机吗？气源有哪些要求？**
  * **A**：是的，脱模动作依赖气动系统，必须连接商用空压机，确保持续提供不低于6 Bar的工作压力。建议在进气口安装带有水分分离功能的空气过滤器-调压器-润滑器（FRL单元），以供给洁净干燥空气，延长阀门与气缸寿命。
