## I. ภาพรวมผลิตภัณฑ์

* **หมวดหมู่**: เครื่องจักรการเกษตร / เครื่องเก็บเกี่ยวขนาดเล็ก / อุปกรณ์เก็บเกี่ยวพืชผลเบา
* **การใช้งาน**: ใช้กันอย่างแพร่หลายในพื้นที่นาข้าวแบบขั้นบันได ภูเขา ที่ดินเล็กไม่เป็นระเบียบ ไร่องุ่น และแปลงนาอ่อนนุ่มที่รถเก็บเกี่ยวขนาดใหญ่เข้าไม่ถึง
* **หน้าที่หลัก**: ใช้การตัดที่มีประสิทธิภาพและระบบนำทางกลไก ตัดพืชผลแล้ววางเรียงรายขนานอย่างเป็นระเบียบบนพื้นดิน ช่วยให้การอบแห้งและการเก็บเกี่ยวต่อไปทำได้ง่ายขึ้น

## II. ข้อได้เปรียบหลัก

1. **การวางพืชผลเรียงขนานอย่างเป็นระเบียบ**: หลังจากตัดพืชผลแล้ว ไม่ได้กองไว้แบบสุ่ม แต่จะวางเรียงราบเรียบบนพื้นดิน โดยหัวข้าวหรือหัวสาลี่หันไปทางเดียวกัน ช่วยให้อากาศถ่ายเทดีขึ้น ทำให้การอบแห้งง่ายขึ้น การผูกเก็บหรือการปลูกเมล็ดออกง่ายขึ้น และลดการหลุดร่วงของเมล็ดได้อย่างมาก
2. **ขนาดกะทัดรัด น้ำหนักเบา และคล่องตัว**: มีน้ำหนักเบาและรัศมีหมุนเล็กมาก ทำให้ทำงานได้อย่างยืดหยุ่น ซึ่งเหมาะอย่างยิ่งกับพื้นที่ขั้นบันได ภูเขา พื้นที่เล็กไม่เป็นระเบียบ และแปลงนาอ่อนนุ่ม
3. **คุ้มค่าต้นทุนสูง ใช้เชื้อเพลิงต่ำ**: เมื่อเทียบกับรถเก็บเกี่ยวขนาดใหญ่ที่มีราคาหลายแสน ตัวเครื่องนี้มีราคาประหยัด (ตั้งแต่ร้อยถึงพันดอลลาร์สหรัฐ) มีการใช้เชื้อเพลิงต่ำมาก ใช้เครื่องยนต์แก๊สโซลีน/ดีเซลขนาดเล็ก บำรุงรักษาง่าย อะไหล่ทั่วไปใช้ได้ทั่วโลก
4. **ความหลากหลายของพืชผล**: ไม่เพียงแค่เก็บเกี่ยวข้าว แต่ยังใช้ได้กับถั่วเหลือง ฟางหญ้า งา ต้นหญ้า พริกไทย น้ำมันมะกอก และสมุนไพร/สะระแหน่
5. **ประสิทธิภาพการทำงานสูง**: เครื่องเดียวสามารถดำเนินการได้ 2–4 หมู่ต่อชั่วโมง ซึ่งเทียบเท่าแรงงานคน 15–20 คน ช่วยลดระยะเวลาเก็บเกี่ยวในช่วงฤดูเก็บเกี่ยวอย่างมาก
6. **ปรับความสูงของเศษพืชได้**: ใบมีดทำงานได้อย่างราบรื่นใกล้พื้นดิน สามารถปรับความสูงของเศษพืชตามลักษณะพืชผลและข้อกำหนดทางการเกษตรโดยไม่ติดขัดหรือเสียหายต่อระบบราก

## III. กระบวนการปฏิบัติงาน

1. **ตรวจสอบก่อนใช้งาน**: ตรวจสอบว่าการต่อประกอบทุกส่วนแน่นหนา ระดับเชื้อเพลิงและน้ำมันเพียงพอ และใบมีดและส่วนส่งกำลังปราศจากเศษพืช
2. **เปิดเครื่อง**: เปิดเครื่องยนต์แก๊สโซลีนหรือดีเซล ให้ทำงานที่ความเร็วต่ำเป็นเวลาไม่กี่นาที เพื่อให้มั่นใจว่ากำลังไฟคงที่
3. **ปรับความสูงของเศษพืช**: ปรับความสูงของเศษพืชให้เหมาะสมตามลักษณะพืชผลและสภาพแปลง
4. **เริ่มเก็บเกี่ยว**: ขับหรือควบคุมเครื่องเข้าสู่แปลงอย่างราบรื่น ข้าวหรือพืชผลที่ถูกตัดจะถูกปล่อยออกด้านข้างอย่างเป็นระเบียบผ่านอุปกรณ์วางเรียง
5. **ปิดเครื่องและทำความสะอาด**: ตัดพลังงานหลังใช้งาน ทำความสะอาดเศษข้าวที่ติดอยู่บนแผ่นใบมีดและส่วนส่งกำลัง พร้อมดูแลรักษาตามปกติ
