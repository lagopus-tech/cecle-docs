## 一、产品概述

* **类别**：农业机械 / 小型收割机 / 轻型作物收获设备  
* **应用领域**：广泛适用于梯田、丘陵山区、小块不规则地块、果园及软泥稻田等大型联合收割机无法进入的区域。  
* **核心功能**：通过高效的切割与机械导引系统，将作物整齐地侧向铺放于地面，便于后续晾晒和收集。

## 二、核心优势

1. **整齐侧铺**：作物收割后不会杂乱堆积，而是整齐平铺于地面，稻穗/麦穗方向一致。有利于通风干燥，方便后续人工捆扎或脱粒，显著减少落粒损失。
2. **紧凑轻便、灵活机动**：整机重量轻，转弯半径极小，操作极为灵活，特别适合梯田、丘陵地带、小块不规则地块及松软稻田作业。
3. **高性价比、低油耗**：相比动辄数万元的大型联合收割机，本款小型收割机价格亲民（数百至千余美元），配备小型汽油/柴油发动机，燃油消耗极低，维护简单，通用配件易得。
4. **多作物适用性**：不仅可收割水稻/稻谷，还可广泛用于大豆、苜蓿/饲草、芝麻、芦苇、辣椒、油菜籽以及中药材/薄荷等多种作物。
5. **高效作业能力**：单台机器每小时可收割2至4亩，效率相当于15至20名熟练人工，大幅缩短集中收获期。
6. **可调留茬高度**：割刀运行平稳贴近地面，可根据作物特性与农艺要求灵活调节留茬高度，避免堵塞或损伤根系。

## 三、操作流程

1. **开机前检查**：确认各部件连接牢固，燃油与机油量充足，割刀及传动部位无杂物。
2. **启动发动机**：启动汽油或柴油发动机，空载运转几分钟以确保动力输出稳定。
3. **调整留茬高度**：根据具体作物特性和田间状况，设定合适的留茬高度。
4. **开始收割**：平稳驶入或引导机器进入田间，被切割的作物将通过铺放装置整齐地侧向排放在地面。
5. **停机与清理**：作业结束后断电，清除割台及传动部件上的残留秸秆，并进行日常保养。
