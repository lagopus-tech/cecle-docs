## III. Operation Workflow
1.  **Fuel & Oil Check**: Inspect the fuel tank and engine oil levels before starting, ensuring proper 2-stroke or 4-stroke mixture/lubrication according to engine specifications.
2.  **Bit Installation**: Select the appropriate drill bit diameter, align it with the output shaft, and secure it firmly with the locking pin.
3.  **Engine Startup**: Set the choke, prime the fuel bulb, and pull the recoil starter cord firmly to start the engine. Let it idle for a short warm-up.
4.  **Drilling Operation**: Hold the dual handles firmly, position the drill tip vertically at the target spot, throttle up, and apply steady downward pressure as the auger penetrates the soil.
5.  **Clearing Soil & Shut Down**: Periodically lift the auger slightly during deep drilling to clear loose earth. Upon completion, idle down, turn off the engine, and clean soil debris from the drill bit.

### FAQ
**Q: What is the difference between 2-stroke and 4-stroke engine options?**
A: 2-stroke engines require mixed fuel (gasoline and 2-stroke oil) and offer a high power-to-weight ratio. 4-stroke engines use separate gasoline and engine oil, running cleaner and quieter with easier maintenance.

**Q: Can I change different sizes of drill bits on the same machine?**
A: Yes! The machine supports multiple bit diameters (ranging from 100mm to 300mm), allowing one machine to handle various hole sizes effortlessly.

**Q: How deep can this earth auger drill?**
A: The standard drill bit reaches up to 800mm. For deeper holes, extension rods can be attached.
