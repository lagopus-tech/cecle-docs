## III. Flujo de Operación
1. **Encendido y Calibración**: Presione el botón de encendido en la pantalla, permita que el sistema se inicialice a cero y asegúrese de que esté en modo de pesaje en espera.
2. **Carga**: Inserte suavemente las horquillas en la base del palé y use el sistema hidráulico para elevar la carga del suelo.
3. **Lectura Instantánea**: Una vez que el valor se estabilice, la pantalla mostrará el peso neto de la mercancía. Si es necesario, use la función "Tara" para restar el peso del palé.
4. **Transporte**: Mueva la carga de manera segura al área designada de almacenamiento o carga.
5. **Registro y Descarga**: Después de confirmar que el peso es exacto, baje lentamente la carga usando la válvula de liberación del manubrio para colocar el palé de forma segura.
