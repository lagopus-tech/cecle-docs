## 三、操作流程
1. **检查**：检查货叉外部及液压系统是否有异常，并确认制动状态正常。
2. **插入与对位**：将货叉平稳推入托盘插孔，确保货物居中放置。
3. **手动起升**：将操纵杆手柄置于起升位置，反复摇动手柄，直至货物完全离地。
4. **搬运**：握紧操纵杆，在平坦路面上以匀速平稳地拉动或推动搬运车。
5. **下降卸货**：到达目的地后，轻轻提起操纵杆上的释放扳手，使货叉缓慢下降，直至托盘平稳落地。
