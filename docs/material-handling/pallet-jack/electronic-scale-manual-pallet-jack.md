## III. Operation Workflow
1. **Power On & Calibration**: Press the power button on the display, allow the system to initialize to zero, and ensure it is in standby weighing mode.
2. **Loading**: Smoothly insert the forks into the pallet bottom and use the hydraulic system to lift the cargo off the ground.
3. **Instant Reading**: Once the value stabilizes, the screen will display the net weight of the goods. If necessary, use the "Tare" function to subtract the pallet weight.
4. **Transport**: Safely move the cargo to the designated storage or loading area.
5. **Record & Unload**: After confirming the weight is accurate, slowly lower the load using the handle release valve to set the pallet securely in place.
